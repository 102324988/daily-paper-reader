## 摘要
伪装目标检测（COD）旨在识别并分割复杂环境中的伪装目标，这些目标通常因其颜色和纹理与背景相似而被隐藏。现有的多种COD方法通过引入深度图，借助学习互补的RGB-D特征来提升检测性能，但忽略了深度域中隐蔽目标的模态特定特性。为解决这一问题，我们提出了一种深度协作网络，称为VCP-DCN，在深度域中挖掘超越视觉隐蔽原型的可区分多模态特征。具体而言，VCP-DCN针对COD任务逐步执行多模态对齐、交互和融合。在对齐阶段，我们提出了一种可分离原型嵌入（SPE）模块，通过原型对比学习来学习模态一致性和模态特定的RGB/深度原型标记。此外，我们开发了一个多模态双注意力（MDA）模块，在交互阶段通过模态一致性RGB/深度原型标记与视觉标记之间的局部响应图来增强跨模态特征表示。最后，我们设计了一个深度自适应注入（DAI）模块，在融合阶段通过决策机制自适应地衡量RGB/深度特征的贡献，该机制计算RGB/深度模态特定原型标记与模态一致性原型标记之间的相似度距离。大量实验证明了我们的VCP-DCN在三个权威数据集上的有效性。

## Abstract
Camouflaged Object Detection (COD) aims to identify and segment camouflaged objects in complex environments, which are often concealed because their color and texture are similar to the background. Several existing COD methods introduce depth maps to boost detection performance via learning complementary RGB-D features, ignoring modality-specific characteristics of concealed objects in the depth domain. To address this issue, we propose a depth collaborative network, called VCP-DCN, to mine distinguishable multi-modality features beyond visual concealed prototype in depth domain. Specifically, VCP-DCN progressively performs multi-modality alignment, interaction, and fusion for the COD task. In the \textbf{alignment} stage, we propose a Separable Prototype Embedding (SPE) module to learn modality-consistency and modality-specific RGB/depth prototype tokens through prototype contrastive learning. Furthermore, we develop a Multi-modality Dual Attention (MDA) module to enhance the cross-modal feature representation through local response maps between modality-consistency RGB/depth prototype tokens and visual tokens on the \textbf{interaction} stage. Finally, we design a Depth Adaptive Injection (DAI) module to adaptively measure contribution of RGB/depth features with a decision-making mechanism, which calculates similarity distance between RGB/depth modality-specific prototype tokens and modality-consistency ones on the \textbf{fusion} stage. Extensive experiments demonstrate the effectiveness of our VCP-DCN on three authoritative datasets.

## 二、论文提出的方法论

### 整体架构
VCP-DCN 采用端到端编码器-解码器结构，以 VMamba-S（或 Swin-S）作为共享参数的双流编码器，提取 RGB 和 Depth 的层次化金字塔特征，并嵌入所提出的**深度协作网络**进行渐进式多模态学习，最终通过三联解码器（RGB、Depth、RGB-D 三个分支）输出三张预测掩膜。

### 核心模块与关键技术

**1. 可分离原型嵌入（SPE）模块——多模态对齐阶段**
- 通过 1×1 卷积生成前景语义图，利用全局平均池化将 RGB/Depth 特征解耦为全局前景与背景原型 token。
- 通过不同的 MLP 投影，分别生成**模态一致性原型**（RGB 与 Depth 共享语义）和**模态特定原型**（各模态独有语义）。
- 引入**原型对比学习**，由三类损失函数构成对齐损失 $L_{align}$：
  - **模态一致性对比损失（$L_{MCL}$）**：拉近 RGB 与 Depth 的前景/背景一致性原型；
  - **模态特定对比损失（$L_{MSL}$）**：推远 RGB 与 Depth 的特定原型，保持模态判别力；
  - **前景-背景对比损失（$L_{RCL}$ 和 $L_{DCL}$）**：拉大同一模态内前景与背景原型的距离。

**2. 多模态双注意力（MDA）模块——多模态交互阶段**
- 利用 SPE 生成的模态一致性原型与特征图做全局到局部的 token 匹配，生成 RGB/Depth 各自的前景与背景响应掩膜。
- 构建**前景掩膜线性注意力（F-MLA）**与**背景掩膜线性注意力（B-MLA）**，通过跨模态交换前景/背景掩膜（如用 Depth 的前景掩膜引导 RGB 的注意力计算），实现 RGB 与 Depth 特征的相互增强与信息交互。

**3. 深度自适应注入（DAI）模块——多模态融合阶段**
- 首先融合 RGB/Depth 模态一致性原型得到多模态联合一致性原型 $P_{Con}$。
- 分别计算 RGB/Depth 模态特定原型与一致性原型的余弦相似度 $W_{ir}$、$W_{id}$，以此衡量各模态在当前场景中的决策贡献度。
- 利用权重进行自适应融合：一致性部分直接加权融合，特定部分经可变形卷积处理后与一致性特征拼接，动态生成融合特征，实现"按需取用"的跨模态补充。

### 损失函数
总损失 $L_{total} = \lambda \times L_{mask} + \mu \times L_{align}$，其中 $L_{mask}$ 为三联解码器预测掩膜与 GT 之间的混合损失（BCE + IoU + SSIM），$L_{align}$ 为原型对齐损失，实验中 $\lambda=0.3$，$\mu=0.1$。

## 六、论文的主要结论与发现

1. **VCP-DCN 在三个 COD 基准数据集上均达到 SOTA 性能**，显著优于同骨干（VMamba）的 Samba、同深度图来源的 DaCOD，以及基于 SAM 的 SAM-COD 等强基线方法。

3. **原型对比学习是解决多模态特征同质化的有效手段**：通过可分离原型嵌入和对齐损失，RGB 与 Depth 特征在保持模态特有判别力的同时实现语义对齐，热力图和 t-SNE 可视化直观验证了该效果。
