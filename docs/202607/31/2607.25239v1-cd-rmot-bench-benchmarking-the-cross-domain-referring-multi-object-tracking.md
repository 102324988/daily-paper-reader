## 摘要
指代多目标跟踪（RMOT）通过将物体轨迹与自然语言表达进行关联，将跟踪从类别驱动的感知扩展到语言引导的理解。尽管近期取得了进展，但现有的RMOT研究大多在域内设置下进行，忽略了语言条件跟踪在不可避免的视觉域偏移下的鲁棒性。在本文中，我们研究了跨域指代多目标跟踪（CD-RMOT），这是一个新的且具有挑战性的问题，评估在标记源域上训练的RMOT模型能否在具有不同视觉条件的无标记目标域中可靠地遵循自然语言表达。为了支持系统性研究，我们构建了CD-RMOT-Bench，这是一个统一的基准，结合了真实清晰域的指代跟踪数据、对齐的数字孪生变体以及真实恶劣域视频。CD-RMOT-Bench支持在共享RMOT协议下进行受控天气/视角偏移分析和真实的合成-真实迁移评估。此外，我们提供了查询中心适应（QCA）框架，旨在稳定连接视觉轨迹和指代表达的查询空间。大量实验表明，域偏移严重降低了RMOT性能，其中失败不仅由目标检测错误引起，更关键的是由不稳定的表达条件时间关联和目标选择引起。QCA建立了强基线，而CD-RMOT-Bench为跨视觉域的鲁棒语言引导跟踪开辟了新方向。

## Abstract
Referring multi-object tracking (RMOT) extends tracking from category-driven perception to language-guided understanding by grounding object trajectories in natural-language expressions. Despite recent progress, existing RMOT studies are largely conducted under in-domain settings, leaving the robustness of language-conditioned tracking under inevitable visual domain shifts unexplored. In this paper, we study Cross-Domain Referring Multi-Object Tracking (CD-RMOT), a new and challenging problem that evaluates whether an RMOT model trained on a labeled source domain can reliably follow natural-language expressions in an unlabeled target domain with different visual conditions. To support systematic study, we construct CD-RMOT-Bench, a unified benchmark that combines real clear-domain referring tracking data, aligned digital-twin variants, and real adverse-domain videos. CD-RMOT-Bench enables both controlled weather/viewpoint shift analysis and realistic synthetic-real transfer evaluation under a shared RMOT protocol. Further, we provide a Query-Centric Adaptation (QCA) framework, designed to stabilize the query space that bridges visual trajectories and referring expressions. Extensive experiments reveal that domain shifts severely degrade RMOT performance, where the failure is not merely caused by object detection errors but more critically by unstable expression-conditioned temporal association and target selection. QCA establishes a strong baseline, while CD-RMOT-Bench opens a new direction for robust language-guided tracking across visual domains.

### 1. 核心问题与整体含义（研究动机与背景）

多目标跟踪（MOT）正经历从被动式、基于类别的感知向主动式、语言引导理解的范式转变，即指代多目标跟踪（Referring Multi-Object Tracking, RMOT）。RMOT 根据自然语言表达同时定位并跟踪视频中的特定目标，在人机交互、具身智能、自动驾驶等领域具有广阔应用前景。

然而，**现有 RMOT 研究几乎完全局限于同域（in-domain）设置**：训练与测试视频来自同一视觉分布。在实际部署中，感知系统不可避免地遭遇视觉域偏移（domain shift）——包括极端天气变化、传感器视角改变、合成到真实的逼真度差距等。这些问题带来一个根本性质疑：**当视觉域变化时，语言引导的跟踪器是否依然可靠？**

该论文首次系统研究 **跨域指代多目标跟踪（Cross-Domain Referring Multi-Object Tracking, CD-RMOT）**，核心设定为：在带标签源域上训练的 RMOT 模型，能否在无标签目标域上可靠地遵循自然语言表达跟踪目标。该问题同时涉及**语言理解、视觉跟踪、域适应**三个维度的交叉挑战，是一个全新的、尚未被现有基准和方法覆盖的研究方向。

#### 2.2 Refer-vKITTI 基准构建流程（5 个阶段）

| 阶段 | 内容 | 关键细节 |
|------|------|----------|
| Stage 1–2 | 源标注与对齐数字孪生 | 从 Refer-KITTI-V2 提取真实域表达与轨迹；使用对齐的 Virtual KITTI 2 数字孪生场景提供受控天气/视角变体 |

#### 2.3 QCA 方法：三个互补模块

共享 RMOT 主干输出一组语言条件时序查询 Q = {q₁, …, q_N}。QCA 总目标函数：

```
L_total = L_s_rmot + λ_mt·L_mt + λ_acda·L_acda + λ_lgca·L_lgca
```

| 模块 | 全称 | 针对的失败模式 | 核心机制 |
|------|------|---------------|----------|
| **CDT-MT** | 跨域时序均值教师 | 目标查询不稳定 | EMA 教师模型（α=0.999），对可靠目标查询执行选择性一致性正则：特征 L2 距离 + 框回归 Smooth-L1 + 指代对数 Sigmoid 差异 |
| **ACDA** | 自适应课程域对抗 | 源-目标任务相关查询不匹配 | 查询级对抗对齐（带梯度反转层），任务相关性分数 cᵢ = σ(oᵢ)·σ(rᵢ)，课程权重由域不确定性、源原型距离和任务难度共同驱动 |
| **LGCA** | 语言引导连续适配 | 语言条件语义漂移 | 使用指代表达作为语义锚点：κᵢ = (1+cos(qᵢ,ℓ))/2·νᵢ，动量原型更新，残差细化 q_out = (1-αᵢ)qᵢ + αᵢq*ᵢ |

关键设计特点：ACDA 的域标签来自源/目标划分这一天然信息，**无需额外手工标注**；LGCA 将语言用作语义锚而非额外标签源。

### 6. 主要结论与发现

1. **域偏移严重损害 RMOT 性能**：仅改变目标视觉域（保持语义不变），HOTA 即从域内的 28.69 降至 16.00（clear→fog），下降超过 44%。

2. **失败根因不仅是检测错误，更是表达式条件化的时序关联与目标选择失败**：AssA 的下降幅度往往大于 DetA，说明即使检测到视觉上合理的对象，模型仍可能选择与语言表达不一致的轨迹。

3. **雾天是最困难的受控域**：在全部受控变体中，clear→fog 对 TempRMOT 的挑战最大。

4. **RVOS 方法无法直接解决 CD-RMOT**：MUTR / ReferDINO 在完全轨迹协议下远落后于原生 RMOT 方法，表明视频语言分割不能替代身份感知的多目标轨迹跟踪。

5. **QCA 在所有迁移设置下取得最优 HOTA 与 AssA**：如 clear→fog 从 16.00 提升至 21.37（+5.37 HOTA）、AssA 从 29.20 到 41.38（+12.18），且不依赖任何目标域监督标注。

6. **仍有显著提升空间**：QCA 尚低于域内参考（28.69 HOTA），说明 CD-RMOT-Bench 暴露的是一个远未饱和的问题空间。

### 7. 优点

- **填补空白**：首次系统定义并评估跨域 RMOT 问题，弥补了 RMOT 研究欠缺域偏移鲁棒性评估的空白
- **基准设计巧妙**：通过"逐场景身份映射 + 表达迁移 + 残差质量控制"将真实表达迁移到对齐数字孪生，实现"语义相同、仅视觉域变化"的受控实验，逻辑严谨
- **双轴评估架构**：受控域偏移（因果清晰）+ 真实跨域迁移（部署逼真）互补，避免纯合成或混合场景各自的局限
- **诊断性指标分解**：通过 DetA/AssA 分解揭示"关联失败比检测失败更关键"的深层洞见，而非停留在单一 HOTA 指标
- **QCA 设计精妙**：三个模块分别对应三个失败模式（查询不稳定、源-目标不匹配、语言语义漂移），理论与诊断高度一致；ACDA 利用天然域标签省去额外标注成本
- **消融实验完整覆盖**：7 种模块组合的消融清晰地展示每个组件的独立价值和协同效应
- **协议严谨**：明确区分"任务输入"与"监督标签"，目标域标注仅用于评估，坚守 UDA 边界

### 8. 不足与局限

- **受控核心规模有限**：Refer-vKITTI 仅基于 5 条具备对齐 vKITTI 对应关系的 Refer-KITTI-V2 序列，场景多样性可能不足（尽管扩展到 50 个视频）
- **身份映射依赖合成数据质量**：KITTI→vKITTI 的对齐质量直接影响标注迁移保真度；边界案例依赖人工 QC，存在一定的标注主观性风险
- **真实域跨度有限**：Refer-BDD 虽提供真实恶劣域锚点，但与 Refer-vKITTI 并非对齐关系，难以精确归因性能差异的来源
- **基线的覆盖范围**：未涵盖更新方法（如 iKUN、DeepRMOT、DKGTrack 等近期 RMOT 方法）；RVOS 基线以伪掩码适配、并非原生 RMOT，比较的公平性有限
- **仅依赖单一主干**：QCA 的实验验证主要基于 TempRMOT 主干，在 TransRMOT/MGLT 等其他主干上的泛化性未验证
- **缺少计算效率信息**：未报告运行时间、模型参数量、内存占用等实际部署相关指标
- **应用范围限制**：基准聚焦于驾驶场景（KITTI/BDD），对无人机、室内、监控等其他 RMOT 场景的适用性有待验证
- **无显著性检验**：论文未报告方差或统计显著性，单次运行的结果可能低估模型稳定性差异的影响
- **语言表达模式有限**：表达较短（平均 6.3–7.26 词/句），未覆盖

**语言表达模式有限**：表达较短（平均 6.3–7.26 词/句），未覆盖长句、嵌套从句、时序指代（如"后来出现的行人"）及模糊数量表达（如"左侧那两辆车"）等复杂语言结构；且表达源自 Refer-KITTI，语言风格受限于驾驶场景，跨场景语言泛化能力（如指代消解、空间推理）尚未验证。

### 9. 未来研究方向（由本文延伸的开放问题）

1. **更复杂的语言与域覆盖**：引入长句、时序与空间混合指代、跨句指代等表达类型，探索语言结构复杂度对跨域跟踪的影响。

2. **从离线 UDA 走向在线/测试时适配**：当前 QCA 依赖完整目标域视频集合的离线训练；在真实部署中，可探索基于单条视频流的在线适配（test-time adaptation），进一步贴近交互式应用需求。

3. **语言条件关联模块的专项设计**：既然 AssA 是主要失败维度，未来应设计显式的、语言引导的时序关联机制（如可学习的表达-轨迹匹配记忆库），而非仅依赖查询一致性正则。

4. **利用大规模预训练视觉-语言模型作为主干**：引入 CLIP 类模型的零样本语义知识作为先验，可能减少语言语义在域迁移中的漂移程度，并提升对未见表达的泛化。

5. **更丰富的域类型与模拟器组合**：加入低光照、雨夜、雪天、车道偏移、多相机视角等更多变体；并探索不同模拟器（CARLA、BDD-X 等）之间的跨模拟器迁移。

6. **自动化标注迁移管道**：减少人工 QC 依赖，探索基于视觉-语言基础模型（如 GPT-4V）的自动标注验证，以规模化方式构建更大范围的多域 RMOT 基准。

### 10. 整体评价与贡献定位

该论文以"问题定义 → 基准构建 → 诊断分析 → 算法设计"的完整闭环，完成了跨域指代多目标跟踪（CD-RMOT）这一全新方向的开创性研究。其核心贡献不仅在于提出了 QCA 这一有效的方法框架，更在于通过精心设计的可解释基准与诊断性指标分解，**首次系统揭示了域偏移对 RMOT 的深层影响机制**——即语言引导的时序关联失败比单纯检测失败更为致命。这一洞见改变了研究者对 RMOT 鲁棒性问题的理解方式，为后续工作指明了结构化的改进方向。

就基准而言，CD-RMOT-Bench 的"受控数字孪生 + 真实跨域锚点"双轴架构，兼具内部效度（因果清晰）与外部效度（部署逼真），具备成为该方向标准评测基准的潜力。就方法而言，QCA 的三个模块与三类诊断性失败模式一一对应，展示了从问题分析到方案设计的严谨映射，且其全流程无需目标域监督标注，具有实际部署可行性。

尽管受控场景规模有限、主干泛化性未验证、且 QCA 距离域内上界仍有差距，但这些限制恰恰说明 CD-RMOT 是一个远未饱和的研究问题，而非一个已解决的工程任务。总体而言，该论文在问题设定、评测资源与诊断深度三个层面均达到了该领域的高水准，对多目标跟踪、域适应与视觉-语言理解三个交叉领域均具有明确的推动作用，是一篇兼具理论启发与工程参考价值的系统性研究。
