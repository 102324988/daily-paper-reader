## 摘要
视觉语言模型通常将预训练视觉编码器产生的所有令牌直接输入大型语言模型。然而，最终层的特征可能会丢弃文本、局部属性和空间关系，而高分辨率输入则大幅增加上下文长度和推理延迟。我们提出MAViE，一种多尺度自适应视觉编码器。MAViE使用位置相关的门控融合视觉Transformer的浅层、中层和深层特征，在保留全局语义的同时增强边缘、文本和局部结构。然后，它根据问题相关性、局部信息含量、全局语义和空间覆盖进行基于问题条件的令牌路由，并采用自适应图像复杂度的令牌预算。为缓解压缩损失，我们进一步引入了全量到压缩的表示蒸馏和空间多样性正则化。在统一的7B语言模型框架下的模拟实验中，MAViE将平均SigLIP-SO400M视觉令牌数从729减少到146（约80.0%），并在VQAv2、GQA、TextVQA、ScienceQA-IMG和MMBench上平均得分提升2.2个百分点，同时将单图像首令牌时间从228毫秒降至129毫秒。我们提供了完整的模型设计和评估协议。所有报告的数值目前仅作为论文组织和实验设计的占位符；正式结论需要实际训练运行、独立复现和官方基准评估。

## Abstract
Vision-language models commonly project all tokens produced by a pretrained vision encoder into a large language model. However, final-layer features can discard text, local attributes, and spatial relationships, while high-resolution inputs substantially increase context length and inference latency. We introduce \method, a Multi-scale Adaptive Vision Encoder. \method uses position-dependent gates to fuse shallow, intermediate, and deep features from a vision Transformer, preserving global semantics while enhancing edges, text, and local structure. It then performs question-conditioned token routing according to question relevance, local information content, global semantics, and spatial coverage, with a token budget that adapts to image complexity. To mitigate compression loss, we further introduce full-to-compressed representation distillation and a spatial diversity regularizer. In an illustrative simulation under a unified 7B language-model framework, \method reduces the average number of SigLIP-SO400M visual tokens from 729 to 146 (approximately 80.0\%) and improves the mean score on VQAv2, GQA, TextVQA, ScienceQA-IMG, and MMBench by 2.2 percentage points, while reducing single-image time to first token from 228\,ms to 129\,ms. We provide the full model design and evaluation protocol. All reported numbers currently serve only as placeholders for paper organization and experimental design; formal claims require real training runs, independent replications, and official benchmark evaluation.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：视觉语言模型（VLM）通常使用预训练的 ViT 编码器（如 CLIP、SigLIP、DINOv2），但存在两个关键问题：
  - 仅使用最后一层特征会丢失浅层的边缘、纹理、字符笔画等局部细节，从而削弱 OCR、计数和局部属性识别能力。
  - 提高输入分辨率能改善细粒度感知，但会使视觉令牌数量成倍增加（224²→448² 约 4 倍），显著增加上下文长度和推理延迟。
- **核心挑战**：如何在不牺牲细粒度感知的前提下，大幅压缩视觉令牌数量以提升效率。
- **整体含义**：MAViE 通过多尺度特征融合和问题动态路由，在保留全局语义与局部细节的同时实现约 80% 的令牌压缩，有望在保持甚至提升任务性能的同时降低推理成本和延迟。

## 2. 论文提出的方法论

### 2.1 核心思想
构建一个多尺度自适应视觉编码器，包括两个主要模块：**层级多级融合（HMF）** 和 **问题条件自适应令牌路由（QATR）**，并辅以蒸馏和正则化损失。

### 2.2 关键技术细节

1. **层级多级融合（HMF）**
   - 从 SigLIP ViT 的第 8、16、24 层分别提取浅层、中层、深层特征（维度对齐）。
   - 对浅层和中层特征使用深度可分离卷积引入局部偏置。
   - **位置相关门控**：每个空间位置独立预测三层的融合权重（softmax），加权求和后以残差方式加到深层特征上（初始残差缩放因子 γ=0.1），防止早期噪声干扰深层语义。
   - **高频率区域增强**：针对局部变化幅度大的令牌（如文本、边界），在局部窗口内执行自注意力，增强细节。

2. **问题条件自适应令牌路由（QATR）**
   - 通过注意力池化从语言模型的 token embedding 中提取问题表示 q。
   - 为每个视觉令牌计算四个分数：问题相关性（cosine）、局部信息含量（归一化局部变化幅度）、全局语义（与全局平均特征的 cosine）、空间覆盖（与已选令牌的最小距离）。
   - 默认权重 λ=(0.45, 0.20, 0.15, 0.20)，后三项在顺序选择过程中动态更新。
   - **动态令牌预算**：基于局部变化统计、视觉注意力熵和问题范数计算复杂度得分 c，映射到 [72, 288] 的整数预算（8 的倍数）。
   - **回收未选令牌**：将未选令牌通过可学习上下文查询聚合为 8 个上下文令牌，保留背景和布局信息。

3. **训练目标**
   - 总损失 L = LLM + α L_align + β L_distill + η L_div。
   - LLM：标准自回归交叉熵。
   - L_align：批次内 sigmoid 对齐损失（匹配图像‑文本对为正例）。
   - L_distill：全量表征（所有令牌）与压缩表征（路由后令牌）之间的 cosine 和 L2 蒸馏损失。
   - L_div：已选令牌的空间多样性正则化（基于高斯核的指数惩罚近距离令牌）。

### 2.3 算法流程简述
图像→SigLIP ViT→提取三层特征→HMF 融合增强→QATR 根据问题选择 K 个令牌 + 生成 8 个上下文令牌→MLP 投影→LLM 自回归生成答案。
