## 摘要
开放词汇语义分割（OVSS）利用文本语义对超出预定义类别的对象进行分割。虽然自监督模型DINOv3提供了强大的结构化视觉表示，但其缺乏原生文本对齐能力，阻碍了其直接应用于OVSS。为了弥合这一差距，我们提出了DINOde，一个基于ODE的框架，它连续地将CLIP文本嵌入与DINO视觉流形对齐。我们的方法包含两个互补组件：(i) 语义文本流（STF），通过连续的ODE轨迹将文本嵌入演化为DINO流形；(ii) 全局上下文流（GCF），逐步优化由DINO的CLS标记承载的整体图像表示。为了在此演化过程中保持特征空间的超球面几何结构，我们进一步引入了速度切向投影，将学习到的速度场约束在切空间内。通过将对齐建模为连续轨迹，DINOde避免了离散MLP投影固有的流形纠缠，并产生了更稳健的跨模态对齐。大量实验表明，DINOde持续优于现有方法，并在多个OVSS基准上取得了最先进的性能。代码可在https://github.com/yoon307/DINOde获取。

## Abstract
Open-vocabulary semantic segmentation (OVSS) leverages textual semantics to segment objects beyond predefined categories. While the self-supervised model DINOv3 provides strong structured visual representations, its lack of native textual alignment hinders its direct application to OVSS. To bridge this gap, we propose DINOde, an ODE-based framework that continuously aligns CLIP text embeddings with the DINO visual manifold. Our approach employs two complementary components: (i) Semantic Text Flow (STF), which evolves text embeddings toward the DINO manifold through a continuous ODE trajectory, and (ii) Global Context Flow (GCF), which progressively refines the holistic image representation carried by DINO's CLS token. To preserve the hyperspherical geometry of the feature space during this evolution, we further introduce Velocity Tangent Projection, which constrains the learned velocity field to the tangent space. By modeling alignment as a continuous trajectory, DINOde avoids the manifold entanglement inherent in discrete MLP projections and yields more robust cross-modal alignment. Extensive experiments demonstrate that DINOde consistently outperforms existing methods and achieves state-of-the-art performance across multiple OVSS benchmarks. The code is available at https://github.com/yoon307/DINOde.

- **核心问题**：开放词汇语义分割（Open-Vocabulary Semantic Segmentation, OVSS）需要将文本语义与视觉表示对齐，以分割未见过的类别。现有主流方法依赖 CLIP 等视觉-语言模型，但 CLIP 的视觉编码器为全局图像-文本对齐优化，缺乏密集预测所需的精细空间定位能力。
- **动机**：自监督视觉 Transformer（如 DINOv3）具有出色的物体中心化定位能力和细粒度空间结构，但其表示空间与文本语义不对齐，无法直接用于 OVSS。已有的对齐方法（如 MLP 投影）采用离散单步映射，忽略了特征空间的弯曲几何，导致流形纠缠（manifold entanglement），语义关系被扭曲。
- **整体含义**：本文提出一种基于常微分方程（ODE）的连续对齐框架 DINOde，将 CLIP 文本嵌入逐步、平滑地演化到 DINOv3 视觉流形上，同时保持特征空间的超球面几何，从而实现更鲁棒的跨模态对齐，在多个基准上达到最先进性能。

## 2. 论文提出的方法论

### 2.1 核心思想
- **连续轨迹建模**：将对齐视为一个从 CLIP 文本空间到 DINO 视觉空间的连续动态过程，通过神经 ODE 学习一个平滑的变换轨迹，避免离散投影带来的结构破坏。
- **双流设计**：分别处理文本嵌入和全局图像表示。
  - **语义文本流（Semantic Text Flow, STF）**：将 CLIP 文本嵌入通过 ODE 逐步映射到 DINO 的 pooled patch 特征空间。
  - **全局上下文流（Global Context Flow, GCF）**：将 DINO 的 [CLS] 令牌（全局表示）也通过 ODE 进行精炼，以更好地捕获整体语义。
- **几何保持**：引入速度切向投影（Velocity Tangent Projection, VTP），将学习到的速度场约束到当前点的切空间，确保演化过程中特征始终位于单位超球面上，维持拓扑结构。

### 2.2 关键技术细节

- **预备知识**：
  - 神经 ODE：$ \frac{d\mathbf{z}_t}{dt} = v_\theta(\mathbf{z}_t, t) $，从 $t=0$ 积分到 $t=1$ 得到流形变换。
  - 使用欧拉方法离散求解：$\mathbf{z}_{t+\Delta t} = \mathbf{z}_t + \Delta t \cdot v_\theta(\mathbf{z}_t, t)$。
- **STF 具体流程**：
  - 初始状态：$ \mathbf{z}_0 = \text{Norm}(W \mathbf{z}_{\text{text}}) $，将 CLIP 文本嵌入线性投影到 DINO 维度并归一化。
  - 目标视觉表示：$ \mathbf{z}_{\text{img}} = \text{Norm}(\text{Pool}(\mathbf{Z}_{\text{img}})) $，使用 Top-K 池化聚合 patch 令牌。
  - 速度网络 $v_\theta$：以正弦时间嵌入作为条件，通过特征调制（FiLM）注入时间信息。
  - VTP：$ \tilde{v}_\theta(\mathbf{z}_t, t) = v_\theta(\mathbf{z}_t, t) - \langle v_\theta(\mathbf{z}_t, t), \mathbf{z}_t \rangle \mathbf{z}_t $，将速度投影到切空间。
  - 最终对齐文本嵌入：$ \hat{\mathbf{z}}_{\text{text}} = \mathbf{z}_1 = \Phi^\text{text}_\theta(\mathbf{z}_0) $。
- **GCF 流程**：
  - 初始状态：$ \mathbf{c}_0 = \text{Norm}(W_{\text{cls}} \mathbf{z}_{\text{img}}^{\text{cls}}) $。
  - 类似 STF 的 ODE 演化 + VTP，得到精炼全局表示 $ \hat{\mathbf{z}}_{\text{img}}^{\text{cls}} $。
- **损失函数**：
  - 构建全局图像表示：$ \mathbf{z}_{\text{img}}^{||} = [\mathbf{z}_{\text{img}}; \hat{\mathbf{z}}_{\text{img}}^{\text{cls}}] \in \mathbb{R}^{2D} $。
  - 重复对齐文本嵌入得到 $ \mathbf{z}_{\text{text}}^{||} \in \mathbb{R}^{2D} $。
  - 使用对称对比损失（CLIP-style NCE loss）优化速度网络。
- **推理**：对每个候选类别，通过 STF 生成视觉对齐的文本锚点，与 DINO patch 令牌计算余弦相似度，得到分割图。
