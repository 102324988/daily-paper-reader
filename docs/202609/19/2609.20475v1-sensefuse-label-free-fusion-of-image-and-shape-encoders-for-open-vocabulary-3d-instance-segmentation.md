## 摘要
开放词汇场景理解是机器人技术的基础，为空间推理和物体操作奠定基础。尽管闭词汇三维实例分割大量利用三维形状信息，最先进的开放词汇方法在掩码标注过程中仍主要局限于二维图像特征或图像蒸馏表示。在本文中，我们提出 SenseFuse，一种无标签融合方法，平衡二维图像与三维形状编码器，以实现稳健的开放词汇三维实例分割，仅对现有流程的掩码标注阶段进行改进。我们揭示，二维图像编码器与三维形状编码器表现出很大程度上不相交的失败模式，且很少共享相同的错误标签，而两个二维图像编码器则经常重复相同的错误。这种截然不同的行为使得二维与三维组合具有内在互补性。我们引入一种自适应机制，选择场景级融合权重以最大化无标签敏感性度量，该度量可直接从单个场景的未标注候选区域在毫秒级时间内估计得到。SenseFuse 在 ScanNet200、Replica 和 ScanNet++ 的每个评估设置中都提升了标注准确率，恢复了使用 oracle 权重可达到增益的 67–100%（中位数 93%），并在 22 个报告设置中的 21 个中提升了实例 AP。代码可在 https://github.com/hanes1207/SenseFuse 获取。

## Abstract
Open-vocabulary scene understanding is fundamental for robotics, laying the groundwork for spatial reasoning and object manipulation. While closed-vocabulary 3D instance segmentation heavily leverages 3D shape information, state-of-the-art open-vocabulary methods remain predominantly restricted to 2D image features or image-distilled representations during mask labeling. In this paper, we propose SenseFuse, a label-free fusion method that balances 2D image and 3D shape encoders for robust open-vocabulary 3D instance segmentation, refining only the mask-labeling stage of existing pipelines. We reveal that 2D image and 3D shape encoders exhibit largely disjoint failure patterns and rarely share identical wrong labels, whereas two 2D image encoders frequently repeat the same errors. This distinct behavior makes the 2D and 3D pair inherently complementary. We introduce an adaptive mechanism that selects a scene-level fusion weight to maximize a label-free sensitivity measure, estimated directly from a single scene's unlabeled proposals in milliseconds. SenseFuse improves labeling accuracy in every evaluated setting across ScanNet200, Replica, and ScanNet++, recovering 67-100% (median 93%) of the gain achievable with an oracle weight, and it raises instance AP in 21 of 22 reported settings. Code is available at https://github.com/hanes1207/SenseFuse.

## 1. 核心问题与整体含义

- **研究背景**：开放词汇三维场景理解是机器人空间推理与物体操作的前提。闭词汇 3D 实例分割（3DIS）方法（如 Mask3D、PointGroup、SoftGroup 等）天然利用 3D 形状与几何信息，但类别集合固定，无法识别新类别。
- **核心矛盾**：现有开放词汇 3DIS 方法（OpenMask3D、Open3DIS、Open-YOLO3D）在**掩码标注（mask labeling）阶段几乎完全依赖 2D 图像编码器或图像蒸馏表示**，3D 形状证据被完全弃用，导致在深度/遮挡主导的场景中（如被桌子遮挡的椅子被误判为“桌子”）出现系统性失败。
- **难点**：直接在 2D 伪标签上训练 3D 网络会引入严重的类别偏置，损害零样本泛化能力。
- **关键洞察**：作者通过实验发现——
  - 2D 图像编码器与 3D 形状编码器的失败模式**高度不相交**，联合错误中仅有 **5.9%** 共享相同错误标签；
  - 而两个 2D 图像编码器（EVA + CLIP）的共享错误率高达 **41.4%**，秩相关 ρ = 0.677，远高于 2D–3D 组合（ρ ∈ [0.079, 0.226]）。
  - 因此 **2D–3D 组合才是更有价值的融合目标**，而非再叠加一个 2D 编码器。
- **整体含义**：提出 SenseFuse——一种**免训练、免标签**的融合模块，仅替换现有开放词汇 3DIS 流程的最终类别分配阶段，使机器人进入未知环境时无需重训练即可重新校准实例标签。

## 2. 方法论

### 核心思想
保持 3D 形状编码器与 2D 图像编码器均**冻结**，在掩码标注阶段用**单一场景级标量权重 w** 线性融合两个编码器的类别分数，权重通过无标签的敏感度（sensitivity）估计自适应选取。

### 关键技术细节

- **问题设定**：给定 RGB 点云 P ∈ ℝ^(N×6) 与候选掩码 {M_q}，对每个掩码 q 分别提取：
  - 2D 图像嵌入 z₂^q（来自现有 pipeline，如 CLIP mask embedding 或图像裁剪特征）；
  - 3D 形状嵌入 z₃^q（对掩码内点重采样至 N₀=10⁴ 点、中心化、缩放至单位球后，经冻结的 3D 形状编码器，如 Uni3D）。
  - 两个头分别与各自的文本锚点做余弦相似度。

- **分数中心化（Eq. 1）**：因两个编码器投影到不同的文本对齐空间，原始余弦分数不可直接比较，故对每个掩码的 K 个类别分数做行中心化：S^q_{h,c} = s^q_{h,c} − (1/K)Σ_{c'} s^q_{h,c'}。

- **敏感度定义（Eq. 2）**：借鉴信号检测理论的可辨别性指数 d'_h = μ_h / σ_h，其中 μ_h 为正确类得分高于背景的平均提升量，σ_h 为背景（错误类）得分的标准差。每个场景估计一组 (μ_h, σ_h)。

- **线性融合与闭式权重（Eq. 3–5）**：
  - 融合分数 S^q_c(w) = (1−w)S₂ + wS₃，标签为 arg max。
  - 假设两头背景分数不相关，融合后的敏感度为 d'_w = [(1−w)μ₂ + wμ₃] / √[(1−w)²σ₂² + w²σ₃²]。
  - 对 w 求导置零得到闭式最优权重：**w_law = (μ₃/σ₃²) / (μ₂/σ₂² + μ₃/σ₃²)**，记 π_h = μ_h/σ_h²，则 w = π₃/(π₂+π₃) ∈ [0,1]。
  - 在高斯分数模型下，该规则与 LDA / 贝叶斯最优决策一致。

- **无标签估计（Alg. 1）**：
  - 由于真实标签未知，用软责任（soft responsibility）替代硬伪标签，迭代求解。
  - 定义软类别责任 P^q_c = softmax(S^q_c/(τ₀ν_q))、背景分布 Γ^q_c = (1−P^q_c)/(K−1)、掩码子集权重 g_q ∝ [1+e^(−β·m̃_q)]⁻¹（按场景标准化的 top-1/top-2 间隔平滑选择）。
  - 用责任加权的均值/方差更新 (μ̂_h, σ̂_h)（Eq. 7），再由 Eq. 5 重算 w，迭代至收敛（最多 12 次，容差 10⁻³）。
  - 超参数 τ₀=0.25、β=8 为无量纲量，对所有数据集和 pipeline 使用同一默认值。

- **收敛性**：软化更新在 [0,1] 上连续，由介值定理保证不动点存在；实测从 w₀ ∈ {0, 0.25, 0.5, 0.75, 1} 任意初始化均收敛到同一权重。

## 6. 主要结论与发现

- **一致提升**：SenseFuse 在所有 11 个评估设置中均提升标注准确率，中位数 +7.1 个百分点（范围 +3.8 至 +25.1）。
- **接近 oracle**：无标签估计权重恢复 oracle 增益的中位数 **93%**（范围 67–100%），与 per-scene 权重表现相当（差距 ≤0.04）。
- **AP 提升**：22 个报告设置中 21 个提升，最大 +4.5 mAP。
- **互补性证据**：2D–3D 组合共享错误率仅 5.9%，远低于 2D–2D 的 41.4%；秩相关 ρ 从 0.677 降至 0.079–0.226。
- **失败模式规律**：几何区分度高的类别（浴室隔间门 +62pp、淋浴墙 +30pp、扶手椅 +29pp）大幅提升；纹理/上下文主导的小物体（纸巾盒 −22pp、纸巾分配器 −21pp）退化。退化集中在稀疏掩码（最低点数量四分位 −2.1pp，第三四分位 +8.4pp）。
- **分数级融合优于决策级**：线性融合最好，PoE 接近（−0.2），MaxPool 无增益，决策级 Router/Veto 反而下降 1.2–1.6pp。
- **相关性修正无效**：显式修正跨模态背景相关性不提升精度，还会产生 3–20% 的不合法权重。

## 7. 优点

- **即插即用、免训练免标签**：仅替换现有 pipeline 的最终标签分配，不改变掩码几何与置信度，可直接部署于机器人探索未知环境。
- **理论优雅**：闭式权重解与 LDA / 贝叶斯最优一致，且权重估计仅需前两阶矩，计算成本毫秒级。
- **洞察有力**：用共享错误率与秩相关量化“2D–3D 互补、2D–2D 冗余”，为融合对象的选择提供了实证依据。
- **鲁棒性设计**：软责任 + 软子集权重使迭代对初始化不敏感，超参数无量纲且跨数据集通用。
- **实验严谨**：统一评测协议重跑基线；定义 oracle 恢复率；对 AP 两种提交规则分别报告，暴露评测协议敏感性。
- **效率高**：单卡串行仅 +18% 耗时，双卡并行几乎无额外关键路径。

## 8. 不足与局限

- **粒度限制**：每个场景仅一个融合权重，无法刻画实例级模态可靠性差异；作者将其列为未来工作（instance-level adaptation）。
- **上限受弱头约束**：融合增益受限于较弱编码器（如 OpenShape 精度低，增益仅 +0.9/+1.6），依赖更强 3D 形状编码器才能提升天花板。
- **小物体退化**：稀疏掩码（<1,000 点）在 ScanNet200 占 28%，几何编码器对此类物体不可靠，导致性能下降。
- **权重不通用**：跨 pipeline 与数据集的最优 w 跨度大（0.085–0.472），单一常数权重仅恢复 81% oracle 增益，甚至会使 ScanNet++/Open3DIS 低于 2D-only。
- **统计显著性有限**：Replica 仅 8 场景，4 个增益中仅 1 个统计显著；部分设置（OpenMask3D + ScanNet++）缺数据。
- **场景局限**：仅限室内重建点云（ScanNet/Replica/ScanNet++），未验证户外、动态场景或真实机器人在线部署。
- **仅两模态**：方法仅融合 2D 与 3D 两个头，扩展到多编码器是未解问题；背景相关性虽被测量但被刻意忽略，其近似在相关性更高时可能失效。
