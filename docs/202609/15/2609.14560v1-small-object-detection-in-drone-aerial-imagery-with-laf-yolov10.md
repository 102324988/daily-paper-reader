## 摘要
通用目标检测器在无人机影像上会损失精度，因为其中的目标仅跨越少数几个像素，且机载算力有限。先前工作将各自独立验证过的架构技术组合到一个检测器中，并假设单独报告的性能增益在组合后仍能迁移。我们直接对这一假设进行压力测试。LAF-YOLOv10 将四项技术集成到 YOLOv10n 中：部分卷积 C2f（PC-C2f）主干模块、注意力引导特征金字塔网络（AG-FPN）、替代大目标 P5 头的 P2 检测头，以及 Wise-IoU v3 回归，旨在考察它们的组合效果是否与各自单独贡献相匹配。我们在 VisDrone-DET2019 上训练 LAF-YOLOv10 三次（随机种子 42、123、256），以未修改的 YOLOv10n 为基准，并使用 TIDE 误差分解、逐类别拆分、逐组件消融、注意力/损失比较、向 UAVDT 的零样本迁移以及留出集/test-dev 评估，来定位该组合在何处成功或失败。可组合性在此并不成立。LAF-YOLOv10 在 2.14M 参数下达到 24.0+/-0.4% mAP@0.5，比 YOLOv10n（31.8%）低 7.8 个百分点；这一差距迁移到 UAVDT 上（-10.0 个百分点），并由留出集和 test-dev 评估（23.5%、22.5%）所证实。背景误报、定位误差和重复检测的变化方向与 AG-FPN 和 Wise-IoU 旨在推动的方向一致。消融将性能差距追溯到一个具体来源：P2/-P5 检测头替换单独造成 2.5 个百分点的损失，当叠加到被 PC-C2f 削弱的主干上时，还会产生 2.5 个百分点的交互惩罚；PC-C2f 自身的 2.0 个百分点损失与部分预训练权重移植（73/150 个主干张量迁移）相符。该失败可归因于一个特定的交互作用，而非四个组件各自的问题。可组合性必须直接验证，而不能假设。代码/检查点：https://github.com/Mudassiruddin7/Small-Object-Detection-in-UAV-Imagery。

## Abstract
General-purpose object detectors lose accuracy on UAV footage, where targets span only a handful of pixels and onboard compute is limited. Prior work composes independently-validated architectural techniques into one detector, assuming gains reported in isolation transfer once combined. We stress-test that assumption directly. LAF-YOLOv10 integrates four techniques into YOLOv10n: a Partial Convolution C2f (PC-C2f) backbone block, an Attention-Guided Feature Pyramid Network (AG-FPN), a P2 detection head replacing the large-object P5 head, and Wise-IoU v3 regression, asking whether their combined effect matches what each contributes alone. We train LAF-YOLOv10 three times (seeds 42, 123, 256) on VisDrone-DET2019, benchmark against unmodified YOLOv10n, and use TIDE error decomposition, per-category breakdown, per-component ablation, attention/loss comparisons, zero-shot transfer to UAVDT, and held-out/test-dev evaluation to localize where the combination succeeds or fails. Composability does not hold here. LAF-YOLOv10 reaches 24.0+/-0.4% mAP@0.5 at 2.14M parameters, 7.8 points below YOLOv10n (31.8%), a deficit that transfers to UAVDT (-10.0 points) and is confirmed by held-out and test-dev evaluation (23.5%, 22.5%). Background false positives, localization error, and duplicate detections move in the direction AG-FPN and Wise-IoU were designed to push. Ablation traces the deficit to a specific source: the P2/-P5 head swap costs 2.5 points independently plus a 2.5-point interaction penalty when layered onto a backbone weakened by PC-C2f, whose own 2.0-point loss is consistent with a partial pretrained-weight transplant (73/150 backbone tensors transfer). The failure is attributable to a specific interaction, not the four components individually. Composability must be verified directly, not assumed. Code/checkpoints: https://github.com/Mudassiruddin7/Small-Object-Detection-in-UAV-Imagery.

## 1. 核心问题与整体含义

- **背景痛点**：无人机（UAV）已成为交通监控、精准农业、搜救、基础设施巡检的标准感知平台，但检测必须跑在机载或边缘设备上，算力预算固定且很小。
- **小目标难题**：飞行高度使多数目标仅占几个像素。作者直接解析 VisDrone-DET2019 训练集标注（343,205 个实例 / 6,471 张图），发现 **54% 的实例小于 32×32 像素、22% 小于 16×16、约 5% 小于 8×8**；密集遮挡、视角多变进一步加剧困难。已有研究（Nikouei 等、Rekavandi 等）表明主流检测器在小目标上普遍低于 30% mAP，而中等目标可超 50%，因此"堆容量"并非解法。
- **被检验的核心假设**：该领域常见的设计范式是——把若干个**各自独立验证有效**的架构技巧拼装进同一个检测器，并默认"单独有效 ⇒ 组合后仍有效"。本文对这一假设做**直接压力测试**。
- **研究含义**：LAF-YOLOv10 将四项技术集成进 YOLOv10n（PC-C2f 主干块、AG-FPN 颈部、P2 替换 P5 检测头、Wise-IoU v3 回归损失），逐项对应上文三类结构缺陷。结论是**可组合性不成立**：整体精度反而大幅下降。因此本文的贡献不在"提出新模块"，而在于**提供一个可复用的诊断协议（误差分解 + 逐组件消融 + 迁移验证），用于发现、定位并量化组合失效**，并给出可检验的成因假说。

## 2. 方法论

### 2.1 核心思想
- 以 YOLOv10n 为基座（nano 级、无 NMS、适配嵌入式 UAV GPU），在**主干 / 颈部 / 检测头**三个层级各改一处，另加一处训练损失替换，共四项改动；每项在文献中均被独立验证过有正向效果。
- 关键在于：不只看聚合精度，而是用 **TIDE 误差分解 + 独立/增量式消融 + 逐类别分析** 去检验"每个组件声称的机制在组合后是否仍然成立"。

### 2.2 四项关键技术细节

- **PC-C2f（部分卷积 C2f 主干块）**
  - 输入张量 X ∈ R^(C×H×W) 按通道切分为活跃组 X_p ∈ R^((C/r)×H×W) 与直通组 X_u，缩减比 **r = 4**（取内存序前 C/4 通道）。
  - 仅活跃组经 3×3 卷积：`X'_p = Conv3×3(X_p)`；再拼接并做 1×1 逐点卷积恢复跨通道信息：`Y = Conv1×1(Concat(X'_p, X_u))`。
  - 空间卷积开销约降 75%，但 1×1 投影仍触及全部 C 通道，故在 YOLOv10n 的通道宽度（32–256）下**有效 FLOPs 降幅约 55–60%**（论文后文实测约 14% 的 GFLOPs 下降）。
  - 作者明确承认"前 C/4 通道"并非有语义依据的特征选择规则，更合理的解释是**隐式正则化**（类似通道级 dropout），并用随机 C/4 子集做了对照实验。

- **AG-FPN（注意力引导特征金字塔）**
  - 在融合前对每层特征 F_i 施加 **SE 通道门控**：`α_i = σ(W_i2 · δ(W_i1 · GAP(F_i)))`，压缩比 **s = 16**；门控后 `F'_i = α_i ⊗ F_i`，再做拼接与 1×1 投影。
  - 选择 SE 而非 CBAM / Coordinate Attention，理由是纯通道重标定契合"抑制背景噪声通道"的目标，且避免与 DySample 的空间分支产生交互。
  - 用 **DySample** 替换最近邻上采样，其子网络预测内容条件化的采样偏移，全颈部三次上采样仅增加 0.06 GFLOPs，可减少小目标边界处的混叠。
  - 作者强调 α_i 是与检测损失联合学习的重标定，**并非有显式前景/背景监督**。

- **P2 检测头替换 P5**
  - 新增 stride-4、160×160 的 P2 头（特征取自主干第 2 阶段，经 AG-FPN 与上采样 P3 融合），标称可覆盖 4×4 像素，实际主要在 **6×6 到 16×16** 区间起作用。
  - 移除 stride-32 的 P5 头：大于 256×256 像素的目标不足标注的 0.8%，且 stride-32 网格主要靠语义上下文而非细粒度空间信息工作；移除可释放约 **0.3M 参数、1.2 GFLOPs**，部分抵消 P2 的代价。

- **Wise-IoU v3 损失**（替换 CIoU）
  - `L_WIoU = R_WIoU · L_IoU`，其中 `R_WIoU = exp(((x−x_gt)² + (y−y_gt)²)/(W_g² + H_g²))`，随预测中心偏移相对包围框对角线增大而增大。
  - 离群度 `β = L_IoU / L̄_IoU`（批内 IoU 损失的指数滑动平均，动量 1/30），β > 1 标记为离群样本；阻尼因子 `α* = (β/δ)^γ`，δ = 3.0、γ = 1.9（参考实现默认值）。
  - 最终 `L_WIoU-v3 = α* · L_WIoU`，对疑似噪声标注**抑制而非删除**其梯度贡献。
