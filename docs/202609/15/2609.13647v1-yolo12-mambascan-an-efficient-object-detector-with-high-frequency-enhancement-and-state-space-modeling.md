## 摘要
无人机（UAV）技术的快速发展，使航拍图像目标检测在自然资源监测、交通管理和灾害响应中日益重要。航拍图像中的小目标检测仍然困难，因为目标仅占据极少数像素，高频线索容易丢失，并且在杂乱场景中难以对全局上下文建模。现有检测器往往无法保留足够的边缘、角点和纹理信息。我们提出了 YOLO12-MambaScan，一种基于 YOLO12 架构构建的航拍图像检测器。该模型结合了三路径高频增强卷积模块（TriPathHFConv）、感受野坐标注意力卷积（RFCAConv）以及基于 Mamba 的全局上下文模块。在 VisDrone 上，当输入分辨率为 960×960 时，YOLO12-MambaScan 达到了 60.0% mAP@50 和 38.6% mAP@50:95，展现出面向小目标检测的良好精度—效率权衡。基准和数据集协议遵循 VisDrone 挑战赛的设置。

## Abstract
The rapid development of unmanned aerial vehicle (UAV) technology has made aerial-image object detection increasingly important for natural-resource monitoring, traffic management, and disaster response. Detecting small objects in aerial images remains difficult because objects occupy very few pixels, high-frequency cues are easily lost, and global context is hard to model in cluttered scenes. Existing detectors often retain insufficient edge, corner, and texture information. We propose \ours, an aerial-image detector built on the YOLO12 architecture. The model combines a triple-path high-frequency enhancement convolution module (TriPathHFConv), receptive-field coordinate-attention convolution (RFCAConv), and a Mamba-based global-context module. On VisDrone, at an input resolution of 960*960, ours achieves 60.0% mAP@50 and 38.6%mAP@50:95, demonstrating a favorable accuracy--efficiency trade-off for small-object detection. The benchmark and dataset protocol follow the VisDrone challenge setup.

## 2. 方法论

### 2.1 核心思想与整体架构
- 在 YOLO12 的 backbone–neck–head 框架上做定点改造：
  - 浅层 backbone（第 2–4 层）用 **TriPathHFConv** 替换原始卷积，显式保留高频细节。
  - 标准下采样层替换为 **RFCAConv**（用于 P1/2、P2/4、P3/8、P4/16、P5/32 尺度转换）。
  - 最深阶段插入 **MambaBlock**，以线性复杂度建模全局上下文。
  - neck 与 head 之间放置 **GSPN SCSA**，增强多尺度空间—通道感知。
  - 保留 YOLO12 解耦头，并新增 **STEL**（P2/4 高分辨率预测分支）应对极小目标。

### 2.2 RFCAConv（感受野坐标注意力卷积）
- **动机**：标准卷积的共享卷积核假设会抑制小目标的位置特定证据。
- **流程**：分组卷积生成感受野特征 → 归一化与 ReLU → 全局平均池化后经 1×1 卷积与 Softmax 得到感受野注意力图 → 与特征逐元素相乘。
- **坐标形式**：保留水平与垂直方向的位置信息（坐标注意力）。
- **成本**：相比标准卷积约增加 1.5% 参数、2.3% FLOPs。
- **定位**：与 TriPathHFConv 互补——前者强化下采样时的感受野表征，后者保留特征提取时的高频细节。

### 2.3 TriPathHFConv（三路径高频增强卷积）
- **动机**：远处行人/车辆主要体现为高频分量（边缘、角点、纹理）。
- **三条并行路径**：
  1. **基础深度可分离路径**：DWConv + BN + SiLU，捕捉局部模式。
  2. **膨胀深度可分离路径**：DWDConv，在不显著增加参数的前提下扩大感受野。
  3. **高频增强路径**：由 3×3 卷积 + 1×1 卷积 + Sigmoid 生成内容自适应注意力图，再与输入相乘并归一化激活。
- **融合**：三路输出拼接后经 1×1 卷积投影输出。设计兼顾特征互补、信息完整与自适应通道重加权，避免手工设计增强算子的固定滤波限制。

### 2.4 MambaBlock（基于 Mamba 的全局上下文增强）
- **动机**：自注意力具二次复杂度，Mamba 的选择性状态空间建模可提供线性复杂度的全局交互。
- **位置**：插入最深 backbone 阶段（语义抽象高、空间分辨率低，避免早期高分辨率图上的昂贵全局运算）。
- **流程**：GroupNorm → 维度重排为序列 → VSSBlock（选择性状态转移、dconv=3 深度卷积、扩展因子 2）→ 重排回原布局并加残差连接，保证优化稳定。

### 2.5 GSPN SCSA（全局空间感知协同注意力）
- **位置**：neck 与检测头之间。
- **组成**：
  - **线性扫描空间模块**：沿两轴均值池化，用深度可分离一维卷积双向扫描，四个方向响应以输入相关门控融合；将空间注意力成本由 O(H²W²) 降至约 O(H+W)。
  - **高效通道注意力**：AdaptiveAvgPool 7×7 压缩后经 VSSBlock 处理，再与全局上下文相加激活。
  - **跨模态融合**：对空间与通道特征投影后动态加权求和。
- **总公式**：`Y = CrossFusion(X⊙A_spatial, X⊙A_channel) + X`。

### 2.6 STEL（小目标增强层）
- **动机**：原 YOLO12 头使用 P3/8、P4/16、P5/32，小于约 10×10 像素的目标在到达这些尺度前已丢失判别信息。
- **设计**：新增 P2/4 分支（640×640 输入时为 160×160），融合两条路径：
  - 细节路径 `F_detail = TriPathHFConv(X_P2)`
  - 语义路径 `F_semantic = Upsample(LateralConnection(X_P3))`
  - 融合 `F_STEL = GSPN SCSA([F_detail, F_semantic])`
  - 轻量头 `Head_STEL = Conv1×1(σ(Conv3×3(F_STEL)))`
- **代价与收益**：通道由 256 压缩至 128，额外计算量限制在 18.7%，小目标检测分数提升 23.4%。
