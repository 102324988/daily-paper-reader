## 摘要
遥感中的密集变化检测要求视觉语言模型（VLM）比较双时相图像并生成精确的像素级掩码。现有 VLM 大多局限于变化描述输出，少数能够生成像素级掩码的方法仍依赖外部解码器或扁平的“文本即掩码”序列化方式，对细小且破碎的变化效果不佳。我们提出 QUAKE-CD，一个将密集变化预测重构为语法可验证的结构化生成的框架。QUAKE-CD 将二值变化掩码表示为受语法约束的四叉树 token 序列，使掩码在自回归生成空间中具有紧凑性、语法可检查性以及确定性可解码性。我们进一步构建 QUAKE-CoT，将这些序列与基于视觉证据的思维链轨迹配对，并通过渐进式课程学习以及语法门控双奖励强化学习，联合优化文本推理与空间密集预测。在 QUAKE-CoT 上，QUAKE-CD 取得了 78.31% 的累积 F1，优于基于解码器和扁平“文本即掩码”的 VLM，同时产生更忠实的双时相推理。

## Abstract
Dense change detection in remote sensing requires vision-language models (VLMs) to compare bi-temporal images and generate accurate pixel-level masks. Existing VLMs are largely confined to change captioning outputs, and the few that produce pixel-level masks still rely on external decoders or flat text-as-mask serialization, which are less effective for small and fragmented changes. We introduce QUAKE-CD, a framework that recasts dense change prediction as syntax-verifiable structured generation. QUAKE-CD represents binary change masks as grammar-constrained quadtree token sequences, making the masks compact, syntactically checkable, and deterministically decodable within an autoregressive generation space. We further construct QUAKE-CoT, which pairs these sequences with chain-of-thought traces grounded in visual evidence, and jointly optimizes textual reasoning and spatial dense prediction through a progressive curriculum followed by grammar-gated dual-reward RL. On QUAKE-CoT, QUAKE-CD achieves 78.31% accumulated F1, outperforming decoder-based and flat text-as-mask VLMs while producing more faithful bi-temporal reasoning.

## 一、核心问题与研究动机

- **任务定位**：遥感双时相变化检测要求视觉语言模型（VLM）对比前后两期影像，直接输出像素级二值变化掩码，是检验"多模态推理能否落地为空间定位"的严格试炼场。
- **现状割裂（语言推理 vs. 像素决策）**：
  - 主流 VLM 多停留在**变化描述（change captioning）**，不产生稠密空间输出；
  - 少数能出掩码的方案依赖**外部分割解码器**（LISA、GLaMM、PixelLM），把稠密预测当作辅助目标，与自回归主干机制正交，导致异构目标、端到端训练困难、无法做 token 级直接优化；
  - **稀疏线索范式**（用框/点提示 SAM 等外部分割器）缺乏双时相上下文，面对多个破碎实例时易发生级联定位错误。
- **"文本即掩码"（text-as-mask）的固有缺陷**：
  - 扁平 patch-grid 序列化对所有空间区域**一视同仁地分配 token 密度**，与变化掩码的稀疏性不匹配；
  - 对遥感影像中**密集分布的小目标**会产生严重**空间粘连（spatial adhesion）**，把本应分离的实例错误合并为一个连通域；
  - 实测证据：Text4Seg 召回高达 84.07%，但精确率仅 14.52%（F1 24.76%），RSUniVLM 同样存在明显召回—精确率失衡。
- **核心诉求**：需要一种**层次化表示**——能压缩均匀背景区域、同时把 token 自适应地集中到需要高空间锐度的边界上，并且能在自回归 token 空间内被**语法校验、确定性解码**。
- **整体含义**：论文把稠密变化预测从"像素回归/解码器问题"重构为**语法可验证的结构化语言生成**，让格式合法性、像素精度与推理忠实性在同一个 token 级优化框架下统一起来。

## 二、方法论

### 2.1 总体框架

- 给定双时相图像对 (I₁, I₂)，VLM π_θ 生成三段式序列：
  **y = [ y_think ; y_answer ; y_seg ]**
  - `y_think`：自由文本思维链（CoT）推理轨迹；
  - `y_answer`：简洁的变化摘要；
  - `y_seg`：来自形式语言 L_Q 的四叉树掩码编码。
- 确定性解码器 **D : L_Q → {0,1}^{H×W}** 把任意合法编码映射回二值
