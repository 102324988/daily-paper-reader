## 摘要
弱监督三维占用预测通过从视觉基础模型生成的二维伪标签中学习，降低了对昂贵三维标注的依赖。然而，现有方法通常直接将这些不完美的伪标签用作监督，使占用学习容易受到错误的几何与语义目标影响。我们观察到，重复观测之间的一致性为评估伪标签可靠性提供了一种低成本且可靠的线索。基于这一观察，我们提出 LetOccVote，一种基于高斯的弱监督占用框架，利用跨帧投票来改进几何与语义监督。在几何方面，Depth Vote 利用跨帧几何一致性来细化受支持的伪深度并拒绝相矛盾的估计，然后再进行体素提升和深度监督。在语义方面，Semantic Vote 在共享三维空间中聚合伪语义观测，以识别可靠和有争议的证据，从而强化可靠的语义监督，同时过滤不可靠的伪标签片段。整个框架仅使用二维伪标签监督进行训练，无需三维占用标注。在 Occ3D-nuScenes 上，LetOccVote 达到 53.27 IoU 和 20.39 mIoU，在基于二维伪标签监督的方法中取得了最先进性能。

## Abstract
Weakly supervised 3D occupancy prediction reduces the reliance on costly 3D annotations by learning from 2D pseudo-labels generated by vision foundation models. However, existing methods typically use these imperfect pseudo-labels directly as supervision, making occupancy learning vulnerable to erroneous geometric and semantic targets. We observe that agreement across repeated observations provides an inexpensive and reliable cue for assessing pseudo-label reliability. Based on this observation, we propose \textbf{LetOccVote}, a weakly supervised Gaussian-based occupancy framework that leverages cross-frame voting to improve both geometric and semantic supervision. For geometry, Depth Vote exploits cross-frame geometric agreement to refine supported pseudo depth and reject contradictory estimates before volumetric lifting and depth supervision. For semantics, Semantic Vote aggregates pseudo-semantic observations in a shared 3D space to identify reliable and contested evidence, strengthening reliable semantic supervision while filtering unreliable pseudo-label segments. The entire framework is trained solely with 2D pseudo-label supervision without requiring 3D occupancy annotations. On Occ3D-nuScenes, LetOccVote achieves 53.27 IoU and 20.39 mIoU, establishing state-of-the-art performance among methods with 2D pseudo-label supervision.

## 1. 核心问题与研究背景

- **研究动机**：3D 语义占用预测是自动驾驶感知的基础任务，但稠密体素级 3D 标注成本高昂。近年方法转向用视觉基础模型（如 Grounded-SAM、Metric3D）自动生成 2D 深度/语义伪标签，以弱监督方式训练占用网络。
- **核心痛点**：现有弱监督方法（如 GaussTR、GaussianFlowOcc）**把不完美的伪标签直接当作优化目标**。伪深度存在几何误差与跨帧不一致，伪语义存在类间混淆；跨帧/多源一致性在这些工作中仅被用于表征学习或一致性约束，而**未被用于显式评估伪标签的可靠性**。
- **关键观察（论文的出发点）**：同一物理位置在不同视角与时刻的重复观测应当具有一致的几何与语义；**观测之间的一致/矛盾本身就是伪标签可靠性的廉价而可靠的证据**。
- **整体含义**：论文提出 LetOccVote，一个基于高斯的弱监督占用框架，用跨帧投票同时改善几何与语义监督——强化一致监督、掩蔽不可靠标签，全程无需 3D 占用标注。

## 2. 方法论

### 2.1 核心思想
用"多观测共识"作为伪标签可靠性的判据：几何上细化/剔除矛盾深度，语义上强化可靠证据、过滤争议片段。

### 2.2 整体流程（Fig. 2a）
1. 用冻结的 DINOv2 提取图像特征 F；
2. **Depth Vote** 先细化/剔除伪深度，再据此把多帧多相机特征提升（lifting）到共享 3D 体素；
3. 3D 编码器（deformable self-attention）细化得到体特征 V；
4. 3D 解码器查询 V，输出语义高斯集合 G = {(μᵢ, Σᵢ, αᵢ, sᵢ)}；
5. 训练时施加 **Semantic Vote** 增强的弱监督（深度 + 语义）；
6. 推理时将高斯体素化得到语义占用 O。训练用当前帧前后帧，推理只用当前帧与历史帧（保证因果性）。

### 2.3 Depth Vote（几何投票）
- 对每个深度样本，将其反投影到当前自车 3D 空间，再重投影到时间窗 T 内各比较帧，查询对应位置的伪深度；
- 先用**鲁棒中值深度比**做尺度对齐，消除图像级尺度偏差；
- 一致性判据（τ(z) 为随距离增大的自适应容差）：
  - **Agreement**：|z − d̄| ≤ τ(z)，支持该候选表面；
  - **Contradiction**：z < d̄ − τ(z)，候选位置在实际表面前方；
  - **Abstention**：其余情况（含远在表面后方可能被遮挡、出视野、深度无效）。
- 同一帧内多相机证据合并为**一个帧级投票**（每帧最多一票）；
- 用 **k 帧投票规则**在 W 帧窗口上决策（Nₐgr 同意帧数、N_con 矛盾帧数）：
  - Nₐgr ≥ k → 用共识校正后的深度 R(D̃) 提升特征；
  - t ≠ 0 且 N_con ≥ k 且 Nₐgr = 0 → 深度置 0（判为无效、排除出 lifting 与监督）；
  - 其余（证据不足/模糊）→ 保留原始伪深度；
  - **当前帧禁用拒绝**，但可被细化。
- 用细化深度把所有相机/帧特征反投影并 splat 到共享体素网格，同体素特征取平均，再由 3D 编码器融合上下文。

### 2.4 Gaussian Derivation
从占据体素采样固定数量查询参考点（体素中心为初始 3D 参考），解码器逐步细化参考位置与查询特征；参考点决定高斯中心 μᵢ，轻量 MLP 头预测 αᵢ、Σᵢ、sᵢ。

### 2.5 Vote-Enhanced Weak Supervision
- **细化深度监督**：同一份细化深度既指导 lifting，又监督渲染深度
  L_depth = Σ_(t,n) wₜ [ L_SiLog(D_rend, D̂) + λ_L1 · L1(D_rend, D̂) ]，仅在被判无效样本之外计算。
- **Semantic Vote（语义投票）**：用细化深度把各帧各相机伪语义投影到共享体素网格，对体素 v 内的候选集合 Yᵥ 做**多数投票**得到 yᵥ，并计算一致率 Aᵥ。
- **可靠池与争议池**（Fig. 2b）：在冻结的骨干特征空间中累积——
  - 伪标签与 yᵥ 一致且 Aᵥ 超过可靠性阈值 → 加入可靠池 F_rel_c；
  - 伪标签与 yᵥ = j 不一致 → 加入对应的争议池 F_ctd_{c,j}；
  - 参考特征：r_c = Norm(Σ_{f∈F_rel_c} f)，Q^¬c_c = { Norm(Σ_{f∈F_ctd_{c,j}} f) }，j ≠ c；
  - 这些统计在**初始训练阶段累积后冻结**。
- **语义掩蔽**：对带伪标签 c 的 token 特征 f，计算
  Δ(f, c) = max_{q∈Q^¬c_c} sim(f, q) − sim(f, r_c)；
  超过预设 margin 即视为争议 token；在同类伪标签的连通片段内聚合，争议比例足够高则**整段掩蔽**。被掩蔽标签**不重分配**到其他类，仅从语义损失中排除。
- **类别权重补偿**：w′_c = w_c / ρ_c（ρ_c 为类 c 未被掩蔽比例的平滑值），避免高频被掩蔽类别被系统性削弱监督。
- **投票辅助监督**：中心落在高一致率、高支持度体素内的高斯，直接用投票类别 yᵥ 监督：
  L_sem = Σ_(t,n) wₜ L_CE(S_rend, S̃; M, w′) + λ_vote Σ_{i∈G_vote} L_CE(sᵢ, yᵥⁱ)。
