## 摘要
伪装目标检测（COD）是智能光学感知中的一项重要工程任务，但当目标与周围环境高度相似时，该任务仍具有挑战性。偏振成像提供了互补的物理线索，而现有方法通常假设固定的多模态输入配置，并将偏振内部协调与红绿蓝（RGB）和偏振表示之间的交互纠缠在一起。我们提出 LGFN，一种轻量级门控 RGB-偏振融合框架，支持分别优化的仅 RGB 配置和偏振辅助配置。一个确定性模态路由器根据偏振可用性选择适当的配置。在多模态配置中，一个可用性条件化的模态门控对可用的偏振分支进行校准；门控偏振中心将学习到的线性偏振度（DoLP）和偏振角（AoP）表示与显式偏振线索进行协调；RGB-偏振交叉融合通过受控残差交互将协调后的表示引入 RGB 层级。多模态配置在推理过程中既不需要依赖样本的统计量，也不需要手工设计的质量描述符。在完整的 230 张图像 PCOD_1200 测试集上，仅 RGB 配置取得了 0.0090 的平均绝对误差、0.8806 的 Dice 分数和 0.8144 的交并比，在评估的基于 RGB 的方法中于全部六项指标上获得最佳结果。在共同的局部重评估协议下，多模态配置在全部六项指标上优于 PolarNet 和 IPNet。相对于 IPNet，其参数量、浮点运算量和延迟分别降低了 53.1%、73.6% 和 63.0%。

## Abstract
Camouflaged object detection (COD) is an important engineering task in intelligent optical perception, but it remains challenging when targets closely resemble their surroundings. Polarization imaging provides complementary physical cues, whereas existing methods typically assume fixed multimodal input configurations and entangle intra-polarization coordination with interaction between red-green-blue (RGB) and polarization representations. We propose LGFN, a lightweight gated RGB-polarization fusion framework supporting separately optimized RGB-only and polarization-assisted configurations. A deterministic Modality Router selects the appropriate configuration according to polarization availability. In the multimodal configuration, an availability-conditioned Modality Gate calibrates the available polarization branches; the Gated Polarization Hub coordinates learned degree of linear polarization (DoLP) and angle of polarization (AoP) representations with explicit polarization cues; and RGB-Polarization Cross Fusion introduces the coordinated representation into the RGB hierarchy through controlled residual interaction. The multimodal configuration requires neither sample-dependent statistics nor handcrafted quality descriptors during inference. On the complete 230-image PCOD_1200 test set, the RGB-only configuration achieves a mean absolute error of 0.0090, a Dice score of 0.8806, and an intersection over union of 0.8144, obtaining the best results on all six metrics among the evaluated RGB-based methods. Under a common local reevaluation protocol, the multimodal configuration outperforms PolarNet and IPNet on all six metrics. Relative to IPNet, it reduces the parameter count, floating-point operations, and latency by 53.1%, 73.6%, and 63.0%, respectively.

- **整体含义**：LGFN 提出"先偏振域内协调、再做非对称跨模态注入、并按模态可用性确定性路由"的轻量融合范式，兼顾 RGB-only 与偏振辅助两种部署形态。

## 2. 方法论

### 2.1 整体框架与确定性模态路由

- 输入：必选 RGB 图像 **I**∈ℝ^{3×H×W}，可选 DoLP 图 **D** 与 AoP 图 **A**；输出伪装概率图 **Ŷ**。
- 定义模态可用性向量 **m**=[1, m_D, m_A]，m_D, m_A∈{0,1}。路由规则：
  - m_D+m_A=0 → 激活**仅 RGB 路线** 𝓕_RGB(I; Θ_RGB)；
  - m_D+m_A>0 → 激活**多模态路线** 𝓕_MM(I, m_D D, m_A A, m; Θ_MM)。
- 两条路线**独立优化、各自保存 checkpoint**；路由器**只依赖偏振可用性**，不做样本级质量估计、不融合多路预测，因此偏振不可用时不会保留无效偏振分支的计算。
- 编码器：RGB 用 PVT-v2-B2 主干，DoLP/AoP 各用**参数不共享**的轻量编码器，均输出 4 级特征 {R_i}、{D_i}、{A_i}；并行有一个**显式线索编码器**产生尺度对齐的 {C_i}，保留层级编码中易被削弱的局部边界/对比信息。融合特征经 FPN 式解码器聚合、上采样与 Sigmoid 得到预测。
- 多模态流程可概括为：(w_D, w_A, γ)=𝓖(m)；P_i=𝓗_i(D_i, A_i, C_i; w_D, w_A, m)；F_i=𝓙_i(R_i, P_i; γ)。

### 2.2 可用性条件化模态门（Modality Gate）

- **仅以 m**=[1, m_D, m_A] 为输入，**不接收图像内容、手工统计量或样本级质量描述子**；用轻量 MLP 映射为三个 logits [z_D, z_A, z_γ]。
- **掩码 softmax** 得到偏振分配权重：w_k = m_k·exp(z_k) / Σ_{j∈{D,A}} m_j·exp(z_j)，不可用分支权重为 0，可用分支归一化满足 w_D+w_A=1。
- **注入强度**：γ = η_pol·[0.3 + 0.7σ(z_γ)]，η_pol=1[m_D+m_A>0]，即 γ∈[0.3, 1]；γ=0 仅为 m_D+m_A=0 时的数学兜底（实际由 RGB-only 路线处理）。
- 语义上 w_D、w_A 表示**可用性条件化的偏振分配**，而非样本级质量估计；它们控制 GPH 中的偏振聚合，γ 控制 RPCF 中的残差注入。

### 2.3 门控偏振枢纽（GPH）

- 目标：在跨模态交互**之前**，先在偏振域内协调 DoLP、AoP 与显式线索，避免跨模态模块同时处理"偏振内部异质性"和"RGB–偏振差异"。
- 先按 m_D、m_A 屏蔽不可用源图；构造 **8 通道线索张量**：掩码后的 DoLP/AoP、其一阶梯度幅值、5×5 局部残差，以及跨可用偏振模态的最大梯度与最大残差响应；轻量线索编码器转为 4 级 {C_i}。
- 尺度级聚合：**U_i = w_D D_i + w_A A_i + C_i**（掩码权重抑制不可用学习分支，C_i 补充局部结构证据）。
- 尺度特异卷积投影：**V_i = δ[BN_i(Conv^{i}_{3×3}(U_i))]**（各尺度独立参数）。
- SE 式通道重校准：α_i = σ[W^i_2 δ(W^i_1 GAP(V_i))]，**P_i = η_pol(α_i ⊙ V_i)**，得到协调后的偏振特征。

### 2.4 RGB–偏振交叉融合（RPCF）

- 采用**非对称残差交互**，RGB 为主表示通路，偏振为受控补充证据；四个尺度共享同一交互形式但参数尺度特异。
- 残差候选：**Δ_i = φ_i(Cat(R_i, P_i))**，φ_i 为 1×1 投影以恢复 R_i 通道数。
- 并行空间注意力与通道注意力重校准：**Δ̂_i = 𝓢_i(Δ_i) ⊙ 𝓒_i(Δ_i) ⊙ Δ_i**。
- 受控注入：**F_i = R_i + 1.5γΔ̂_i**（残差缩放经验固定为 1.5）；恒等捷径保留原 RGB 表示，仅引入标定后的偏振增量。γ=0 时形式化退化为 F_i=R_i（仅为数学兜底）。

### 2.5 损失函数（辅助项仅训练期使用，不增加推理开销）

- 结构感知分割损失：**L_str = L_wBCE + L_wIoU + L_Dice**，权重图 **W = 1 + 5‖AvgPool_{31}(G) − G‖**，强调结构模糊的边界区域。
- 边缘监督 G_edge 由真值掩码的膨胀/腐蚀形态学差生成。
- **融合一致性损失**（仅训练期 Fusion Decoder）：梯度目标 **T_grad = max(|∇I_gray|, |∇D|, |∇A|)**；**L_fusion = ‖P_fus − I_gray‖₁ + ‖∇P_fus − T_grad‖₁ + (1 − SSIM(P_fus, I_gray))**，前两项锚定 RGB 外观、梯度项保留偏振结构。
- **门控损失**：**L_gate = ‖[w_D, w_A] − [w*_D, w*_A]‖²₂ + (γ − γ*)²**，离线目标由 26 维描述子（训练前提取、全程固定）构造；该描述子**从不输入门控或任何推理路径**。
- 总目标：**L_task = L_str(P_final, G) + 0.2·L_str(P_rgb, G) + 0.5·L_str(P_edge, G_edge)**；**L_total = L_task + 0.3·L_fusion + 0.3·L_gate**。
