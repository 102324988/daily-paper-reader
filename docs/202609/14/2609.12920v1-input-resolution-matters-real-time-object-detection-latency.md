## 摘要
我们在简化独立性近似下，将总延迟建模为预处理、推理和后处理分布的卷积，并将选定的阶段参数表示为源图像分辨率的函数。在该假设下，总延迟的概率密度是各阶段密度的卷积，其累积分布函数（CDF）给出了端到端检测时间的分布。每个阶段均用参数分布建模（例如指数分布、Erlang分布、正态分布、Gamma分布），其参数表示为源图像分辨率的函数。在NVIDIA Jetson Orin NX上使用YOLOv11n和多个分辨率的COCO2017图像进行实验，利用Kolmogorov Smirnov、Anderson Darling和Cramér von Mises统计量，将所提模型与固定参数基线进行评估比较。结果表明，在测量设置中，分辨率感知参数化可以改善分布近似，尤其是对于更灵活的正态分布和Gamma模型；但拟合质量仍取决于具体分布。我们的贡献是提出了一种具有理论依据且轻量的公式化方法，用于研究实测目标检测流水线中依赖分辨率的延迟分布。

## Abstract
We model total latency as the convolution of preprocessing, inference, and postprocessing distributions under a simplifying independence approximation, with selected stage parameters expressed as functions of source-image resolution. Under this assumption, the probability density of the total latency is the convolution of the stage-wise densities, and its cumulative distribution function (CDF) provides the distribution of end-to-end detection time. Each stage is modeled by a parametric distribution (e.g., Exponential, Erlang, Normal, Gamma), with parameters expressed as functions of the source-image resolution. Experiments with YOLOv11n on NVIDIA Jetson Orin NX using COCO2017 images across multiple resolutions assess the proposed models against fixed-parameter baselines using Kolmogorov Smirnov, Anderson Darling, and Cramér von Mises statistics. The results indicate that resolution-aware parameterization can improve distributional approximation in the measured setting, particularly for the more flexible Normal and Gamma models, while the quality of fit remains distribution dependent. Our contribution is a theoretically grounded and lightweight formulation for studying resolution-dependent latency distributions in a measured object detection pipeline.

## 1. 核心问题与整体含义

- **研究动机**：实时目标检测系统（自动驾驶、无人机、工业检测等）对延迟有严格要求，但现有文献多关注检测精度，延迟性能尤其是其**变异性与可预测性**研究不足。
- **背景痛点**：延迟通常仅以均值推理时间或平均 FPS 等标量指标报告，偶尔补充分位数或标准差，无法刻画延迟的随机行为，难以支撑细粒度性能分析与瓶颈定位。
- **关键观察**：以 YOLOv11n 为例，端到端延迟可分为预处理、推理、后处理三阶段。推理与后处理运行在固定尺寸内部张量上，延迟基本与源图像尺寸无关；而**预处理延迟随源图像分辨率显著变化**。
- **整体含义**：需要建立一种**分辨率感知的、阶段可分解的延迟分布模型**，而非将端到端延迟视为黑盒分布，从而为实时目标检测系统提供更准确的时延评估与部署决策依据。

## 2. 方法论

- **核心思想**：将总延迟 \(T\) 分解为三个阶段随机变量之和：
  \[
  T = T_{pre} + T_{infer} + T_{post}
  \]
  在**简化独立性近似**下，总延迟的概率密度为三阶段密度的卷积，累积分布函数（CDF）即端到端检测时间分布。
- **关键技术细节**：
  - 每个阶段用参数分布建模：**指数分布、Erlang 分布、正态分布、Gamma 分布**。
  - 分布参数 \(\theta(r)\) 可表示为源图像分辨率 \(r\) 的函数；若某参数与分辨率无相关性，则退化为常数。
  - 参数化形式示例：\(\lambda(r)=a_\lambda r+b_\lambda\)，\(\beta(r)=a_\beta r+b_\beta\) 等线性函数。
  - 正态分布具有闭包性质，三阶段正态之和仍为正态，均值与方差分别为各阶段参数之和。
- **算法/流程**：
  1. 在最低与最高锚点分辨率（\(r=320\) 与 \(r=1024\)）分别进行最大似然估计（MLE）拟合各阶段分布参数。
  2. 对锚点参数做线性回归，得到参数随分辨率变化的函数 \(\theta(r)\)。
  3. 对中间分辨率，用 \(\theta(r)\) 生成各阶段分布，再卷积得到总延迟分布。
  4. 用 CDF 型拟合优度指标与固定参数基线比较。
- **混合参数策略**：
  - 指数与 Erlang 族：预处理用分辨率相关函数，推理与后处理用固定两锚点参数。
  - 正态与 Gamma 族：预处理与推理用分辨率相关函数，后处理用固定两锚点参数。

## 6. 主要结论与发现

- **阶段延迟趋势**：
  - 推理阶段均值几乎不随分辨率变化（约 20.3–20.8 ms），因为 YOLOv11n 处理固定尺寸内部张量。

  - 原生 \(640\times640\) 时预处理延迟异常低（约 2.05 ms），因内部空间变换减少，但预处理阶段并未跳过。
- **独立性近似影响**：阶段间 Pearson 相关系数弱到中等，但忽略协方差会使总延迟方差低估 **10.2%–35.2%**，独立重组与观测总延迟的 KS 距离为 **0.039–0.137**。独立性仅作为可处理的近似保留。
- **拟合优度**：
  - 预处理阶段：分辨率感知参数化收益最明显，正态与 Gamma 分布表现最好；指数分布提升有限，Model 2 在某些范围更优；Erlang 在部分区间优于 Model 1，但 Model 2/3 在 \(704\times704\) 仍有竞争力。
  - 推理阶段：收益较小且不一致，参数化主要调整方差与分布形状，而非中心位置。
  - 端到端总延迟：在 **正态与 Gamma** 分布下，提出模型在 KS、CvM、AD 三项指标上均优于所有固定基线；在指数与 Erlang 下，Model 2/3 略优。
- **总体结论**：分辨率感知参数化能改善分布近似，尤其对更灵活的分布族；但拟合质量依赖具体分布选择与测量设置，不存在普适最优分布。
