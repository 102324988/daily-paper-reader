## 摘要
基于原型的局部模型通过将输入区域与学习到的原型进行比较来提供可解释的预测。然而，当前方法受限于复杂且多阶段的训练流程，并严重依赖辅助正则化来防止原型坍缩。为克服这些限制，我们提出了正交原型对齐学习（OPAL），一种单阶段、端到端的框架，简化了可解释分类。我们的方法使用预定义的正交基来锚定潜在空间，将每个类别嵌入到由固定部件原型张成的专用子空间中。为实现精确的部件定位，OPAL在特征图上强制进行空间竞争。该机制隔离出稀疏的判别性区域，引导每个原型在不同图像中始终关注相同的语义概念。通过将分类视为直接的表示对齐任务，我们的方法消除了对辅助损失的需求。在细粒度基准上的大量实验表明，OPAL优于其不可解释的对应方法以及最先进的部件原型方法，并通过明确揭示驱动每次预测的具体图像区域，提供细粒度的视觉解释。代码可在 https://github.com/ilancarretero/OPAL 获取。

## Abstract
Prototypical part-based models provide explainable predictions by comparing input regions to learned prototypes. However, current approaches are burdened by complex, multi-stage training pipelines and heavily rely on auxiliary regularization to prevent prototype collapse. To overcome these limitations, we introduce Orthonormal Prototype Alignment Learning (OPAL), a single-stage, end-to-end framework that simplifies interpretable classification. Our approach anchors the latent space using predefined orthonormal bases, embedding each class within a dedicated subspace spanned by fixed part-prototypes. To achieve precise part localization, OPAL enforces spatial competition across feature maps. This mechanism isolates sparse, discriminative regions, directing each prototype to consistently attend to the same semantic concept across different images. By framing classification as a direct representation alignment task, our method eliminates the need for auxiliary losses. Extensive experiments on fine-grained benchmarks demonstrate that OPAL outperforms both its non-interpretable counterparts and state-of-the-art part-prototype methods, delivering granular visual explanations by explicitly revealing the specific image regions driving every prediction. Code is available at https://github.com/ilancarretero/OPAL.

- **核心痛点**：现有可解释的原型部件模型（如 ProtoPNet 及其变体）普遍依赖**多阶段交替训练流程**（主干优化→原型聚类→投影），且需引入**聚类、分离、多样性等辅助正则化损失**来防止原型坍缩，导致超参调试复杂、训练成本高。
- **根本原因**：原型作为可学习参数存在于**持续漂移的潜空间**中，形成"移动目标"问题，模型难以同时学习判别性特征并使原型与之对齐。
- **既有方案局限**：
  - 部分方法（如 LucidPPN）依赖外部部件发现模型 PDiscoNet，引入预训练依赖；
  - 部分方法（如 MCPNet）牺牲原型粒度的可解释性；
  - post-hoc 方法无法修改冻结骨干的特征质量。
- **论文目标**：设计一种**单阶段、端到端、无辅助损失**的固有可解释分类框架，同时提升分类精度与部件级解释质量。

## 2. 方法论：OPAL 框架

### 2.1 核心思想

将"自由学习原型位置"转变为**在固定、结构化几何空间中的表征对齐**：每个类别被预先分配一个专用正交子空间，可解释性不是通过优化自由原型得到，而是源于输入表征与固定几何结构的直接对齐。

### 2.2 预定义正交子空间

- 设类别数为 C，每类原型槽数为 m，输出维度 K = C·m；
- 坐标集被划分为 C 个互不相交的块 Bc，每个块对应类别 c 的专属子空间 Sc；
- 类间子空间满足 Sc ⊥ Sc′（任意 c ≠ c′），保证最大类间分离；
- 每个类的 m 个部件原型 pc,j 取为**标准正交基方向** e_(c−1)m+j，单位范数且两两正交；
- 类别锚点 ac 定义为块内均匀向量（1/√m 倍的单位向量叠加），该设计偏好证据在正确的 m 个槽间**均匀分布**，而非集中于单一槽位。

### 2.3 空间竞争机制（部件定位）

- 骨干网络输出 F ∈ R^D×H×W，经 **1×1 卷积投影**至 K 通道 G；
- 在每个空间位置对 K 个通道执行 **Channel-wise Softmax（CWS）**，强制∑ₖ Aₖ(u,v)=1，实现"胜者全得"的通道间空间竞争，同一像素不能同时支持多个原型；
- 对每个通道执行**全局最大池化（GMP）**，得 s_k 及其唯一空间最大值位置 (u*, v*)；
- 堆叠后经 L2 归一化得嵌入 z = s/‖s‖₂ ∈ R^K——每个坐标可溯源至唯一的空间位置。

### 2.4 分类与训练

- 分类采用距离对齐：logit ℓc = −‖z − a_c‖²；由于 z 和 a_c 均 L2 归一化，欧氏距离等价于余弦相似度排序；
- 训练仅用**标准交叉熵损失**，无任何辅助正则化；锚点固定不参与学习；
- 整体为单阶段端到端优化。

### 2.5 推理与解释生成

- 预测类别 ˆy 自动选出对应块 B_ˆy 中的 m 个通道作为证据原型；
- 每个通道 GMP 记录的唯一最大响应坐标经线性缩放映射回原图分辨率，生成候选区域的定位框和对应的部件图块，即直接可视化的解释。

## 6. 主要结论与发现

1. **单阶段可行性得到验证**：固定正交子空间 + 空间竞争足以消除辅助正则化/多阶段训练的必要。
2. **性能超越不可解释基线**：
   - 在 45 组骨干-数据集实验中，OPAL 在 39 组上提升或持平对应 CNN 基线，平均提升 **+2.94** 个百分点；
   - 5 个细粒度数据集上平均提升 +1.56（ConvNeXt-Tiny 下），仅在少量配置出现 ≤1.0 的下降。
3. **在可解释模型中表现领先**：5/5 数据集中 4 个夺冠、1 个第三，是唯一在所有基准上一致超越非可解释骨干的固有可解释方法。
4. **正交锚定是性能提升核心**：消融显示加入正交锚定平均带来 +4.07 个百分点的提升；
5. **CWS 是防止原型坍缩的关键**：移除 CWS 后 SPC（空间原型坍缩分数）从接近 0 升至 72~94（越高越坍缩）；
6. **GMP 保证解释可溯源性**：移除 GMP 会破坏"每通道唯一最大值位置"的可信解释机制；
7. **m=5 为稳健操作点**：m=1 容量不足（低于基线 −1.04），m∈{3,5,10} 均能超越基线。

## 7. 方法优点

- **流程极致简化**：单阶段、端到端、无辅助损失、无外部模型、无预测后处理，与标准 CNN 训练复杂度同级；
- **理论动机扎实**：用极值几何结构（正交、最大分离）替代启发式的正则化约束，并提供命题证明（块均匀锚点偏好分布式证据、规范基的唯一性）；
- **解释天然可溯源**：每个原型通道经 GMP 与唯一空间位置绑定，且 1×1 投影通道与固定原型坐标一一对应，解释是从前向计算直接产出，非事后近似；
- **泛化性强**：跨 3 个骨干族 × 3 种规模均表现稳健，从不解释替换为解释不牺牲精度；
- **可解释性与精度同时提升**：几何约束不仅带来透明性，还通过消融证明其本身构成有效的表征学习归纳偏置；
- **分析工具完备**：提出 SPC 指标量化原型坍缩，补充一致性/稳定性（CUB）、多距离对比、效率分析等，验证充分。

## 8. 不足与局限

- **架构限制**：当前设计依赖 CNN 的局部性归纳偏置；作者自述拓展至 ViT 需要设计 token 级竞争与聚合机制，尚未实现；
- **原型分配僵化**：每类固定 m 个原型、类间不共享原型——类别复杂度差异大或属性跨类普遍出现时，表征效率受限；
- **数据集覆盖偏差**：
  - 全部为自然图像细粒度分类，未涵盖医学影像、遥感、X 射线等高风险应用场景；
  - 小样本/长尾分布场景未验证；
  - 原型质量量化依赖部件级标注，仅在 CUB 上验证；
- **少量性能回退**：45 组骨干实验中存在 6 组小幅下降（最大 −1.0），虽幅度小但说明并非所有设置中都严格占优；
- **潜力隐忧**：m=10 的定性分析显示部分原型开始关注背景等低语义区域，说明扩展原型槽存在边际收益递减问题；
- **算力透明度不足**：数十组实验（9 骨干 × 多数据集 × 多种子）仅交代 A100 单卡，未披露 GPU 总量与训练耗时，影响复现成本估算。
