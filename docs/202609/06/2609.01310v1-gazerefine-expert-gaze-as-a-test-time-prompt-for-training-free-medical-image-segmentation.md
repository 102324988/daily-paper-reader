## 摘要
医学图像分割仍难以规模化，因为高性能方法通常依赖密集的专家标注和特定任务的训练。我们引入GazeRefine，一个免训练框架，利用凝视作为推理时的提示，用于零样本医学图像分割。稀疏的、持续时间加权的注视点被转换为前景和背景先验，在冻结的DINOv3特征空间中初始化语义原型。这些原型通过前景-背景判别、特征空间亲和传播以及对初始凝视引导的锚定进行迭代细化，使分割能够扩展到直接注视区域之外，同时限制语义漂移。GazeRefine不需要分割掩膜、微调、适配器、提示编码器或梯度更新。我们在凝视标注的息肉分割和前列腺MRI分割上评估了该方法。结果显示，该方法在结肠镜图像上表现强劲，在前列腺MRI上具有竞争力，支持凝视引导的原型细化作为分割标签高效、人在回路的医学图像分割的一种有前景的方法。我们的工具和代码可在以下仓库中找到：https://github.com/MohammedOussamaBEN/GazeRefine.git

## Abstract
Medical image segmentation remains difficult to scale because high-performing methods typically rely on dense expert annotations and task-specific training. We introduce GazeRefine, a training-free framework that uses gaze as an inference-time prompt for zero-shot medical image segmentation. Sparse, duration-weighted fixations are converted into foreground and background priors that initialize semantic prototypes in frozen DINOv3 feature space. These prototypes are iteratively refined through foreground-background discrimination, feature-space affinity propagation, and anchoring to the initial gaze guidance, allowing segmentation to extend beyond directly fixated regions while limiting semantic drift. GazeRefine requires no segmentation masks, fine-tuning, adapters, prompt encoders, or gradient updates. We evaluate the method on gaze-annotated polyp segmentation and prostate MRI segmentation. The results show strong performance on colonoscopy images and competitive performance on prostate MRI, supporting gaze-guided prototype refinement as a promising approach for segmentation-label-efficient, human-in-the-loop medical image segmentation. Our tools and code can be found in the following repository: https://github.com/MohammedOussamaBEN/GazeRefine.git

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

- **核心思想**：利用眼科追踪的注视点（位置+时长）作为空间先验，在冻结的 DINOv3 特征空间中构建前景/背景原型（prototypes），然后通过迭代的细化和传播过程来生成密集分割掩膜，使分割结果超出直接注视的区域，同时避免语义漂移。
- **算法整体流程**（四个阶段）：
  1. **特征提取与凝视建模（Feature Extraction and Gaze Modeling）**
     - 使用冻结的 DINOv3 ViT-L/16 提取 l2 归一化的补丁嵌入 `{pi}`。
     - 将时长加权的凝视注视点转换为空间凝视热图 `H(u,v)`，并由高斯分布做空间扩展。
     - 将热图上采样映射到补丁网格，得到 `hi`，进而为每个补丁计算初始前景权重 `W_fg,i` 与互补的背景权重 `W_bg,i`。
  2. **凝视引导的原型初始化（Gaze-Guided Prototype Initialization）**
     - 通过**加权平均池化**计算初始前景原型 `F(0)` 与背景原型 `B(0)`，随后进行 l2 归一化。
  3. **凝视锚定的原型迭代精炼（Recurrent Gaze-Anchored Prototype Refinement）**
     - **置信度计算**：计算补丁与前景/背景原型的余弦相似度 `s_fg` 和 `s_bg`，定义非负前景置信度 `S_i = max(0, s_fg - s_bg)`。
     - **kNN 亲和传播（Affinity Propagation）**：基于特征空间中的 k 近邻，使用 softmax（温度 `τ`）作为权重对置信度进行传播，以提升空间连贯性。
     - **原型更新**：将传播后的置信度经 sigmoid 转换后作为下一轮的前景权重，分别更新前景和背景原型。
     - **锚定（Anchoring）**：通过线性插值（`λ`）将新原型与初始凝视锚定原型混合，以限制语义漂移。迭代直到收敛或达到上限 `T` 次。
  4. **最终掩膜生成（Final Mask Generation）**
     - 返回最后一轮迭代的响应图 `S(T*)`，上采样到原图分辨率并归一化。
     - 以固定阈值 `θ=0.5` 进行二值化生成最终分割掩膜。

该方案不依赖任何图像分割标签、梯度回传、任务特定微调、适配器或提示编码器，学习过程完全为零参数。
