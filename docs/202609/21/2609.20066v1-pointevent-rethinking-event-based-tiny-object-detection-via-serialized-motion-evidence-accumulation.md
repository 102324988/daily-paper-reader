## 摘要
事件相机为微小无人机检测提供了高时间分辨率和运动敏感性，但远距离目标产生的事件稀疏且碎片化，容易被杂波和自运动淹没。现有方法主要依赖稠密事件表示或局部稀疏时空建模，导致冗余计算，或对远距离异步事件之间的运动连续性进行碎片化建模。为解决这一局限，我们引入序列化运动证据积累，将运动连续性视为有序的证据传播过程。具体而言，同一事件流通过潜在的互补序列化，被组织为保持局部性的时空路径和保持时间顺序的时间路径。基于这一原理，我们提出 PointEvent，一种轻量级的逐事件状态空间框架，在互补顺序之间交替进行序列化扫描，逐步整合超出固定局部邻域的碎片化运动证据。高分辨率事件分支保留细粒度目标响应，而紧凑的上下文调制抑制干扰。实验表明，PointEvent 在对比方法中以最少的参数和最快的实测推理速度达到了 SOTA。代码：https://github.com/wzz-z/PointEvent

## Abstract
Event cameras offer high temporal resolution and motion sensitivity for tiny UAV detection, yet distant targets generate sparse and fragmented events that are easily overwhelmed by clutter and ego-motion. Existing methods mainly rely on dense event representations or local sparse spatiotemporal modeling, resulting in redundant computation or fragmented modeling of motion continuity across distant asynchronous events. To address this limitation, we introduce serialized motion evidence accumulation, which treats motion continuity as an ordered evidence propagation process. Specifically, the same event stream is organized into locality-preserving spatiotemporal paths and chronology-preserving temporal paths through the latent complementary serializations. Based on this principle, we propose PointEvent, a lightweight event-wise state-space framework that alternates serialized scans across the complementary orders, progressively consolidating fragmented motion evidence beyond fixed local neighborhoods. A high-resolution event branch preserves fine-grained target responses, while compact context modulation suppresses interference. Experiments demonstrate that PointEvent achieves SOTA with the fewest parameters and fastest measured inference among the compared methods. Code: https://github.com/wzz-z/PointEvent

## 1. 核心问题与整体含义

- **研究背景**：微小无人机检测对反无人机感知与低空安全很重要。远距离 UAV 在图像中只占少量像素，帧相机易受复杂背景、运动模糊和极端光照影响。
- **事件相机的优势与困难**：事件相机具有微秒级时间分辨率、高动态范围和低延迟，但远距离小目标只产生稀疏、微弱、碎片化事件，容易被背景杂波、传感器噪声和相机自运动淹没。
- **现有方法局限**：
  - 稠密表示（事件帧、Time Surface、Voxel Grid 等）会量化异步时间戳，并在非活跃区域产生冗余计算。
  - 局部稀疏时空建模（如 x-y-t 空间中的稀疏聚合）面临“时空感受野困境”：小邻域会割裂弱目标轨迹，大邻域会引入杂波。
  - 直接分离空间与时间建模虽可缓解，但会削弱区分目标与噪声所需的 x-y-t 耦合运动模式。
- **整体含义**：论文提出“序列化运动证据积累”新范式，将运动连续性视为有序的证据传播过程，而不是依赖固定局部邻域或稠密表示。

## 2. 方法论

- **核心思想**：对同一事件流构造互补的序列化顺序：
  - **保局域时空路径**：保持局部 x-y-t 运动连续性。
  - **保时序时间路径**：保留异步事件的时间演化。
  - 通过交替扫描这些顺序，让弱目标事件沿不同路径交换信息并逐步积累运动证据。
- **输入与任务**：输入事件集 \(E=\{e_i\}_{i=1}^N\)，每个事件 \(e_i=(x_i,y_i,t_i,p_i)\)。任务为事件级二分类预测：\(\hat p_i=P(\text{class}_i=1|E)\)。
- **多序序列化**：
  - 将事件分配到离散 cell：\(c_i=(\lfloor x_i/s_x\rfloor,\lfloor y_i/s_y\rfloor,\lfloor t_i/s_t\rfloor)\)。
  - 使用 Z-order、Hilbert-order 及其转置等构造时空顺序；使用升序和降序时间戳构造时间顺序。
  - 给定事件特征 \(F\) 和扫描顺序 \(\pi\)，序列化为 \(F_\pi=[f_{\pi(1)},...,f_{\pi(N)}]^\top\)，处理后通过逆序恢复原事件索引。
- **Event Coordinate Embedding, ECE**：
  - 融合三类输入：时空坐标 \([x_i,y_i,t_i]\)、极性感知坐标 \([x_i,y_i,p_i]\)、轻量 transition cue \(q_i=[\Delta t_i,p_i p_{i-1},\exp(-\Delta t_i/\bar{\Delta t})]\)。
  - 通过门控残差注入极性与局部连续性线索，同时保留基础几何坐标。
- **Serialized Evidence Block, SEB**：
  - 包含 Anisotropic Curve Positional Encoding, ACPE、序列化状态空间扫描和前馈网络。
  - ACPE 使用空间稀疏卷积分支和时间稀疏卷积分支，并通过通道门自适应融合，注入局部曲线先验。
  - 序列算子采用 Mamba 风格选择性状态空间模型：\(s_n=A_n s_{n-1}+B_n z_n\)，\(\hat z_n=C_n s_n+D z_n\)。
  - 展开后 \(s_n=\sum_{m=1}^n \Phi_{n,m}B_m z_m\)，隐藏状态被视为沿选定顺序的可学习证据累积器。
  - 不同 SEB 不共享 SSM 参数，扫描顺序只决定传播路径；每个块学习自己的证据累积动态。
- **整体架构**：
  - **Event-Level Evidence Branch**：保持原始事件级分辨率，默认 2 个 SEB、8 通道，保留弱目标响应。
  - **Compact Context Branch**：对事件按粗化时空编码分组，池化 stride 为 2，使用 max 和 mean 聚合，默认 2 个 SEB、16 通道，以低计算代价聚合广域运动证据。
  - **Gated Context Fusion**：将上下文特征按保存的池化分配映射回事件级 token，并用门控残差融合：\(f_i^{fuse}=f_i^e+\sigma(\phi_g([f_i^e;c_{\rho(i)}]))\odot\phi_c(c_{\rho(i)})\)。
  - **Context-Guided Refinement Stage**：默认 4 个 SEB、8 通道，进一步整合上下文引导的运动证据。
  - 最后通过轻量二分类头输出事件级概率。
- **训练目标与复杂度**：
  - 使用加权二分类交叉熵，权重 \((\lambda_0,\lambda_1)=(1,15)\) 缓解严重类别不平衡。
  - 状态空间扫描复杂度为 \(O(NCd_s)\)，在事件数上线性；默认状态维度 \(d_s=16\)，扩展比 2，深度卷积核 5。
