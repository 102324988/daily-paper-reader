## 摘要
开放词汇伪装目标分割（OVCOS）旨在在文本引导下分割未见过的伪装目标。我们观察到，在 OVCOS 中，SAM3 仍然存在全局文本语义与细粒度像素级视觉线索之间明显的语义鸿沟。同时，完全微调文本编码器会引入沉重的参数开销，并存在对训练类别过拟合的风险，从而损害开放词汇表示的灵活性。为解决这些问题，我们提出了 ViCo-SAM3，一个专为 OVCOS 设计的视觉条件对齐框架。具体而言，我们引入视觉条件（ViCo）模块，该模块利用全局视觉上下文动态调制文本嵌入，使文本表示能够适应当前图像内容，从而有效弥合视觉与文本之间的语义鸿沟。在此基础上，我们进一步设计了视觉条件跨模态绑定（ViCoBind）模块，以增强跨模态交互以及视觉与文本表示之间的语义对齐。无需额外技巧，ViCo-SAM3 在 OVCamo 基准上取得了最先进的性能，并展现出强大的泛化能力。

## Abstract
Open-vocabulary camouflaged object segmentation (OVCOS) aims to segment unseen camouflaged objects under text guidance. We observe that SAM3 still suffers from a pronounced semantic gap between global textual semantics and fine-grained pixel-level visual cues in OVCOS. Meanwhile, fully fine-tuning the text encoder introduces heavy parameter overhead and risks overfitting to training categories, which compromises open-vocabulary representation flexibility. To address these issues, we propose ViCo-SAM3, a Vision-Conditioned alignment framework designed for OVCOS. Specifically, we introduce vision-conditioned (ViCo) module, which dynamically modulates text embeddings with global visual context, enabling textual representations to adapt to the current image content and thereby effectively bridging the semantic gap between vision and text. Building on this, we further design a vision-conditioned cross-modal binding (ViCoBind) module to enhance cross-modal interaction and semantic alignment between visual and textual representations. Without bells and whistles, ViCo-SAM3 achieves state-of-the-art performance on the OVCamo benchmark and demonstrates strong generalization.

- **现状与痛点**：SAM3 等基础模型虽具备较强的开放词汇分割能力，但直接迁移到 OVCOS 存在两个问题：

- **核心矛盾**：OVCOS 中存在一个根本性权衡——**既要让语义表示适配歧义的伪装场景，又要保留预训练继承的开放词汇知识**。
- **整体含义**：论文提出 ViCo-SAM3，主张**不改动预训练文本编码器本身**，而是让文本表示在当前视觉上下文的条件下被动态调制，从而在保持原有开放词汇表示空间的前提下弥合视觉—文本语义鸿沟。

## 2. 方法论

### 2.1 核心思想
在 SAM3 的编码器与解码器之间插入两个轻量模块：**ViCo**（视觉条件文本调制）与 **ViCoBind**（视觉条件跨模态绑定），在不微调文本编码器的前提下实现视觉自适应的文本表示与双向跨模态对齐。

### 2.2 整体流程
1. 用 SAM3 的视觉编码器与**冻结**的文本编码器分别提取视觉特征 `Fv` 与文本特征 `Ft`；
2. `Fv`、`Ft` 输入 **ViCo** 模块，得到视觉自适应的文本特征 `F′t`；
3. `F′t`、`Fv` 以及由 SAM3 Neck 从 `Fv` 导出的位置特征 `P` 输入 **ViCoBind**，得到融合表示 `M`；
4. `M` 送入 SAM3 解码器输出最终分割预测。

### 2.3 ViCo 模块（关键技术细节）
- **全局视觉上下文提取**：对 `Fv` 先用 BConv 3×3（3×3 卷积 + BN + ReLU）增强局部表示，再用注意力池化（AP）聚合得到全局视觉表示 `Fgv`。
- **环境表示构造**：将池化结果与残差视觉分支 `R(Fv)` 相加，经轻量线性映射 `φe` 投影为紧凑的环境表示 `Venv`，用于概括当前图像的全局视觉上下文。
- **视觉条件门控**：将 `Ft` 与 `Venv` 拼接，经可学习投影 `φg` 与 Sigmoid 得到门控权重 `G`；语义偏移量 `ΔFt = G ⊙ Venv`（逐元素乘）。
- **残差注入**：`F′t = Ft + ΔFt`，即用残差方式把视觉条件偏移注入原始文本特征，保留原表示空间。

### 2.4 ViCoBind 模块
- **位置先验注入**：`Fpv = Fv ⊙ P`，得到位置感知的视觉表示。
- **分支编码**：`F′t` 经自注意力得到 `Qt, Kt, Vt`；`Fpv` 经 1×1 卷积投影得到 `qv, kv, vv`。
- **双向跨模态注意力**：
  - 视觉 query 关注文本 key/value：`F̂v = Softmax(qv Ktᵀ/√d) Vt`，为每个空间位置注入语义引导；
  - 文本 query 关注视觉 key/value：`F̂t = Softmax(Qt kvᵀ/√d) vv`，使文本表示捕获图像特有的视觉证据。
- **残差保留**：`F*v = Fpv + F̂v`，`F*t = F′t + F̂t`，保留单模态原始信息。
- **迭代与融合**：上述双向交互重复 `L` 层，实现渐进式信息交换；最终 `M = FFN(Fuse(F*t, F*v))`，送入 SAM3 解码器做掩码预测 `P̂`。

### 2.5 训练损失
- 沿用已有方法，采用**二元交叉熵（BCE）+ 加权 IoU** 的组合损失。

## 6. 主要结论与发现

- **SAM3 直接用于 OVCOS 存在明显语义鸿沟**：零样本 SAM3 的 cIoU 仅 0.552，虽强于此前方法，但仍受限于跨模态语义不匹配。
- **视觉条件适配有效**：引入 ViCo 后 cIoU 从 0.695（微调文本编码器）提升至 0.767，cFm 从 0.656 提升至 0.854，说明用图像特定视觉上下文动态调制文本表示能够显著缓解语义歧义。
- **双向跨模态绑定带来进一步增益**：加入 ViCoBind 后取得最佳整体性能（cSm 0.889、cIoU 0.773），在 cFm 与 cEm 上的提升表明区域判别能力与结构对齐能力增强。
- **增益源于视觉条件适配而非提示工程**：提示消融显示，默认提示 0.761、类别无关提示 0.765、伪装感知提示 0.744，均低于完整模型 0.773；且 ViCo 与类别无关提示结合时性能反而下降到 0.743，说明视觉条件适配仍需**有意义的类别语义作为语义锚点**。

## 7. 局限性与潜在问题（基于论文已披露信息的推断）

- **评测覆盖面偏窄**：仅在 OVCamo 单一基准上验证，缺少在传统伪装数据集（CAMO、CHAMELEON、COD10K 等）以及通用开放词汇分割基准（如 Pascal-VOC / COCO 的开放词汇划分、ADE20K-OV）上的交叉验证，无法判断该方法是否对"伪装"这一特定属性有强依赖，也难以排除数据集特定偏置带来的增益放大。
- **核心论点的量化证据链不完整**："冻结文本编码器优于微调"这一主张的直接对照（微调文本编码器 vs. ViCo 视觉条件调制）在消融中虽给出了 cIoU（0.695 → 0.767），但"灾难性遗忘"的具体表现——即微调后在**未见类别**上的性能退化曲线、语义空间偏移的定量度量（如与原始 CLIP 文本嵌入的相似度保持率）——并未提供，论证更多依赖直觉与单张热力图。
- **ViCo 的设计存在信息瓶颈**：环境表示 `Venv` 由全局注意力池化得到，本质上是**单向量**的全局视觉上下文。当同一图像中包含多个伪装实例、或前景与背景在全局统计上高度相似时，单一全局门控可能不足以产生充分的、位置差异化的语义偏移。论文未讨论多实例/密集场景下的行为。
- **门控机制的稳定性未评估**：`ΔFt = G ⊙ Venv` 的幅度完全由 Sigmoid 门控决定，且 `Venv` 与 `Fgv` 共享池化来源。论文未报告门控值的分布、是否出现门控饱和（全 0 或全 1）或训练不稳定现象，也未说明该设计对学习率/初始化是否敏感。
- **对语义锚点的依赖构成双刃剑**：结论指出"类别无关提示（a photo）"配合 ViCo 反而使性能下降（0.743 < 0.773），这说明方法**并未真正实现"无提示"的开放词汇能力**，仍需要用户提供有区分度的类别名词。在类别名本身具有歧义（如"animal""object"）或类别体系超出预训练词汇覆盖时，方法的表现缺乏分析。
- **效率与部署成本未量化**：ViCo 与 ViCoBind 引入的额外参数、推理时延、显存增量均未报告。考虑到 SAM3 本身是重型基础模型，附加双向跨模态注意力（且重复 `L` 层）的边际成本是否可接受，对实际部署决策至关重要，目前无法评估。
- **骨干绑定性**：整个流程依赖 SAM3 的 Neck 输出位置特征 `P` 以及其解码器接口，方法的通用性（能否迁移至 SAM2、SEEM、其他掩码解码器）未被验证，跨骨干的鲁棒性未知。

## 8. 方法启示与可迁移价值

- **"调制而非重训"的范式**：论文最具迁移价值的思想是——面对领域偏移时，**保持预训练语义编码器冻结，用轻量条件模块在特征空间中施加残差式偏移**。这一思路可直接迁移到开放词汇检测、指代分割（RES）、开放词汇语义分割、乃至多模态检索等领域，用于在保留预训练泛化性的同时注入任务/域特定上下文。
- **残差式视觉条件注入（`F′t = Ft + ΔFt`）**：以加法残差而非替换方式修改文本表示，理论上保证了 `ΔFt → 0` 时模型退化为原始 CLIP/SAM3 文本编码器，是一种"安全"的适配设计，可解释性与可控性优于直接微调。
- **位置先验与语义的双向绑定**：ViCoBind 中"视觉 query 取文本 value / 文本 query 取视觉 value"的双向注意力，实质上是把跨模态对齐从单向（文本引导视觉）扩展为互相校正。该结构与"提示工程 vs. 特征适配"的消融设计，为同类工作提供了可复用的实验范式——**即通过类别无关提示作为下界控制，隔离提示贡献与架构贡献**。
- **对 SAM 系基础模型落地 OVCOS 的提示**：结果暗示 SAM3 的零样本能力已显著高于专用伪装分割方法（cIoU 0.552 vs. OVCoser 0.443、BaClip 0.488），说明**在基础模型之上做轻量适配，可能比从零设计专用架构更高效**，这一趋势对后续研究具有方向性意义。

## 9. 总体评价

- **贡献层面**：论文针对 OVCOS 中"语义适配 vs. 知识保持"这一真实存在的权衡，提出了一个动机清晰、结构简洁的解决方案。ViCo（视觉条件文本调制）与 ViCoBind（双向跨模态绑定）两个模块职责分明，分别对应"表示适配"与"对齐增强"，且都建立在"不破坏预训练表示空间"的设计约束下，问题定位准确。
- **实验层面**：主实验指标领先幅度明显（cIoU 0.773 vs. 次优 0.488，提升幅度超 58%），提示策略消融的设计尤其值得肯定——它主动排除了"仅靠提示词调优即可取得增益"的替代解释。但整体实验的**广度与严谨度仍偏弱**：单数据集、单骨干、无方差报告、无效率指标、缺少关键对照（如"微调 + ViCo"），使得结论的外部有效性（external validity）有待加强。
- **写作与可复现性**：训练超参（384×384、AdamW、bs=4、lr=3e-5、30 epoch、单卡 4090）披露充分，具备基本可复现条件；但损失函数仅笼统描述为"BCE + 加权 IoU"，权重设置、`L` 的取值、各模块通道维度等关键实现细节缺失，复现仍需依赖代码补充。
- **综合判断**：这是一篇**方法直觉好、工程实现轻、初步结果亮眼，但实验验证尚不充分**的工作。其核心思想（冻结语义编码器 + 视觉条件残差调制 + 双向绑定）具备较强的通用性与后续扩展潜力；若能在多数据集、多骨干、含效率指标与消融完备性上补齐验证，工作价值将显著提升。就当前证据强度而言，结论方向可信，但"显著优于"这一判断仍需更严格的统计与跨域验证支撑。
