## 摘要
现实世界中的检测器常常必须解释功能性或模糊的提示，而YOLO等传统模型仍局限于固定的类别列表。即使像YOLO-World这样的开放词汇模型，也经常将模糊语言与目标对象错误对齐。基于我们先前的工作《Commonsense-Guided Open-World Object Detection Using LLMs and Visual-Semantic Matching》，我们针对YOLO-World在将任务驱动查询进行视觉落地方面的局限性展开研究。我们提出Vague2Detect，一个混合流水线，其中经过微调的Sentence-BERT从结构化家庭知识库（KB）中检索候选，YOLO-World则验证这些候选是否存在于图像中。对于知识库之外的提示，大语言模型（GPT-3.5-turbo）生成候选描述，动态扩展KB以覆盖新概念。在使用自定义图像和Open Images V7子集构建的家庭场景基准上，单独使用YOLO-World仅达到32%的模糊提示成功率（VPSR），即把模糊查询映射到正确检测结果的能力。相比之下，Vague2Detect将性能提升至61% VPSR且保持高精确率，并在加入GPT回退机制后最高可达85%。

## Abstract
Real-world detectors must often interpret functional or ambiguous prompts, yet conventional models such as YOLO remain restricted to fixed class lists. Even open-vocabulary models like YOLO-World frequently misalign vague language with the intended objects. Building on our prior work Commonsense-Guided Open-World Object Detection Using LLMs and Visual-Semantic Matching, we address YOLO-World's limitations in grounding task-driven queries. We propose Vague2Detect, a hybrid pipeline in which a fine-tuned Sentence-BERT retrieves candidates from a structured household Knowledge Base (KB), and YOLO-World verifies their presence in the image. For prompts outside the KB, a large language model (GPT-3.5-turbo) generates candidate descriptions, dynamically expanding the KB to cover novel concepts. On a benchmark of household scenes using custom images and an Open Images V7 subset, YOLO-World alone achieves only 32% Vague Prompt Success Rate (VPSR), the ability to map ambiguous queries to correct detections. In contrast, Vague2Detect improves performance to 61% VPSR with high precision, and up to 85% when augmented with GPT fallback.

# Vague2Detect 论文深度总结

## 1. 核心问题与研究动机

- **背景痛点**：真实世界的目标检测器需要理解功能性或模糊的提示（如“用来装剩菜的东西”指容器，“用来喝水的”指杯子），但传统检测器（如 YOLO 系列）受限于固定类别列表，无法处理此类查询。
- **开放词汇模型的局限**：即便 YOLO-World 等开放词汇模型引入了视觉-语言对齐，它们仍假设查询是明确的物体标签或近似同义词，面对功能性/可供性（affordance）驱动的模糊提示时，常将语言与目标对象错误对齐。
- **基准缺失**：COCO 等标准基准聚焦类别标签，不评估功能性语言，因此模型可在 COCO 上取得高 mAP，却在间接表述的查询上失效。
- **研究定位**：本文是作者先前工作（Commonsense-Guided Open-World Object Detection Using LLMs and Visual-Semantic Matching）的扩展。先前系统仅在模糊提示能映射到 KB 已有对象时成功，且存在 KB 无法推理时扩展、未微调 BERT 检索差、多模型并行计算开销大等缺陷。Vague2Detect 针对更难的可供性驱动提示场景，引入微调 SBERT 的语义落地，并提出新基准与指标。

## 2. 方法论

### 2.1 核心思想
构建一个混合流水线，将**符号知识（KB）**、**语义检索（微调 SBERT）**与**视觉验证（YOLO-World）**结合，并辅以 **GPT 回退**实现知识库的动态扩展。用户查询先经 SBERT 编码，从 KB 检索最相关对象；若相似度超过阈值 τ，则交给 YOLO-World 验证；否则触发 GPT 回退生成新候选并经验证后加入 KB。

### 2.2 知识库构建
- 聚焦家庭场景（水槽、肥皂、冰箱、微波炉、牙刷等）。
- 使用 **GPT-5** 为 100+ 物体生成条目，每条包含两个字段：
  - **Visual Description**：外观描述（如“带手柄的锋利金属刀刃”）。
  - **Usage Description**：功能说明（如“用于切割和切片食物”）。
- **模糊提示语料**：构建约 500 条 prompt–object 配对，每个 KB 物体配 5 条模糊但语义相关的提示，措辞有意区别于 KB 原文。该语料仅用于微调，之后丢弃以防数据泄漏；测试时 KB 仅含规范条目，嵌入预先计算。

### 2.3 语义相似度编码器（SBERT）
- **基线**：BAAI/bge-base-en-v1.5，输出 768 维嵌入。
- **相似度计算**：余弦相似度  
  \(S(q, d_o) = \frac{enc(q) \cdot enc(d_o)}{\|enc(q)\| \|enc(d_o)\|}\)，预测对象为 \(o^* = \arg\max_o S(q, d_o)\)。
- **微调**：以 bge-base-en-v1.5 初始化，加分类头（输出单元数等于 KB 规模），交叉熵损失，Hugging Face Trainer API。批大小 2，学习率 2×10⁻⁵，权重衰减 0.01，10 个 epoch，fp16 混合精度，按准确率和 macro-F1 在 20% 留出集上选模型。
- **推理**：若最大相似度 \(S_{max} = \max_o S(q, d_o)\) 超过阈值 τ（设为 0.6），接受该对象；否则触发回退模块。

### 2.4 视觉验证（YOLO-World）
- 使用 YOLO-World（YOLOv8 的开放词汇扩展，CLIP 文本编码器），不微调。
- 若 SBERT 置信度高（\(S_{max} \geq \tau\)），仅检查 top-1 候选；若置信度低，检查 top-k（如 k=3）候选。
- YOLO-World 检测阈值 0.25：若至少一个边界框被检出，返回最高置信度结果；否则触发 LLM 回退。
- 该步骤防止语义错误（如 SBERT 建议画笔但图像中不存在，则允许回退建议钢笔/铅笔）。YOLO-World 实时运行（约 50 FPS），计算开销相比 GPT 调用可忽略。

### 2.5 GPT 回退机制
- 当提示无法映射到任何 KB 条目时，调用 **GPT-3.5-Turbo**。
- **Prompting 要求**：(i) 推断 1–3 个具体物体候选；(ii) 为每个候选提供 visual_description 和 usage；(iii) 以 JSON 格式返回。
- **集成**：JSON 解析后合并入 KB，永久扩展以供未来查询；拒绝格式错误或非 JSON 响应。
- **验证**：新条目不盲信，每个候选都经 YOLO-World 视觉验证，仅保留当前图像中检测到的对象，防止幻觉性 KB 扩展。

## 3. 实验设计

### 3.1 数据集与 Benchmark
- 构建约 **1000 张图像**、涵盖 **60 个家庭物体类别** 的基准。
- 数据来源：**Open Images** 样本 + 作者自采室内环境照片。
- 每条数据包含原始图像、目标物体标签、边界框标注。
- 类别分为两组：
  - **In-KB objects**：KB 中明确表示的类别（如水槽、微波炉、牙刷）。
  - **Out-of-KB objects**：KB 中缺失的类别（如音箱、坚果夹），需 GPT 回退。

### 3.2 评估指标
- **Class accuracy (Cls.Acc) / VPSR**：检索类别与真值匹配，衡量模糊提示成功落地的比例。
- **Detection accuracy (Det.Acc)**：预测框与真值 IoU ≥ 0.5，衡量视觉定位能力。

### 3.3 对比方法（Baselines）
| 配置 | 描述 |
|---|---|
| YOLO-World baseline | 无 KB 或语义落地，直接检测 |
| SBERT (fine-tuned) + YOLO-W | 微调 SBERT 检索候选，YOLO 验证 |
| Full pipeline (with GPT) | 加入 LLM 回退，支持 KB 扩展 |

### 3.4 主要结果
| 配置 | VPSR (%) | Det.Acc (%) |
|---|---|---|
| YOLO-World baseline | 32 | 29 |
| SBERT (fine-tuned) + YOLO-W | 61 | 61 |

### 3.5 定性结果
- **KB 内成功落地**：“I want to wash my hands” → sink，经 YOLO-World 验证。
- **未见概念泛化**：“I want to play some music” → GPT 生成 speaker，加入 KB 并被检测。
- **失败模式**：细粒度区分（盐 vs 胡椒）、小/遮挡物体、多有效答案的提示；如“I need something to cut with”，YOLO-World 无响应，vanilla SBERT 混淆 knife/peeler，微调后正确映射为 knife。

## 6. 主要结论与发现

- 单独 YOLO-World 在模糊提示上表现差（32% VPSR，29% Det.Acc），证实开放词汇模型难以处理功能性查询。
- 微调 SBERT 显著提升语义落地能力（61% VPSR / 61% Det.Acc），说明针对家庭可供性微调对模糊提示检索至关重要。
- 加入 GPT 回退后达到 **85% VPSR / 83% Det.Acc**，表明 LLM 回退可有效扩展覆盖范围至未见概念，同时保持视觉验证。
- 模块互补：SBERT 改善功能落地，YOLO-World 确保视觉验证，GPT 回退实现动态知识扩展。
- 总体表明检测可“从识别物体是什么”迈向“推理为什么需要它”，为可供性驱动、任务导向的感知系统开辟方向。

## 7. 优点

- **混合架构设计合理**：符号 KB + 神经检索 + 视觉验证 + LLM 回退，各组件职责清晰，兼顾可解释性、效率与可扩展性。
- **动态 KB 扩展且防幻觉**：GPT 生成的新条目必须经 YOLO-World 视觉验证后才入库，避免盲目接受 LLM 输出。
- **提出新指标 VPSR**：填补了功能性/模糊提示评估的空白，弥补 COCO 等基准不评估间接语言的缺陷。
- **SBERT 微调语料设计巧妙**：提示措辞有意区别于 KB 原文，促进模型泛化而非记忆；语料用后即弃，防止数据泄漏。
- **计算效率优化**：相比先前工作（同时运行 YOLOv8、CLIP、LLaVA、GPT-4），本方案仅用 YOLO-World + 单一 LLM 回退，更轻量；KB 嵌入预计算，YOLO-World 实时运行。
- **定性示例具体**：附录提供 speaker、knife、sink 三个完整系统日志，可复现性强。

## 8. 不足与局限

- **KB 规模有限**：约 100 个家庭物体，跨领域覆盖不足，限制在多样化场景的适用性。
- **细粒度错误**：视觉相似类别易混淆（如盐 vs 胡椒），小物体或遮挡物体检测困难。
- **GPT 回退成本**：虽仅在 out-of-KB 时触发，但仍增加计算开销与外部 API 依赖。
- **基准自建、规模偏小**：约 1000 张图、60 类，未在公开标准 OVD 基准上验证，泛化性存疑；自建基准可能存在选择偏差。
- **缺乏与主流方法对比**：未与 ViLD、Detic、GLIP、CoT-Det 等方法进行数值对比，难以判断相对先进性。
- **细节不一致**：SBERT 微调的超参数（epoch 数、学习率）在 3.2 节与 5.1 节描述不一致，影响可复现性。
- **未报告统计显著性**：无方差、置信区间或显著性检验，结果稳健性未知。
- **模糊提示的多答案问题**：对存在多个合理答案的提示（如“cut with”），系统难以处理歧义。
- **未来方向**：扩大 KB 至更广领域、探索轻量适配器替代 GPT 回退、引入时空与常识推理、扩展到机器人可供性感知场景。
