## 摘要
目标检测器在多个领域（包括医学影像、监控和自动驾驶）中已展现出卓越性能。然而，在实际部署中遇到未见过的物体时，它们容易过度自信，从而可能引发安全问题。为解决这一问题，检测分布外（OOD）物体对于可靠的目标检测至关重要。现代方法利用 CLIP 等基础模型广泛的语义知识，进行事后少样本和零样本 OOD 检测。然而，这些方法通常在特征空间中进行 OOD 评估，这可能对目标检测器的定位误差和物体外观变化较为敏感。此外，当前最先进（SOTA）的零样本方法在推理时需要计算成本高昂的扩散过程。在本工作中，对于我们所提出的零样本目标 OOD 检测方法 SAM3-O2D2，我们以高效的方式使用 SAM3-Image 基础模型。具体来说，我们仅用目标检测器预测的类别来提示 SAM3，并比较目标检测器和 SAM3 的预测结果。如果 SAM3 也在相应位置检测到物体，则该物体为分布内（ID）。如果 SAM3 未检测到所提示的物体，则表明检测器的预测与图像内容之间存在不匹配，说明该物体是 OOD。实验结果表明，我们的方法显著超越了迄今为止的零样本 SOTA 方法。具体而言，我们在 ID 数据集 Pascal-VOC 和 BDD100K 以及 OOD 数据集 MS-COCO 和 OpenImages 上均取得了新的 SOTA AuROC 和 FPR95 指标。

## Abstract
Object detectors have shown remarkable performance in various fields, among these medical imaging, surveillance, and autonomous driving. However, they are prone to overconfidence when encountering unseen objects in real-world deployments, causing potential safety issues. To address this, detecting out-of-distribution (OOD) objects is essential for reliable object detection. Modern approaches leverage the broad semantic knowledge of foundation models such as CLIP for post-hoc few- and zero-shot OOD detection. However, these methods typically perform OOD assessment in feature space, which can be sensitive to object detector localization errors and variations in object appearance. Moreover, the current state-of-the-art (SOTA) zero-shot method performs computationally costly diffusion in inference. In this work, for our proposed zero-shot object OOD detection method SAM3-O2D2, we employ the SAM3-image foundation model in an efficient manner. Specifically, we prompt SAM3 only with the object detector's predicted classes and compare the predictions of the object detector and SAM3. An object is in-distribution (ID), if SAM3 also detects an object at the corresponding location. If SAM3 does not detect the prompted object, this indicates a mismatch between the detector's prediction and the image content, suggesting that the object is OOD. Experimental results show that our method significantly surpasses the so-far zero-shot SOTA method. Specifically, we achieve new SOTA AuROC and FPR95 metrics over both ID datasets Pascal-VOC and BDD100K and both OOD datasets MS-COCO and OpenImages.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务定位**：论文研究**目标级分布外（Object-level OOD）检测**，即对目标检测器输出的每一个预测物体，独立判定其为分布内（ID, ✓）还是分布外（OOD, ✗）。这与整图级 OOD 检测不同，更贴合自动驾驶等场景中"一图多物、需分别评估"的真实需求。
- **问题根源**：目标检测器仅在闭集 ID 类别上训练，部署时遇到未见物体容易**过度自信**，带来安全隐患（医疗影像、监控、自动驾驶等）。
- **现有方法的局限**：
  - 传统方法（VOS、SIREN、SAFE 等）需在 ID 全量训练数据上训练附加模块，且每换一个检测器都要重训；
  - 少样本方法（RUNA、UNI-OOD）借助 CLIP，但每个 ID 数据集仍需微调额外模块；
  - 当前零样本 SOTA 方法 **RONIN** 用类别条件扩散模型对目标区域做 inpainting，再在 CLIP 特征空间比较相似度——**计算代价高**（迭代扩散），且**特征空间相似度对检测框定位误差、物体外观（尺寸、光照）变化不鲁棒**，判定依据也不易解释。
- **论文主张**：换用另一类基础模型 **SAM3-image**，把 OOD 判定从"抽象特征空间"搬到"**预测层面（detection space）**"，实现**免训练、免微调、低算力、可解释**的零样本目标 OOD 检测。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 用目标检测器预测的**类别文本**作为提示（prompt）去调用 SAM3-image 检测器；若 SAM3 在**同一位置、同一类别提示**下也检出物体，则该预测为 ID；若 SAM3 未检出，说明图像内容与该类别不匹配，判为 OOD。
- 直观例子：检测器把大象误判为 "cow"，而 SAM3 在 "cow" 提示下在该位置不产生检测 → 判为 OOD。

### 2.2 算法流程（文字化描述）
1. **目标检测器推理**：输入图像 $x$ 同时送入检测器与 SAM3 图像编码器；检测器输出预测物体 $y=(b,c)$，含 $M$ 个框 $b=(b_m)$ 与类别 $c=(c_m)$，类别文本串记作 $c^{(s)}$，ID 类别集合 $S=\{1,\dots,S\}$。
2. **文本嵌入选择（离线）**：用 SAM3 文本编码器离线预计算全部 ID 类别的文本嵌入 $Z=\{z^{(1)},\dots,z^{(S)}\}$，推理时按检测器预测到的**唯一类别** $R$ 取出对应嵌入。例：预测到 car/person/bus 三类 → 取 $z^{(1)},z^{(4)},z^{(10)}$。
3. **SAM3 检测器推理**：对每个唯一类别 $s$ 调用一次（共 $R$ 次），得到 $v^{(s)}=(b^{(s)},u^{(s)})$，即 SAM3 预测框及其置信度 $u^{(s)}\in[0,1]$；$Y^{(s)}_m$ 表示框内像素集合。
4. **检测框选择**：把检测器预测框按类别分组，得到 $b^{(s)}=(b^{(s)}_{\hat m})$，与同类别 SAM3 预测配对比较。
5. **OOD 计算**：
   - 计算同类框之间的 IoU：
     $$\mathrm{IoU}(b^{(s)}_{\hat m}, b^{(s)}_m)=\frac{|Y^{(s)}_{\hat m}\cap Y^{(s)}_m|}{|Y^{(s)}_{\hat m}\cup Y^{(s)}_m|}$$
   - 用阈值 $\theta_{\mathrm{IoU}}$ 筛出与检测器框充分重叠的 SAM3 预测集合：
     $$\mathcal{M}^{(s)}_{\hat m}=\{m\in\mathcal{M}^{(s)} \mid \mathrm{IoU}\ge\theta_{\mathrm{IoU}}\}$$
   - 若该集合中**至少一个** SAM3 置信度超过分数阈值 $\theta_{\mathrm{score}}$，则该框判为 ID：
     $$\mathcal{M}^{(s)}_{\mathrm{ID}}=\{\hat m\in\mathcal{M}^{(s)} \mid \exists m\in\mathcal{M}^{(s)}_{\hat m}: u^{(s)}_m\ge\theta_{\mathrm{score}}\}$$
   - 其余判为 OOD：$\mathcal{M}^{(s)}_{\mathrm{OOD}}=\mathcal{M}^{(s)}\setminus\mathcal{M}^{(s)}_{\mathrm{ID}}$。
6. **ROC 曲线构造**：固定 $\theta_{\mathrm{IoU}}$，通过变化 $\theta_{\mathrm{score}}$ 得到 AuROC / FPR95。主实验取 $\theta_{\mathrm{IoU}}=0.2$（兼顾闭集设定与开放世界泛化）。
7. **算力受限变体（$R\le3$）**：若唯一类别数超过 3，只对"平均检测置信度最低的 3 类"进行提示，其余预测直接视为 ID，以限制 SAM3 调用次数。

## 6. 主要结论与发现

- **性能新 SOTA**：在所有 ID 数据集、OOD 数据集和指标上一致最优，平均排名 **1.0**（RONIN 为 2.0 / 2.6）。例如 VOC-ID + MS-COCO/OpenImages 达 97.52%/6.56% 与 94.62%/16.52% AuROC/FPR95；BDD100K-ID 下达 98.46%/4.55% 与 98.40%/5.00%。全量测试集上优势更大。
- **效率优势**：比最快的 RONIN 配置还快约 5 倍（0.1 s vs 0.48 s/帧），TFLOPs 也低一个数量级，且算力随提示类别数增长远低于扩散模型。
- **鲁棒性更强**：对检测框定位误差（$\epsilon\le0.5$）几乎不敏感，而 RONIN 的 FPR95 恶化 6.8 个百分点；在低光照与小物体上优势尤为明显（小物体 AuROC 90.76% vs RONIN 51.09%，接近随机）。
- **开放世界更实用**：在 ID/OOD 共存的真实设定下优势进一步扩大（94.11%/16.19% vs RONIN 81.72%/51.21%），且 $\theta_{\mathrm{IoU}}=0.2$ 优于 0.0，支持其阈值选择。
- **与少样本方法可比**：零样本的 SAM3-O2D2 已可与少样本 UNI-OOD 竞争，在 MS-COCO 为 OOD 时全面胜出；$\theta_{\mathrm{IoU}}=0$ 时 8 个组合中 7 个最优。
- **失败来源分析**：在 FPR95 工作点上 FNR=5.00%、FPR=6.56%，其中 5.00% 的假阴性里仅 0.27% 源于本方法（SAM3 未确认真实 ID 物体），4.73% 源于检测器本身的错误预测；OpenImages 上的部分"失败"实为数据集标注问题（OOD 图中出现真实 ID 物体如 bottle）。

## 7. 优点

- **范式创新**：首次把可文本提示的基础检测模型（SAM3）用于目标

级 OOD 检测，把判定依据从抽象特征相似度搬到可验证的检测输出层面（detection space），思路简洁、可解释性强。
- **零样本、免训练、免微调**：无需在 ID 训练集上训练附加模块，也不需要为每个新检测器/新 ID 数据集重新训练，换检测器时只需保证类别文本可提供给 SAM3，迁移成本极低，实用性强。
- **效率显著优于同类零样本方法**：端到端约 0.1 s/帧、TFLOPs 低一个数量级，且计算量随提示类别数增长近乎线性，远优于扩散类方法的快速增长；在算力受限时还能通过 $R\le3$ 变体进一步控制开销。
- **可解释性好**：判定逻辑是"同一位置、同一类别提示下 SAM3 是否也检出物体"，中间量（IoU、SAM3 置信度）均可直接检视，便于人工核查与调试，区别于黑箱式的特征距离打分。
- **鲁棒性强**：对检测框定位误差、光照变化、物体尺度变化（尤其小物体）不敏感，弥补了特征空间相似度方法的典型弱点。
- **实验维度较全面**：涵盖两个 ID 数据集、两个 OOD 数据集、效率、鲁棒性、开放世界、少样本对比、失败案例归因，且坦率报告了方法失效来源（多数假阴性来自检测器本身而非本方法），学术态度诚实。
- **阈值设计务实**：主要只依赖 $\theta_{\mathrm{IoU}}$ 与 $\theta_{\mathrm{score}}$ 两个阈值，且 $\theta_{\mathrm{IoU}}=0.2$ 在闭集与开放世界设定下均表现良好，调参负担小。

## 8. 局限与不足

- **依赖上游检测器质量**：方法只做"复核"而不修正检测器，检测器漏检或类别严重错判时本方法无法补救（失败分析中 4.73/5.00 的假阴性来自检测器）。因此整体性能上限被检测器锁死。
- **依赖 SAM3 的类别覆盖能力**：若 SAM3 对某 ID 类别本身识别不佳（词汇歧义、细粒度类别、专业领域术语），会产生假阴性；对 ID 与 OOD 在语义上高度相近（如"dog"与"狼"、"cup"与"mug"）的难例，检测空间的判别力可能不足。
- **闭集评测假设偏乐观**：主实验假设 ID 与 OOD 物体不同图共存，低 $\theta_{\mathrm{IoU}}$ 不会引入假阳性；开放世界结果虽已补充，但仍是单一数据集（MS-COCO 验证集）上的验证，覆盖面有限。
- **数据集与规模限制**：主实验仅用前 400/200 张图像子集，虽附录给出全量结果，但正文主结论建立在子集之上；ID 数据集仅 VOC 与 BDD100K 两个，域多样性（医学、遥感、工业检测等）未验证。
- **基线公平性存在细节隐忧**：部分基线数值直接引用 RONIN 原文而非全部重跑，虽为可比性考虑，但若实现细节、检测器版本或预处理存在差异，可能影响对比的严格性；鲁棒性分析仅对 RONIN 重跑。
- **额外依赖一个大型基础模型**：方法本身免训练，但推理时需同时加载检测器与 SAM3（图像编码器 + 文本编码器），显存与部署复杂度高于轻量级打分方法；论文未报告显存占用与模型参数量。
- **开放世界中的类别先验问题**：$R\le3$ 变体把"平均置信度较高的类别"直接判为 ID，这一启发式在检测器系统性过自信时可能失效，论文未对此做敏感性分析。
- **评测指标单一**：仅报告 AuROC 与 FPR95，未涉及更贴近部署的固定工作点下的精度/召回权衡、校准误差（ECE）等。

## 9. 启示与未来方向

- **"用生成/检测式基础模型做验证"是一条通用思路**：本文表明，把 OOD 判定转化为"另一模型在同一条件下能否复现该预测"，比在特征空间做距离比较更鲁棒、更可解释。该范式可迁移到分割、深度估计、图像描述等任务的一致性校验。
- **检测空间判别的鲁棒性优势值得深挖**：几何对齐（IoU）天然抑制外观与定位扰动，未来可探索更精细的空间匹配（如 mask 级、部件级）以提升细粒度难例的区分度。
- **与检测器协同而非仅复核**：把 SAM3 的检测结果反馈给检测器（如重分类、框修正、置信度重校准），有望突破当前"假阴性不可救"的性能天花板。
- **降低部署成本**：探索更小的可提示检测模型、缓存文本嵌入与图像嵌入、按需触发 SAM3（先做廉价初筛）等策略，可进一步压缩推理开销。
- **扩展到开放词表与未知类别命名**：结合 SAM3 的文本提示能力，不仅能判 ID/OOD，还可能对 OOD 物体给出候选语义描述，向"检测 + 未知物体描述"一体化发展。
- **更严格的评测协议**：建议未来工作在开放世界、跨域、细粒度相似类别、标注噪声等条件下建立统一 benchmark，并报告显存、参数量、固定工作点性能等部署相关指标。

## 10. 总体评价

论文提出了一种简洁而有效的零样本目标级 OOD 检测范式：以检测器预测类别为提示，用 SAM3-image 在同一位置做"复检"，把判定从抽象特征空间迁移到可解释的检测空间。方法免训练、免微调，速度比零样本 SOTA 的 RONIN 快约 5 倍、算力低一个数量级，并在 AuROC/FPR95 上全面领先，对定位误差、光照与小物体等扰动表现出明显更强的鲁棒性，在更贴近真实的开放世界设定下优势进一步扩大。其核心贡献不在于复杂机制，而在于**问题视角的转换**——用一个基础模型的检测能力去"证伪"另一个模型的预测，这一思路具有很强的可迁移性与启发性。主要不足在于性能受制于上游检测器与 SAM3 的类别覆盖、主实验规模与域多样性有限、开放世界验证仍较初步，以及部署需额外承载大型基础模型。总体而言，这是一篇在方法新颖性、效率、可解释性与实验充分性上较为均衡的工作，为该方向提供了一个值得跟进的新基线。
