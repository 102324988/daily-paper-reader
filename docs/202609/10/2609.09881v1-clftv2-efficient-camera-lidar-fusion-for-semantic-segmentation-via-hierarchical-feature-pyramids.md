## 摘要
自动驾驶中的语义分割需要在严重类别不平衡的情况下可靠地检测弱势道路使用者（VRU）。我们提出 CLFTv2，一种层次化相机-LiDAR融合框架，它用基于 Swin 的多尺度编码器和轻量级 FPN 风格残差解码器取代全局 ViT 注意力。CLFTv2 在二维透视域中运行，通过移位窗口注意力和逐尺度残差融合来整合多尺度几何线索，避免了查询匹配解码器的计算开销。在三个驾驶数据集上，CLFTv2 持续提升 VRU 召回率。在 ZOD 上，CLFTv2-Large 达到 53.5% mIoU，将行人 IoU 从 35.5% 提升至 44.9%，优于先前的 CLFT 模型。在 Waymo 上，CLFTv2 达到 61.7% mIoU。此外，一项模态隔离研究表明，ViT 的全局感受野仅在密集 LiDAR 回波下才能带来更强的融合增益。与基于 Swin 的 Mask2Former 改编版相比，CLFTv2 所需 GFLOPs 减少 1.4 倍，吞吐量提高 2.2 倍，同时达到相当的整体准确率。这些结果表明，层次化局部注意力融合为智能交通系统中的实时车载感知提供了一种高效、可扩展的替代方案，可替代全局注意力和基于查询的解码器。源代码已公开。

## Abstract
Semantic segmentation for autonomous driving requires reliable detection of vulnerable road users (VRUs) despite heavy class imbalance. We introduce CLFTv2, a hierarchical camera-LiDAR fusion framework replacing global ViT attention with a Swin-based multi-scale encoder and a lightweight FPN-style residual decoder. Operating in the 2D perspective domain, CLFTv2 integrates multi-scale geometric cues through shifted-window attention and per-scale residual fusion, avoiding the computational overhead of query-matching decoders. Across three driving datasets, CLFTv2 consistently improves VRU recall. On ZOD, CLFTv2-Large achieves 53.5\% mIoU, improving pedestrian IoU from 35.5\% to 44.9\% over the prior CLFT model. On Waymo, CLFTv2 reaches 61.7\% mIoU. Additionally, a modality-isolation study suggests ViT's global receptive field yields stronger fusion gains only under dense LiDAR returns. Compared to a Swin-based Mask2Former adaptation, CLFTv2 requires 1.4$\times$ fewer GFLOPs and delivers 2.2$\times$ higher throughput, while achieving comparable overall accuracy. These results demonstrate that hierarchical local-attention fusion offers an efficient, scalable alternative to global-attention and query-based decoders for real-time on-vehicle perception in intelligent transportation systems. Source code is publicly available.

- **已有方法的瓶颈**：
  - 作者前作 **CLFT** 采用 ViT 编码器，具备优异的跨模态上下文，但标准 ViT 存在**二次复杂度**且仅输出**单一固定空间分辨率**，难以高效生成小目标检测所需的多尺度特征金字塔。
  - 基于查询（query-matching）的通用分割解码器（如 Mask2Former）面向开放场景分解，对**闭集固定类别语义分割**引入不必要的训练开销（匈牙利匹配、逐层深监督）。
- **论文定位**：提出 CLFTv2，用 **Swin 层次化编码器 + 轻量 FPN 式残差解码器**替代全局 ViT 注意力与查询解码器，在 2D 透视域实现高效、可扩展的车载实时感知。

## 2. 方法论

### 核心思想
- 完全在 **2D 透视投影域**运行：LiDAR 点云投影到图像平面，编码为三通道坐标图（X, Y, Z），从而可直接复用 ImageNet 预训练骨干，无需专用 3D 处理。
- 用 **层次化局部窗口注意力**（Swin）原生提取多尺度特征，配合 **逐尺度残差融合 + 粗到细 FPN 式累加**，避免查询匹配解码器的开销。

### 关键技术细节
- **层次化骨干（Swin Transformer）**：
  - 输入切分为 4×4 patch，经四个阶段；每阶段在 M×M 非重叠窗口内做自注意力，交替块使用移位窗口（SW-MSA，偏移 (⌊M/2⌋, ⌊M/2⌋)）实现跨窗口信息流动。
  - W-MSA 复杂度 Ω = 4hwC² + 2M²hwC，为 **O(hw)**，远优于全局注意力的 O((hw)²)。
  - Patch Merging 逐阶段减半分辨率、加倍通道，形成四级金字塔，stride ∈ {4, 8, 16, 32}。
  - 嵌入维度：Tiny {96,192,384,768}；Base {128,256,512,1024}；Large {192,384,768,1536}。使用 SwinV2 + ImageNet 预训练权重。
- **孪生编码（Siamese）**：RGB 与 LiDAR 张量由两个**权重共享**的 Swin 编码器并行处理，参数减半，且两流均可复用 ImageNet 权重。
- **通道投影**：每级特征经 1×1 卷积统一到 D=256，保持原生分辨率。
- **粗到细残差融合解码器**：
  - 每模态先经独立 **ResConv**（两个 3×3 卷积 + ReLU + 恒等跳连）精炼；
  - 最粗层 A₄ = Rout(R_RGB(F′_RGB,4) + R_LiDAR(F′_LiDAR,4))；
  - 后续层 A_i = Rout(R_RGB(F′_RGB,i) + R_LiDAR(F′_LiDAR,i) + Up₂×(A_{i+1}))，即加入上层上采样语义上下文后经共享 ResConv。
  - 输出 A₁ 为 H/4 分辨率。
- **分割头**：3×3 Conv → BN → ReLU → 1×1 Conv → 4× 上采样，输出 H×W×C_cls 的 logits。
- **损失函数**：加权交叉熵，权重按类别像素频率近似逆平方根调度（背景权重低至 0.1，人/车权重高达 10–20）。

### 消融揭示的关键设计
- 递归项 Up₂×(A_{i+1}) 是精度主要来源：移除后 ZOD mIoU 从 35.9% 降至 23.1%（绝对下降 12.8%）。
- 用五种门控/注意力加权替代逐元素相加，mIoU 变化不超过 ±0.7%，说明额外融合参数在当前监督条件下无必要。

## 6. 主要结论与发现

- **精度提升**：ZOD 上 CLFTv2-Large 达 **53.54% mIoU**（CLFT-Large 为 46.82%），行人 IoU 从 35.5% → **44.9%**，标志 IoU 33.2% → 43.2%；Waymo 达 **61.69% mIoU**；ISEAuto 达 73.3%。
- **效率优势**：相比 Swin 版 Mask2Former，**GFLOPs 少 1.4×、吞吐高 2.2×**，精度相当。Tiny 规模：CLFTv2-Tiny 22.0 ms/187 MB vs Mask2Former-Tiny 48.4 ms/314 MB。Large 规模亦更轻更快（204.4G vs 265.3G FLOPs；81.8 ms vs 118.2 ms）。
- **全局 vs 局部注意力权衡**：在 Waymo（稠密 LiDAR）上，ViT 系 CLFT-Large（68.3%）显著优于 Swin 系 CLFTv2-Large（61.7%），差距达 6.6%；而单模态下两者 mIoU 几乎相同（差 0.2–0.4%），说明差距**源于融合交互机制**——ViT 的全局感受野更利于稠密点云跨模态对齐。
- **模态贡献差异**：Waymo 几何主导（LiDAR-only 常优于 RGB-only），CLFT 融合增益平均 +10.52%，CLFTv2 约 +4.85%（约小 2.2×）；ISEAuto 因标注稠密、类别简单，LiDAR 边际增益仅 +0.34%~+1.21%。
- **融合策略**：简单相加/平均/仅 ResConv 约 23% mIoU，加入残差传播后升至 35.9%，延迟仅从 10.8 ms 增至 13.2 ms（+22.2%），性价比高；门控机制无额外收益。
- **迁移学习**：跨数据集初始化可加速收敛、提升早期轮次 mIoU；类别重叠度影响迁移质量（ISEAuto 无标志类，迁移到 ZOD 效果较弱）。
- **安全侧写**：CLFTv2 主打**高召回**（Waymo 行人夜间雨天召回 95.7%，白天晴天 96.1%），但精度低于 CLFT；架构的安全画像高度依赖数据集传感器特性。
- **总体论断**：在大规模开放数据集的稀疏/噪声监督下，**架构复杂度并非普遍有益**，轻量残差融合可与查询解码器性能相当。

## 7. 优点

- **效率-精度平衡突出**：Swin 局部窗口线性复杂度 + 权重共享孪生编码器 + 轻量 FPN 解码器，显著降低 FLOPs、延迟与显存，适合实时车载部署。
- **原生多尺度**：Swin 四阶段金字塔直接提供多尺度特征，避免 ViT 单尺度生成金字塔的高开销。
- **2D 透视域设计简洁**：LiDAR 编码为三通道坐标图，直接复用 ImageNet 预训练骨干，工程落地门槛低。
- **消融深入且有洞察**：明确指出递归残差路径是精度主导因素，门控融合无必要；并诚实揭示局部注意力在稠密点云融合上的短板。
- **公平性努力**：基线在同一代码库、同一融合管线、相同种子与数据管线下重实现；使用 top-10 检查点平均降低噪声。
- **安全导向指标**：专门报告 VRU 召回与精度、天气鲁棒性、跨数据集迁移，贴合智能交通实际部署关切。
- **可复现性**：代码与预处理脚本公开，训练结果可在线查看。

## 8. 不足与局限

- **局部感受野局限**：在几何稠密的 Waymo 上，Swin 局部窗口的跨模态融合能力明显弱于 ViT 全局注意力（差 6.6%），即便扩大窗口也无法完全弥合，作者建议未来探索混合全局-局部架构。
- **监督质量混杂**：ZOD 使用 SAM 生成的伪标签，遮挡/截断目标拒绝率高，IoU 是受可见性约束的上界，难以将模型架构能力与对噪声标签的鲁棒性分离。
- **算力评估单一**：效率指标仅在高端 A100 上测量，**未在低功耗边缘设备/微控制器上验证**，实时车载部署结论有待落地检验。
- **消融非严格单变量**：窗口大小消融与输入分辨率耦合，结论解释受限。
- **3D 原生方法未直接数值对比**：作者声明与 BEV 类 3D 方法（BEVFusion、UniAD 等）不在同一范式，未做直接比较，跨范式可比性缺失。
- **类别与场景覆盖**：ZOD/Waymo 仅四类、ISEAuto 仅两类，未涵盖更多细粒度交通参与者类别；ISEAuto 无标志类导致迁移分析不完整。
- **统计稳健性有限**：部分消融为单次运行，虽有 ± 方差但未做多轮统计显著性检验。
- **精度-召回权衡**：CLFTv2 高召回但精度偏低（如 ZOD 精度约 50%），在误检敏感场景可能受限；ZOD 夜间雨天 Mask2Former-Base 反而领先（48.9% vs 44.5%）。
