## 摘要
无人机（UAV）和遥感图像中的小目标检测需要在建模长距离上下文的同时保留高分辨率细节。增加步幅为4的检测层并移除步幅为32的阶段有利于微小目标，但会削弱外围空间支持；而将选择性扫描直接插入主特征路径则可能干扰微弱的局部线索。我们提出ScopeMamba-YOLO，其核心是旁路零门控选择性扫描原则，将上下文建模与卷积流解耦。该原则在骨干网络中由级联全局上下文模块（CGCM）实现，在颈部由选择性扫描PAN（SS-PAN）实现。自适应多尺度条带（AMS）模块降低了高分辨率特征提取的开销，而尺度自适应DFL（SA-DFL）检测头仅以额外0.008M参数在不同尺度间重新分配分布支撑和回归能力。对照实验表明，在同等配置下将选择性扫描置于主路径会使mAP50降低0.98个百分点，而旁路CGCM相比三种子无CGCM均值使最终配置提升0.67个百分点；算子对照表明，该增益不能仅由辅助分支容量解释。ERF分析进一步表明，在步幅8处，完整上下文通路将外围能量比从0.008提高到0.090。在VisDrone-2019上，ScopeMamba-S以3.57M参数达到50.8% mAP50，超过YOLOv8s 10.8个百分点，而参数量仅为其32%；ScopeMamba-M以6.48M参数达到52.6% mAP50。在AI-TOD上也观察到一致的改进，尤其是对极微小目标和微小目标。

## Abstract
Small object detection in unmanned aerial vehicle (UAV) and remote sensing imagery requires preserving high-resolution detail while modeling long-range context. Adding a stride-4 detection level and removing the stride-32 stage benefits tiny targets but weakens peripheral spatial support, whereas directly inserting selective scanning into the main feature path can interfere with weak local cues. We propose ScopeMamba-YOLO, built around an off-path, zero-gated selective-scanning principle that decouples contextual modeling from the convolutional stream. The principle is instantiated by a Cascaded Global-Context Module (CGCM) in the backbone and a Selective-Scan PAN (SS-PAN) in the neck. An Adaptive Multi-scale Strip (AMS) Block reduces the cost of high-resolution feature extraction, while a Scale-Adaptive DFL (SA-DFL) head reallocates distributional support and regression capacity across scales with only 0.008M additional parameters. Controlled experiments show that matched main-path selective scanning reduces mAP50 by 0.98 pp, whereas off-path CGCM improves the final configuration by 0.67 pp over the three-seed no-CGCM mean; operator controls indicate that this gain is not explained by auxiliary branch capacity alone. ERF analysis further shows that the complete context pathway increases the peripheral energy ratio from 0.008 to 0.090 at stride 8. On VisDrone-2019, ScopeMamba-S achieves 50.8% mAP50 with 3.57M parameters, exceeding YOLOv8s by 10.8 pp while using 32% of its parameters; ScopeMamba-M reaches 52.6% mAP50 with 6.48M parameters. Consistent improvements are also observed on AI-TOD, especially for very-tiny and tiny objects.

# ScopeMamba-YOLO 论文总结

## 1. 核心问题与研究动机

- **背景**：无人机（UAV）与遥感图像中的目标检测是城市规划、交通监控、灾害评估、精准农业、海事监视等对地观测应用的基础前提。在高空宽视场图像中，车辆、船只、行人常小于 32×32 像素，甚至小于 16×16 像素（VisDrone、AI-TOD 中此类实例占绝大多数）。
- **核心矛盾（分辨率–上下文两难）**：
  - **向内（inward）**：小目标外观证据极少（纹理稀疏、边界模糊、信噪比低），在骨干网络反复下采样中极易被削弱或淹没，因此需要更高分辨率的细粒度表示。
  - **向外（outward）**：识别弱信号反而需要**更多**支撑信息——既需要细粒度局部细节区分"车"与"屋顶设备"，又需要长程上下文（道路、港口、停车场）抑制主导航拍场景的背景杂波。
  - 即检测器的感知范围必须**同时向两个相反方向拓宽**。
- **现有方案的偏斜**：
  - 为保细节：多尺度特征金字塔、切片推理、小目标友好标签分配；轻量航拍检测器常用"加 stride-4（P2）+ 去 stride-32（P5）"的尺度重分配，效果显著但**移除了最深层，削弱外围空间支撑**。
  - 为扩上下文：大核/选择性感受野（LSKNet、PKINet）、注意力、Transformer 预测头；但自注意力对高分辨率特征图有二次复杂度代价。
  - Mamba/SSM 提供线性复杂度全局建模，但现有设计**普遍把选择性扫描直接插入骨干或颈部主路径**：扫描与细粒度卷积争夺有限通道容量，且在背景 token 远多于小目标 token 的特征图上传播状态，存在"长程聚合稀释弱局部证据"的风险。
- **本文定位**：作者用一个匹配配置下的对照实验佐证该担忧——主路径插入选择性扫描使 mAP50 下降 0.98 pp；由此提出**把长程上下文建模与承载细节的主路径解耦**的核心设计原则。

## 2. 方法论

### 2.1 总体思路（单一主线）

1. **重分配**检测尺度到小目标可存活的更高分辨率区间；
2. 用各向异性算子**低成本读取**高分辨率特征；
3. 通过**旁路选择性扫描**回接场景级上下文；
4. 用**尺度自适应的分布式回归预算**回归边界框。

### 2.2 高分辨率重分配（HRR，作为"采用的前人先验"而非贡献）

- 在 YOLOv8 骨架上加入 stride-4（P2，640² 输入下 160²）检测分支，**完全移除 stride-32（P5）阶段及其检测头**，在 P2/P3/P4（stride {4,8,16}）上检测。
- 依据：VisDrone 框尺寸统计显示绝大多数实例低于 stride-32 网格能保留单格响应的面积区间；P5 路径被剪除约 7M 参数。
- 代价：外围空间支撑被削弱（后文用 ERF/PER 定量），即"以分辨率换上下文触达"。

### 2.3 数据流

- **骨干（Context-Cascaded Backbone）**：卷积空间主路径（stem → P2 处 C2f → SCDown → P3 处 AMS-Block → SCDown → AMS-Block → SPPF 位于 P4 末端），两侧挂两条低分辨率上下文流 g3、g4，**仅通过零初始化乘性门控**回流主路径。
- **颈部（SS-PAN）**：先自顶向下用 DySample 上采样融合 P4→P3→P2，并用 P3 的方向性语义增强 P2；再自底向上，其 P3/P4 融合节点带零门控选择性扫描分支。
- **头部**：SA-DFL 消费三张特征图，640² 输入下共 160²+80²+40² = 33,600 个 anchor。

### 2.4 AMS-Block（各向异性多尺度读取）

- 替换 C2f 内部瓶颈为四分支单元，配 SCDown 下采样（1×1 通道混合 + stride-2 深度卷积）。
- 输入按通道四等分：分支 1 为局部 DW 3×3；分支 2/3 为自适应条带；分支 4 为恒等捷径。
- **自适应条带（以水平为例）**：用 GAP 驱动的通道门控在短核与长核之间混合
  - `α_h = σ(W_g · GAP(x₂))`
  - `f_h = α_h ⊙ DW_{1×5}(x₂) + (1−α_h) ⊙ DW_{1×11}(x₂)`
  - 垂直分支对称使用 5×1 与 11×1 核。
- **交叉方向门控**：`f̃_h = f_h ⊙ σ(g_{v→h}(f_v))`，`f̃_v = f_v ⊙ σ(g_{h→v}(f_h))`，使垂直结构证据可抑制或锐化同位置的横向读取。
- **输出**：`y = x + W_f [f_ℓ; f̃_h; f̃_v; x₄]`。条带核只触及 k 个像素而非 k²，故以接近深度卷积的成本覆盖约 11×11 范围。
- 定位：**资源高效组件**，在 HRR 基线上 mAP50 几乎不变，参数减少约 24%、GFLOPs 减少约 9%，为后续上下文通路腾出预算。

### 2.5 旁路零门控选择性扫描与 CGCM

- **SSM 预备**：连续形式 `h′(t)=Ah(t)+Bx(t), y(t)=Ch(t)`；零阶保持离散化后得线性递推 `h_t = Āh_{t−1} + B̄x_t, y_t = Ch_t`。Mamba 使 Δ、B、C 成为输入的函数（选择性扫描），代价对序列长度线性。
- **NCSSD2D（二维化算子）**：非因果四方向变体，沿行左→右、行右→左、列上→下、列下→上四种顺序分别序列化并做选择性扫描，再合并四个输出；每个位置以 O(HW) 成本聚合全图证据。
- **放置原则（三条约束）**：
  1. **旁路、仅调制**：扫描不替代主路径特征变换，只产生调制信号，卷积流保留用于小目标定位的细粒度表示。
  2. **降低成本**：骨干中上下文分支作用于 4× 池化、32 通道特征（1/4 分辨率，token 数减少 16×），两级骨干上下文站点累计开销仅 +0.44 GFLOPs；颈部不池化，但分支工作在输出宽度的一半。
  3. **零初始化门控**：上下文信号经零初始化投影进入，使增广网络在初始化时**功能上等同于其卷积骨架**，上下文分支在优化中渐进引入。
- **CGCM（站点 1，骨干）**：
  - `g₃ = W↑ NCSSD2D(LN(W↓ AvgPool₄(F₃)))`，其中 AvgPool₄ 池化 4×（640² 输入下 20×20 网格），W↓ 投到 32 通道工作宽度，扫描 state size d_state=8，W↑ 恢复原宽度。
  - **乘性注入**：`F̂ = F · (1 + tanh(W₀ g))`，g 双线性对齐，W₀ 零初始化，门控范围 (0,2)，第 0 步为恒等。
  - **级联**：g₄ 由**已被调制的** P4 特征以同样链路（10×10 网格）计算，并在 SPPF 前再次注入——场景证据沿深度累积而非一次性施加。
- **门控可视化**：CGCM 门控响应分布于广阔场景结构而非局限于目标局部区域，符合"场景级上下文调制器"的定位。

### 2.6 SS-PAN（颈部）

- **方向性自顶向下通路**：用 DySample 上采样；P′₃ 上采样对齐为 64 通道语义图 s，按 `s_dir = s_h ⊙ σ(g_{v→h}(s_v)) + s_v ⊙ σ(g_{h→v}(s_h))`（s_h = DW_{1×5}(s)，s_v = DW_{5×1}(s)）方向分解后，经与式 (9) 相同的零门控乘性门注入得到 P₂^final。作者将其视为轻量颈部组件而非独立贡献。
- **自底向上选择性扫描融合**：P3/P4 融合节点以 C2f-SDMamba 替换 C2f：
  - `y = C2f(x) + γ Φ_SSM(x)`，`γ = 0 at init`
  - Φ_SSM：1×1 卷积压缩到输出宽度一半 → 归一化 → NCSSD2D（d_state=16）→ 残差 DW 3×3 精修 → 1×1 扩张回原宽度。
  - 主路径 C2f 保持不变，扫描分支提供全局重校准信号并从零渐进引入。
- 消融显示移除任一扫描节点或缩减扫描宽度都会降低精度，且缩减配置无参数优势。

### 2.7 SA-DFL 尺度自适应头部

- DFL 将每条边回归为 K 个（以 stride 为单位索引的）离散 bin 上的期望。标准 YOLOv8 所有检测层共用 K=16；P2/P3/P4 重分配后，同样的图像空间偏移在不同 stride 下对应不同数量的特征格单元，故为每个尺度分配专属 bin 预算 Kᵢ。
- 解码：`d̂ = Σ_{j=0}^{Kᵢ−1} j · p_j`，`p = softmax(z_side)`。
- 输出通道 `n⁽ⁱ⁾ = n_c + 4Kᵢ`；回归隐藏宽度 `cᵢ = max(16, ⌊C₁/4⌋, 4Kᵢ)`。
- 因回归分支宽度随 4Kᵢ 缩放，改变 bin 分配**同时重分配回归容量**，故作者将增益归因于"联合的尺度自适应回归设计"而非单纯更细的 bin 间距。
- 主配置 K=[24,16,10] 对应 stride [4,8,16]，Nano 用 [16,12,8]；仅增加 **0.008M** 参数。
- 训练使用按尺度索引的 DFL 项，配合标准 CIoU 与 BCE 分类损失，不引入额外输入或质量分支。

### 2.8 模型缩放

- 沿用 YOLOv8 复合缩放：通道宽度乘 w 并取 8 的倍数，C2f 类块重复次数乘 d；四个变体拓扑完全一致。
- 唯一变化的超参是 Nano 的 bin 列表：Nano 宽度（C₁=64）下保留 K=[24,16,10] 会把回归分支钉在 [96,64,40]，比自身输入还宽且不随宽度缩放；缩至 [16,12,8] 恢复比例缩放（[64,48,32]）。
- 变体：N (d=0.33, w=0.25, 1.01M, 15.87
