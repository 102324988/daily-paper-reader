## 摘要
360°显著目标检测（SOD）旨在在全视场内准确分割显著区域。然而，等距柱状投影（ERP）在将球面域映射到平面表示时会引入严重的空间畸变。现有方法主要关注补偿投影畸变，却忽略了特征感知和预测细化过程中全景几何与显著目标结构之间的相互作用。为此，我们提出SphereSOD，一种将全景几何与演化中的显著结构相耦合的ERP原生框架。具体而言，球面几何支配特征采样与空间加权，而粗粒度显著性和轮廓预测在渐进式解码过程中影响上下文聚合。SphereSOD首先基于球面投影几何初始化可变形采样，然后采用有界的内容自适应偏移，从而得到与底层全景几何更好对齐的特征。随后，解码器执行结构引导的上下文聚合和渐进式细化，以恢复完整的显著区域和准确的边界。在三个公开的360° SOD基准上的大量实验证明了最先进的性能和良好的精度-效率权衡，支持直接在ERP空间中进行保结构推理，作为投影密集型全景流程的一种有前景的替代方案。

## Abstract
360° salient object detection (SOD) aims to accurately segment salient regions across a full field of view. However, equirectangular projection (ERP) introduces severe spatial distortion when mapping the spherical domain onto a planar representation. Existing methods mainly focus on compensating projection distortion while overlooking the interaction between panoramic geometry and salient object structure during feature perception and prediction refinement. To this end, we propose SphereSOD, an ERP-native framework that couples panoramic geometry with evolving salient structures. Specifically, spherical geometry governs feature sampling and spatial weighting, while coarse-grained saliency and contour prediction influence context aggregation during the progressive decoding process. SphereSOD first initializes deformable sampling based on spherical projection geometry and then employs bounded, content-adaptive offsets, yielding features that are better aligned with the underlying panoramic geometry. Subsequently, the decoder performs structure-guided context aggregation and progressive refinement to recover complete salient regions and accurate boundaries. Extensive experiments on three public 360° SOD benchmarks demonstrate state-of-the-art performance and a favorable accuracy-efficiency trade-off, supporting structurepreserving inference directly in ERP space as a promising alternative to projection-heavy panoramic pipelines.

## 2. 方法论

### 2.1 核心思想

- 提出 **SphereSOD**，一个 ERP 原生框架，将全景几何与演化中的显著结构在特征感知与渐进解码中耦合。
- 球面几何支配**特征采样位置**与**空间上下文加权**；粗粒度显著性与轮廓预测决定聚合时应强调**哪些区域与边界**。
- 二者交互将几何自适应特征感知与结构条件渐进恢复直接连接在 ERP 空间，无需额外投影转换。

### 2.2 总体架构

- 输入全景图，输出显著图与轮廓。
- 采用 **Swin-s** 提取四个分辨率特征；将最深层的 f₄ 与 f₃ 沿通道拼接并经 MLP 融合，得到兼具全局语义与局部细节的特征。
- 特征随后送入 **PG-ME**（在三个尺度上应用 PG-DSA）产生几何对齐特征；f₃ 经 **GTC** 转换为全局显著/轮廓 token 与空间特征；最后由 **DPPD** 从粗到细渐进细化预测。

### 2.3 先验引导多尺度编码器（PG-ME）

- 每个尺度由两个堆叠的 Transformer 块组成：LayerNorm → **PG-DSA** → 残差；LayerNorm → **LeFF** → 残差。
- **PG-DSA 关键细节**（图 3）：
  - 输入特征线性投影为 Query Q 与 Key K；Q 经投影层计算采样点注意力分数，Softmax 归一化得注意力权重 A。
  - Q 送入偏移生成器预测原始偏移 R；在偏移生成器中应用**循环填充**以保持 ERP 水平连续性。
  - **有界内容自适应偏移**（式 1）：
    - Δp = tanh(R) · R_max · g，g = σ(γ)
    - tanh 将原始偏移约束到 (−1, 1)；R_max 为最大偏移幅度（经验设为 1.5）；g 为可学习偏移门，σ 为 Sigmoid，γ 为可学习参数。
    - 门 g 初始化为 0.1，以抑制训练早期的过大偏移。
  - **畸变采样先验**在 ERP 平面上提供初始位置；将 Δp 施加到先验位置得到最终采样点 P；再次应用循环填充处理经度连续性。
  - K 线性投影并 reshape 为多头特征，在采样点双线性采样，按注意力权重 A 加权并投影得到输出。
- 三种先验共同作用：**球面采样先验**、**局部语义先验**（有界偏移）、**水平连续性先验**（循环填充）。

### 2.4 全局 Token 转换器（GTC）

- 论文明确说明 GTC **并非核心贡献**，遵循 VST++ 设计，仅为完整性而描述。
- 仅应用于 1/16 尺度特征以兼顾语义与效率。
- 输入 f₃ 先经四个标准多头自注意力层建立全局上下文；引入两个可学习全局 token——**显著 token T_gs** 与**轮廓 token T_gc**，拼接到 patch token F 两端形成长度 N+2 的序列；再经四个带位置编码的多头自注意力层建模 patch 间空间关系。
- 更新后的特征解耦为三路输出：patch 特征 F 作为 Q，T_gs/T_gc 分别作为 K、V，经 Sigmoid 激活注意力与残差连接得到任务增强的显著特征 F_s 与轮廓特征 F_c；两个全局 token 经各自 LayerNorm 与 FFN 生成最终全局 token。

### 2.5 双分支先验引导渐进解码器（DPPD）

- **ON-rT2T（重叠归一化反 T2T 上采样）**（式 2）：
  - 反 T2T 将投影的 k×k patch 以步长 s（s<k）折叠为 2D 图，但 Fold 操作直接对重叠区域求和，产生空间幅度偏差，损害高频边界定位。
  - 对投影 token 折叠得累积图 U；同时对全 1 张量应用相同 Fold 得覆盖计数图 D；最终上采样特征 Û = U / max(D, 1)，避免除零。
  - 将重叠求和转为平均，无额外参数地消除空间偏差；上采样特征与低层编码器特征拼接并经线性投影融合。
- **PGTR（先验引导 Token 细化）**（图 5 上）：
  - 以 O(N) 加权池化替代昂贵的 token-to-pixel 自注意力，分显著（蓝）与轮廓（绿）两支。
  - **前景对比先验**：显著目标与其半周长区域的差异大于与相邻周围的差异（在 360-SOD 与 360-SSOD 训练集中分别对 68.5% 和 72.1% 的图像成立，基于 CIELab 直方图距离）。显著支：x_anti = Roll(x, W/2)，C_s = x − x_anti；轮廓支：E = Edge(x)，E_anti = Roll(E, W/2)，C_c = E + α_con(E − E_anti)。α_sal、α_con 初始化为 0，作为弱残差。
  - **Sal-con 先验**：显著支权重 W_s = M_s；轮廓支 W_c = max(B(M_s), M_c)，其中 B(·) 为全景边界提取器，以排除无关高频纹理。
  - **Pano-distortion 先验**：纬度感知权重 w = max(cos(πy/2), 0.25)，y ∈ [−1,1] 为归一化纬度；赤道处为 1，两极衰减至 0，截断最小值 0.25 避免极区权重过小。
  - 各支以 W_s/W_c × w 为最终空间权重做加权平均池化（式 8–10），得到全局上下文 Z_s、Z_c ∈ R^{B×64}；再经残差方式注入上一阶段全局 token 与位置编码进行更新（式 11–12）。
- **双预测（Dual Prediction）**（图 5 下）：
  - **主分支**：ˆF = x + 0.5·g_s⊙C_s + 0.5·g_c⊙C_c（式 13），归一化投影得 F_p，与更新后全局 token 计算逐位置相似度得主分支显著预测 S_p 与轮廓预测 S_c（式 14）；ˆF 同时传入下一 ON-rT2T 阶段。
  - **辅助分支**：ˆF_s = x + g_s⊙C_s，ˆF_c = x + g_c⊙C_c（式 15），归一化投影得局部特征 F_ls、F_lc，线性分类得辅助预测 S_a、C_a。
  - 1/16 尺度略有不同：无上一阶段粗预测，主分支直接匹配 patch 特征 F 与全局 token，辅助分支从任务增强特征 F_s/F_c 预测；从 1/8 尺度起遵循标准流程。
- **PCRD（概率-上下文残差解码器）**（图 6）：
  - 输入 1/4 阶段的空间特征、主/辅预测与更新后全局 token。
  - 拼接三个 1/4 尺度空间特征，经 16 通道低维反 T2T（LD-RT2T）上采样得全尺度特征 F_ld ∈ R^{B×16×H×W}，以低计算成本保留结构细节。
  - 粗预测双线性上采样为全尺度 logit 基底；主 logit 基底经 Sigmoid 得 P_s、P_c ∈ [0,1]，并导出两个先验（式 16）：**不确定性** U = |1 − 2P_s − 1|（在轮廓附近 P_s≈0.5 时高，在背景或目标内部 P_s≈0/1 时低，指示需细化区域）与**显著性差异** D_anti = P_s − Roll(P_s, W/2)。
  - 将概率域图与低维特征拼接为上下文 Ω = Concat(F_ld, P_s, P_c, U, D_anti) ∈ R^{B×20×H×W}（16+4 通道）。
  - 主分支残差 ∆S = H_sp(Ω) + r_s，∆C = H_cp(Ω) + r_c（式 18），其中 r_s、r_c 为 F_ld 与全局 token 的相似度响应；辅助残差直接由上下文预测。
  - 门 G = σ(Conv_{1×1}(DWConv(Ω))) ∈ [0,1]（式 19）；最终 S¹_p = B_s + G·∆S，C¹_p = B_c + ∆C（式 20），S¹_a = B_as + G·H_sa(Ω)，C¹_a = B_ac + H_ca(Ω)（式 21）。G 仅应用于显著分支，因轮廓本身已代表边界。

### 2.6 损失函数

- **BCE Loss**（式 22）：对 S 个尺度的显著与轮廓预测施加像素级监督，使用下采样 GT；尺度权重 w₁=1.0、w₂=0.8、w₃=0.5、w₄=0.5。
- **IoU Loss**（式 23）：对所有尺度的显著与轮廓预测施加区域重叠一致性约束，缓解前景-背景不平衡下小目标被忽略的问题。
- **Align Loss**（式 25–27）：对全分辨率主/辅显著预测，先均值中心化得偏差 φ_P、φ_G，计算逐像素方向一致性 ξ = 2·φ_P·φ_G / (φ_P² + φ_G² + ε)，映射 ϕ = (ξ+1)²/4 ∈ [0,1]，L_align = 1 − Σϕ/(H×W)，以约束全局强度分布一致性。
- **总损失**（式 28）：L_total = L_base + L_aux_base + L_align + L_aux_align，其中 L_base = L_bce + L_iou。
