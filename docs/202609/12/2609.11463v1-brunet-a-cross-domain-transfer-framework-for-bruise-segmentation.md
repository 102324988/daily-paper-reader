## 摘要
由于数据与标注有限、边界弥散且外观变化极大，瘀伤分割在医学影像中是一项颇具挑战性的任务。在本工作中，我们提出了 BruNet，这是一种将基于 ViT 的视觉编码器（自监督 DINOv3 或预训练的 LingBot-Vision 骨干网络）与基于 SAM 的掩码解码器相结合的分割框架。BruNet 在 HAM10000 皮肤病变数据集上进行训练，并在一个独立的瘀伤数据集上评估，无需额外微调。尽管此前已有少数研究探索了机器学习和计算机视觉在瘀伤分析中的应用，但现有工作主要聚焦于检测、分类或颜色分析，而非像素级定位。据我们所知，这是首个针对自动瘀伤分割的研究。我们的结果表明，BruNet 优于基于 CNN 的模型、最先进的分割模型、ChatGPT-4o/5 辅助的 SAM2 零样本基线以及面向医学的 MedSAM 模型，展现出对瘀伤分割的强大跨域泛化能力。

## Abstract
Segmenting bruises is a challenging task in medical imaging due to limited data and annotations, diffuse boundaries, and highly variable appearance. In this work, we propose BruNet, a segmentation framework that combines a ViT-based visual encoder (a self-supervised DINOv3 or a pretrained LingBot-Vision backbone) with a SAM-based mask decoder. BruNet is trained on the HAM10000 skin lesion dataset and evaluated on a separate bruise dataset without additional fine-tuning. Although a small number of prior studies have explored machine learning and computer vision for bruise analysis, existing work has primarily focused on detection, classification, or colour analysis rather than pixel-level localisation. To the best of our knowledge, this is the first study to address automatic bruise segmentation. Our results show that BruNet outperforms CNN-based models, state-of-the-art segmentation models, ChatGPT-4o/5-assisted SAM2 zero-shot baselines, and the medical-oriented MedSAM model, demonstrating strong cross-domain generalisation to bruise segmentation.

- **数据瓶颈**：瘀伤图像常为自我管理、低报告率，涉及敏感场景（如家庭暴力）时受伦理与隐私限制，导致**缺乏公开的像素级标注数据集**。
- **研究空白**：现有计算机视觉在瘀伤领域的工作主要集中于**检测、分类（如年龄估计）或颜色分析**，几乎没有像素级定位/分割研究。皮肤病变、伤口、烧伤等相邻领域虽有大量分割工作，但瘀伤具有更弱的表面结构和更强的边界模糊性，不能直接等同。
- **整体含义**：本文提出 **BruNet**，首次系统性地解决**自动瘀伤分割**问题，并采用"在皮肤病变数据上训练、直接迁移到瘀伤数据评估"的零样本跨域迁移范式，模拟临床中罕见病标注稀缺的真实场景。

## 2. 方法论

### 2.1 核心思想
- 将 **ViT 视觉编码器**（提供结构感知的语义特征）与 **SAM 掩码解码器**（提供可提示的分割能力）组合，通过轻量适配器解决二者之间的分辨率鸿沟，实现跨域分割。
- 训练仅使用 HAM10000 皮肤病变掩码，**不做任何瘀伤特定微调**，以检验域偏移下的泛化能力。

### 2.2 架构三组件
1. **视觉骨干（Visual Backbone）**：
   - 选项 A：**LingBot-Vision ViT-B/16**（掩码边界预训练，输入 512×512，输出 32×32 token 网格）。
   - 选项 B：**DINOv3 ViT-B/16**（自监督预训练，输入 224×224，输出 14×14 token 网格）。
2. **卷积上采样适配器（Convolutional Upsampling Adapter）**：
   - 将 token 重塑回空间网格 → 投影到 256 通道 → 上采样至 **56×56** → 两个 3×3 卷积块（GroupNorm 8 组 + GELU）。
   - 作用：① 匹配 SAM 解码器期望的嵌入分辨率；② 恢复细粒度边界细节；③ 作为**分辨率无关接口**，使两种骨干共用同一个 SAM 解码器。
3. **SAM 提示编码器与掩码解码器（SAM ViT-B）**：
   - 使用 LoRA（秩 r=8，缩放 α=8）适配其注意力、MLP、投影和线性层。
   - 最终掩码 logits 经双线性上采样 + Sigmoid + 阈值化得到二值瘀伤掩码。

### 2.3 训练策略
- **训练数据**：HAM10000（10,015 张皮肤镜图像）+ 专家二值掩码；86 张瘀伤图**仅用于评估**。
- **数据增强**：针对皮肤镜光照变化，采用 **MSRCP（多尺度 Retinex 色度保持）** 增强光照/对比度不变性。
- **损失函数**：总损失 `L_total = L_Dice + L_BCE`
  - Dice 损失鼓励预测概率图 P 与二值真值 G 的重叠；
  - BCE 损失通过 Sigmoid 概率 `P = σ(z)` 计算逐像素交叉熵。
- **优化配置**：
  - AdamW，权重衰减 1×10⁻⁴，bfloat16 混合精度。
  - DINOv3：150 epoch，lr = 2×10⁻⁵，batch size 64；输入 resize 256→中心裁剪 224。
  - LingBot：50 epoch，lr = 3×10⁻⁶，batch size 8 + 8 步梯度累积（有效 batch 64）；输入 resize 576→中心裁剪 512。

### 2.4 双区域标注协议（Dual-Region Protocol）
- 背景：瘀伤边界弥散，单一真值轮廓临床不现实；PRI/STAPLE 等多标注者协议在专家资源稀缺下难以实施。
- 流程：
  1. 一位医学专家先标注；
  2. 训练轻量分割模型，在多个概率阈值下生成候选掩码；
  3. 第二位医学专家审阅候选掩码，选定**高置信内区域（inner region）**与**可能但不确定的外区域（outer region）**。
- 评估时：内区域作为正样本真值，内-外之间的像素**从所有指标计算中排除**，避免边界不确定像素被误判为 FP/FN。

- **BruNet-LingBot 取得最佳综合性能**：Dice 0.8674、IoU 0.7897、Accuracy 0.9556。
- **BruNet-DINOv3 取得最高 Recall（0.8491）**，Dice 0.8386、IoU 0.7592，覆盖瘀伤更完整。
- 两个 BruNet 变体**均显著优于所有基线**（Holm–Bonferroni 校正后 p<0.05），包括最强非 BruNet 基线 OneFormer（Dice 0.7097 / IoU 0.6352）。
- **两个 BruNet 变体之间差异不显著**（Dice p_adj=0.4096，IoU p_adj=0.5480），但 LingBot 均值更高。
- **LLM 提示 + SAM 管道普遍偏保守**：GPT-5+SAM2 精度最高（0.9467）但 Recall 仅 0.2924；GPT-4o+SAM2 更保守（Dice 0.2299）。MedGemma+MedSAM 在 LLM 管道中最佳（Dice 0.5157）。
- **SAM3 零样本表现亮眼但不稳定**：Precision 0.9372、Accuracy 0.9208，但 Recall 0.5888；86 张中有 5 张未返回瘀伤实例。

  - 替换 SAM 解码器为卷积头 → Dice 0.867→0.848，IoU 0.790→0.764（Recall 高但 Precision 下降，表现为过分割）。

## 10. 总体评价

本文在**问题选择**上具有明确价值：瘀伤分割长期被忽视，却兼具临床、法医学与社会意义，且天然面临标注稀缺与边界不确定两大难题。作者没有回避这些困难，而是用"跨域零样本迁移 + 双区域不确定性感知评估"两条主线给出务实回应，思路清晰、动机自洽。

**方法上**，BruNet 的工程组合是合理且克制的：不重新设计分割范式，而是复用 ViT 语义特征与 SAM 可提示解码能力，用一个小型卷积适配器弥合分辨率鸿沟，并用 LoRA 降低适配成本。消融实验证明 SAM 解码器与 56×56 中间上采样各自贡献显著，说明设计并非堆砌。

**实验上**，基线覆盖面在同类工作中属较全面（传统 CNN、ViT SOTA、LLM 提示、医学 SAM、SAM3），并配有配对检验、bootstrap 置信区间与多重比较校正，统计规范性强于多数同类论文。结果一致显示 BruNet 显著领先，且效率优势明显（约 400 MiB、≤30 ms/图），具备部署可行性。

**主要短板**集中在证据强度而非方法本身：评估集仅 86 张、单次运行、消融仅在单一骨干上开展、训练时长与部分关键超参（阈值、MSRCP 增益、LoRA 必要性）未报告。这些使得"显著优于所有基线"的结论虽方向可信，但**稳健性边界仍待更充分的实验界定**。

**结论**：BruNet 是一篇定位精准、设计合理、实验规范的开创性工作，为瘀伤分割建立了首个可比较的基准与方法起点；其最大贡献或许不只是具体模型，而是提出了"跨域迁移 + 不确定性感知标注协议"这一在标注稀缺医学场景中可复用的研究范式。后续工作若能在更大规模、多来源、多种子、多专家标注的条件下复现并扩展，将进一步巩固其结论的可信度与临床相关性。
