## 摘要
平面设计，如海报、广告和信息图，是传递信息和塑造理解的重要媒介。与自然图像不同，它们由具有明确构成顺序的分层元素组成。然而，现有的目标检测模型将这些元素视为无序集合，未利用其构成顺序。为解决这一局限，我们提出平面设计任意检测（Detect Anything in Graphic Design, DAD），该模型将平面设计检测形式化为构成性解构。它按构成顺序解码元素，利用低层元素更好地检测高层元素。DAD 的关键特性是非模态检测，即预测每个元素的完整边界框，包括被位于其上方的元素遮挡的区域。基于这一形式化，我们提出元素相对策略优化（Element Relative Policy Optimization, EleRPO），它将 GRPO 从序列级监督扩展到元素级优化。EleRPO 提供细粒度训练信号，捕捉每个检测到的元素如何对整体检测质量作出贡献，并与构成顺序协同作用以提升检测性能。为支持训练和评估，我们构建了一个包含 1000 万个平面设计的数据集。实验表明，DAD 优于所有基线，并在非模态检测中达到人类水平性能，支持有效的图像到图层分解。在九个检测基准上，EleRPO 持续优于 GRPO。

## Abstract
Graphic designs, such as posters, advertisements, and infographics, are an important medium for communicating information and shaping understanding. Unlike natural images, they consist of layered elements with explicit compositional order. However, existing object detection models treat these elements as an unordered set, leaving compositional order unexploited. To address this limitation, we present Detect Anything in Graphic Design (DAD), a model that formulates graphic design detection as compositional deconstruction. It decodes elements in compositional order, using lower-layer elements to better detect higher-layer ones. The key feature of DAD is amodal detection, which predicts the full bounding box of each element, including regions occluded by elements placed above it. Building on this formulation, we propose Element Relative Policy Optimization (EleRPO), which extends GRPO from sequence-level supervision to element-level optimization. EleRPO provides fine-grained training signals that capture how each detected element contributes to overall detection quality, and works synergistically with compositional order to improve detection performance. To support training and evaluation, we build a dataset of 10 million graphic designs. Experiments show that DAD outperforms all baselines and achieves human-level performance in amodal detection, supporting effective image-to-layer decomposition. EleRPO consistently improves over GRPO across nine detection benchmarks.

## 1. 核心问题与整体含义

- **研究背景**：平面设计（海报、广告、信息图等）是信息传播的重要媒介。与自然图像不同，平面设计由离散的分层元素按明确的**构成顺序（compositional order）**堆叠而成，元素之间常发生部分或完全遮挡。
- **现实痛点**：设计作品常以扁平栅格图像（JPEG/PNG）分发，图层信息丢失，导致后续编辑困难；从扁平图像恢复图层成为关键下游任务。
- **现有方法的两个核心局限**：
  - 现有目标检测模型（面向自然图像或文本文档）将目标视为**无序集合**，无法预测元素间的构成顺序，恢复出的元素无法忠实还原原始设计。
  - 由于大规模遮挡区域标注困难，现有模型通常只预测**可见区域**，被遮挡元素的隐藏部分无法恢复。
- **整体含义**：论文提出 DAD 模型，将平面设计检测重新形式化为"**构成性解构（compositional deconstruction）**"，同时解决构图顺序预测与遮挡区域恢复两大问题，并配套提出元素级强化学习优化方法 EleRPO 与千万级数据集 DAD-10M。

## 2. 方法论

### 2.1 核心思想：构成性解构（DAD）

- **任务形式化**：给定图像 $I$，模型按构成顺序自回归地生成元素序列 $(e_1, \dots, e_m)$，策略为 $e_k \sim \pi_\theta(\cdot \mid e_{<k}, I)$，即用已预测的**低层元素**作为上下文来检测**高层元素**，契合设计师逐层构建设计的流程。
- **关键特性——非模态检测（amodal detection）**：每个元素由类别（文本 `t` / 视觉 `v`）和**完整边界框**表示，包含被上层元素遮挡的区域。
- **输出格式**：分号分隔的序列，每个元素编码为 `(x1, y1, x2, y2, c)`，坐标归一化到 [0, 1000]。

### 2.2 EleRPO：元素级奖励优化

- **动机**：GRPO 将序列级奖励（IoU 加权 F1）均匀分配给所有 token，忽略了每个元素对最终检测质量的贡献。高奖励 rollout 中的错误元素仍会获得正优势，从而被错误强化。
- **元素级奖励的三大理想性质**：
  - **完备性**：$\sum_{k=1}^m r_k = \text{F1} - \mathbb{E}[\text{F1} \mid I]$
  - **因果性**：$r_k$ 仅依赖 $e_{\leq k}$
  - **无偏性**：$\mathbb{E}[r_k \mid e_{<k}, I] = 0$
- **鞅差分解（Martingale Difference Decomposition）**：上述三性质唯一确定元素级奖励为 F1 的鞅差：
  $$r_k = \mathbb{E}[\text{F1} \mid e_{\leq k}, I] - \mathbb{E}[\text{F1} \mid e_{<k}, I]$$
  进一步分解为：
  $$r_k = \Delta\text{F1}(k) - \left(\mathbb{E}[\text{F1} - \text{F1}(k-1) \mid e_{<k}, I] - \mathbb{E}[\text{F1} - \text{F1}(k) \mid e_{\leq k}, I]\right)$$
  论文附录 A.1 给出了完整证明，包括三性质与鞅差的唯一对应关系。
- **奖励估计（无需额外奖励模型或重采样）**：
  - 用 rollout 采样近似条件期望；不同 rollout 的 $e_{<k}$ 不同，直接比较有偏。
  - **前缀聚类近似**：用 $\text{F1}(k-1)$ 作为前缀状态的代理，对 rollout 做 k-means 聚类（$N_c$ 由轮廓系数选择），同一簇内做**配对比较**：
    $$\hat{r}_k^{(i)} = \Delta\text{F1}(k)^{(i)} - \frac{1}{|C_k(i)|}\sum_{j \in C_k(i)} \Delta\text{F1}(k)^{(j)}$$
  - 与昂贵的重采样估计器达到 Pearson 相关 0.81（附录 A.3，36,018 个 rollout、约 72 万次重采样验证）。
  - 论证了**必须对两个残差项使用同一簇**，否则引入 cluster-reassignment bias（附录 A.2）。
- **幅度分析与归一化**：证明 $|\hat{r}_k^{(i)}| = O(1/(k+n))$（$n$ 为真实元素数），低层元素奖励幅度更大，故按**层内标准差**归一化：
  $$\hat{A}_k^{(i)} = \hat{r}_k^{(i)} \Big/ \sqrt{\frac{1}{|G_k|}\sum_{j \in G_k}(\hat{r}_k^{(j)})^2 + \epsilon}$$
- **优势组合**：将元素级优势与序列级 GRPO 优势按 $\tilde{A} = \frac{1}{2}(\hat{A}_{\phi(i,t)}^{(i)} + \hat{A}^{(i)})$ 结合，兼顾细粒度与稳定性。
- **损失函数**：采用 PPO 式裁剪目标 + KL 正则（系数 $\beta=0.04$）。

### 2.3 DAD-10M 数据集构建

- **数据采集**（共 10,416,655 个设计）：

- **排序准确率（POA）显著高于所有基线**：由于自回归策略天然建模构成顺序，DAD 是唯一能稳定输出符合设计堆叠顺序的模型；论文的元素顺序消融进一步显示，使用构成顺序监督相比随机顺序或左边缘启发式排序带来明显提升。
- **人工评估接近人类水平**：在 500 个遮挡元素上，DAD 与人类标注的平均 IoU 高于 GPT-5.5 与 Gemini-3.1-Pro，且与组内标注者间 IoU（人类水平参考）差距较小，表明其非模态框在主观质量上已具实用价值。
- **下游分解质量受益**：在图像到图层分解任务中，以 DAD 输出框驱动 MRT 模型，在 PSNR、SSIM、RGB L1、Alpha SIoU 以及遮挡区域的 Occ-PSNR / Occ-SSIM 上全面优于使用 GPT-5.5、Gemini-3.1-Pro 框的结果，接近（但未超过）使用 GT 框的上界，验证了检测质量的端到端价值。
- **EleRPO 优于现有 RL 方法**：在 DAD-10M 上，EleRPO 在 F1@[.5:.95] 与 IoU 加权 F1 上稳定超过 GRPO、GRPO-λ、GTPO、PRIME、VinePPO、SPO；尤其值得注意的是，EleRPO 以远低于 re-rollout 类方法（VinePPO、SPO）的采样开销取得更好效果，说明其前缀聚类奖励估计是有效的低成本替代方案。
- **消融结论要点**：
  - **因果性**：使用 $\Delta\text{F1}$ 而非原始 IoU 作为元素奖励信号更优，验证了鞅差分解中"奖励应反映边际贡献"的设计。
  - **优势组合**：元素级 + 序列级组合优于任一单独使用，说明细粒度信用分配与序列级稳定性互补。
  - **归一化**：逐层（per-layer）标准差归一化优于无归一化与全局归一化，与 $|\hat{r}_k| = O(1/(k+n))$ 的理论分析一致。
  - **均值减法**：逐层均值减法优于全局均值减法，避免了不同层级奖励分布混杂。
  - **前缀聚类**：轮廓系数自适应选 $N_c$ 优于固定 $k$、无聚类或跨簇配对；跨簇配对会引入 cluster-reassignment bias，与附录 A.2 的论证吻合。
- **泛化性结论**：在 DAD-SFT、Rex-Omni-SFT、微调 Qwen3-VL 三个模型上，EleRPO 在 9 个基准（含 COCO、LVIS、BDD100K、Objects365 等自然图像数据集）上普遍优于 GRPO，说明元素级信用分配并非平面设计任务专属，而是对一般自回归检测/定位式奖励优化具有可迁移性。

## 7. 方法优势与创新点

1. **问题重定义**：将平面设计检测从"无序集合预测"重构为"构成性解构"，把构成顺序显式纳入输出空间，这是与既有自然图像检测范式的根本区别。
2. **非模态检测的规模化监督**：借助设计师分层源文件自动导出被遮挡区域的真实框，绕开了人工标注非模态框的瓶颈，是 DAD-10M 能成立的关键。
3. **理论驱动的 RL 奖励设计**：EleRPO 从完备性、因果性、无偏性三性质出发，唯一导出鞅差形式的元素级奖励，而非启发式设计；并给出前缀聚类近似与幅度分析，形成"理论—估计—归一化"闭环。
4. **工程可行性**：奖励估计不需要额外奖励模型，也不需要 re-rollout，仅复用已有的 16 个 rollout，显著降低 RL 训练成本（20 小时 / 8×H200）。
5. **数据选择策略**：两步过滤（小元素召回率筛 + union-find 重叠连通分量筛）针对"粒度歧义"这一平面设计特有的标注难题，具有可复用性。

## 8. 局限性与批判性讨论

- **数据来源偏置**：训练数据主要来自设计师原创分层作品与元素替换合成，可能偏向特定设计风格（如模板化海报、社交媒体图），对极端艺术化、手绘或 3D 渲染类设计的外推能力未充分验证。
- **顺序定义的唯一性**：构成顺序来自源文件图层堆叠顺序，但同一视觉结果可能存在多种合法图层组织方式；论文用 POA 评估排序，但 POA 是成对相对排序，对"平局/等价顺序"的处理未详述。
- **RL 对比范围有限**：EleRPO 与 7 种 RL 方法的横向对比仅在 DAD-10M（IoU 加权 F1 奖励）上进行；泛化性实验虽覆盖 3 个模型 × 9 个基准，但仅对比 GRPO，未与其他 RL 基线在自然图像任务上复现对比。
- **专有模型评估次数**：因 API 成本，专有基线仅单次评估、无方差报告，虽然论文如实说明，但与开源模型 3 次运行的均值±方差相比，统计可比性略弱。
- **推理效率**：自回归逐元素生成在元素数量多（如复杂信息图）时存在序列长度瓶颈；论文报告了平均推理时间，但未深入讨论元素数增长下的延迟曲线与失败模式。
- **类别粒度较粗**：仅区分文本与视觉两类元素，未涉及更细的语义类别（如按钮、图标、图片、形状），限制了在需要类别语义的下游编辑任务中的直接可用性。
- **文本元素处理**：文本元素以边界框表示，未涉及文本内容识别（OCR）或字体属性，若下游任务需要文本重排，仍需额外模块。

## 9. 总体评价

本文的核心贡献在于把一个被忽视的任务属性——**元素间的构成顺序与遮挡**——提升为建模的第一性问题，并配套给出可规模化的数据、可证明的奖励设计与完整的实证验证。DAD 在多项基准与人工评估上的领先、以及在图层分解下游任务中的增益，表明该形式化是有效的而非仅指标上的技巧。EleRPO 的鞅差分解为该类"序列生成 + 集合式指标"的 RL 优化提供了有理论依据的通用工具，其跨任务泛化结果增强了这一贡献的独立性。主要不足在于数据风格覆盖、顺序定义的等价性处理与 RL 对比广度，这些也构成后续工作的自然方向。
