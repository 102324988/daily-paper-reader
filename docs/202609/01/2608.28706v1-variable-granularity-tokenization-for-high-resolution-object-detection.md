## 摘要
ViT检测器在任何学习阶段之前固定一个均匀的令牌网格。原生分辨率航空检测器必须在解析少像素目标和保持在计算与内存限制内之间做出选择。我们提出了VGTok，一种免训练的tokenizer，在编码器之前根据像素为每个区域设置块粒度。VGTok通过多尺度形态学顶帽可分离性对其周围背景进行评分，然后以每图像百分位数对这些分数进行阈值化，从而确定令牌预算。结构张量门（λ_min）仅在二维目标结构支持的地方进行细化，留下粗粒度的一维杂波。生成的令牌集是图像的严格划分。在使用EVA-02 ViT-L编码器的Co-DETR检测器中，VGTok在40%到100%的令牌预算下清除了所有已发表的VisDrone-val AP和AP_S。在40%预算下，它记录了44.22 AP，在第一个transformer块之前丢弃了五分之三的序列；密集时达到48.38 AP，比最强发表条目高6.08。VGTok无需修改即可迁移到AI-TOD-v2，使用相同的评分器和相同的排名，并在37.27 AP和19.51 AP_vt上创下新纪录。作为冻结检查点的纯插入式模块，它以78.5%的令牌实现了36.29 AP，超过所有已发表条目，其中我们的376.3M参数检测器超过了3.0B多专家模型。我们表明，在主干之前根据局部可分离性和结构几何单独确定令牌预算，在以3.1倍更少的编码器计算和1.9倍更少的编码器内存下，在主导航空检测的微小目标区域上保持准确性。代码和模型可在github.com/khayrulbuet13/vgtok和huggingface.co/khayrulbuet13/vgtok获取。

## Abstract
ViT detectors fix a uniform token grid before any learned stage. A native-resolution aerial detector must then choose between resolving few-pixel objects and staying inside compute and memory limits. We introduce VGTok, a training-free tokenizer that sets patch granularity per region from pixels, ahead of the encoder. VGTok scores each region by multi-scale morphological top-hat separability from its surround, then thresholds those scores at a per-image percentile, which fixes the token budget. A structure-tensor gate ($λ_{\min}$) refines only where two-dimensional object structure supports it, leaving one-dimensional clutter coarse. The resulting token set is a strict partition of the image. In a Co-DETR detector with an EVA-02 ViT-L encoder, VGTok clears every published VisDrone-val AP and AP$_S$ at every budget from 40\% to 100\% of tokens. At 40\% it records 44.22 AP with three fifths of the sequence discarded before the first transformer block; dense, it reaches 48.38 AP, $6.08$ above the strongest published entry. VGTok transfers to AI-TOD-v2 untouched, same scorer and same rank, and sets a new state of the art at 37.27 AP and 19.51 AP$_{vt}$. As a pure drop-in into a frozen checkpoint it reaches 36.29 AP at 78.5\% of tokens, above every published entry, where our 376.3M-parameter detector clears a 3.0B multi-expert model. We show that a token budget fixed before the backbone, from local separability and structure geometry alone, holds accuracy on the tiny-object regimes that dominate aerial detection, at $3.1\times$ less encoder compute and $1.9\times$ less encoder memory. Code and models are available at \href{https://github.com/khayrulbuet13/vgtok}{\texttt{github.com/khayrulbuet13/vgtok}} and \href{https://huggingface.co/khayrulbuet13/vgtok}{\texttt{huggingface.co/khayrulbuet13/vgtok}}.

## 1. 论文的核心问题与整体含义（研究动机和背景）

高分辨率航拍图像中的微小目标检测面临严重的分辨率与计算效率矛盾。ViT检测器在进入任何学习阶段之前就固定了均匀的Token网格，若网格过细则全图计算成本过高，若网格过粗则无法解析只有几个像素的微小目标。已有方法如SAHI通过滑动窗口切块来提升分辨率，但将计算预算均匀分配，导致背景区域和致密集群获得相同的每像素分配。核心问题在于：**如何在进入主干网络之前，仅从像素级信息出发，为每个区域动态分配合理的Token粒度，在保持微小目标精度的同时大幅降低计算量。**

## 2. 方法论：核心思想、关键技术细节

### 核心思想
VGTok是一个**免训练的Token化器**，在编码器运行之前根据像素特征为每个区域设置粒度等级。其Token集构成图像的**严格划分**（每个像素只被描述一次，不存在重叠），通过两个训练无关的统计量实现：**多尺度形态学顶帽分离度**（决定"看哪里"）和**结构张量最小特征值门控**（决定"在哪里停止细化"）。

### 关键技术细节

**（1）区域评分——多尺度形态学顶帽分离度**
- 在BT.601亮度通道上计算白色和黑色顶帽变换；
- 在结构元素宽度 w ∈ {5, 9, 17} 下取两种极性的最大响应，使分数与目标面积无关（边长2与边长16的目标得分相同）；
- 三种尺度网格（16/32/64像素）从单一画布上最大池化获得，保证嵌套关系：每个粗节点恰好覆盖4个细节点；
- 单遍（Single-pass）和四叉树（Top-hat）两种消费方式：前者按尺度独立设置百分位数阈值并做差集；后者从最细网格取一个全局百分位数后自顶向下递归。

**（2）停止规则——λmin门控**
- 结构张量 J 为梯度外积的窗口均值，λmin 为较小特征值；
- 一维结构（道路标线、屋顶脊线）的梯度方向一致，λmin ≈ 0，为各向异性；二维结构（车辆、转角）梯度方向分散，λmin 较大；
- 定义各向异性分数 g(v) = 1/(1 + λmin)，节点取内部最大λmin；
- 对Top-hat要访问的忙碌节点按g排序，排名前 r = 0.20 的节点停止细化并以其粗粒度输出，抛弃其4个子节点；
- 门控是唯一的超参数，在VisDrone和AI-TOD-v2上均保持 r = 0.20。

**（3）预算控制与打包执行**
- τ 取最细网格分数的第 p 百分位数（按图像），保留比例由操作者设定，不依赖学习权重；
- 所有尺寸的Token嵌入共享同一卷积；4个Token的预算替代先覆盖的16个Token；在4个Token预算下，丢弃60%序列后仍达到44.22 AP；全Token时达到48.38 AP，比最强已发表结果（DroneFINE-L的42.3 AP）高出6.08 AP。

## 7. 优点（方法与实验设计的亮点）

- **免训练设计**：评分器和门控均无学习参数，可直接插入冻结检查点使用，部署灵活；
- **预编码器决策**：在补丁投影之前完成，所有后续机制（剪枝、注意力等）继承此预算，无需反向映射；
- **严格划分保证**：Token集是图像的严格分区，无重叠描述，节省后处理成本；
- **λmin门控的创新使用**：利用结构张量特征值区分二维对象结构与一维杂波（如路面标记、建筑边缘），精准防止token浪费在一维结构上；
- **按图像百分位控制预算**：保留比例成为操作者输入而非学习结果，同一检查点可服务多个预算档位；
- **解耦评分与停止决策**：将"是否值得细化"与"是否真的需要细化"分离，有效解决了传统四叉树全有全无细化的浪费问题；
- **实验设计的严格性**：双层预算匹配（反向保留表+再测量）、三次种子均值报告、seed floor制度、AI-TOD-v2跨数据集零调参验证、可复现的推理成本表（FLOPs、延迟、内存同时报告）；
- **规模分解分析**：对AI-TOD-v2按面积段和类别逐一审计门控效果，识别出风车类别符合预期的性能下降，显示了机制的因果性而非相关性。

## 8. 不足与局限

- **AI-TOD-v2上无80%预算数据**：r=0.20时门控将AI-TOD-v2的保留率上限限制在78.5%，因而缺少80%档的对比数据；
- **能源与成本细节不足**：未详细报告训练的GPU总时长、电力消耗或全部微调的总算力，难以进行训练成本的横向比较；
- **通用性局限**：VGTok的两项统计量针对航空影像中的微小目标设计；在背景杂波稀疏或一维结构较多的场景中（如城市街景）其门控可能表现不佳；
- **对超参数r的敏感性**：虽然r=0.20在两种数据集上均适用，但该值是在VisDrone val上选择的，对其他数据集（如遥感、医学影像等）的普适性未验证；
- **大规模对象的退化**：门控机理预测小对象受益最大，但未说明对中、大对象或密集场景（如人群）的潜在负面影响；
- **AI-TOD-v2上APvt的不稳定性**：门控在very-tiny带上的效果受个别类别（如飞机类仅有17个标注框）的极端影响，且对风车类造成明显损失（-1.04 APvt）；
- **头部开销未优化**：编码器外的neck和检测头（4.76–4.83 GB内存）不随token数下降，VGTok的节省集中在编码器部分；
- **融合层的训练需求**：粗尺度Token嵌入继承自patch融合，该融合层在零样本中保持惰性（零初始化），但在学生训练时若不经过微调可能产生偏差；
- **实验覆盖的不对称性**：在AI-TOD-v2上，训练态数据仅在70%和40%两个预算下可用，与VisDrone的4–5档完整覆盖形成对比，限制了跨预算跨数据集的泛化断言。
