## 摘要
指称单目标跟踪通过联合利用语义线索和视觉模板，实现基于语言的目标初始化和后续跟踪。核心难点在于不同阶段对语言的使用方式不同：语言对于目标定位必不可少，但在跟踪过程中若过度强调，则可能导致语义漂移。同时，当前方法通常需要昂贵的视觉-语言对齐训练。我们提出了LVTrack，一个纯Transformer框架，引入了模式条件门控特征注入器来自适应调节文本指导并缓解语义漂移。结合针对性的适配，它直接利用冻结的视觉-语言预训练模型，大幅降低训练成本并保持强大的语言理解能力。为了进一步提升时间定位，LVTrack集成了混合相对-绝对位置编码和轻量级记忆机制，并使用高斯平滑KL损失优化自回归框预测。在标准基准上的大量实验表明，LVTrack取得了强劲的性能。

## Abstract
Referring single-object tracking enables language-grounded target initialization and subsequent tracking by jointly leveraging semantic cues and visual templates. The core difficulty is to use language differently across stages: it is indispensable for grounding but can induce semantic drift during tracking when overemphasized. Meanwhile, current methods often require costly vision-language alignment training. We present LVTrack, a pure transformer framework that introduces a mode-conditioned Gated Feature Injector to adaptively regulate textual guidance and alleviate semantic drift. Together with targeted adaptations, it directly harnesses a frozen vision-language pretrained model, greatly reducing training cost and preserving strong language understanding. To further improve temporal localization, LVTrack integrates hybrid relative-absolute positional encodings with a lightweight memory mechanism and optimizes autoregressive box prediction using a Gaussian-smoothed KL loss. Extensive experiments on standard benchmarks demonstrate that LVTrack achieves strong performance.

### 1. 论文的核心问题与整体含义

- **研究背景**：指称单目标跟踪（Referring Single-Object Tracking, RSOT）允许用户通过自然语言描述来指定并跟踪目标，相比仅靠边界框（BBOX）的传统跟踪更灵活、更直观。RSOT 通常被解耦为视觉定位（visual grounding）与视觉跟踪（visual tracking）两个子任务。
- **核心问题**：语言在不同阶段的作用存在内在矛盾：
  - 在第一帧定位（grounding）时，语言是主要甚至唯一的定位线索，不可或缺；
  - 在后续逐帧跟踪中，语言描述往往不足以提供可靠的时序线索，过度依赖语言会诱发**语义漂移**（semantic drift），使模型偏向语义相似的干扰物。
- **另一个关键问题**：现有 RSOT 方法通常依赖端到端训练视觉与语言骨干来实现跨模态对齐，而训练数据（跟踪和定位数据集）规模不足以支撑通用级别的对齐学习，导致训练成本高昂且容易过拟合。
- **论文含义**：提出 LVTrack 框架，通过冻结大规模视觉-语言预训练（VLP）模型，配合轻量级门控注入器，在不进行昂贵对齐训练的情况下实现高效的指称式单目标跟踪，同时抑制跟踪过程中的语义漂移，兼顾定位能力与跟踪稳定性。

### 2. 论文提出的方法论

#### 2.1 总体框架
LVTrack 包含三个核心组件：
- **多模态骨干 + 特征注入器**：使用冻结的 VLP 骨干（采用 PE-Base，Perception Encoder Base 规模），取前 10 层 ViT 特征；
- **时空增强 Transformer 编码器**：对模板与搜索区域特征进行交互建模；
- **自回归定位解码器**：以 SeqTrack 风格逐 token 预测归一化边界框坐标 (x, y, w, h)。

框架支持三种模式：模板跟踪（S）、语言定位（G）、语言+模板联合跟踪（T），通过动态输入掩码在同一架构下实现任务解耦。

#### 2.2 模式条件门控特征注入器（MGFI）
- **注入机制**：在视觉骨干的选定层（第 5–10 层）插入跨注意力模块，从对应的语言层（第 14、16、18、20、22、24 层）聚合文本语义，并通过可学习的通道级门控注入视觉特征流。更新方式可写成扰动形式：

  \[
  \hat{f}_s^n = f_s^n + \lambda_{attn}^m \odot \text{MHCA}_n(f_s^n, f_L^{\tau(n)}, f_L^{\tau(n)})
  \]
  \[
  \Delta_m^n = (\hat{f}_s^n - f_s^n) + \lambda_{mlp}^m \odot \text{MLP}_n(\hat{f}_s^n)
  \]
  \[
  \tilde{f}_s^n = f_s^n + \Delta_m^n
  \]

  其中 \(\lambda = \tanh(\gamma)\)，\(\gamma\) 初始化为 0，实现从零扰动开始的渐进式注入。

- **双模式门控与正则化**：跨注意力模块在模式间共享，但门控参数 \(\gamma^m\) 与 MLP 分支按模式区分。为了抑制跟踪时的语言主导，引入幅值比损失：

  \[
  \mathcal{L}_{ratio} = \max\left(0, \log\|\lambda_{attn}^T\| - \log\|\lambda_{attn}^G\| - \log\rho\right)
  \]

  该损失强制跟踪模式的门控幅值不超过定位模式的 \(\rho\) 倍（默认 \(\rho=0.6\)），实现"视觉锚定、语言辅助"的不对称融合，从原理上限制语言注入对跟踪决策的最大扰动。

#### 2.3 时空跟踪建模
- **记忆融合**：用 RoI Align 从历史预测框对应的特征图中提取固定长度记忆 token，通过跨注意力注入当前搜索特征，并配备可学习门控 \(\lambda_{mem}\)；推理时仅当置信度超过阈值（0.03）才更新记忆，避免噪声累积。
- **混合位置编码**：结合共享的 2D 可学习绝对位置嵌入（模板位置通过双线性插值从搜索区域坐标网格采样得到）与 2D 轴向 RoPE（将通道分裂为 x/y 两半分别施加旋转位置编码），同时提供绝对坐标参考与平移不变的相对几何先验。

#### 2.4 高斯平滑 KL 损失（GS-KL）
- 将自回归坐标 token 分类的 one-hot 目标替换为以真实 bin 为中心的高斯软目标（带宽 \(\sigma=4\)），使损失对"接近正确"的 bin 给予更大的监督权重，注入空间序数先验，缓解坐标离散化带来的量化歧义，使分类任务获得类似回归的距离敏感性：

  \[
  T_i(k) = \frac{\exp\left(-\frac{(k-y_i)^2}{2\sigma^2}\right)}{\sum_j \exp\left(-\frac{(j-y_i)^2}{2\sigma^2}\right)}, \quad \mathcal{L}_{loc} = \sum_{i=1}^4 D_{KL}(T_i \| P_i)
  \]

- 总体训练目标：\(\mathcal{L} = \mathcal{L}_{loc} + \lambda_{ratio}\mathcal{L}_{ratio}\)。

### 6. 论文的局限性与潜在问题

- **对预训练模型及其内部结构的依赖**：方法从冻结的 VLP 骨干中抽取语言 token 并固定手工选择层（第 14、16、18、20、22、24 层）进行注入，这种设计依赖特定模型架构的内部语义分布，更换骨干时需要重新标定层对应关系，通用性受到一定限制。
- **语言注入门控的路径约束仍然较粗**：门控幅值比损失从"总注入能量"层面约束语言影响，但并未精细化到 token 级或通道级的语义维度，因此无法完全避免某些高频干扰属性（如颜色、纹理）通过特定通道被过度注入。
- **跟踪模式的长尾场景鲁棒性存疑**：在跨模态指代与视觉模板存在明显冲突（例如描述目标是"树下那只白猫"，而模板框内实际不止一只猫）时，仅靠门控比例的全局约束并不能显式建模"语言与视觉不一致时的仲裁机制"，可能仍会发生错跟。
- **记忆融合的阈值策略简化**：仅根据置信度阈值决定是否更新记忆，缺少对遮挡、形变、出视野等复杂状态的显式状态机建模，在长时跟踪或目标反复消失出现的场景中，记忆污染风险没有彻底解除。
- **自回归坐标解码的参数量与训练难度**：虽然坐标 bin 分类方式与大型语言模型式解码器天然契合，但自回归解码导致的序列依赖在长尾样本上的误差累积风险未被专门分析。
- **评估局限**：未在短期跟踪基准，如 GOT-10k 的完整测试集、UAV123 等更大规模数据上进行验证，也未在长时跟踪协议（如 LaSOT_extension）下报告结果，因此对泛化性的论证仍不完整。
