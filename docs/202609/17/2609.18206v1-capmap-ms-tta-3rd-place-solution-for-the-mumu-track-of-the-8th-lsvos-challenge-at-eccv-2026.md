## 摘要
第8届大规模视频目标分割（LSVOS）挑战赛的 MUMU 赛道要求使用一个统一的多模态模型，在严格资源约束（参数不超过 0.5B、GPU 峰值显存不超过 8 GB）下，联合解决图像标注（任务 A）、开放词汇目标检测（任务 B）和英文描述生成（任务 C）。我们提出 CapMap-MS-TTA，这是一种无需训练的提交方案，基于 Microsoft Florence-2-base（约 2.31 亿参数）构建，结合了描述关键词映射与多尺度翻转测试时增强。任务 C 使用原生 <DETAILED_CAPTION> 路径，并进行长度/词元清洗。任务 A 通过扩展的关键词词典，采用全词匹配以及轻量级扩展提示阶段，将同一详细描述映射到官方的质量/场景/事件词汇表中。任务 B 运行 Florence-2 开放检测（<OD>），采用多尺度和水平翻转测试时增强（TTA），随后进行标签感知非极大值抑制（NMS）。在不进行微调的情况下，该系统将我们复现的 Florence-2 基线从 15.16 提升至最佳公开分数 16.4815，并在最终 MUMU 排行榜上排名第 3。

## Abstract
The MUMU track of the 8th Large-scale Video Object Segmentation (LSVOS) Challenge requires a single unified multimodal model to jointly solve image tagging (Task A), open-vocabulary object detection (Task B), and English captioning (Task C) under strict resource constraints (<=0.5B parameters and <=8 GB peak GPU memory). We present CapMap-MS-TTA, a training-free submission built on Microsoft Florence-2-base (~231M parameters), combining caption keyword mapping with multi-scale flip test-time augmentation. Task C uses the native <DETAILED_CAPTION> pathway with length/token sanitization. Task A maps the same detailed caption into the official quality/scene/event vocabularies via an expanded keyword lexicon with whole-word matching and a lightweight expand-hints stage. Task B runs Florence-2 open detection (<OD>) with multi-scale and horizontal-flip test-time augmentation (TTA), followed by label-aware non-maximum suppression (NMS). Without fine-tuning, the system improves our reproduced Florence-2 baseline from 15.16 to a best public score of 16.4815, and ranks 3rd on the final MUMU leaderboard.

## 2. 方法论：CapMap-MS-TTA

- **核心思想**：
  - 使用一个共享的 Florence-2-base 检查点服务全部三项任务；
  - 任务 A 和任务 C 共享 `<DETAILED_CAPTION>` 描述路径；
  - 任务 B 使用 `<OD>` 开放检测，并叠加多尺度与水平翻转 TTA；
  - 全程不微调，依赖确定性后处理和测试时计算。

- **统一骨干**：
  - 模型：`microsoft/Florence-2-base`；
  - 参数量约 **231.41M**，低于 0.5B；
  - batch size = 1 时峰值显存约 **0.6 GB**，低于 8 GB；
  - 所有任务共享参数 \(\theta\)，不进行微调。

- **任务 C：详细描述生成**：
  - 使用原生 `<DETAILED_CAPTION>` 路径；
  - 解码使用 beam search，`num_beams = 3`，固定 `batch_size = 1`，因为 padding 会改变 Florence 生成结果并破坏可复现性；
  - 后处理流程：
    1. `Norm`：合并空白字符；
    2. `Trunc≤300`：限制字符数不超过 300；
    3. `Π≤30`：贪心丢弃末尾空白分隔 token，直到 token 数不超过 30。
  - 最终提交描述可表示为：
    \[
    c = \Pi_{\le 30}(\text{Trunc}_{\le 300}(\text{Norm}(y)))
    \]

- **任务 A：描述关键词映射 + Expand-Hints**：
  - 维护短语到官方标签的词典 \(M: \text{phrase} \rightarrow t \in V\)；
  - 对描述文本小写化后做**全词/全短语匹配**，避免子串误匹配，例如 `ski ⊂ skin`、`mall ⊂ small`；
  - 匹配集合为：
    \[
    \text{Map}(y;M)=\{M(p)\mid p\in dom(M), p \text{ 在 } \tilde y \text{ 中作为完整短语出现}\}
    \]
  - 图像统计质量先验：
    - 计算灰度图 \(G\) 的拉普拉斯方差 \(v=\text{Var}(\Delta G)\) 和均值 \(\mu=\text{Mean}(G)\)；
    - 根据模糊、低光、过曝/欠曝阈值生成启发式质量标签 \(Q(v,\mu)\subseteq V_q\)。
  - Expand-Hints 融合：
    \[
    T = T_0 \cup \text{Map}(y;M) \cup Q(v,\mu)
    \]
    即只增加标签，不删除基础标签，保证召回不会低于基础阶段。
  - 室内/室外清理：
    - 若同时出现 `indoor` 和 `outdoor`，移除 `outdoor`；
    - 否则根据室内/室外指示子集补充对应标签，减少互斥冲突。

- **任务 B：多尺度 + 翻转 OD TTA**：
  - 尺度集合 \(S=\{0.75,1.0,1.25\}\)；
  - 对每个尺度 \(s\)，生成原图和水平翻转图的检测结果；
  - 翻转空间框先反射回原方向：
    \[
    H^{-1}(b)=(W-x_2, y_1, W-x_1, y_2)
    \]
  - 再按尺度映射回原图坐标：
    \[
    \Phi_s(b_s)=\left(x_1\frac{W}{W_s}, y_1\frac{H}{H_s}, x_2\frac{W}{W_s}, y_2\frac{H}{H_s}\right)
    \]
  - 候选框池：
    \[
    P = \bigcup_{s\in S}\left(\Phi_s(\text{OD}(I_s)) \cup \Phi_s(H^{-1}(\text{OD}(H(I_s))))\right)
    \]
  - 使用**标签感知 NMS**：
    - IoU 阈值 \(\tau=0.5\)；
    - 保留框数 \(|K|\le 300\)；
    - 仅当标签不同或 IoU 不超过阈值时才保留；
    - 丢弃畸形标签，如含逗号、冒号或长度超过 60 的标签。
  - Florence OD 常返回空分数列表，此时统一设置分数 \(s(b)\equiv 0.85\)。由于分数恒定，阈值化无法排序，因此主要增益来自几何 TTA + NMS。

- **整体推理流程**：
  1. 用 `<DETAILED_CAPTION>` 生成描述 \(y\)，经清洗得到任务 C 输出 \(c\)；
  2. 用词典映射、质量先验和 expand-hints 得到任务 A 标签 \(T\)；
  3. 用多尺度翻转 TTA 和标签感知 NMS 得到任务 B 检测框 \(K\)；
  4. 输出 `{T, K, c}`，仅包含官方 `model_info` 字段。
