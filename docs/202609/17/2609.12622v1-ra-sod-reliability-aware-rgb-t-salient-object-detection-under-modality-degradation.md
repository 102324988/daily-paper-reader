## 摘要
RGB-热成像（RGB-T）显著目标检测利用可见光和热成像模态的互补线索，以提高在挑战性环境中的鲁棒性。然而，在现实场景中，每种模态的可靠性本质上是不稳定的：RGB 图像在低照度、运动模糊和噪声下会退化，而热成像图像则常常受到对比度压缩和传感器伪影的影响。此类退化会引入不可靠的感知证据，从而误导跨模态融合并显著降低检测性能。为应对这一挑战，我们提出 RA-SOD，一种可靠性感知的 RGB-T 显著目标检测框架，它显式地建模模态可靠性并将其集成到特征学习和跨模态融合中。首先，我们引入一种可靠性条件表示，能够自适应地补偿退化的模态特征，同时保留结构线索。其次，一种不确定性引导的双流细化策略逐步校正跨模态表示，同时抑制不可靠证据。最后，我们提出一种逐像素模态竞争机制，根据空间可靠性动态选择模态线索以进行细粒度融合。在四个基准（VT821、VT1000、VT5000 和 VT-IMAG）上的大量实验表明，RA-SOD 达到了最先进的性能，并在严重模态退化下表现出强鲁棒性。代码和模型可在 https://github.com/zaoxienian/RA-SOD 获取。

## Abstract
RGB-Thermal (RGB-T) salient object detection leverages complementary cues from visible and thermal modalities to improve robustness in challenging environments. However, in real-world scenarios, the reliability of each modality is inherently unstable: RGB images degrade under low illumination, motion blur, and noise, while thermal imagery often suffers from contrast compression and sensor artifacts. Such degradation introduces unreliable perceptual evidence that can mislead cross-modal fusion and significantly deteriorate detection performance. To address this challenge, we propose RA-SOD, a reliability-aware RGB-T salient object detection framework that explicitly models modality reliability and integrates it into feature learning and cross-modal fusion. First, we introduce a reliability-conditioned representation that adaptively compensates degraded modality features while preserving structural cues. Second, an uncertainty-guided dual-stream refinement strategy progressively corrects cross-modal representations while suppressing unreliable evidence. Finally, we propose a pixel-wise modality competition mechanism that dynamically selects modality cues according to spatial reliability for fine-grained fusion. Extensive experiments on four benchmarks (VT821, VT1000, VT5000, and VT-IMAG) demonstrate that RA-SOD achieves state-of-the-art performance and exhibits strong robustness under severe modality degradation. Code and models are available at https://github.com/zaoxienian/RA-SOD.

## 1. 核心问题与整体含义

- **研究背景**：RGB-T（可见光—热红外）显著目标检测通过融合两种模态的互补信息，提升低照度、复杂背景等场景下的鲁棒性。现有方法多聚焦于设计精巧的融合策略（双流架构、注意力加权等），隐含假设编码阶段提取的模态特征足够可靠。
- **核心问题**：真实场景中模态可靠性本质上不稳定——RGB 易受低照度、运动模糊、噪声影响；热红外常出现对比度压缩、温度梯度抑制、块状伪影。这类**模态退化**会引入不可靠甚至误导性的感知证据，且退化往往在编码早期出现并沿网络层级传播、放大，使后续融合模块工作在已损坏的表示上。
- **整体含义**：论文提出 RA-SOD，将“可靠性”从辅助先验或后期加权线索提升为**贯穿表示、细化、融合三个阶段的核心建模原则**，构建统一的层级化可靠性框架，以抑制退化证据对跨模态融合的误导。

## 2. 方法论

- **核心思想**：在共享冻结骨干网络基础上，引入并行残差调制分支、显式不确定性估计与像素级模态竞争，使网络能够根据输入相关的可靠性自适应地补偿退化特征、校正跨模态表示并选择可靠模态线索。
- **总体架构**：给定对齐的 RGB 与热红外输入，采用共享冻结骨干提取各阶段基础特征，构建可靠性条件表示；随后并行解码 RGB 流、热流与融合流三条层级结构，各流经独立轻量预测头输出显著图，最终线性聚合得到 S = S_r + S_t + S_fus。

- **可靠性条件骨干表示（RCBR）**：
  - 冻结骨干块产生基础特征 F^{m,base}_l = B_l(F^{m}_{l-1})，保留稳定结构先验。
  - **特征条件模态路由**：由轻量门控函数 g 从基础特征预测专家权重 α，经 Softmax 归一化，使路由决策隐式捕捉模态相关的可靠性分布偏移。
  - **MoE 引导残差适应**：残差分支由 K 个共享专家变换 E_{l,k} 与模态特定低秩适配器 A_l 组成，ΔF = Σ α·E(F) + A(F)，最终表示 F = F^{base} + ΔF。该设计在保留骨干结构先验的同时自适应调制不可靠特征分量。

- **不确定性引导双流解码（UGDD）**：
  - 自顶向下递归构建初步解码特征 D̂，最粗层级由编码特征直接生成，后续层级拼接上采样后的细粒度特征。
  - 用模态共享的轻量不确定性预测器输出 U = σ(φ(D̂))，作为结构化可靠性信号。
  - **双向跨模态校正**：D_r = D̂_r + U_r ⊙ T(D̂_t)，D_t = D̂_t + U_t ⊙ T(D̂_r)，其中 T 为通道对齐变换。不确定性高的区域对跨模态修正的接受度更高，从而防止不可靠特征在层级传播中被强化。

- **像素级融合流解码（PMC）**：
  - 融合流以 MFM 模块融合的编码表示 E_fus 为输入，自顶向下递归聚合。
  - **像素级模态竞争**：由 ψ 预测逐空间位置的模态 logits，经 Softmax 得到权重 [W_r, W_t]，融合引导特征 H = W_r ⊙ D_r + W_t ⊙ D_t + Up(D_fus^{l+1})。该机制按空间可靠性动态选择模态，而非使用固定融合权重。

- **训练目标**：对 RGB、热、融合三流施加深度监督，联合优化 BCE 损失与 IoU 损失：L = Σ_{m∈{r,t,fus}} (λ₁ L_BCE + λ₂ L_IoU)，避免模态主导并稳定优化。

## 6. 主要结论与发现

- RA-SOD 在 VT821、VT1000、VT5000 上均取得最佳或次佳结果；在 VT5000 上五项指标全部排名第一，相比 ConTriNet 提升 F_β 0.010、F_wβ 0.009、E_m 0.003，降低 M 0.001。
- 在挑战集 VT-IMAG 上，RA-SOD 在五项指标中四项领先，F_β 提升 0.020、F_wβ 提升 0.008，S_m 达 0.829、E_m 达 0.908，显著优于基线。
- 合成退化条件下，相比最强竞争方法，S_m 从 0.921 提升至 0.927，F_β 从 0.895 提升至 0.906，F_wβ 从 0.895 提升至 0.907，M 降至 0.020，验证可靠性建模对退化场景的有效性。
- 使用 Swin-B 骨干时 RA-SOD† 在 VT5000 五项指标全面最佳，说明可靠性感知设计可泛化至 Transformer 架构。
- 不确定性图可视化显示：早期阶段不确定性集中于目标边界，随解码深入内部不确定性下降；RGB 与热流呈现不同不确定性模式，表明模型学到的是模态相关可靠性而非随机噪声。
- 消融表明：RCBR 中适配器与专家库均有效，K=3 为最佳折中；UGDD 与 PMC 均带来一致增益。

## 7. 优点

- **建模视角新颖**：将可靠性作为贯穿编码、解码、融合的统一原则，而非仅在融合端做加权，更贴合退化在早期出现并逐层传播的实际。
- **架构设计合理**：冻结骨干 + 并行残差调制，兼顾稳定结构先验与输入自适应补偿；低秩适配器 + 共享专家库在参数量可控的前提下提升表达力。
- **不确定性显式建模**：用预测的不确定性图调控双向跨模态校正，提供可解释的可靠性信号，并可视化验证其语义合理性。
- **像素级模态竞争**：相比固定或全局权重融合，逐空间位置选择可靠模态，更适应局部退化。
- **训练策略稳健**：三流深度监督避免某一模态主导，提升聚合预测质量。
- **实验较扎实**：多基准、合成退化、挑战集、骨干泛化、复杂度与消融兼备；对 RGB-T 方法统一重训，公平性较好。
