## 摘要
遥感图像中的少样本细粒度目标检测（FGOD）具有挑战性，因为有限的标注必须同时支持目标定位和视觉相似子类别之间的区分。尽管多模态大语言模型（MLLMs）提供了强粗粒度目标定位能力，但它们缺乏可靠的细粒度识别所需的明确视觉证据。为解决这一局限性，我们提出了ProtoRAG，一种基于原型的检索增强框架，通过为MLLMs配备外部对象级视觉记忆，将粗粒度定位与细粒度识别解耦。为了从有限的支撑样本中构建可靠的视觉记忆，我们引入了判别性原型空间学习（DPSL），通过监督对比学习和原型一致性正则化来鼓励判别性和原型稳定的表示。我们进一步开发了一种不确定性引导的候选约束推理策略，该策略用检索到的候选特定视觉参考增强MLLMs，并仅对模糊实例调用多模态推理。大量实验表明，ProtoRAG在九个少样本设置中持续超越代表性基线，在MAR20、HRSC2016和FAIR1M-2.0上分别比最强基线高出14.80、2.27和4.04 mAP$_{50}$。

## Abstract
Few-shot fine-grained object detection (FGOD) in remote sensing imagery is challenging because limited annotations must support both object localization and discrimination among visually similar subcategories. Although multimodal large language models (MLLMs) provide strong coarse object localization, they lack explicit visual evidence for reliable fine-grained recognition. To address this limitation, we propose ProtoRAG, a prototype-based retrieval-augmented framework that decouples coarse localization from fine-grained recognition by equipping MLLMs with an external object-level visual memory. To construct a reliable visual memory from limited support samples, we introduce Discriminative Prototype Space Learning (DPSL), which encourages discriminative and prototype-stable representations through supervised contrastive learning and prototype-consistency regularization. We further develop an uncertainty-guided candidate-constrained reasoning strategy that augments MLLMs with retrieved candidate-specific visual references and invokes multimodal reasoning only for ambiguous instances. Extensive experiments show that ProtoRAG consistently surpasses representative baselines in nine few-shot settings, outperforming the strongest baselines by 14.80, 2.27, and 4.04 mAP$_{50}$ on MAR20, HRSC2016, and FAIR1M-2.0, respectively.

## 1. 论文核心问题与整体含义

### 研究背景与动机
- 遥感图像中的**细粒度目标检测（FGOD）** 需要在完成目标定位的同时，区分视觉上高度相似的子类别（如不同型号的战斗机/舰船）。这类任务在遥感场景中尤为困难，因为目标尺寸小、方向尺度变化大、背景杂乱，且判别性线索只存在于微小的局部结构差异中。
- **少样本设定下**，有限的标注样本必须同时支持定位和细分类的学习，导致传统检测器易过拟合，难以学到充分的细粒度判别表征。
- **多模态大语言模型（MLLMs）** 具备强大的粗粒度目标定位和开放词汇理解能力，但其细粒度识别依赖隐式的预训练语义知识，**缺乏可比较的显式视觉证据**，因此容易混淆视觉相似的细粒度子类别（如F-16与F-15）。
- 核心洞察：细粒度识别本质上需要**对象级视觉证据的比较**，而非仅依赖粗粒度的语义知识。少量标注的支撑实例天然提供了这类参考，因此可将它们组织为外部视觉记忆，在推理时检索代表性子类别样本以辅助判别。

## 2. 方法论

### 总体框架：粗定位-细识别解耦的两阶段范式
ProtoRAG 将 MLLM 的粗粒度定位与基于原型记忆的细粒度识别**解耦**，整体分为两个阶段：

1. **阶段一（离线）**：判别性原型空间学习（DPSL）与视觉记忆构建；
2. **阶段二（在线）**：MLLM 粗定位 → 对象级原型检索 → 不确定性引导的候选约束推理。

### 关键技术一：判别性原型空间学习（DPSL）
- 固定 DINOv3 视觉编码器，仅训练一个轻量残差映射头：
  \( \mathbf{z}_i = \mathrm{DPSL}_\theta(\mathbf{u}_i) = \mathbf{u}_i + \alpha\, g_\theta(\mathbf{u}_i) \in \mathbb{R}^d \)
- 两个互补的训练目标：
  - **实例判别**：监督对比损失 \( \mathcal{L}_{\mathrm{supcon}} \)，拉近同类、推开异类嵌入，增大细粒度类别间的间隔；
  - **类别级原型一致性**：从每类采样两个互不相交的子集，计算子集原型并最小化其余弦距离（\( \mathcal{L}_{\mathrm{pc}} \)），抑制由支撑集采样差异带来的原型漂移。
- 总损失：\( \mathcal{L}_{\mathrm{DPSL}} = \mathcal{L}_{\mathrm{supcon}} + \mathcal{L}_{\mathrm{pc}} \)。

### 关键技术二：原型库（Prototype Bank）构建
- 对每个类别计算所有支撑样本 DPSL 嵌入的均值作为类别原型；
- 同时为每个类别缓存一个支撑参考裁剪图，作为触发推理时的视觉证据；
- 原型矩阵 \( \mathbf{P} \in \mathbb{R}^{|C|\times d} \) 和参考图共同构成对象级视觉记忆。

### 关键技术三：不确定性引导的粗到细推理
1. **MLLM 粗定位**：仅提供粗粒度超类提示（如"aircraft"），定位图中所有目标；
2. **原型检索**：将每个定位裁剪映射到 DPSL 空间中，与原型库计算余弦相似度，取 Top-K（默认 K=3）候选类别；
3. **检索不确定性估计**：用温度缩放 Softmax 将 Top-K 相似度转为概率，计算熵 \( H \)：
   - \( H < \delta \) → 直接采用 Top-1 原型预测；
   - \( H \ge \delta \) → 触发**候选约束推理**：将查询目标及其场景上下文和各候选类别的缓存参考图送入 MLLM，进行显式的视觉比较后确定最终类别（默认 \( \delta = 0.60 \)）；
4. **输出**：最终类别的原型相似度作为检测排序分数，并用于 mAP 评估。

## 6. 主要结论与发现

- ProtoRAG 在 **MAR20、HRSC2016、FAIR1M-2.0** 三个数据集上全部取得最优结果，10-shot 下分别超过最强基线 14.80、2.27、4.04 mAP@50；
- **解耦策略有效**：MLLM 负责粗定位 + 原型检索负责细分类，胜过由同一套有限标注联合学习定位和细分类的检测器范式；
- **DPSL 是主要增益来源**：在 MAR20 10-shot 下将 mAP@50 从 71.08 提升至 83.46（+12.38），表明仅用原生视觉骨干特征做检索不够；
- **原型一致性正则化效果显著**：单独使用达到 84.92% Top-1 准确率，与监督对比学习联合后提升至 87.24%，证明两目标互补；
- **不确定性引导的推理高效精准**：触发率仅约 6%–14%，而触发后有约 60%–67% 的概率纠正错误 Top-1 预测；
- **MLLM 的粗定位质量决定上限**：粗定位 F1 从 58.59 提升到 94.94 时，最终 mAP@50 从 46.78 提高至 84.06；
- DPSL 在多个骨干上具有一致的正向迁移，且训练开销极小。

## 8. 不足与局限

### 实验覆盖层面
- 未报告不同随机种子下的多次运行标准差或显著性检验，无法确认性能提升是否具有统计显著性。
- 未纳入旋转/定向边界框（oriented bounding box）的评估——遥感目标角度任意，现有 HRSC2016 常规评测包含旋转框协议，而本文仅用水平框，可能低估或遗漏实际部署中的复杂度差异。
- 未在更多 MLLM 家族或更大规模（如数十亿参数以上）的模型上进行充分的泛化测试。
- 缺少跨数据集泛化测试（如在 MAR20 训练 DPSL、在 FAIR1M-2.0 上测试）。

### 方法局限
- **MLLM 定位误差传导**：粗定位召回不足时，下游检索与推理无从弥补，MLLM 能力会成为系统瓶颈（表 5 已揭示该敏感性）。
- 原型均值在极端低样本时（K=3）对支撑集合选择较敏感，虽有原型一致性约束但无法完全消除。
- 判别性依赖 DINOv3 基础特征的质量：若基础特征本身不含细粒度判别信息，DPSL 的残差修正空间有限。
- UGR 的 δ 与 K 固定为全局经验值、未见对每类或每图自适应的策略，且 MLLM 触发推理会增加推理延迟和 API 成本。
- 缓存参考图仅每个类别一张，单张参考可能无法覆盖类内较大外观变化。

### 偏差与应用风险
- 遥感细粒度类别分布天然长尾，MAR20 和 FAIR1M-2.0 的类别选取可能偏向易区分场景，真实场景中类别间相似度的不均衡分布未在实验中专门讨论。
- 方法依赖支撑集的标注精确性（高质量裁剪），标注噪声的影响未见实验评估。
- 军事目标（如 MAR20）等特定域数据存在伦理与使用边界问题，限制了方法在通用遥感任务中的即插即用范围。
