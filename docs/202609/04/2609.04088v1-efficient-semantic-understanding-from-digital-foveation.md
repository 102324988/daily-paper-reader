## 摘要
密集语义分割将计算资源均匀地分配到整个图像上，而不考虑场景复杂性或任务相关性。受生物视觉启发，我们研究是否可以通过数字中心凹感知更高效地实现语义理解。我们介绍了一种轻量级主动视觉流水线，结合了显著性驱动的注视点选择、高分辨率中心凹观察、低分辨率上下文信息、语义累积和自适应计算。除了传统的密集预测指标外，我们使用对象级评估来衡量稀疏观察下的语义理解。在ADE20K-Object上，单次中心凹观察达到了基线Top-1准确率的95.9%和基线Top-3准确率的96.9%，而仅需要4.7%的计算成本。在场景层面，语义累积恢复了基线对象召回率的90.6%，同时使用了58.6%的计算量。这些结果表明，当计算被选择性地分配时，从稀疏观察中可以产生大量的语义理解，突出了主动视觉作为均匀密集处理的高效替代方案，并激励了超越传统逐像素分割指标的评估协议。

## Abstract
Dense semantic segmentation allocates computational resources uniformly across the entire image, regardless of scene complexity or task relevance. Inspired by biological vision, we investigate whether semantic understanding can be achieved more efficiently through digital foveated perception. We introduce a lightweight active-vision pipeline that combines saliency-driven fixation selection, high-resolution foveal observations, low-resolution contextual information, semantic accumulation, and adaptive computation. Beyond conventional dense prediction metrics, we use object-level evaluation to measure semantic understanding under sparse observations. On ADE20K-Object, a single foveated observation achieves 95.9% of the baseline Top-1 accuracy and 96.9% of the baseline Top-3 accuracy while requiring only 4.7% of the computational cost. At the scene level, semantic accumulation recovers 90.6% of the baseline object recall while using 58.6% of the computation. These results suggest that substantial semantic understanding can emerge from sparse observations when computation is allocated selectively, highlighting active vision as an efficient alternative to uniform dense processing and motivating evaluation protocols beyond conventional pixel-wise segmentation metrics.

- 传统密集语义分割（dense semantic segmentation）对整幅图像**均匀分配计算资源**，忽视了场景复杂度、目标大小与任务相关性。
- 人类视觉系统通过**注意力和中心凹化（foveation）**实现高效感知：只在少数选取位置获取高分辨率信息，其余区域用低分辨率粗略上下文补充。
- 论文的核心问题：**语义理解需要多少视觉信息？能否通过选择性（稀疏）处理来高效获取这些信息？**
- 整体意义：为资源受限的机器人/嵌入式系统提供一种受生物启发的主动视觉范式，以远低于均匀全图处理的代价逼近全图模型的对象级语义理解能力，并推动超越像素级分割指标的评估方式。

## 2. 方法论

### 核心思想
- 构建一个**模块化、可解释且无需训练的主动视觉管线**，用数字化的中心凹感知（digital foveation）模拟生物视觉中的注视点选择与多glimpse累积。

### 主要技术组成（关键步骤）
- **低分辨率全局预览**：输入图像缩小后用于两个用途：计算显著性图（仿照 Itti 等模型）以及提供全局场景上下文。
- **注视点选择（Fixation Selection）**：
  - 使用 Winner-Take-All（WTA）机制在显著性图上选取当前最显著位置。
  - 结合**抑制性返回（Inhibition of Return, IoR）**，避免重复注视已访问区域，鼓励探索新区域。
  - 该选择策略是训练无关的（training-free），无需额外策略网络。
- **高分辨率中央凹观测（Foveal Observation）**：
  - 在每次注视点提取一个高分辨率小图（如 CLEVR 上 40×40，ADE20K 上 96×96），送入轻量级分割网络。
  - 低分辨率全图信息通过一个轻量级“上下文 CNN”编码成紧凑的上下文嵌入，并通过特征相加/投影方式融入中央凹网络的中间特征中。
- **稀疏视图训练（Training from Sparse Object Views）**：
  - 训练时注视点**从语义掩膜中采样**，而不是按显著性采样，从而避免显著性偏向大/突出区域导致训练分布失衡。
  - 对每次注视点内所有有效语义像素施加标准密集分割监督，使得模型能在不同位置/偏移下学习物体的局部表示，学习“从部分观测识别对象”。
- **语义画布与证据累积（Semantic Canvas and Accumulation）**：
  - 每次注视后，网络输出的局部分割 logits 被映射回原图坐标。
  - 使用以注视点为中心的高斯权重掩膜 w_t 加权后写入画布：  
    `S ← S + w_t * L_t`，`W ← W + w_t`。
  - 多次注视后，归一化得到最终语义图：  
    `C = S / (W + ε)`，再取每个像素最大 logit 的类别。
  - 该过程不含可学习的循环记忆或写规则，确定性且开销低。
- **自适应计算（Adaptive Computation）**：
  - 注视点数量可作为计算预算的控制旋钮。
  - 画布提供了不确定性/覆盖率信息，可用于决定何时停止注视；停止条件基于剩余显著性与画布不确定性的加权评分低于阈值。
  - 停止评分公式（补充材料中给出）：
    - 候选得分 `F_t(p) = (A(p) + α U_t(p)) * I_t(p)`
    - 停止量度 `R_t(p) = A(p) * I_t(p) * U_t(p)`。
- **计算成本量化**：
  - 总 FLOPs = 一次性固定成本（显著性、上下文）+ T × 单次注视成本（中央凹网络前向 + 画布写入）。
  - 上下文嵌入可缓存复用，因此总成本随注视点数量近似线性增长。

## 3. 实验设计

### 基线方法（Baselines）
- 采用公开的轻量级密集分割网络 **Lite R-ASPP** 作为全图像密集处理基线，提供精度与计算量参考。
- 同一模型结构用于中央凹分支（foveal network），并添加上下文组件，因此对比主要看**计算量与性能**，而不是模型家族。

  - 全物体裁剪训练（complete-object crop training）

  - 不同注视点预算 T（4–24）

## 6. 主要结论与发现

- **稀疏观测足以获得丰富的语义信息**：单次中央凹注视即可在对象级指标上接近全图处理：
  - ADE20K-Object 上：Top-1 达 95.9%、Top-3 达 96.9%，仅用 4.7% FLOPs。
  - CLEVR 上：单次注视甚至优于全图基线（Top-1 0.982 vs 0.929；visible mIoU 0.961 vs 0.648），因为目标小而局部特征充分。
- **多注视点证据累积能高效恢复对象级语义**：
  - ADE20K-Object 上，T=16 时对象召回率达到 90.6%，Top-1 达 93.7%，计算量仅 58.6%；T=24 达到 98.2% 召回而计算量为 87.4%。
- **密集重建（全图 mIoU）仍落后于基线**，表明中心凹感知对“物体发现/识别”比“完整场景逐像素补全”更擅长。
- **上下文信息是有益的**：加入低分辨率全局上下文后，Top-1 从 0.499 上升到 0.509，且对床、桌子、台面、扶手椅等类别增益最大。
- **数字中心凹化可以作为一种高效替代均匀密集处理的可控范式**，通过注视次数 T 即可权衡计算量与语义性能。

## 7. 优点

- **丰富的生物视觉机制集成**：显著性、WTA、抑制性返回、低分辨率上下文、中央凹采样和语义画布等，均在**训练无关**的前提下模块化组合，设计清晰、可解释。
- **评估视角有重要扩展**：不仅仅用逐像素 mIoU，而是补充对象级 Top-1/Top-3/召回，能更好衡量“语义理解”而不是“密集重建”，更符合主动感知的实际任务需求。
- **计算成本建模合理清晰**：明确区分一次性成本与每次注视成本，并报告相对全图基线的比例，便于可复现比较。
- **训练分布与推理分布解耦**（用语义掩膜采样而非显著性采样训练），这样做避免了显著性偏向造成的训练失衡，是一个有价值的方法论细节。
- **画布累积机制简单、可扩展**：无训练参数的加权累积、可显式度量覆盖率与不确定性，可用于自适应停止或目标搜索，展示出作为记忆与探索接口的潜力。

## 8. 不足与局限

- **数据集覆盖有限**：实验仅限制在 CLEVR（合成）和 ADE20K-Object（静态图像），缺少真实世界、动态、遮挡严重或室内/室外机器人场景的验证，难以全面衡量实际嵌入式环境中中心凹感知的鲁棒性。
- **物理化程度低**：采用数字中心凹化，而不是基于物理相机旋转/移动的真实 foveation；结论与边缘传感器设备的迁移性还需进一步验证。
- **学习/决策环节弱**：
  - 注视点选择完全依赖训练无关的显著性+IoS，缺少端到端策略或基于任务的可学习引导；
  - 语义画布作为“记忆”并未真正影响注视选择，自适应的停止机制也仍较弱；
  - 在更具挑战的扩展实验中，学习式场景置信画布（learned scene-belief canvas）虽然提升 mIoU 和对象召回，却降低对象级 Top-1 并增加计算，因而未被选为主要方法。
- **密集重建精度的落差**：全图 mIoU 在中心凹感知下始终低于全图基线，因此该方法适合“快速获得对象级语义概览”的任务，而不能替代需要精确像素级建图的任务。
- **报告透明度略有欠缺**：没有提供训练所需的 GPU 型号、数量、耗电/耗时等信息，削弱了复现和效率评估的完整证据；类别不均衡、不同对象尺寸的影响也未做更深入的统计分析。
- **与传统基线的对比角度不完全公平**：基线模型（Lite R-ASPP）固定为全图输入且不经过针对中心凹使用的训练，而 glimpse 模型因获得稀疏视图训练而更适应新评估协议；结论的正确性有赖于这种特定评估配置。
