## 摘要
深度可以解决RGB-D显著目标检测（SOD）中的外观模糊问题，但传感器深度并非均匀可靠。缺失区域、模糊边界和结构伪影可能通过多模态融合传播，使RGB-D检测器比仅使用RGB的检测器更不准确。现有的质量感知方法调节观测深度，但仍然依赖于可能具有缺陷的同一模态。我们提出了\method{}，一个为RGB-D SOD基准开发的可靠性感知几何蒸馏框架，在训练或推理期间不使用数据集提供的深度。冻结的Depth Anything V2模型仅作为训练时的教师，将密集相对几何、层次空间注意力和边界结构转移到紧凑的边缘感知几何分支。池化双向交互将几何与外观对齐，像素级可靠性估计器选择性地注入与当前RGB表示兼容的几何。训练后移除教师，留下仅使用RGB的推理网络。在2,985对RGB-掩码对上训练，\method{}在36个指标-数据集比较中，与十种近期RGB-D SOD方法相比，在26个中达到最佳或并列最佳结果，包括在ReDWeb-S上相对MAE降低13.4%。在DUTS-TR上重新训练时，它还在PASCAL-S上将最强先前的$F$度量提高了4.2%，表明蒸馏的几何超越了特定传感器或数据集领域。代码将在发表后发布。

## Abstract
Depth can resolve appearance ambiguity in RGB-D salient object detection (SOD), yet sensor depth is not uniformly reliable. Missing regions, blurred boundaries, and structural artifacts can propagate through multimodal fusion and make an RGB-D detector less accurate than its RGB-only counterpart. Existing quality-aware approaches regulate observed depth but remain dependent on the same potentially defective modality. We propose \method, a reliability-aware geometry distillation framework developed for RGB-D SOD benchmarks without using dataset-provided depth during training or inference. A frozen Depth Anything V2 model serves only as a training-time teacher, transferring dense relative geometry, hierarchical spatial attention, and boundary structure to a compact edge-aware geometry branch. Pooled bidirectional interaction aligns geometry with appearance, and a pixel-wise reliability estimator selectively injects geometry that is compatible with the current RGB representation. The teacher is removed after training, leaving an RGB-only inference network. Trained on 2,985 RGB-mask pairs, \method{} achieves the best or tied-best result in 26 of 36 metric-dataset comparisons against ten recent RGB-D SOD methods, including a 13.4\% relative MAE reduction on ReDWeb-S. When retrained on DUTS-TR, it also improves the strongest prior $F$-measure by 4.2\% on PASCAL-S, showing that the distilled geometry transfers beyond a particular sensor or dataset domain. Code will be released upon publication.

- 现有质量感知方法（如不确定性建模、质量校准、深度过滤）虽然改善了对观测深度图的利用方式，但**未能消除模型对深度质量与可用性的依赖**，本质上仍受困于同一具有缺陷的模态。论文将其归纳为三种范式的不足（图 1）：

  - 范式 B（原始深度作为监督）：噪声标签污染训练过程；

### 2. 方法论

**核心思想：将几何获取与几何利用分离**
- 训练阶段，冻结的 Depth Anything V2 教师模型向紧凑的几何分支蒸馏密集相对深度、多尺度空间注意力与边界结构；
- 蒸馏决定“学到什么几何”，可靠性感知融合决定“何时信任该几何”；
- 推理阶段教师与深度完全移除，仅保留 RGB-only 网络。

**整体架构（图 2）三阶段流程：**

**(1) 外观编码与共享金字塔**

- 主干网络（默认 PVT-v2-B5）生成 strides {4, 8, 16, 32} 的四层特征金字塔 {X₁..X₄}；
- 每层经独立 1×1 卷积 + BN + ReLU 投影至公共宽度 C = 128（公式 1），以适配 ResNet-50、PVT-v2、Swin-B 等不同主干的通道差异。

**(2) 教师引导的几何学习（仅训练期）**

- 冻结的 Depth Anything V2 教师接收同一 RGB 图像，暴露 DINOv2 中间层特征与 DPT 深度头，输出：归一化相对深度 D_teacher 和四层特征 {T₁..T₄}（公式 2）；
- 学生几何分支 G 采用 ESCNet 的 AETP 边缘提取器 + ESC 解码器结构，输出中间几何预测、四层几何特征与几何边缘 logits（公式 3）；
- 三重蒸馏损失：
  - **密集相对深度监督**（公式 4）：逐级对教师深度进行值一致性与水平/垂直梯度一致性约束；
  - **层次特征对齐**（公式 5、6）：不对齐原始张量，而对齐归一化的逐通道能量图，传递教师的空间聚焦模式；
  - **几何边界监督**（公式 7）：用教师深度图的梯度边界以 BCE 损失监督学生边缘输出。

**(3) 跨模态增强与可靠性感知融合**

- **池化双向交互（公式 8、9）**：外观与几何特征在各层级互为主体（query），以自适应平均池化的 keys/values 进行注意力增强，将空间注意力复杂度从 O(HᵢWᵢ²) 降为 O(HᵢWᵢP²)。残差门控 α、β 初始化零，保证训练初期两个分支保持独立稳定；
- **像素级可靠性估计（公式 10、11）**：估计器接收外观特征、几何特征、二者绝对差异及重采样的几何预测图，输出像素级可靠性图 rᵢ；融合公式为 RGB 主导：rᵢ 小时接近纯外观基线，rᵢ 大时激活乘法调制和残差几何注入。最终可靠性层加负偏置，防止不稳定几何在训练初期主导。

**(4) 边缘感知 SOD 解码**

- 独立的 AETP + ESC 解码栈将融合金字塔还原为显著性 logits 和 SOD 边缘 logit；
- 几何与 SOD 分支共享结构但参数独立，“一个分支保存教师几何、另一分支专注前景选择”；
- 最终损失（公式 13）：Ls + 0.4·Le + 0.1·L_ge + 0.2·Ld + 0.05·La，其中 Ls 采用结构损失（structure loss）+ 深度监督，Le 为 SOD 边缘 BCE。

### 6. 主要结论与发现

1. **GeoDistill 在 RGB-D SOD 基准上表现强劲**：36 项“指标×数据集”对比中 26 项最佳或并列最佳（72.2%），其中 21 项是绝对最优。

2. **跨数据集鲁棒性是核心优势**：在分布偏移最大的 ReDWeb-S 上，Sm、F^max、E^max 分别相对最强基线提升 3.9%、4.5%、2.4%，MAE 降低 13.4%；SSD 上 MAE 降 11.4%、COME-H 降 8.5%、COME-E 降 4.7%、STERE 降 3.5%。

3. **“内部蒸馏”优于“伪深度替代”**：GeoDistill 在全部 36 个比较中超过 SATNet（同属不直接使用传感器深度的方法），相对 MAE 降幅最高达 26%~29.5%。多种证据表明，多层教师的层次结构与注意力知识比压缩为单通道伪深度输入有效得多。

4. **蒸馏的几何具有跨域可迁移性**：转至 DUTS-TR 训练后评估 RGB 基准，PASCAL-S 的 Sm 提升 1.3%、F^max 提升 4.2%、E^max 提升 3.3%，说明所学几何是任务导向的结构先验，而非特定传感器或数据集的捷径。

5. **消融验证了各组件均不可缺**：
   - 容量 C=128 是最佳精度-效率平衡点；
   - 蒸馏几何优于 RGB-only（SIP MAE 降 28.3%）也优于原始深度输入（SIP MAE 降 8.3%）；
   - 几何分支架构与教师监督二者互补——仅加架构降 MAE 19.6%，再加重监督进一步降 10.8%。

6. **完整模型框架层面**：实现了 RGB-D 基准范式下“训练与推理均不碰传感深度”的可行性，开创了“depth-free RGB-D SOD”的这一公式化路径。

- **偏差风险**：
  - 训练集中 RGB-D 数据仅 2,985 对，对跨库泛化的解读要小心：部分“未知集提升”可能来自训练分布差异而非几何蒸馏本身；
  - 与原始深度融合的“Raw depth”策略未做参数/容量匹配，而完整模型参数量显著更高，严格意义上的公平受一定影响；
  - C=128 与 C=256 的性能接近，但 C=256 的 FLOPs 暴增 3 倍，结论“128 最优”不只来自精度，更多来自效率权衡，属可接受的工程决策但需明确读出。

- **方法本身的适用限制**：
  - 论文自述：输出的几何图是任务导向的相对结构，并非标定度量深度，不能替代物理传感器用于测量类任务；
  - 教师模型（Depth Anything V2-Small）是冻结的，训练依赖外部基础模型，若部署方的数据分布与教师预训练分布差异大，蒸馏质量可能退化；
  - 训练成本仍非零——80 epoch × batch 4、416² 输入 + 364² 教师前向，在单张 RTX 4090 上运行，迭代开销未被量化，也未做教师输出缓存实验；
  - 推理时需要完整四层金字塔的注意力交互与可靠性估计，FLOPs 高于典型轻量级 RGB SOD 方法（C=128 时为 311 GFLOPs），虽比部分 RGB-D 模型低，但并非轻量方案。

- **潜在争议点**：论文称之为“RGB-D SOD”评估，但方法不再消费深度传感器输入——这在语义上接近“用几何蒸馏提升 RGB SOD”，部分审慎读者可能质疑归类是否恰当（不过论文在正文中用“depth-free RGB-D SOD”这一术语做了明确定义，一定程度化解了该疑虑）。
