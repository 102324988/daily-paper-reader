## 摘要
视觉Transformer（ViTs）通常使用固定的输入分辨率和模型宽度处理每个图像，即使许多图像可以用更少的计算量进行分类。我们提出ProgResViT，一种输入自适应的ViT，它在多轮中逐步进行推理。第一轮使用窄子网络处理低分辨率图像。当预测足够自信时，推理终止；否则，模型重用当前轮次产生的表示，并继续使用更高分辨率的输入和更宽的子网络来精炼其预测。由于所有轮次共享单一骨干网络，我们提出了进度条件软门控（PSG），它根据当前轮次、块和输入分辨率来调节令牌融合和层输出。在图像分类上，将ProgResViT应用于DeiT相比自适应宽度、自适应深度和动态令牌基线，获得了更好的精度-计算权衡。通过知识蒸馏，基于DeiT的ProgResViT在相当评估设置下达到了84.9%的top-1准确率，略高于报告的DeiT-III-S准确率。我们表明，相同的设计也为自监督DINO表示和下游语义分割提供了有利的精度-计算权衡。代码可在 https://github.com/ds-kiel/ProgResViT 获得。

## Abstract
Vision Transformers (ViTs) typically process every image using a fixed input resolution and model width, even though many images can be classified with substantially less computation. We introduce ProgResViT, an input-adaptive ViT that performs inference progressively across multiple rounds. The first round processes a low-resolution image with a narrow subnetwork. Inference terminates when the prediction is sufficiently confident; otherwise, the model reuses the representations produced in the current round and proceeds with a higher-resolution input and a wider subnetwork to refine its prediction. As all rounds share a single backbone, we propose Progress-Conditioned Soft Gating (PSG), which conditions token fusion and layer outputs on the current round, block, and input resolution. On image classification, applying ProgResViT to DeiT yields better accuracy-compute trade-offs than adaptive-width, adaptive-depth, and dynamic-token baselines. With knowledge distillation, a DeiT-based ProgResViT achieves 84.9% top-1 accuracy, slightly exceeding the reported DeiT-III-S accuracy under a comparable evaluation setting. We show that the same design also provides favorable accuracy-compute trade-offs for self-supervised DINO representations and downstream semantic segmentation. Code is available at https://github.com/ds-kiel/ProgResViT.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：传统 Vision Transformers（ViTs）以固定输入分辨率、固定 token 网格、固定深度和固定模型宽度处理所有图像。这种“一刀切”的设计忽略了两个重要事实：不同图像具有不同难度；不同图像的分类往往需要不同的空间细节和表征能力。
- **整体含义**：一张清晰、居中、大目标的图像可以在极低分辨率和小模型下被正确识别，而杂乱或需要细粒度区分的图像则需要更高分辨率、更多 token 和更强模型容量。固定成本的推理造成大量不必要的计算开销。
- **研究背景（相关工作）**：
  - **自适应宽度**：Matryoshka Representation Learning、MatFormer、HydraViT、SlicingViT、ThinkingViT 等通过嵌套子网络支持弹性部署或输入自适应推理。
  - **分辨率弹性**：FlexiViT、ResFormer、NaViT 等支持不同分辨率/补丁大小，但不按样本难度自适应地选择分辨率。
  - **早期退出与动态 token**：LGViT、A-ViT、DynamicViT、AdaViT 等方法分别从深度、token 稀疏性等维度进行动态推理。
- **既有空白**：现有自适应 ViT 通常只沿一个计算轴进行调节（如宽度或深度或分辨率），或依赖多个独立优化的操作点；缺少在单一共享骨干中联合自适应空间分辨率与模型容量、并在各轮次间渐进精化表征的统一方案。

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- **渐进式推理**：ProgResViT 以“简单样本早终止，困难样本多轮细化”为原则，将推理组织为一系列有序的 **分辨率-宽度操作点** `{(r_s, h_s, d_s)}`。
- **两轮示例流程**：
  1. **第 1 轮**：低分辨率图像 + 窄子网络 → 分类预测。
  2. **判定退出**：若预测不确定性（熵）低于阈值则终止。
  3. **第 2 轮**（若需要）：输入更高分辨率原图 → 重新嵌入 → 复用并融合第 1 轮 token → 激活更宽子网络继续精化。
- **单模型多输出**：最终可通过调节阈值获得连续可调的精度-计算曲线，仅需一次训练。

### 2.2 关键设计

- **窄子网络抽取**：共享主干的所有 Transformer 块被多次执行，并采用“前缀切片”式宽度子网络——只使用前 `h_s` 个头、前 `d_s` 个通道，覆盖 attention 投影、MLP、LayerNorm 等。
- **跨分辨率 Token 投影**：由于轮次间 token 网格和嵌入宽度不匹配，引入跨分辨率 Token 投影器：
  - 将 patch token 重塑为二维网格；
  - 双线性插值到新一轮分辨率对应的网格；
  - 用一个 identity 初始化的 depthwise 3×3 卷积精化；
  - 用一个 1×1 通道投影扩展到下一轮嵌入宽度；
  - 对 class token 用单独 linear 层进行扩展。
- **Progress-Conditioned Soft Gating（PSG）**：
  - 动机：共享 Transformer block 多次在不同输入分布下运行，需要让同一批共享权重感知当前“推理阶段”。
  - 元数据向量：包含五个值——轮次序号、归一化全局块进度、当前分辨率、前一分辨率、分辨率比值。
  - 一个小编码器将元数据映射为条件向量；随后不同分支 head 产生 channel-wise 乘子向量：
    - attention 更新乘子 `G_attn`；
    - MLP 更新乘子 `G_mlp`；
    - 块输出乘子 `G_out`；
    - 融合时的“新图流”与“前一周期特征流”乘子（用于跨轮 token 融合）。
  - 块计算改写为（蓝色为 PSG 引入项）：
    - `X ← X + G_attn ⊙ LayerScale(Att(X))`
    - `X ← X + G_mlp ⊙ LayerScale(MLP(X))`
    - `X_out = G_out ⊙ X`
  - 每个 gate 输出残差 `ΔG`，最终 `G = 1 + ΔG`；最后一层零初始化，保证初始化恒等映射。
- **训练与推理**：
  - 训练阶段退出机制关闭，所有样本被训练执行所有轮次；各轮分类损失等权相加联合优化。
  - 推理阶段采用 **top-10 类别熵**作为不确定度进行路由，低于阈值就退出；改变阈值获得不同精度-算力操作点，无需重训练。
  - 附录实验显示：在匹配继续率前提下，学习式路由比熵路由的最大改进仅 0.21 个百分点，因此最终选择熵路由。

## 6. 论文的主要结论与发现

- **精度-算力权衡大幅提升**：
  - 默认 `192→240`：Round 2 精度 82.21% @ 6.27 GMACs；熵路由后 82.18% @ 4.47 GMACs，计算节省 28.7%，精度仅降 0.03 点；
  - 蒸馏 `160→384`：84.90% @ 16.15 GMACs；路由后 84.87% @ 11.12 GMACs，计算节省 31.1%。
- **超越同类基线**：在各自对比谱系（adaptive-width、dynamic-token、early-exit 等）中均处最强高精度前沿；相对主要基线 ThinkingViT 最高提升 0.74 个百分点。
- **知识蒸馏可达 ± DeiT-III-S**：使用 DeiT-S 结构的蒸馏版达到 84.90%，略超报告的 21K 预训练 DeiT-III-S/384（84.80% @ 15.5 GMACs），且所需计算更少。
- **分辨率渐进+宽度渐进联合 > 单一维度**：逐级消融表明，仅在宽度基础上加入跨分辨率特征重用已能提升精度，再叠加 PSG 获得最大提升（最终精度 +0.76 vs 固定分辨率宽度基线，计算基本持平）。
- **第 1 轮特征信息对第 2 轮有实质贡献**：低通模糊/激活替换/Token 替换等多项干预都会显著降低第 2 轮精度，证明跨轮融合确实有效。
- **PSG 起到非平凡、阶段相关调制作用**：可视化表明 PSG 学到的乘子随通道、深度与轮次变化，并非均匀缩放；
- **通用性较强**：同样的设计在 DINO 自监督（20-NN 与线性探测超过固定分辨率基线）和 ADE20K 分割上均展示出有利的精度-算力前沿。

## 7. 优点

- **新问题定义清晰、补齐空白**：联合渐进分辨率与宽度，且在同一模型中统一调整，不依赖多个独立模型；
- **特征复用机制合理**：
  - 跨分辨率 token 投影引入 identity 初始化 conv 以最小化对已有特征的破坏；
  - 跨轮融合在嵌入宽度和网格两个维度上进行对齐，设计干净且实用；
- **PSG 设计轻量高效**：参数量和计算量开销极小（block 级 PSG 计算仅增加约 0.002 GMACs），零初始化保证训练稳定性；
- **简单而有效的路由机制**：最终选择熵路由而非复杂学习式路由，极大提高了易用性，性能差距极小；
- **评估全面且迁移性强**：涵盖分类、分布偏移、自监督、分割、多轮扩展、路由消融、可视化与干预实验等；

- **写作与代码构建质量高**：附录提供伪代码、完整阈值扫描、GMACs 分解与实验细节，可复现性较好。

## 8. 不足与局限

- **计算浪费于“困难但无解”样本**：熵无法区分“可以通过继续计算改进”的样本和由于分布偏移/固有歧义而无法通过计算改进的样本；对于后者，第二轮计算造成浪费。
- **主干泛化性证据有限**：几乎全部实验基于 DeiT-S；在更大骨干（如 DeiT-B/L 或不同系列）上是否依旧保持收益未有证据。
- **训练资源细节缺失**：未报告训练 GPU 数量与总时长，影响对训练成本的理解。
- **跨论文比较的系统性偏差**：一部分基线直接引用旧文献数字，不同训练策略、数据增强、评估方法等因素可能影响公平性。
- **仅验证了少数固定调度**：调度（如分辨率序列、head 数量、训练 epoch）并非自适应/自动化搜索，最优调度选择仍需人工设计。
- **感知/生成任务未覆盖**：没有给出检测、视频理解等更多下游任务的验证；分割也只是单尺度线性解码器形式。
- **性能上限略受限制**：三轮模型最高准确率（82.13%）略低于默认两轮模型（82.21%），说明多轮并不必然带来精度上限提升，只是提供更细粒度的退出控制。
