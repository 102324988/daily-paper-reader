## 摘要
弱监督3D占用预测通过从视觉基础模型生成的2D伪标签中学习，减少了对昂贵3D标注的依赖。然而，现有方法通常直接将这些不完美的伪标签用作监督，使得占用学习容易受到错误的几何和语义目标的影响。我们观察到，跨重复观察的一致性为评估伪标签可靠性提供了廉价且可靠的线索。基于这一观察，我们提出了LetOccVote，一个基于高斯的弱监督占用框架，利用跨帧投票来改进几何和语义监督。对于几何部分，Depth Vote利用跨帧几何一致性来细化受支持的伪深度，并在体积提升和深度监督之前拒绝矛盾的估计。对于语义部分，Semantic Vote在共享3D空间中聚合伪语义观测，以识别可靠和有争议的证据，加强可靠的语义监督，同时过滤不可靠的伪标签片段。整个框架仅使用2D伪标签监督进行训练，不需要3D占用标注。在Occ3D-nuScenes上，LetOccVote实现了53.27 IoU和20.39 mIoU，在采用2D伪标签监督的方法中建立了最先进的性能。

## Abstract
Weakly supervised 3D occupancy prediction reduces the reliance on costly 3D annotations by learning from 2D pseudo-labels generated by vision foundation models. However, existing methods typically use these imperfect pseudo-labels directly as supervision, making occupancy learning vulnerable to erroneous geometric and semantic targets. We observe that agreement across repeated observations provides an inexpensive and reliable cue for assessing pseudo-label reliability. Based on this observation, we propose \textbf{LetOccVote}, a weakly supervised Gaussian-based occupancy framework that leverages cross-frame voting to improve both geometric and semantic supervision. For geometry, Depth Vote exploits cross-frame geometric agreement to refine supported pseudo depth and reject contradictory estimates before volumetric lifting and depth supervision. For semantics, Semantic Vote aggregates pseudo-semantic observations in a shared 3D space to identify reliable and contested evidence, strengthening reliable semantic supervision while filtering unreliable pseudo-label segments. The entire framework is trained solely with 2D pseudo-label supervision without requiring 3D occupancy annotations. On Occ3D-nuScenes, LetOccVote achieves 53.27 IoU and 20.39 mIoU, establishing state-of-the-art performance among methods with 2D pseudo-label supervision.

- **缓解方案与瓶颈**：近年来，弱监督方法利用可微渲染，将3D占用预测转化为仅需2D深度与语义伪标签的学习问题；更进一步，视觉基础模型（如 Metric3D、Grounded-SAM）可自动生成这些2D伪标签，完全摆脱人工标注。但现有方法通常**将伪标签直接视为真值**用于监督，而伪深度存在几何误差和跨帧不一致，伪语义则存在类别混淆，导致学习目标不可靠，最终损害占用预测精度。
- **核心观察**：同一物理位置在不同视角、不同时刻被重复观测时，其几何与语义应当一致；这种**跨观测的一致性/矛盾性可以直接作为伪标签可信度的信号**，而不只是辅助信息。
- **论文定义的问题**：如何显式区分“可靠的伪标签”与“不可靠的伪标签”，在弱监督占用学习中减少噪声标签的干扰，同时增强一致性好的监督信号。

## 2. 论文提出的方法论：核心思想与关键技术细节

论文提出 **LetOccVote**，一个基于3D高斯的弱监督占用框架，核心是**利用多观测共识来评估并改进伪标签的可靠性**，包括深度与语义两条分支。

### 2.1 整体框架
- 输入：以当前帧为中心的时间窗口内（共 W 帧）的多视角环视图像，利用相机内外参和自车位姿。
- 使用冻结的 DINOv2 提取图像特征。
- 在特征提升前应用 **Depth Vote** 细化伪深度；随后将多帧多视角特征按细化深度投影并聚合到共享体素空间，经3D编码器得到体素特征。
- 用3D解码器查询体素特征，生成一组语义3D高斯；训练时以渲染深度和渲染语义进行监督，推理时高斯体素化得到语义占用。

### 2.2 深度投票（Depth Vote）
- 目的：在特征提升和深度监督前，抑制几何不一致的伪深度估计，并对可信估计做修正。
- 判定规则：将某一深度样本视为“候选表面假设”，反投影到当前自车3D空间，再重投影到其他对比帧；查询对应位置的伪深度并作尺度对齐（利用中值深度比消除尺度偏差）。根据重投影深度 z 与对齐伪深度 ¯d 的差异，分为三类：
  - **一致**：`|z−¯d| ≤ τ(z)`，支持该候选位置；
  - **矛盾**：`z < ¯d−τ(z)`，说明候选位置位于观测表面前方（与实际表面冲突）；
  - **弃权**：候选深度位于观测表面后方（可能被遮挡）、或投影越界/深度无效，不提供正反证据。
- 使用 **k 帧投票规则**：同一帧内各相机的证据合并为该帧的一票。
  - 一致帧数 ≥ k → 基于一致帧进行共识修正得到细化深度；
  - 矛盾帧数 ≥ k 且无一致帧 → 丢弃该深度样本（非当前帧禁止被拒绝，但可被修正）；
  - 否则保持原深度。
- 修正后的深度同时用于特征提升和渲染深度监督，保证几何线索的一致性。

### 2.3 语义投票（Semantic Vote）
- 目的：语义伪标签存在类别相关、反复出现的混淆，无法仅靠几何一致性解决，因此需要在语义层面聚合证据。
- 步骤：
  1. 将各帧的语义伪标签按细化深度投影到共享体素空间，对每个体素进行**多数投票**得到投票类别与一致性比例；
  2. 依据投票结果，将冻结的骨干特征划分为**可靠池**（伪标签与投票类别一致且一致性比例高）和**争议池**（伪标签与投票类别不一致）；
  3. 用池内特征均值（归一化）得到每个类的可靠参考特征 `rc` 和争议参考特征集合 `Q¬c_c`；
  4. 训练初始阶段累积这些特征统计并冻结；
  5. 对于每个特征 token，计算其与争议参考的最大相似度和与可靠参考的相似度之差 `Δ(f,c)`，超过阈值则标记为有争议；
  6. 在同一伪标签类别的连通段内聚合token级判断，当段内争议token占比足够高时，**整段mask**，不参与语义损失。
- 为避免过度削弱被频繁mask的类别，按类保留比例调整损失权重（`w'_c = w_c / ρ_c`）。
- 对高投票支持度高一致性比例的体素，其所包含的高斯中心位置直接以投票类别作为**辅助稀疏监督**。

### 2.4 损失函数
- 深度损失：对渲染深度和细化深度计算 SiLog + L1，只在有效目标上计算。
- 语义损失：对渲染语义与原始伪标签计算交叉熵，仅保留未mask区域，并做类别权重补偿；加上高置信投票体素的辅助CE监督。
