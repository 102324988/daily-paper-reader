## 摘要
对周围环境进行可靠的3D理解是自动驾驶的核心要求。多视角环绕摄像头装置提供了广泛的场景覆盖，但空间相邻图像通常仅有极小的重叠。因此，大多数像素的深度必须从单目外观线索中推断。这些线索在不同图像中可能表现不同，因此深度估计模型可能对其进行不同的解释。我们针对跨图像不一致性的两个主要来源：相机内参差异和每张图像的有限感受野。我们通过对特征进行基于逐像素相机感知射线嵌入的条件化处理来解决前者，使网络能够考虑单目线索中与相机相关的变化。我们通过将每个像素的上下文扩展到其自身图像之外来解决后者，通过受几何合理区域约束的跨图像注意力，该区域由标定的相机装置推导得出。模型基于光度一致性以完全自监督的方式进行训练。在DDAD和nuScenes上的评估显示，在域内和跨域评估中，与最先进的自监督方法相比，整体深度精度和跨图像深度一致性均有所提高。代码可在 https://abualhanud.github.io/CrossDepthPage/ 获取。

## Abstract
Reliable 3D understanding of the surrounding environment is a core requirement for autonomous driving. Multi-view surround camera rigs provide broad scene coverage, but the spatially adjacent images typically overlap only minimally. Consequently, the depth of most pixels must be inferred from monocular appearance cues. These cues can appear differently across images and may therefore be interpreted differently by the depth estimation model. We target two main sources of cross-image inconsistency: differences in camera intrinsics and the limited receptive field of each image. We address the former by conditioning the features on per-pixel camera-aware ray embeddings, enabling the network to account for camera-dependent variations in monocular cues. We address the latter by extending each pixel's context beyond its own image through cross-image attention constrained to geometrically plausible regions, derived from the calibrated rig setup. The model is trained in a fully self-supervised manner based on photometric consistency. Evaluations on DDAD and nuScenes show improved overall depth accuracy and cross-image depth consistency over state-of-the-art self-supervised methods under in-domain and cross-domain evaluation. Code is available at https://abualhanud.github.io/CrossDepthPage/.

## 1. 论文的核心问题与整体含义

**研究背景与动机**

在自动驾驶领域，车辆需要对周围环境进行可靠的 3D 理解，以支持路径规划、定位和场景仿真等下游任务。多视角环绕相机系统（surround-view camera rig）能够低成本地提供 360° 的密集辐射度信息，是构建 3D 场景地图的重要感知来源。然而，多视角环视系统在实际应用中面临一个核心矛盾：相邻相机图像之间的空间重叠区域通常极小，导致**基于立体匹配的深度估计仅对少量像素可行**，绝大多数像素的深度必须依赖单目外观线索（如物体大小、语义、遮挡、透视关系等）来推断。

这种"以单目为主"的深度估计范式引入了一个关键问题——**跨图像深度不一致**。论文识别出两大根源：

1. **相机内参差异**：不同相机可能具有不同的内参（如焦距），使得同一 3D 物体在不同图像中呈现不同的视角和表观尺寸。若模型未显式建模这一差异，单目外观线索（如物体大小与深度的关系）会被不同相机以不同方式解读，导致推理偏差。
2. **图像感受野受限**：单幅图像中的单目线索嵌于该图自身的上下文中；同一 3D 点在多幅图像中处于不同的周围环境背景下，缺乏跨视图的全局上下文关联，容易造成不一致的深度预测。

**整体含义与意义**

论文提出的 CrossDepth 旨在系统性地解决以上两个跨图像不一致的根源：通过**逐像素相机感知射线嵌入**（Camera-Aware Ray Embedding）对特征进行条件化，使网络学会考虑相机内参依赖的单目线索变化；通过**受几何约束的跨图像注意力**（Geometry-Constrained Cross-Image Attention）扩展每个像素的上下文范围，使其能够聚合其他视图中几何合理区域的互补信息。整个模型以**光度一致性自监督**方式训练，不依赖昂贵的深度真值标签，从而具备在更多视觉域中训练的可扩展性。这项工作为多相机环视深度估计提供了一种**显式建模相机差异与空间约束的通用自监督方案**。

## 2. 方法论

### 2.1 核心思想

CrossDepth 的整体框架是一个两阶段前向过程的编码器-解码器架构：

- **第一阶段（初始前向）**：在不启用跨图像注意力的情况下独立编码所有输入图像，获得一个初步的深度估计。
- **第二阶段（细化的前向）**：利用初步深度，结合相机内参和外参，将各图像的特征 token 投影到共享圆柱坐标中，据此推导每个查询 token 在几何上合理的候选邻域，然后执行受约束的跨图像注意力，输出最终的深度预测。

这种"先粗后细"的设计将跨图像注意力的搜索范围从全图缩小到几何合理的局部邻域，排除了表观相似但几何上不合理的候选，从而降低特征匹配的歧义。

### 2.2 跨图像特征聚合（Cross-Image Feature Aggregation）

**（1）共享圆柱网格（Shared Cylindrical Grid）**

受 CylinderDepth 启发，论文采用垂直圆柱表示来统一各相机图像的坐标空间。每个 token（共 Z = N·Hp·Wp 个）基于初步深度、相机内参和相机到车体的变换被投影至以相机投影中心质心为原点的车体坐标系下的 3D 点，再映射到圆柱面上，得到角坐标 θs 和垂直坐标 hs。

为提升计算效率并避免在全部 token 间进行穷举距离搜索（CylinderDepth 的做法），论文将圆柱空间**离散化为 Bθ × Bh 的 2D 网格**。token s 的网格坐标为：

- u_s = ⌊Bθ·(θs + π)/(2π)⌋
- v_s = ⌊Bh·(hs − hmin)/(hmax − hmin)⌋

水平方向具有周期性（跨边界时绕回另一侧），垂直方向非周期（越界单元被忽略）。每个网格单元可存储多个 token；对于每个查询 token，候选键 token 从以其为中心的 KW×KW 窗口中收集，每个窗口最多包含 M = K²W · Kmax 个候选，其中 Kmax 为整个网格中任一单元容纳的最大 token 数。

**（2）跨图像注意力**

跨图像注意力在每个选定的编码器层输出上独立执行。由于编码器内的自注意力层已建模了图像内的交互，跨图像注意力**仅允许查询 token 关注来自其他图像的候选 token**。对特征进行 flatten 后，通过多头注意力计算 Q、K、V：

- 相似度：S(h)s,m = (Q(h)s)ᵀK(h)m / √Ch
- 注意力权重（在 M 个候选中做 softmax）：A(h)s,m = exp(S(h)s,m) / Σⱼ exp(S(h)s,j)
- 输出特征：Y(h)s = Σₘ A(h)s,m·V(h)s,m
- 各头输出拼接后经 WO ∈ R^(Nh·Ch×Fl) 线性投影并重塑回原特征形状

其复杂度从全注意力的 Z² 降至 ZM（M ≪ Z）。值得注意的是，论文将此注意力应用于**所有传入解码器的特征层**，而 CylinderDepth 仅在单一粗糙分辨率上应用跨图像注意力。

### 2.3 相机感知射线嵌入（Camera-Aware Ray Embedding）

为让解码器在解释单目线索时考虑到对应相机内参的影响，论文在每个 token 进入解码器之前，将其编码器特征 Ft 与射线嵌入 Rt 结合：

- 根据各相机内参构建逐像素的射线方向图 Bt ∈ R^(N×Hp×Wp×3)
- 参考 NeRF 使用含 Ldir 个频带的正弦编码 γ(·) 对射线方向进行编码得到 Rt
- 通过 CAMFusion 模块（对拼接特征应用 3×3 卷积）融合特征与嵌入：F̃t = CAMFusion(Ft ∥ Rt)

与常用的焦距归一化 + 全局深度缩放因子方法相比，射线嵌入允许网络学习**空间变化、非线性的内参-外观-度量深度关系**（例如，同一物体在不同焦距下呈现不同尺寸，但仍然应恢复到相同的度量深度）。

### 2.4 解码器与输出

解码器采用 DPT 架构的 CNN 头部，包含多个上采样阶段。每个解码器阶段将原始跨图像调制特征 Ft 与相机感知特征 F̃t 融合后逐步上采样，为每幅输入图像预测对应的深度图 D̂t。

### 2.5 自监督训练目标

训练中没有使用深度真值，而是基于光度一致性进行自监督。光度损失沿用了 Godard 等人的经典形式（SSIM + L1，α = 0.85）：

Lphoto = (1/|Ω|) Σ_p [α(1−SSIM(Î, I))/2 + (1−α)|Î(p) − I(p)|₁]

监督信号来自三种视图关系：

1. **空间监督（Spatial）**：利用已知度量相对位姿，将目标图像像素投影到空间相邻相机的图像中并采样渲染，为重叠区域提供度量尺度监督（公式 8）。
2. **时间监督（Temporal）**：仅预测前视相机的时间姿态，利用刚性相机配置推导各相机的时间变换，渲染相邻帧目标图像（公式 9）。
3. **时空监督（Spatio-temporal）**：从不同帧中的不同相机渲染目标图像（公式 10）。

总损失为各项加权之和：

L = Lphoto,temp + λsp·Lphoto,sp + λspt·Lphoto,spt + λsm·Lsm + λDCCL·LDCCL + λMVRCL·LMVRCL

其中 Lsm 为边缘感知深度平滑损失，LDCCL 为稠密深度一致性损失，LMVRCL 为多视图重建一致性损失。权重分别为 λsp = 0.03、λspt = 0.1、λsm = 0.1、λDCCL = 1×10⁻³、λMVRCL = 0.2。

## 7. 优点

### 方法设计的亮点

1. **几何约束跨图像注意力**：将跨图像注意力限制在由初步深度与相机标定推导出的圆柱网格邻域内，既显著降低了自注意力复杂度（从 Z² 降至 ZM），又排除几何上不合理的候选，避免了仅依据外观相似性导致的误匹配。相比 CylinderDepth 仅在单一组件上做全搜索，本文在所有传入解码器的特征层上应用受约束注意力，使得深度细化功能贯穿多尺度特征，这很可能是精度提升的关键之一。

2. **相机感知射线嵌入**：通过基于逐像素射线方向的频带编码，对解码器特征进行条件化，使网络能够建模不同内参下“同一度量深度对应不同像素位置/尺寸”的映射关系。与图像级焦距归一化相比，该嵌入具有更强的表达力，而且不需要额外假设内参模型的解析形式，适用于任意鱼眼/针孔等混合相机配置。这与跨图像注意力形成互补：前者保障几何投影的一致性，后者保障单目推理在不同相机间的一致性。

3. **自监督训练方式的可扩展性**：完全采用光度一致性进行训练，不需要深度真值。与依赖深度标签的监督方法相比，该方法可以更自然地利用大规模无标签驾驶数据，有利于推广到新场景和新传感器布局。

4. **较好的任务/效率权衡**：尽管引入了多头跨图像注意力和射线嵌入，训练显存峰值仅 8.1 GB，推理峰值 1.0 GB，远低于 VFDepth 和 SurroundDepth 等对比方法，便于在实际车载平台上部署。同时，LoRA 微调 DINOv3 编码器也避免了全量微调的高昂开销。

5. **评估体系较为周全**：分别在域内、跨域、全图、重叠区域等维度下报告指标，能清楚区分“整体深度精度”与“跨视图深度一致性”两个层面的改善，对后续工作有较大借鉴价值。

## 8. 潜在局限与不足

尽管 CrossDepth 在主要指标上均取得了领先，但从论文中可分析出以下局限性（论文也在补充材料中列了局限性分析，不过主干内容的描述有限）：

1. **依赖初步深度的质量**：跨图像注意力的几何邻域基于第一阶段输出的初步深度推导。如果初步深度在严重遮挡或运动模糊区域误差较大，则候选区域的筛选可能遗漏真实对应像素，导致细化的“天花板”受限。这方面的级联误差并未在文中被进一步消融或分析。

2. **空间监督依赖已知位姿的准确性**：空间与时间监督均隐式假设各相机间相对位姿精确已知且不随时间漂移。若自行车或卡车场景中存在车载平台的抖动与标定误差，光度损失在重叠区域的约束质量会受到影响，而文中未讨论该类误差鲁棒性。

3. **没有显式运动物体处理**：深度网络输出为静态场景假设下的一致深度，而运动物体（其他车辆、行人）在时间帧之间的投影并不符合刚性相机位姿模型，单纯遮挡掩蔽并不能完全解决动态物体污染监督信号的问题。论文没有在架构上对动态对象与静态场景进行解耦，理论上限制了其在高度动态城区场景中的深度精度。

4. **评估指标局限**：与绝大多数自监督方法一样，主要采用 LiDAR 参考深度进行评测，但 LiDAR 在远距离、反射面与透明表面上的测量本身有噪声和空洞，且点云插值得到的“伪深度”并不完全等同于真实几何。深度一致性误差（Depth Cons）也仅对比了重叠区域内对应的预测点，不能反映非重叠区域的一贯性。

5. **训练轮数偏少 / 配置简略表述**：论文仅在 20 个 epoch、batch size 为 4 的条件下完成训练，对于需要大量外观多样性的自监督深度估计来说，这一规模属于“轻量级”验证，其跨域指标未必能反映模型在更大数据规模下的极限性能；同时，文中未报告具体训练时长、不同随机种子下的方差等，使复现与公平比较的难度有所增加。

## 9. 总结

CrossDepth 针对多视角环绕相机深度估计中普遍存在的“跨图像不一致”问题，提出了一整套基于标定几何的训练与推理方案。其核心贡献在于：

- 将自注意力从单幅图像拓展到多相机特征空间，但利用圆柱投影将候选范围限制在几何合理区域内，在降低计算成本的同时提高了匹配的鲁棒性；
- 借助逐像素射线嵌入，使解码器能够在不同内参条件下解释单目线索，弥补了以往对此物理因素的建模缺失；
- 在完全不依赖深度真值的自监督框架内，以空间、时间、时空三种视图关系共同约束，实现了优于既有多视图自监督方法的域内与跨域精度。

实验证明，模型的性能提升在跨域评估和深度一致性维度上尤为突出，表明其设计在泛化性、内存效率和几何可靠性之间取得了较均衡的折中。未来工作可在动态物体解耦、级联误差缓解、更大规模数据验证以及更严格的标定误差鲁棒性分析等方向加以延伸。
