## 摘要
密集文档图像通常包含许多细粒度的视觉和文本实体，其相关性取决于用户查询。标准的视觉-语言检索器使用单一向量对裁剪区域进行编码，这可能会混合不同的实体信号，并模糊细粒度检索所需的证据。我们将这种失败模式称为语义稀释，并定量表明它会随着实体密度的增加而降低实体级检索性能。为了缓解这一问题，我们提出了SAGE，一个无需训练的框架，它从密集文档图像中解析语义实体，将其表示为具有多向量嵌入的层次图节点，并通过迭代的实体级子图匹配来检索与查询相关的证据。我们还引入了DEAR，一个包含1,055个查询-图像对的数据集，这些图像对来源于产品详情页，其中每个查询需要从视觉密集的输入中检索和比较多个细粒度实体，涵盖四种复杂度递增的问题类型。实验表明，SAGE显著减少了语义稀释，并在DEAR上优于基于补丁和基于OCR的检索基线，在多实体视觉比较查询上实现了0.849的Recall@3和2.746的生成分数。我们的代码可在https://github.com/All4Nothing/SAGE获取。

## Abstract
Dense document images often contain many fine-grained visual and textual entities whose relevance depends on a user query. Standard vision-language retrievers encode cropped regions with a single vector, which can mix distinct entity signals and obscure the evidence needed for fine-grained retrieval. We call this failure mode Semantic Dilution and quantitatively show that it degrades entity-level retrieval as a function of entity density. To mitigate it, we propose SAGE, a training-free framework that parses semantic entities from dense document images, represents them as hierarchical graph nodes with multi-vector embeddings, and retrieves query-relevant evidence through iterative entity-level subgraph matching. We also introduce DEAR, a dataset of 1,055 query--image pairs sourced from product detail pages, where each query requires retrieving and comparing multiple fine-grained entities from visually dense inputs across four question types of increasing complexity. Experiments show that SAGE substantially reduces semantic dilution and outperforms patch-level and OCR-based retrieval baselines on DEAR, achieving a Recall@3 of 0.849 and a generation score of 2.746 on multi-entity visual comparison queries. Our code is available at https://github.com/All4Nothing/SAGE.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：密集文档图像（如产品详情页）中通常包含大量细粒度、视觉与文本混合的实体（如电池容量、屏幕参数、摄像头规格等），这些实体的相关性取决于用户查询。现有检索系统需要对这些实体进行定位、关联和推理。
- **核心问题——语义稀释（Semantic Dilution）**：标准视觉-语言检索器（如 ColPali、ColQwen、MM-Embed）将整张图、区域或 patch 压缩为单个向量。当一张图中包含多个语义上相互独立的属性时，它们的信号会被混合"稀释"，导致单个属性难以被区分和检索。
- **经验证据**：作者定义了语义稀释分数 δ(I)，即整图嵌入与其各独立属性嵌入间的平均余弦相似度；实验显示该指标随实体密度上升而下降，且 CLIP、Jina-CLIP-v2、SigLIP2、ColQwen 等编码器的高密度图像检索排名均有明显恶化。
- **benchmark 空白**：现有文档 VQA 基准（如 MMLongBench-Doc、M3DocVQA、UniDoc-Bench）多以页面/文档为单位，缺少以"细粒度视觉实体"为检索单元、同时覆盖高密度输入、多实体对齐和比较推理的评测框架。
- **论文目标**：提出无需训练的 SAGE 框架和 DEAR 基准，以"实体-属性图"为检索单位，缓解语义稀释，支持多实体视觉比较查询。

## 2. 方法论：SAGE 框架

- **总体思想**：将密集文档图像显式解析为层级化的"实体-属性图"，每个语义连贯的实体/属性作为独立图节点，用多向量嵌入保留细粒度证据；查询时通过迭代的子图检索来收集完整证据，再交给冻结的 VLM 生成回答。
- **技术路线（5 个模块）**：
  - **1. Attribute Parser（属性解析）**：使用基于 OCR 的版面解析器（PaddleOCR）将图像分解为"边界框-文本"对 {(bᵣ, tᵣ)}，并额外裁剪对应视觉区域 cᵣ，以保留图标、图表等非文本信号。
  - **2. Attribute Captioner（语义描述）**：对纯图像区域，用冻结的 VLM 生成语义描述 τᵣ，得到富化属性记录 âᵣ = (bᵣ, cᵣ, tᵣ, τᵣ)。
  - **3. Hierarchical Graph Construction（层级图构建）**：
    - 构建两级图 G=(V,E)：实体级根节点（如某个产品）+ 属性叶子节点；
    - 用冻结 LLM 将语义上应合并的记录聚为叶子节点 K 个；
    - 叶子节点嵌入 = 文本嵌入（属性文本与语义描述）与复合图像嵌入的加权融合：h = α·t + (1−α)·c；
    - 图中只保留父子边，并序列化为向量索引数据库。
  - **4. Retrieval Planner（两阶段自适应 Top-K 检索）**：
    - 第一阶段：按查询嵌入相似度检索 top-kᵣ 根节点；
    - 第二阶段：在每个候选根节点内部检索最匹配的属性叶子节点，并用加权分数 s = β·s_root + (1−β)·s_attribute 重排序；
    - 迭代式清单细化：LLM 把查询解析为 required-item checklist C(Q)，逐项检查是否覆盖，未覆盖则改写查询继续检索，直到全部覆盖或达到最大迭代次数 T。
  - **5. Subgraph Augmentor（子图增强生成）**：将检索到的子图序列化为结构化上下文，连同查询一并输入冻结 VLM，生成以证据为基础的回答。

## 6. 主要结论与发现

- SAGE 相较基于 patch 和基于 OCR 的基线，在 DEAR 上显著提升检索与生成效果：整体 Recall@3 达 **0.8265**，启用自适应 Top-K 后达 **0.849**，生成分达 **2.746**。

- 作者因此认为：以“语义实体”而非“无结构 patch/整图”作为检索单元，是缓解语义稀释的有效且通用途径。

## 8. 不足与局限

- **领域覆盖有限**：DEAR 主要来源于电子产品详情页与汽车目录；科学图表、医疗报告等存在专业符号与更复杂版面的领域尚未验证。

- **基准规模与偏差风险**：1,055 条 Q-A 对规模尚小；商品信息是时间敏感的，数据收集时的快照可能随时间过期；所有数据源于公开商品网页，覆盖的商品类型和品牌分布也可能带来选择偏差。
