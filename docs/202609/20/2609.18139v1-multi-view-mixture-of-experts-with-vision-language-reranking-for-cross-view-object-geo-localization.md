## 摘要
跨视角目标地理定位（CVOGL）利用无人机或街景查询在卫星影像中定位目标。现有方法为每个视角训练单独的检测器，导致参数冗余并阻碍跨视角知识共享。此外，排名靠前的卫星候选区域往往视觉相似，因此仅凭视觉外观和类别标签不足以解决这种歧义。为解决这些问题，我们提出 MVLGeo，一个高效框架，旨在统一多个视角并减少模型冗余。首先，我们引入来自查询视角的环境上下文文本作为线索，通过视觉-语言重排序（VL-Rerank）区分视觉相似的候选区域。其次，我们设计了一种多视角混合专家架构（MV-MoE），其具有共享编码器和视角特定专家，以减少冗余并促进知识共享，同时跨视角对比学习对齐它们的表示以保持一致性。第三，我们引入自适应椭圆先验（ESAM-Prior）作为辅助位置编码，用于各向异性几何感知。在 CVOGL 基准上的大量实验证实，作为面向多个查询视角的统一模型，MVLGeo 达到了最先进的性能，展现出对输入退化的鲁棒性以及跨视角的泛化能力。代码和模型将在 GitHub 上公开，以促进未来研究。

## Abstract
Cross-view object geo-localization (CVOGL) locates a target in satellite imagery using drone or street-view queries. Existing methods train separate detectors for each viewpoint, leading to parameter redundancy and impeding cross-view knowledge sharing. Moreover, top-ranked satellite candidates are often visually similar, so visual appearance and categorical labels alone are insufficient to resolve such ambiguity. To address these, we propose MVLGeo, an efficient framework designed to unify multiple viewpoints and reduce model redundancy. First, we introduce environmental contextual text from the query view as cues to distinguish visually similar candidates via Vision-Language Reranking (VL-Rerank). Second, we design a multi-view Mixture-of-Experts architecture (MV-MoE) with a shared encoder and view-specific experts to reduce redundancy and promote knowledge sharing, while cross-view contrastive learning aligns their representations for consistency. Third, we introduce an adaptive elliptical prior (ESAM-Prior) as auxiliary positional encoding for anisotropic geometric perception. Extensive experiments on the CVOGL benchmarks confirm that MVLGeo, as a unified model for multiple query viewpoints, achieves state-of-the-art performance, demonstrating robustness to input degradation and generalization across viewpoints. Code and models will be available on GitHub to facilitate future work.

- **三大关键局限**：
  - **候选歧义**：检测与非极大值抑制后，排名靠前的卫星候选视觉上几乎无法区分（置信度分数聚集在很窄区间）。论文观察到 GT 框进入 Top-3 的比例为 78.3%，但排名第一的仅 55.1%。类别级文本标签缺乏空间与拓扑上下文，无法消歧。

  - **输入先验不足**：多数位置编码是方向无关的各向同性先验，对细长/不规则目标会把激活扩散到背景，直接拉偏边界框回归。

## 2. 方法论

- **总体思路**：以 DetGeo 为基线，从三个方向改进——各向异性实例自适应位置编码、多视角统一架构、语言引导候选消歧，构成端到端统一框架（阶段 A–F）。

### 2.1 VL-Rerank：视觉-语言重排序

- **环境描述生成**：设计四组互补提示（道路拓扑、建筑布局、停车场、植被、地标），由 Qwen-VL-Chat 从查询视角生成描述；点击点叠加红色圆形标记以引导注意（仅用于 VLM，不进入检测）。描述刻意规避绝对方向（如"north of"），改用视角不变的稳定空间关系（如"adjacent to""surrounded by"），并离线缓存复用。
- **VLM 对比重排序**：微调 InternVL 做多图比较推理。将 Top-K 卫星候选裁剪、缩放、加彩色编号边框拼成一张合成图，与环境描述配对作为多模态输入；推理时直接输出最佳候选索引，无需中间打分函数。
- **训练数据构造**：用冻结的 DetGeo 检测器离线生成，每样本拼接 Top-3 候选，取与 GT 的 IoU 最高者作为目标标签，按 LLaMA-Factory chat 模板进行下一 token 预测微调。

### 2.2 MV-MoE：多视角混合专家架构

- **核心思想**：共享-残差分解，将某视角在某插入点的函数写为 `f_view(x) = f_shared(x) + Δ_view(x)`，共享部分捕获跨视角通用能力，残差补偿视角差异；残差近零初始化，使模型只需学习从共享最优态出发的最小偏移。
- **硬路由**：按视角身份（UAV/SVI）硬路由而非学习门控，消除路由开销与训练不稳定；训练目标为各视角检测损失之和，并额外加入跨视角对比对齐。
- **两个专家插入点**：
  - ResNet18 的 layer4（高层语义层，跨视角差异显著）：专家为两个 3×3 卷积 + BN + ReLU；末层卷积零初始化、末层 BN 取 γ=1、β=0，保证初始为恒等映射。浅层（conv1–layer3）编码视角不变的边缘纹理，不插专家。
  - 检测头专家：单个 1×1 卷积 + BN，512 通道降至 54（YOLOv3 输出维度），权重取自零均值高斯（σ=10⁻⁴），贡献 `head_shared(f) + α·Δ_view(f)`，α 初始化为 1.0。
- **对比特征对齐**：对称 InfoNCE 损失 `L_CL = ½[InfoNCE(z_UAV, z_SVI) + InfoNCE(z_SVI, z_UAV)]`，`z` 为 2 层 MLP 投影头输出的 128 维归一化嵌入（SimCLR 风格）；批次内配对正样本、非配对为负样本。**关键设计**：从 L_CL 到检测头专家的梯度被阻断，以保留检测层专化性。
- **总损失**：`L_total = 0.5(L_det^UAV + L_det^SVI) + λ·L_CL`，λ 取 0.1。

### 2.3 ESAM-Prior：SAM 自适应椭圆
