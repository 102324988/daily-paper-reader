## 摘要
量子机器学习提供了一种颇具吸引力的表示视角：角度编码态存在于希尔伯特空间中，其中周期性相似性与相互作用可以被自然地表达。然而，将这一视角用于视觉识别仍然困难，因为当前的量子神经网络受到有限量子比特数、昂贵的电路模拟与测量、噪声，以及在含噪中等规模量子设备上不稳定的优化等限制。我们研究量子模型中有益的结构性思想能否转而实现为可扩展的经典 Transformer 操作。我们提出 QiT，一种用于视觉任务的量子启发式 Transformer，包含三个组件：(i) 角度启发式编码，将图像 token 映射为学习到的三角希尔伯特空间特征，类似于基于量子旋转的态编码；(ii) 在这些周期性特征上进行自注意力，诱导出一个近似量子保真度核的经典余弦核；(iii) 门控乘法模拟，一种可训练的经典代理，用于模拟变分电路中出现的相互作用项。所有组件都是可微张量运算，因此 QiT 既不主张量子计算，也不主张量子加速，并保留了标准 Vision Transformer 的 O(N^2D) 注意力复杂度。在图像分类基准上，QiT 与匹配的经典 Transformer 相比具有竞争力，同时避免了小型模拟量子 Transformer 中观察到的严重运行时开销。QiT-B 以 45.7M 参数和 11.5 GFLOPs 达到 78.3% 的 ImageNet-1K top-1 准确率。这些结果使 QiT 成为在视觉识别中分离和评估量子启发的归纳偏置的可扩展基线。

## Abstract
Quantum machine learning offers a compelling representational perspective: angle-encoded states inhabit Hilbert spaces in which periodic similarities and interactions can be expressed naturally. Realizing this perspective for visual recognition remains difficult, however, because present quantum neural networks are constrained by limited qubit counts, costly circuit simulation and measurement, noise, and unstable optimization on noisy intermediate-scale quantum devices. We investigate whether useful structural ideas from quantum models can instead be realized as scalable classical Transformer operations. We introduce QiT, a Quantum-inspired Transformer for vision tasks with three components: (i) angle-inspired encoding that maps image tokens to learned trigonometric Hilbert-space features analogous to quantum rotation-based state encoding; (ii) self-attention over these periodic features, inducing a classical cosine kernel approximated to quantum fidelity kernels; and (iii) gated multiplicative emulation, a trainable classical surrogate for interaction terms found in variational circuits. All components are differentiable tensor operations, so QiT claims neither quantum computation nor quantum speedup and retains the $\mathcal{O}(N^2D)$ attention complexity of a standard Vision Transformer. Across image-classification benchmarks, QiT is competitive with a matched classical Transformer while avoiding the severe runtime cost observed for a small simulated quantum Transformer. QiT-B reaches 78.3\% ImageNet-1K top-1 accuracy with 45.7M parameters and 11.5 GFLOPs. These results position QiT as a scalable baseline for isolating and evaluating quantum-motivated inductive biases in visual recognition.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：量子机器学习（QML）提供了一种有吸引力的表示视角——角度编码态位于希尔伯特空间中，周期性相似性与相互作用可被自然表达；参数化量子电路（PQC）可产生角度编码、特征空间内积与乘法式相互作用。
- **核心障碍**：将这一视角用于视觉识别极为困难，因为当前量子神经网络受限于：
  - 可用量子比特数少、电路深度受限；
  - 电路模拟与测量成本高昂、需重复采样；
  - NISQ 硬件噪声与退相干；
  - 特定电路族存在贫瘠高原（barren plateau），梯度集中难以优化。
- **现有混合方案的困境**：轻量混合（如 QSANN、QSAM）只把少数层交给量子电路，表达能力增益有限；重量混合（如 QViT、QKSAN、QSAN）试图做全量子注意力，却无法在真实序列长度上训练。量子注意力研究普遍在远小于现代 ViT 的规模上评估，缺乏受控的大规模对比。
- **论文的核心提问**：量子模型在希尔伯特空间中的结构性动机（周期角度特征、乘法相互作用）能否在不使用量子硬件、不模拟电路、不假设量子优势的前提下，作为归纳偏置整合进可扩展的经典 Transformer？
- **整体含义**：QiT 是一项**"去量子化"的架构翻译工作**——把量子启发的函数形式隔离出来，用常规 GPU 张量运算实现，从而在视觉规模上评估这些归纳偏置的价值。作者反复强调：QiT 既不执行也不模拟 PQC，不主张量子计算或量子加速。

## 2. 方法论

### 2.1 核心思想
在标准 ViT 编码器中替换两处：（1）注意力投影的输入特征图；（2）通道 MLP 为门控乘法混合器。所有操作均为可微经典张量运算，保留 O(N²D) 注意力复杂度与并行训练。

### 2.2 三个关键组件

**（i）量子角度启发编码（Angle-Inspired Encoding）**
- 将 token 嵌入 h ∈ R^d 映射为有界旋转角：θ(h) = π·tanh(W_θ h + b_θ) ∈ R^Q，其中 Q 为"虚拟量子比特/学习角度"数，tanh 将角度约束到 [−π, π] 以匹配量子旋转门的周期性。
- 构造三角函数希尔伯特空间特征：φ(h) = (1/√Q)[sin θ(h), cos θ(h)] ∈ R^{2Q}，即 Fourier 特征表示。
- 该特征模长为 1（单位范数），其内积为显式余弦核：
  k(h, h′) = φ(h)ᵀφ(h′) = (1/Q) Σ_q cos(θ_q(h) − θ_q(h′))，且**必然正半定**（因是内积）。

**（ii）希尔伯特空间自注意力**
- 对 φ(h_i) 施加独立学习的投影得到 q_i = φ(h_i)W_Q，k_i = φ(h_i)W_K，v_i = φ(h_i)W_V，然后走标准缩放点积 + softmax。
- **关键边界声明**：投影前是显式余弦核（PSD）；投影后 q_iᵀk_j 只是可训练的双线性相似度，一般**不对称、非正半定，也不等于量子态保真度**。QiT 不估计也不近似量子保真度（如 swap test）。
- 论文用图 2 明确区分两条路线：上方是电路相关的保真度核 K_Q(x,x′)=|⟨ψ(x)|ψ(x′)⟩|²，下方是 QiT 实际使用的有限维余弦核 K_m；二者不等价。附录还对比了单比特 RY 编码的乘积态保真度 K_prod = Π_q cos²((θ_q−θ_q′)/2)，与 QiT 的平均余弦核不同。

**（iii）量子启发门控乘法通道混合器**
- H1 = GELU(XW1)，G = σ(XW_g)，Mix(X) = (H1 ⊙ G)W2，⊙ 为逐元素乘。
- Hadamard 积产生输入依赖的非加性特征交互，形式上类比变分电路中旋转门（角度编码）→ CNOT 纠缠（门控）→ 测量读出（线性层）的序列，但**不实现物理纠缠**，也不与某一纠缠门一一对应。

### 2.3 算法流程（一个 QiT 编码块）
1. Θ ← π tanh(HW_θ + b_θ)；Φ ← Q^{−1/2}[sin Θ, cos Θ]
2. 每个注意力头：Q_a,K_a,V_a ← ΦW^(a)，A_a ← softmax(Q_aK_aᵀ/√d_h)，Z_a ← A_aV_a
3. 多头拼接 + 输出投影 → 残差 + LayerNorm
4. 门控混合器 → 残差 + LayerNorm → 输出

### 2.4 复杂度
每块 O(BN²d + BNQd + BNdr)，仍对 token 数二次；相比 CViT 省去 O(ND²) 的通道 MLP（替换为 O(NDr)）。

## 6. 主要结论与发现

- **Q1（模拟器成本）**：FQT-P 的 wall-clock 为 QiT 的 **881.8×、884.1×、996.7×**（2/4/10 类），推理延迟差距 1557.5–1782.6×；QiT 相对小型 CViT 有约 2.30× FLOPs、2.20× 参数的额外开销，wall-clock 增加 1.58–1.76×。结论是**计算性的**：所测 PennyLane 模拟器无法支撑更大规模研究。
- **Q2（可移植性）**：同一 QiT 配置在 32×32 到 224×224、10–257 类之间均可训练。CIFAR-10 78.84%、SVHN 95.94%、CIFAR-100 51.52%、STL-10 63.50%、Flowers-102 65.00%、Caltech-256 68.23%、Pets 71.23%、Food-101 72.00%。
- **Q3（ImageNet 规模）**：QiT-XS 75.0%（18.1M/3.8G）、QiT-S 77.4%（31.0M/5.6G）、**QiT-B 78.3%（45.7M/11.5G）**，呈现单调但递减的增益。QiT-B 与所列 ResNet-50 持平，比所列 ViT-B/16 高 0.4 点且 FLOPs 更少；但落后 DeiT-B 3.5 点、落后最强谱域/状态空间模型 3.8–5.4 点。**不支持 SOTA 主张。**
- **总体定位**：结果确立了执行可行性与实测成本，**没有证明量子启发组件优于收敛且参数匹配的经典 Transformer**，更不构成量子优势证据。

## 7. 优点

- **概念边界极其诚实清晰**：反复区分"启发形式"与"量子等价"，明确指出投影后相似度非 PSD、非保真度核，门控乘法不产生物理纠缠，不使用"量子加速"话术。
- **数学刻画严谨**：给出特征单位范数、余弦核的显式表达与正半定性证明（Σc_i c_j k = ‖Σ c_i φ(h_i)‖² ≥ 0），并对比乘积态保真度与保真度核，划清"谱与架构层面"的联系范围。
- **工程可落地**：纯经典张量操作，无需量子硬件、无需电路模拟与重复测量，天然规避贫瘠高原与测量噪声，可复用标准 GPU 训练栈。
- **架构改动小而可控**：只改特征图与通道混合器，保留 softmax 注意力、残差、归一化与多头结构，复杂度不劣化。
- **可复现性意识强**：主动列出缺失的复现要素（种子、区间、超参、划分定义、能耗流程），为后续受控研究设定明确议程。
- **横向语境建设充分**：表 1 系统梳理 7 项量子注意力工作的资源特征并标注不可比性；表 4 提供 20+ 模型的精度-成本坐标。

- **缺少核心消融**：没有验证周期角度编码、希尔伯特空间注意力、门控乘法三者各自的边际贡献；无法回答"量子启发是否真的有增益"这一核心问题。
- **统计证据薄弱**：全部为单次运行点估计，无重复种子、无置信区间，精度差异的显著性未知。
- **基线不匹配**：Q1 三类模型参数量相差 20 倍以上且仅训 1 epoch，精度对比几乎无信息量；Q3 的 ImageNet 对比因训练配方不同而非受控实验。
- **绝对精度有限**：QiT-B
