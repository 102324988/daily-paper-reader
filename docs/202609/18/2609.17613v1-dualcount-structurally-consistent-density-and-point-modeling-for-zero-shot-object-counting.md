## 摘要
零样本目标计数旨在无需类别特定训练的情况下，估计由文本查询指定的目标数量。近期方法主要依赖密度回归或检测式实例预测。尽管这些方法有效，基于密度的模型常因质量分配受到弱约束而出现空间模糊和背景泄漏，导致表征碎片化或偏向局部，从而在复杂场景中增加计数误差。在这项工作中，我们提出了一种实例感知的双解码器框架，将密度与点表示进行结构化耦合以用于零样本目标计数。我们不将密度估计视为独立的逐像素回归，而是将其解释为潜在目标实例集合上的结构化质量分配问题。预测的实例中心诱导密度图的软实例级分解，在此基础上我们施加两个几何约束：(1) 每个实例的质量守恒，确保每个目标贡献约一个单位的密度质量；(2) 质心对齐，促使每个密度分量围绕其对应的预测中心集中。这些约束引入实例级几何一致性，并带来更准确的质量分配，从而降低计数误差。在 FSC-147、PUCPR+ 和 CARPK 上的大量实验表明，我们的方法持续降低计数误差，并在零样本目标计数中建立了新的最先进性能。

## Abstract
Zero-shot object counting aims to estimate the number of objects specified by a text query without category-specific training. Recent approaches primarily rely on density regression or detection-style instance prediction. While effective, density-based models often suffer from spatial ambiguity and background leakage due to weakly regulated mass allocation, leading to fragmented or part-biased representations that increase counting error in complex scenes. In this work, we propose an instance-aware dual-decoder framework that structurally couples density and point representations for zero-shot object counting. Instead of treating density estimation as independent pixel-wise regression, we interpret it as a structured mass allocation problem over a latent set of object instances. Predicted instance centers induce a soft instance-wise decomposition of the density map, upon which we enforce two geometric constraints: (1) per-instance mass conservation, ensuring each object contributes approximately one unit of density mass, and (2) center-of-mass alignment, encouraging each density component to concentrate around its corresponding predicted center. These constraints introduce instance-level geometric consistency and lead to more accurate mass allocation, thereby reducing counting error. Extensive experiments on FSC-147, PUCPR+, and CARPK show that our approach consistently reduces counting error and establishes new state-of-the-art performance in zero-shot object counting.

- **研究背景**：零样本目标计数（zero-shot object counting）要求模型在无类别特定训练、无视觉示例（exemplar）的情况下，仅根据文本查询估计图像中目标实例的数量。相比少样本计数，它更接近开放世界、全自动的计数需求。
- **核心问题**：现有方法主要分两类——密度回归与检测式实例预测。密度回归虽然对遮挡和尺度变化更鲁棒，但其监督信号本质上是逐像素/分布层面的，**缺乏实例级空间结构约束**，导致：
  - 密度质量可能泄漏到相关背景区域；
  - 密度质量可能集中在目标的局部判别性部位，而非稳定实例中心；
  - 在复杂形状、严重遮挡、杂乱背景下产生碎片化或部分偏置的表示，增加计数误差。
- **关键洞察**：密度图隐式地是多个目标级分量的混合。若每个目标约贡献一个单位的密度质量，则密度估计可重新表述为**潜在实例集合上的结构化质量分配问题**。因此，引入实例级几何一致性可直接提升计数可靠性。
- **整体含义**：论文将零样本计数从“纯像素级密度回归”推进为“实例感知的结构化质量分配”，通过密度与点表示的结构耦合来抑制空间模糊和背景泄漏。

## 2. 方法论

### 2.1 核心思想

- 提出 **DualCount**：一个实例感知的双解码器框架，联合预测密度图与实例中心点集。
- 不将密度与点预测视为独立任务，而是将其解释为同一潜在目标集合的互补视图。
- 预测的实例中心诱导密度图的**软实例级分解**，并在该分解上施加两个几何约束：
  - **逐实例质量守恒**：每个目标贡献约 1 单位密度质量；
  - **质心对齐**：每个密度分量应围绕其对应预测中心集中。
- 最终将密度估计从无约束连续场回归，转变为结构化实例级建模问题。

### 2.2 架构流程

1. **编码器**：
   - 图像编码器 \(E_v\) 提取空间特征图 \(F_v \in \mathbb{R}^{C \times H' \times W'}\)；
   - 文本编码器 \(E_t\) 将查询 \(t\) 映射为语义嵌入 \(f_t \in \mathbb{R}^C\)，二者维度对齐。
2. **跨模态特征增强模块 \(E\)**：
   - 图像自注意力：捕捉长程空间依赖；
   - 图像到文本交叉注意力：视觉 token 关注文本嵌入，突出与查询类别相关的区域；
   - 文本到图像交叉注意力：文本特征反向关注视觉特征，加强跨模态对应；
   - 前馈网络精炼，得到增强视觉特征 \(\tilde{F}_v\) 与增强文本嵌入 \(f_t^{enh}\)。
3. **特征融合模块 \(F\)**：
   - 由文本特征生成通道级调制参数 \(\gamma = W_\gamma f_t^{enh}\)、\(\beta = W_\beta f_t^{enh}\)；
   - 融合特征图 \(F(x) = \gamma \odot \tilde{F}_v(x) + \beta\)，使文本语义动态重加权视觉通道。
4. **双解码器头**：
   - 共享轻量上采样与细化结构（双线性插值 + 2×2 卷积），保证密度与点预测空间对齐；
   - **密度预测头**：输出 \(\rho \in \mathbb{R}^{H \times W}\)，预测计数 \(\hat{N} = \sum_{x \in \Omega} \rho(x)\)，使用最优传输损失 \(L_{ot}\) 与真值点标注对齐；
   - **点预测头**：输出 logit 图 \(S\)，经 sigmoid 得置信度图 \(h(x)\)，通过 NMS 和阈值 \(\tau\) 提取中心候选 \(\hat{P} = \{\hat{p}_i\}_{i=1}^M\)，使用 Focal loss \(L_{focal}\) 训练；
   - 使用匈牙利算法建立预测点与真值点的一对一二部匹配 \(M\)；
   - 对每个预测点，从 CNN 主干多尺度特征图中双线性采样并拼接得到点表示 \(f(\hat{p}_i)\)；
   - 使用 InfoNCE 风格对比损失 \(L_{cst}\)，拉近匹配点对、推远未匹配预测与背景负样本，提升点特征判别性并抑制假阳性。

### 2.3 软实例分解

- 对每个预测中心 \(\hat{p}_i\)，用高斯核定义空间位置 \(x\) 的软分配权重：
  \[
  w_i(x) = \frac{\exp(-\|x-\hat{p}_i\|^2 / 2\sigma^2)}{\sum_{j=1}^M \exp(-\|x-\hat{p}_j\|^2 / 2\sigma^2)}
  \]
  其中 \(\sum_i w_i(x)=1\)。
- 全局密度图分解为 \(\rho_i(x) = w_i(x)\rho(x)\)，满足 \(\rho(x) = \sum_{i=1}^M \rho_i(x)\)。
- 该分解将可微的实例级结构引入密度表示。

### 2.4 两个几何约束

- **逐实例质量守恒**：
  - 实例质量 \(m_i = \sum_{x \in \Omega} \rho_i(x)\)；
  - 损失 \(L_{mass} = \frac{1}{M} \sum_{i=1}^M (m_i - 1)^2\)；
  - 鼓励每个预测实例获得约 1 单位质量，防止质量过度集中或分散。
- **质心对齐**：
  - 实例质心 \(\bar{p}_i = \frac{1}{m_i} \sum_{x \in \Omega} x \rho_i(x)\)；
  - 损失 \(L_{align} = \frac{1}{M} \sum_{i=1}^M \|\bar{p}_i - \hat{p}_i\|_2^2\)；
  - 促使密度分量围绕对应预测中心集中，减少碎片化或部分偏置。

### 2.5 总体损失

- 计数一致性损失：\(L_{consistent} = (\hat{N} - M)^2\)，惩罚密度积分与预测点数之间的差异。
- 总损失：
  \[
  L = \lambda_{ot}L_{ot} + \lambda_{cst}L_{cst} + \lambda_{focal}L_{focal} + \lambda_{consistent}L_{consistent} + \lambda_{mass}L_{mass} + \lambda_{align}L_{align}
  \]
- 各权重通过网格搜索确定。

## 3. 实验设计

### 3.1 数据集与场景

- **FSC-147**：大规模少样本计数数据集，6,135 张图像、多类别，实例数 7–3,731，平均 56；89 类训练，29 类验证、29 类测试，是开放集零样本计数的主要 benchmark。
- **CARPK**：无人机航拍停车场车辆计数，989 张训练、459 张测试，超过 89,000 辆车。
- **PUCPR+**：固定监控摄像头车辆计数，作为 CARPK 的互补固定视角 benchmark。

### 3.2 评价指标

- **MAE**（平均绝对误差）与 **RMSE**（均方根误差）。

### 3.3 对比方法

- **少样本类**：FamNet、BMNet、LOCA、SAM、PseCo、GMN 等。
- **无参考类**：FamNet、BMNet、LOCA、RCC 等。
- **零样本类**：Patch-selection、CLIP-Count、CounTX、VLCounter、PseCo、DAVE、VA-Count、GeCo、CountGD、T2ICount。
- 自身变体：DualCount (CLIP) 与 DualCount (SwinT + BERT)。

### 3.4 主要结果

- FSC-147 验证集：DualCount (SwinT+BERT) 达到 **11.21 MAE / 42.77 RMSE**，优于 CountGD 的 12.14 / 47.51。
- FSC-147 测试集：**11.32 MAE / 97.16 RMSE**，优于 T2ICount 的 11.76 / 97.86。
- CARPK：DualCount 为 7.95 MAE / 9.78 RMSE，排名第二，优于 CLIP-Count、CounTX、T2ICount，但低于 CountGD 的 3.83 / 5.41。
- PUCPR+：DualCount 为 **24.27 MAE / 28.91 RMSE**，优于 CountGD 的 24.31 / 32.16 等。

### 3.5 消融实验

- **损失组件消融**：完整模型 11.32 MAE；移除 \(L_{align}\) → 12.84；移除 \(L_{mass}\) → 13.05；移除 \(L_{consistent}\) → 14.25；移除 \(L_{cst}\) → 14.49。
- **架构组件消融**：仅密度解码器 14.12 MAE；仅点解码器 14.54 MAE；无特征增强器 13.11 MAE；CLIP 骨干 12.33 MAE；SwinT+BERT 骨干 11.32 MAE。

### 3.6 定性结果

- 与 VLCounter、CLIP-Count、CounTX 对比，DualCount 生成更集中、更准确的密度图，减少自相似物体、非凸布局、拥挤场景、干扰背景中的假阳性。

## 6. 主要结论与发现

- 将密度估计重新解释为潜在实例上的结构化质量分配，并引入实例级几何约束，可有效缓解密度回归的空间模糊与背景泄漏。
- 逐实例质量守恒和质心对齐分别从“质量平衡”和“空间集中”两个角度提升密度分配的可靠性。
- 密度与点双解码器提供互补信息：仅密度或仅点解码器均显著劣于双解码器。
- 计数一致性损失、对比点特征损失、特征增强模块均对最终性能有正贡献。
- DualCount 在 FSC-147 零样本设定下取得新的 SOTA，并在 PUCPR+ 上领先；在 CARPK 上具有竞争力但非最优。
- 方法在拥挤和几何复杂场景中改进尤为明显，说明实例级结构建模对复杂场景计数具有价值。
