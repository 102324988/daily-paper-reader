## 摘要
视觉Transformer（ViT）在语义理解方面表现出色，但在区分对象实例（例如，两只狗的嵌入完全相同）方面有所欠缺，这限制了其在实例级任务（如目标检测和实例分割）中的使用。我们提出了对比视觉Transformer（CoViT），一种通过几何引导的对比学习将实例感知注入ViT的自监督学习框架。CoViT独特地协调ViT的注意力图和嵌入，通过构建三元组：（1）注意力引导掩蔽：通过自适应阈值化和形态学操作细化多头注意力以生成实例掩码，识别前景锚点；（2）最难对比挖掘：对于每个锚点，计算成对嵌入相似度，以选择实例内最难正样本（其掩码内最不相似的块）和实例间最难负样本（来自其他实例的最相似块），在负样本搜索期间屏蔽实例内区域。这些三元组驱动对比损失，同时压缩实例内方差并扩大实例间间隔，迫使ViT辨别实例间的微妙几何和外观差异。通过使用ViT作为骨干架构，CoViT在多个实例级感知任务中一致地实现了超过2个AP点的稳定性能提升。值得注意的是，CoViT不需要额外的解码器或标签，证明了纯ViT可以通过固有的注意力先验和针对性的对比约束来学习实例感知表示。代码和模型将发布。

## Abstract
Vision Transformers (ViT) excel in semantic understanding but fail to discriminate between object instances (e.g., identical embeddings for two dogs), limiting their use in instance-level tasks such as object detection and instance segmentation. We propose Contrastive Vision Transformer (CoViT), a self-supervised learning framework that injects instance-awareness into ViT through geometry-guided contrastive learning. CoViT uniquely coordinates ViT's attention maps and embeddings by constructing triplets: (1) Attention-guided masking: Refine multi-head attention via adaptive thresholding and morphological operations to generate instance masks, identifying foreground anchors; (2) Hardest contrastive mining: For each anchor, computing pairwise embedding similarities to select the intra-instance hardest positive (least similar patch within its mask) and inter-instance hardest negative (most similar patch from other instances), with intra-instance regions masked during negative search. These triplets drive a contrastive loss that simultaneously compresses intra-instance variance and expands inter-instance margins, forcing ViT to discern subtle geometric and appearance differences between instances. CoViT consistently achieves stable performance gains of over 2 AP points across multiple instance-level perception tasks by using ViT as backbone architecture. Notably, CoViT requires no extra decoders or labels, demonstrating that a pure ViT can learn instance-aware representations via inherent attention priors and targeted contrastive constraints. Code and models will be released.

## 二、方法论

### 2.1 核心思想

CoViT 的核心是构建并优化“实例感知三元组”，通过对比学习实现对特征空间的几何结构重塑：

- **压缩实例内方差**：使同一实例的各个 patch 嵌入更紧凑、一致；
- **扩大实例间距离**：增大不同实例间（特别是视觉上相似或语义易混淆的实例间）的嵌入差异。

### 2.2 关键技术流程

方法由三个阶段构成，循环迭代，无需任何真实标注：

**阶段一：注意力引导的实例掩码生成**

- 将 ViT 的多头自注意力图在头维上平均，得到聚合注意力矩阵：  
  Ā = (1/M) Σ A(m)；
- 将每个查询 patch 对应的注意力图重排为二维空间张量；
- 采用自适应阈值进行二值化（依查询与图像调节敏感度）：
  - B_{i}(h,w)=1，如果 Â_{i}(h,w) ≥ τ · max(Â_{i})，否则为 0；
- 对二值图执行形态学操作：
  - 先后进行膨胀与腐蚀（1D1E），形成形态学闭运算，连接碎片化前景并补洞；
- 通过连通域分析（connected components）分离潜在实例区域，生成候选实例掩码集合。

**阶段二：实例对应关系挖掘（hardest contrastive mining）**

- **锚点筛选**：要求该 patch 所在的实例连通域规模不小于设定阈值 γ，排除碎片噪声；
- **实例内最难正样本**：在锚点所属实例掩码内，寻找与锚点嵌入相似度最低的 patch（该点通常位于同一实例外观差异显著的区域，例如“狗头与狗腿”）；
- **实例间最难负样本**：先抑制锚点所在实例内部区域的相似度（置为 −∞），再在全局范围内选出与锚点嵌入相似度最高的补丁，该补丁应属于其他实例；
- **三元组保留条件**：要求满足语义难度约束，即锚点与最难负样本的相似度大于锚点与最难正样本的相似度减去一个边距阈值 α，以确保三元组具有训练价值。

**阶段三：混合对比学习目标**

- **三元组损失**（Triplet Loss）：在嵌入空间对每个三元组施加“正样本-锚点”相似度高出“负样本-锚点”一个边距 α 的约束，采用自适应边距策略，根据不同三元组难度动态调节 α，避免对已分离的简单三元组过度优化；
- **实例内对比损失**（Intra-instance InfoNCE-style Loss）：以锚点为中心，将所有同实例内 patch（除锚点）作为正样本，以最难负样本作为分母中的唯一负面竞争者，提高完整实例区域的协同一致性；
- 总损失为三元组损失与实例内对比损失的加权和（λ_tri = 0.4，λ_intra = 0.6）。

## 六、主要结论

- CoViT 能在不使用任何额外实例标签、不引入解码器的情况下，使纯 ViT 主干提升实例感知能力；
- 在 COCO 目标检测与实例分割上，ViTDet-L 的 box AP 从 46.2 提升到 48.1（+1.9），mask AP 从 41.4 提升至 43.0（+1.6），边界定位精度亦有 3.3 点增益；
- 在 HICO-DET 上，DEFR 全类 mAP 从 32.35 提升到 34.89（+2.54）；与 ViPLO 结合达到参评的 ViT 主干新式 mAP 39.25，提升 2.03 点；
- 不同 ViT 规模均有正向提升，且规模越大提升越明显：MAE-H/14 在 HICO-DET 上比基线提升 7.48 mAP；
- MAE 预训练权重与 CoViT 的适配度最高，说明像素级空间结构知识有助于实例边界的理解；
- 实验结果证明：ViT 自身的注意力先验可以在经过正确的对比约束后转化为实例感知能力，无需架构重新设计或解码器补充。

## 七、优点

1. **方法设计巧妙、低成本**：无需标注，无额外解码器，完全基于 ViT 本身输出的注意力图与嵌入相似性完成实例区域挖掘与约束，部署成本低、泛化性好；
2. **首次系统地将“注意力图形态学后处理”与“最困难正负样本挖掘”结合**：既有几何约束又能感知语义，相较单纯套用通用对比学习（如 SimCLR）或单纯依赖注意力图（如 MaskContrast）更精细；
3. **混合对比目标的设计具有理论合理性**：三元组损失解决了“正负样本之间相对间隔”的问题，实例内对比损失则改善了“同一实例全局紧致性”，二者互补，避免传统对比学习在结构化正负样本上失效的问题；
4. **验证了“语义表征”与“实例感知”并非矛盾而可兼得**：CoViT 在不牺牲原有语义能力的条件下显著提升实例级任务效果；
5. **实验覆盖较广**：既覆盖多种 ViT 规模（T→H），也覆盖多个下游框架和自监督预训练任务，说明了方法的通用性。

## 八、不足与局限

1. **注意力图本身作为伪标签存在固有误差**：在目标严重遮挡、重叠、背景干扰强或同类物体接触密切时，注意力图生成的“伪实例掩码”可能错切/粘连实例，导致后续三元组部分带有噪声；
2. **未对训练时长与算力成本做透明披露**：缺少关于 GPU 数量和训练耗时的报道，实际落地时，训练成本估算困难；
3. **全网络微调成本较高**：方法需要先冻结、再逐步解冻、再全网络微调，总共 50 个 epoch，且输入分辨率高（1024×1024），对算力小的研究团队不够友好；
4. **难以端到端运用于预训练阶段**：目前是在已预训练的 ViT 上做“后期注入”，属于后训练微调的范畴，不直接适用于从零开始的端到端自监督预训练流程；
5. **正文实验在少样本与开放域场景上的验证不完整**：摘要提及 PASCAL VOC 少样本识别效果，但正文没有相应表格与可视化证据，一定程度上削弱了完整性；
6. **与前沿同类工作缺乏全面数值横向对比**：如与 MaskContrast、BOAT、CRATE 等方法没有在同一标准下进行系统对比，只以“Baseline vs. Ours”的内部比较作为主要证据；
7. **有效负采样依赖实例掩码质量的正确性**：当掩码不准确时，负样本可能来自同一真实对象，产生误导性梯度，论文未讨论这种“伪负样本”可能性的处理方案；
8. **应用范围评估局限于检测/分割/HOI 任务**，未能在视频实例分割、多目标跟踪等实时实例级任务上验证其潜力。
