## 摘要
少样本动作识别旨在仅利用少量带标注的视频样本来识别未见过的动作类别。近期的工作通常在网络输出端采用单一原型监督，未能充分利用视频中丰富的跨帧全局空间信息。即使现有的多级度量方案也只是在中间层施加并行的原型约束，没有在整个特征处理流程中进行渐进式监督，导致学习到的类原型泛化能力有限。受此启发，我们提出一种新方法——面向少样本动作识别的层次度量学习。首先，开发了一个空间增强模块来捕捉跨帧全局空间表示，并结合时间多头注意力、异质对齐、时空特征融合和字典学习模块，构建了完整的特征处理流程。其次，将层次度量学习策略嵌入到所提方法中。层次度量学习由中心度量、对齐度量、对比度量、字典度量和原型度量组成，从帧级表示到最终类原型施加渐进式多阶段互补约束，从而联合优化特征紧凑性、异质时空对齐、类间区分性和抗噪鲁棒性。所提出的方法在五个广泛使用的少样本动作识别数据集上进行了验证，实验结果充分证明了其有效性。

## Abstract
Few-shot action recognition (FSAR) aims to recognize unseen action categories with only a small number of annotated video samples. Recent works typically apply single-prototype supervision at the network output and fail to sufficiently exploit rich cross-frame global spatial information in videos. Even existing multi-level metric schemes only impose parallel prototype constraints on intermediate layers, without progressive supervision along the full feature pipeline, which results in limited generalization ability of the learned class prototypes. Inspired by this, we present a novel method, hierarchical metric learning for few-shot action recognition (HML-FSAR). First, a spatial-enhanced module is developed to capture cross-frame global spatial representations. Combined with temporal MHA, heterogeneous alignment, spatial-temporal feature fusion and dictionary learning modules, it constructs the complete feature processing pipeline. Second, a hierarchical metric learning (HML) strategy is embedded into HML-FSAR. Composed of center metric, alignment metric, contrastive metric, dictionary metric and prototype metric, HML imposes progressive multi-stage complementary constraints from frame-level representations to final class prototypes, so as to jointly optimize feature compactness, heterogeneous spatial-temporal alignment, inter-class discriminability and anti-noise robustness. The proposed HML-FSAR method is validated on five widely-used FSAR datasets, and experimental results fully demonstrate its effectiveness.

- **现有方法的主要不足**：
  1. **空间信息利用不充分**：多数方法只关注帧内局部空间特征或时间建模，忽视了跨帧全局空间特征（即视频级整体空间表现）对动作识别的帮助。
  2. **监督信号过于单一**：典型方法只在网络输出端使用一个简单的原型度量（prototype metric）来约束学习。这样中间层的特征仅靠反向传播间接更新，缺乏显式约束，导致高层特征虽有判别力但泛化性有限。
  3. **多级度量流于并行**：已有的多级度量方案（如 MML-FSAR）只是在多个中间层分别施加类似“原型的并行约束”，不同层之间的监督信号彼此独立，缺乏**渐进式的层次关系**，没有从根本上优化完整特征管道的演化。
- **论文提出方案**：提出 HML-FSAR（Hierarchical Metric Learning for Few-Shot Action Recognition），核心是：
  - 设计空间增强模块（SE），提取跨帧全局空间表示；
  - 将完整特征管道分成多个阶段，并在每个阶段引入**互补的、逐级递进的度量约束**，从帧级特征覆盖到最终类别原型，从而联合优化特征的紧凑性、对齐性、判别力和鲁棒性。

## 2. 论文提出的方法论

### 2.1 总体架构
HML-FSAR 的特征管道由以下核心模块组成：

- **FE 特征提取模块**：基于预训练 MAE（Masked Autoencoder），逐帧提取帧级 `[CLS]` token 作为特征。
- **SE 空间增强模块**：利用帧特征计算协方差矩阵（SPD 矩阵），并堆叠两层 SPDNet 在黎曼流形上学习视频级全局空间表示。
- **TMHA 时间多头注意力模块**：以 `[Seq] + frame features` 作为序列输入，通过多层的时序 Transformer 捕获初步时空特征（PST）。
- **HA 异构对齐模块**：用两个并行 MLP 分别作为核函数，把来自黎曼流形的空间特征和来自欧氏空间的 PST 特征映射到统一空间，以便后续融合。
- **STFF 时空特征融合模块**：通过可学习的融合 token 和两层 Transformer 自注意力，将对齐后的空间、时间特征融合为统一视频级表示。
- **DL 字典学习模块**：用分析字典 P（编码）和综合字典 U（重构）对融合特征进行重构；经过 ReLU 编码和线性映射得到“提纯”的特征，以抑制噪声。
- **最后进行原型学习与分类**：对支持集中各类的提纯特征取平均，得到各类原型；用查询特征与原型的余弦相似度进行分类。

### 2.2 层次度量学习（HML）五个具体度量
HML-FSAR 的关键创新并不是简单地多个损失相加，而是让它们分别作用于**不同特征层级**，形成渐进式约束：

1. **中心度量（Center Metric）**  
   - 作用位置：帧级特征。
   - 目标：使同一视频内部帧特征靠近视频中心，减小帧间差异。
   - 公式：
     ```
     L_center = (1/T) Σ ||f_k - μ||²₂
     ```
     其中 `μ` 是视频特征均值。

2. **对齐度量（Alignment Metric）**  
   - 作用位置：空间增强特征与时间（PST）特征在共享空间中的对齐。
   - 目标：缩小两类异构特征之间的表示差距。
   - 损失包含两个部分：
     - 样本级对齐项：同一视频的空间/时间向量的余弦相似度，
     - 分布级对齐项：小批量内两类特征的协方差或二阶矩差异。

3. **对比度量（Contrastive Metric）**  
   - 作用位置：融合后的时空特征。
   - 目标：对同类样本拉近距离，对不同类样本推开距离并满足一定 margin。
   - 采用经典的成对对比损失公式（margin-based）。

4. **字典度量（Dictionary Metric）**  
   - 作用位置：字典编码和重构的提纯特征上。
   - 目标：过滤噪声、减轻少样本下“原型漂移”问题。
   - 损失包含三个分量：
     - **重构损失**：用 stop-gradient 保证梯度不直接污染原始特征；
     - **判别性编码约束**：使同类样本字典编码紧凑、不同类别编码中心彼此远离；
     - **字典正交约束**：减小字典原子的冗余。

5. **原型度量（Prototype Metric）**  
   - 作用位置：类别原型层面，用于分类。
   - 对查询集提纯特征与各类原型做余弦相似度并进行 softmax 分类，加入可学习的温度参数。

最终总损失函数为：

```
L_total = L_prototype + β1 L_center + β2 L_align + β3 L_contrast + β4 L_dict
```

各模块和对应度量层级形成“从帧到视频、从局部到全局、从生成到分类”的渐进约束链。

## 6. 论文的主要结论与发现

## 6. 论文的主要结论与发现

结合实验结果与消融分析，HML-FSAR 的核心结论可以归纳为：

**（1）多阶段渐进式度量约束显著优于单一或并行度量**

论文的核心论断是：少样本动作识别中的特征学习不应该只依赖最终的原型损失。通过逐层引入中心度量、对齐度量、对比度量、字典度量和原型度量，形成了一个“帧级紧凑 → 模态对齐 → 样本判别 → 重构提纯 → 类别可分”的渐进式优化链条。实验表明，移除任一层次度量都会导致性能下降，而全部联合使用时的精度最高。这证明了不同层级的监督信号能够互补，并且层级之间的顺序关系有助于特征管道逐步演化，而不是单纯地“堆砌多个损失”。

**（2）跨帧全局空间特征是少样本动作识别的重要补充**

论文通过空间增强模块（SE）将视频帧的协方差信息嵌入黎曼流形学习，得到的视频级全局空间表示明显提升了识别效果。消融实验中，单独去除 SE 模块会造成显著精度下降，说明视频动作不仅体现在时序变化上，也体现在整体空间布局与物体分布的全局模式中。已有方法普遍偏重时间建模，而该研究为“空间全局特征”在少样本场景中的作用提供了实证支持。

**（3）异构特征的对齐与融合是提升泛化能力的关键**

由于空间特征来自黎曼流形、时间特征来自欧氏空间，二者天然存在分布差异。论文使用异构对齐模块（HA）将两者映射到统一子空间，再用时空融合模块（STFF）以可学习融合 token 进行特征交互。实验结果表明，HA+STFF 的引入不仅让融合特征更具判别性，也增强了查询集与支持集之间的匹配稳定性。这提示：少样本动作识别中，多模态特征的有效利用应包含“对齐”而非简单的拼接或相加。

**（4）字典学习能够缓解少样本下的原型漂移**

在少样本条件下，支持样本稀少，直接计算原型往往易受噪声和类内差异干扰。论文采用分析字典与综合字典联合重构的方式，通过 ReLU 编码和重构约束获得“提纯”特征，并配合判别性编码与正交约束。消融结果表明，字典度量在 1-shot 设置下的贡献尤为明显，说明重构式特征提纯对于抵抗过拟合、稳定原型估计具有实际价值。

**（5）HML-FSAR 在多个基准上达到先进水平**

在 HMDB51、UCF101、Kinetics、SSv2-Small 和 SSv2-Full 五个数据集的 5-way 1-shot 与 5-shot 任务上，HML-FSAR 均取得了优于或持平于现有方法的精度，尤其在更具挑战性的 Something-Something 数据集上表现出较强的时序与空间联合建模能力。相比于依赖大规模视频预训练或视觉-语言模型的方法，HML-FSAR 在相对轻量的骨干网络（如 MAE）基础上仍能占据优势，说明层次化的度量约束能够有效弥补特征提取器容量的不足。

**（6）对领域研究范式的启示**

论文的方法论价值不仅在于性能提升，更在于提出了一种新的思路：少样本动作识别中的“元学习”不仅是对支持集的匹配策略设计，也可以是对特征提取过程的分层监督设计。通过把不同层次、不同性质的度量有机地组织成一条递进链，模型能够显式地指导底层特征学习到高层任务所需的结构性质。这一思想可推广到其他视频理解任务（如视频检索、时间动作定位）以及其他少样本多模态场景。

**局限性方面，论文作者也在结束部分承认**：

- 当前方法在 SSv2 等复杂时序数据集上的 1-shot 性能仍不够理想，有待更强的时间结构建模；
- 层次度量包含多个超参数，调参成本较高，自动化的权重学习是未来改进方向；
- 空间增强模块基于协方差矩阵计算，当输入帧数或视频分辨率较高时，计算开销较大；
- 大部分实验基于单卡进行，训练大规模数据集时效率受限，未来可探索分布式训练和更高效的特征提取器。

**未来工作**可能包括：将层次度量与自监督预训练结合；自适应学习各度量损失的权重；设计无需显式协方差计算的轻量空间增强方案；以及在跨域少样本动作识别（如从合成视频迁移到真实视频）中验证 HML-FSAR 的泛化能力。

总体而言，HML-FSAR 在技术设计上具有系统性，实验验证较全面，结论可信，为少样本动作识别提供了一种新的层次化度量学习框架，具有较强的参考价值。
