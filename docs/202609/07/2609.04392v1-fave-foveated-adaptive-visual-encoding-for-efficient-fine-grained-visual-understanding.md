## 摘要
细粒度的视觉理解依赖于局部细节，然而视觉编码器在高成本的整图高分辨率处理与可能削弱此类证据的紧凑全局编码之间面临权衡。受人类主动视觉的启发，我们将“看向何处”与“编码什么”分离开来。我们专注于后者，并提出了FAVE（中央凹自适应视觉编码）——一种轻量级可变分辨率ViT，它通过高锐度编码外部选择的区域，同时保留原始几何结构。我们首先在受控的小物体场景中，使用基于真值标注的裁剪块来独立研究这一编码问题。在原生最大边长为96像素的ImageNet物体上，与同一裁剪窗口上的固定分辨率ViT相比，FAVE的Top-1准确率提高了9.4个百分点，同时计算量（FLOPs）降低了12.7倍。提高全局分辨率或骨干网络容量无法达到同样的性能工作点。随后，我们将FAVE作为补充性局部分支集成到FastVLM中。其局部标记与FastVLM的全局视觉标记相结合，同时原始全局路径和语言模型保持冻结。在最多增加16个局部标记的情况下，FAVE使TextVQA的准确率提升了1.60个百分点，并在受控条件下相比SmolVLM2-2.2B实现了3.3倍的首令牌时间（TTFT）加速。在GQA属性问题上，它比FastVLM-1.5B提升了1.31个百分点，将优势延伸到文本之外，同时缩小了与FastVLM-7B的差距。这些结果共同表明，选择性地分配高锐度的局部处理能力，可以为更广泛的全局表示和模型缩放提供高效补充，从而支持对小物体、文本和属性的细粒度理解。

## Abstract
Fine-grained visual understanding depends on local detail, yet visual encoders face a trade-off between costly full-image high-resolution processing and compact global encoding that can weaken such evidence. Inspired by human active vision, we separate where to look from what to encode. We focus on the latter and introduce FAVE (Foveated Adaptive Visual Encoding), a lightweight variable-resolution ViT that encodes externally selected regions at high acuity while preserving native geometry. We first isolate this encoding problem using oracle ground-truth crops in a controlled small-object regime. On ImageNet objects with a native maximum side of 96 pixels, FAVE improves Top-1 by 9.4 points over a fixed-resolution ViT on the same crop window with 12.7 times lower FLOPs. Increasing global resolution or backbone capacity does not recover the same operating point. We then integrate FAVE as a complementary local branch in FastVLM. Its local tokens are combined with FastVLM's global visual tokens, while the original global pathway and language model remain frozen. With at most 16 additional local tokens, FAVE improves TextVQA by 1.60 points and achieves a 3.3 times controlled TTFT speedup over SmolVLM2-2.2B. On GQA attribute questions, it improves FastVLM-1.5B by 1.31 points, extending the benefit beyond text while narrowing the gap to FastVLM-7B. Together, these results show that selectively allocating high-acuity local capacity provides an efficient complement to broader global representations and model scaling for fine-grained understanding of small objects, text, and attributes.

## 二、方法论：FAVE（Foveated Adaptive Visual Encoding）

### 2.1 总体架构与核心思想

FAVE 是一个**轻量级可变分辨率 ViT**，对**外部选定的区域**进行高锐度编码，同时**保留其原生几何结构**（即不强制缩放到统一的方形分辨率）。其设计将“空间选择”与“局部编码”解耦，在不同任务中：
- **空间选择**由外部机制完成（ImageNet 用 GT 框、TextVQA 用 DBNet++、GQA 用 YOLOE-26S）
- **FAVE 负责"如何编码"选定的区域**

### 2.2 核心技术细节

**① 物体中心自适应裁剪（Object-centric Adaptive Crops）**
- 从源图像直接裁剪选定区域，保留原始空间尺寸与宽高比
- 小尺寸裁剪保持原生分辨率；大尺寸裁剪可选择在各向同性的前提下缩放，以符合任务相关的最大尺寸上限
- 裁剪区域进一步对齐到 16 像素的 patch 网格——通过调整边界而非重新缩放

**② Patch 化与可变 token 序列**
- 每个对齐后的裁剪划分为 16×16 的 patch，因裁剪尺寸各异，产生尺寸为 Hᵢ×Wᵢ 的可变 patch 网格
- 前置一个 CLS token：`[CLSᵢ | xᵢ,₁, …, xᵢ,Pᵢ]`,序列长度 Nᵢ = Pᵢ + 1

**③ 因子化位置编码（Factorized Positional Encoding）**
- 位置编码采用行向量与列向量相加的形式：**e_pos(u,v) = e_row(u) + e_col(v)**
- 避免了固定网格位置嵌入的限制，使同一 ViT 可以处理任意尺寸与宽高比的 patch 网格

**④ 序列批处理（Sequence Batching）**
- **标准 Padding**：填充至最长序列 N_max，对填充位置施加掩码
- **Patch-n-Pack**：在 token 上限 T_max 下打包多个完整序列，使用块对角注意力掩码防止跨样本交互
- 两种模式均可运行同一 FAVE 检查点，不改变学习到的预测函数

### 2.3 两阶段训练流程（多模态设置）

**阶段 1（Stage 1）— 紧凑局部 token 学习**：
- FAVE ViT 与共享的交叉注意力 reducer 从头联合训练
- 每个区域的可变长度 patch 特征 Xᵢ ∈ R^(Pᵢ×D_FAVE) 被压缩为一个内容相关的紧凑 token：**zᵢ = R(Xᵢ)**,zᵢ ∈ R^D_FAVE
- 区域编码分辨率与最终 LLM token 预算完全解耦

**阶段 2（Stage 2）— 局部投影与 token 融合**：
- FAVE ViT **冻结**，token reducer **微调**，局部投影器（MLP,192→512→1536）从头训练
- 投影后的局部 token 与 256 个 FastVLM 全局 token 拼接：**V = [G; F] ∈ R^((256+K)×D_LLM)**
- 送入**冻结的** Qwen2 语言模型生成答案

**关键约束**：FastVLM 的视觉塔、全局投影器以及语言模型全程冻结，因此性能提升完全归因于新增的局部视觉证据。

### 2.4 任务特定目标

- **TextVQA 阶段 1**：混合目标 = 双视图 InfoNCE 一致性 + 问题条件区域相关性（Rosetta 弱监督）+ 跨源特征对齐（Rosetta→DBNet）
- **GQA 阶段 1**：监督学习（掩码交叉熵物体分类 + 分组多标签属性分类 + 双视图一致性），使用**延迟长尾平衡**策略（前 10 epoch 无调整，之后线性增加 logit 调整强度）
- **TextVQA 阶段 2**：Sharpened 多答案交叉熵（γ=1.5）+ 辅助区域相关性损失
- **GQA 阶段 2**：纯自回归答案监督，无 OCR 或辅助目标

## 六、主要结论与发现

1. **自适应局部编码优于固定分辨率编码**：在 ≤96 像素小物体 cohort 上，FAVE-T 比同一 GT 裁剪窗口上的固定分辨率 ViT-T/16 高 9.4 点 Top-1，同时 token 数减少 11.1 倍、FLOPs 降低 12.7 倍。
2. **物体中心训练本身是不可或缺的**：即使给 Adaptive ViT-T 完全相同的裁剪几何与推理预算，如果是在全图上训练的（表 1 中 "Adaptive ViT-T (Full) Oracle crop"），准确率仅为 9.55，远低于 FAVE 的 50.45，说明**对象中心表征的归纳偏置**起关键作用。
3. **计算应瞄准选定区域，而非均匀扩散**：FAVE Adaptive Zoom（对选定区域放大）在 ≤96 和 ≤224 分组显著提升准确率；而 NaViT 提高全图分辨率（从 r=224 到长边上限）只增加 token 与 FLOPs，Top-1 却几乎不变。
4. **轻量局部容量胜过重型全局缩放**：在同样 GT-crop 下将 ViT 从 Tiny 扩到 Base（86.57M 参数、17.68 GFLOPs），Top-1 仍低于 5.70M 参数、0.101 GFLOPs 的 FAVE-T，说明针对小物体，局部容量是更高效的投资方向。
5. **局部证据有效增强多模态理解**：以至多 16 个新 token，FAVE 将 FastVLM-1.5B 在 TextVQA 上从 71.95 推到 73.55（+1.60），在 GQA 属性上从 70.73 推到 72.04（+1.31），接近 8B 级模型，而模型总参数量几乎不变。
6. **推理效率卓越**：相比 SmolVLM2-2.2B（74.51 对比 246.54），在可控条件下取得 3.3× TTFT 加速。
7. **跨域迁移性好**：TextVQA 训练的模型在 OCRBench Scene Text VQA 上从 66.5 提升至 80.0，且无需任何针对性的训练。

## 七、方法优点

1. **思想清晰、目标聚焦**：论文明确区分"where to look"与"what to encode"，将空间选择从编码策略中分离出来，使 FAVE 可用于多种上游选择器。
2. **保留原生几何结构**：不强制将裁剪区域缩放到统一方形——窄长文本行和小物体都被公平对待，不会因形状重采样而丢失关键信息。
3. **每区域一个 token 的紧凑性**：区域编码分辨率完全解耦于下游 LLM 的 token 预算——区域可以很大、分辨率很高，对 LLM 的开销却恒定，这是工程上的巧妙设计。
4. **冻结全局路径是可验证的**：FastVLM 全局视觉塔与 Qwen2 全程冻结，证明收益完全来自新增的局部路径，剔除了其他混淆因素。
5. **清晰的实验逻辑链**：从隔离的 ImageNet 编码研究（oracle 设置）到真实 VLM 部署的渐进路线，让每个结论都有可控变量的证据支持。
6. **效率评估的透明性**：对 TTFT 测量协议、crop cap 敏感性、组件级延迟（视觉编码 vs LLM）做了详尽说明，提高了可比性和可复现性。

## 八、不足与局限性

1. **未完整披露训练算力信息**：如 GPU 型号与数量、单模型训练时长、总 GPU 小时等关键训练成本数据，在附录中仅有推理侧的细节，削弱了工程复现与成本评估的完整性。
2. **对空间选择质量的依赖**：FAVE 依赖外部提议器，文中的 GQA 提案机制甚至专门准备了训练时的 GT fallback 与 Dedup-v2——真实环境中的劣质提议如何影响 FAWE 增益，目前缺乏系统性鲁棒性分析。
3. **性能比较范围有限**：当前基于 FastVLM/Qwen2 体系验证，未展示与其他"全局+局部"范式（如 Mini-Gemini 的第二编码器直接提供高分辨率特征）在相同条件下的更广泛横向对比。
4. **GQA 结论的局限**：仅报告 attribute 子集而非整体推理准确率；属性识别提升不等于完整视觉感知系统的全面改善。
5. **OCRBench 迁移的覆盖度有限**：对未接受 OCRBench 训练的模型而言，非 Scene Text 类别的无提升可被预期，但在论文中未深入讨论这些结果对方法边界条件的启示。
6. **两阶段训练流程的复杂性**：Stage 1 与 Stage 2 的训练目标、数据筛选（matched hybrid examples）、特征对齐等各环节对超参数敏感，完整复制难度偏高。
