## 摘要
自主系统需要在快速变化的场景动态和具有挑战性的光照条件下进行鲁棒的低延迟感知。在事件相机中，目标检测通常依赖于循环架构来随时间累积稀疏的时间信息。这项工作研究了如何将时间信息直接编码到事件表示中。我们提出了一种基于对数B样条时间编码的置信度归一化连续多时间尺度表示，以及一种利用事件生成空间结构的几何感知局部置信度机制。使用固定的前馈EventCenterNet检测器，我们证明了所提出的表示在PEDRo和Gen1数据集上始终优于紧凑的CSTR表示。我们进一步引入了一种递归指数-多项式近似，它能够实现高效的逐事件更新，同时大致保持检测性能。这些结果表明，精心设计的事件表示可以捕获通过循环时间建模学习到的大部分时间信息，为高效的前馈、事件驱动和未来的神经形态目标检测提供了有前景的基础。

## Abstract
Autonomous systems require robust low-latency perception under rapidly changing scene dynamics and challenging illumination. In event cameras object detection commonly relies on recurrent architectures to accumulate sparse temporal information over time. This work investigates how temporal information can be encoded directly within the event representation. We propose a confidence-normalized continuous multi-timescale representation based on logarithmic B-spline temporal encoding together with a geometry-aware local confidence mechanism that exploits the spatial structure of event generation. Using a fixed feed-forward EventCenterNet detector, we show that the proposed representations consistently outperform the compact CSTR representation on PEDRo and Gen1 datasets. We further introduce a recursive exponential-polynomial approximation that enables efficient event-by-event updates while largely preserving detection performance. These results demonstrate that carefully designed event representations can capture a substantial portion of the temporal information learned through recurrent temporal modeling, providing a promising foundation for efficient feed-forward, event-driven, and future neuromorphic object detection.

## 1. 论文的核心问题与整体含义（研究动机与背景）

本文关注**事件相机（Event Camera）前馈目标检测**中的时间信息表示问题。

- **背景**：传统帧式相机在动态场景中存在运动模糊、时间分辨率低、光照变化剧烈等问题。事件相机以微秒级时间分辨率异步测量对数亮度变化，具有低延迟、高动态范围等优势，适用于机器人、自动驾驶、无人机等场景。
- **核心问题**：现有事件相机目标检测通常依赖**循环（递归）架构**（如循环隐藏状态、循环注意力）来随时间累积稀疏的事件信息。这些方法虽然有效，但引入顺序依赖和额外架构复杂度，限制并行计算，也阻碍高效的事件驱动/神经形态实现。
- **本文研究的主要问题**：**有多大程度的时间信息可以直接编码在事件表示中，从而无需依赖循环架构？**
- **研究意义**：若时间信息可以直接编码在表示层面，则可以用简单的前馈检测器完成高质量检测，为低延迟、事件驱动、未来神经形态感知系统提供基础。

## 2. 论文提出的方法论

### 2.1 核心思想

将事件流投影到一组**多时间尺度的时间函数**上，用**置信度归一化**刻画极性与时间支持度，并引入**局部空间置信度**增强弱目标的空间一致性。核心在于设计一种编码函数，使其在保留近期事件高时间分辨率的同时，以可压缩的形式保留事件的中长期时间上下文。

### 2.2 关键技术细节与公式

**事件生成模型**：
- 事件在累积光学对数亮度变化超过阈值 C 时触发：|ΔL(x,y,t)| ≥ C
- 每个事件表示为 eᵢ = (xᵢ, yᵢ, tᵢ, pᵢ)，其中 pᵢ ∈ {−1, +1} 为极性

**总体表示结构**：将事件流转换为 3N 通道张量（N 正极性通道 + N 负极性通道 + N 置信度/支持通道）。

**指数衰减编码**：
- φₖ(Δt) = exp(−Δt/τₖ)
- 支持递归逐事件更新：Dₖ(tᵢ) = exp(−δtᵢ/τₖ)·Dₖ(tᵢ₋₁) + Eᵢ
- 缺点：不同时间常数的指数函数间相关性高，时标区分度有限

**对数 B 样条编码（核心创新）**：
- 将事件年龄映射到对数空间：aᵢ = log(1 + Δtᵢ/τ₀)，sₖ = k/(K−1)·log(1 + τ_max/τ₀)
- 时间函数为：φₖ(Δtᵢ) = B(aᵢ − sₖ)，其中 B 为二阶 B-spline 基函数
- 优点：近期事件获得高时间分辨率，远历史被对数压缩；通道间相关性低，时间编码多样性高

**置信度归一化**：
- 累计正负极性时间证据：Sₖ⁺(x,y)、Sₖ⁻(x,y)
- 计算总时间支持度：Cₖ(x,y) = Sₖ⁺ + Sₖ⁻
- 归一化：Ŝₖ⁺ = Sₖ⁺/(Cₖ + ε)，Ŝₖ⁻ = Sₖ⁻/(Cₖ + ε)
- 与归一化卷积 [16] 思想一致，支持度表示该时标下证据的置信程度

**几何感知局部置信度**：
- 由于事件多沿运动目标边缘生成，邻近事件提供几何支持
- C̃ₖ(x,y) = Σ G(u−x, v−y, σ)·Cₖ(u,v)，G 为高斯权重；权重用归一化 3×3 二项式核近似
- 区别于直接平滑正负通道：局部置信度增强归一化所用支持度，不模糊极性具体的时间结构

**递归指数-多项式近似**：
- 为支持事件驱动/神经形态的低成本递归逐事件更新，用 M 个指数衰减核的**多项式组合**来近似 B 样条函数：B̂ₖ(Δt) = fₖ(e₁(Δt), …, e_M(Δt))
- 多项式系数通过采样点的最小二乘回归拟合，不使用偏置项以保证可完全递归重构
- 指数核状态可直接递归更新，多项式映射在查询时重建样条响应的近似值

## 6. 论文主要结论与发现

1. **两种多时间尺度表示均一致优于 CSTR**（PEDRo 与 Gen1 的所有指标）。
2. **对数 B 样条优于指数衰减**：PEDRo 上 AP_s 从 0.015 → 0.062，AR_s 从 0.142 → 0.219；说明时间函数形状影响检测性能。
3. **局部置信度的效果取决于时间编码类型**：对指数衰减几乎无增益，对 B 样条在 PEDRo 上增益明显（AP 50:95 0.625 → 0.630；AP_s 0.041 → 0.062）。
4. **最佳时间参数因数据集而异**：Gen1 需要更长窗口（150 ms）和更高时间分辨率（τ₀=0.6 ms）；PEDRo 在 τ₀=1.2 ms、τ_max=35 ms 效果最优。**时间参数需按应用场景适配**。
5. **递归多项式近似可行**：四阶近似可极大还原解析样条（MSE 1.03×10⁻⁶），性能几乎无损，提示准确重建函数并非检测要求。
6. **与循环模型的差距有限**：PEDRo 上前馈模型 AP 50 最高（0.918）、AP 50:95 和最轻量循环模型 ReYOLOv8n 相当（0.636 vs 0.639），表示设计可揭示循环模型的主要收益源于长时上下文而非短期时间建模。
7. **Kalman 滤波收益甚微**（仅尺寸滤波 AP 50:95 0.636 → 0.639），说明表示已捕获大部分短期时间连续性。

## 7. 优点

- **问题视角新颖**：将时间建模从架构层面（循环网络）迁移到表示层面，挑战了"时间信息必须通过隐藏状态传播"的范式假设。
