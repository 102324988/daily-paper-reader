## 摘要
上下文分割（ICS）旨在根据一个或几个带注释的视觉示例，精确分割任意语义概念，如对象或部分。在本文中，我们从更经典的分割视角重新审视ICS，将其视为从粗到细的渐进式细化过程。我们不是通过参考-查询匹配直接预测最终掩码，而是从粗糙且模糊的前景响应逐步细化到精确且完整的前景结构。基于这一视角，我们提出了一种无需训练的上下文分割框架，称为FoRIS。具体而言，FoRIS包含三个关键阶段：前景净化、前景定位和前景巩固，分别通过语义聚合逐步抑制背景干扰、定位判别性目标区域并恢复完整的前景结构。实验结果表明，FoRIS在语义分割和部分分割任务上均达到了最先进的性能，在1-shot和5-shot设置下，平均比现有方法分别提高了4.5和4.8个mIoU点。代码：https://github.com/Xi-Mu-Yu/FoRIS。

## Abstract
In-Context Segmentation (ICS) aims to precisely segment arbitrary semantic concepts, such as objects or parts, given one or a few annotated visual exemplars. In this paper, we revisit ICS from a more classical segmentation perspective, viewing it as a coarse-to-fine progressive refinement process. Rather than directly predicting the final mask through reference-query matching, we progressively refine the segmentation from coarse and ambiguous foreground responses to precise and complete foreground structures. Building upon this perspective, we propose a training-free in-context segmentation framework, termed FoRIS. Specifically, FoRIS consists of three key stages: Foreground Purification, Foreground Localization, and Foreground Consolidation, which progressively suppress background distractions, localize discriminative target regions, and recover complete foreground structures through semantic aggregation. Experimental results demonstrate that FoRIS achieves SOTA performance across semantic and part segmentation tasks, with average improvements of 4.5 and 4.8 mIoU points over existing approaches in the 1-shot and 5-shot settings, respectively. ## 1. 核心问题与研究动机

- **任务背景**：上下文分割（In-Context Segmentation, ICS）要求模型根据一张或多张带掩码标注的参考图像，在推理时分割任意语义概念（如目标对象或部件），无需针对特定类别重新训练。
- **现有方法的局限**：
  - 当前免训练（training-free）ICS 方法大多采用“以对应关系为中心”（correspondence-centric）的范式，即通过参考图像与查询图像之间的特征相似度/匹配直接生成掩码。
  - 这种一步式语义迁移存在三个耦合的不确定性问题：
    1. **前景污染（foreground contamination）**：参考掩码对应特征包含上下文、位置、背景相关信息，并非纯净的前景语义。
    2. **目标定位模糊（ambiguous target localization）**：查询图像中与参考前景在视觉上相似的背景区域（例如白色方形墙体类似白色方形冰箱）可能被错误匹配。
    3. **前景响应碎片化（fragmented foreground responses）**：受视角、外观和结构变化影响，真实目标区域可能只产生部分、不完整的语义响应。
- **核心论点**：ICS 不应被视为一个简单的“参考-查询匹配”问题，而应看作一个从粗到细（coarse-to-fine）的渐进式前景细化过程。对应关系只是中间语义证据，而非最终输出。

## 2. 方法论

### 2.1 总体框架

- FoRIS 完全免训练，仅使用冻结的自监督视觉基础模型（DINOv3）特征，无需额外的分割监督或辅助分割模型。
- 输入为 \(S\) 个参考图像-掩码对 \(\{(\mathbf{I}^s, \mathbf{M}^s)\}_{s=1}^S\) 和一个目标图像 \(\mathbf{I}^t\)；输出为目标掩码估计 \(\hat{\mathbf{M}}^t\)。
- 特征提取：使用冻结编码器 ϕ 提取所有图像 patch 特征（\(\ell_2\) 归一化），全部流程基于这些 patch 级 token 进行。

### 2.2 三阶段流水线

**阶段一：前景净化（Foreground Purification, FP）**

- **自适应位置去偏（Adaptive Positional Debiasing, APD）**：
  - 位置偏差有时是噪声，但在空间规律性强的领域（如肺 X 光片中解剖结构布局固定）却是有用的先验，因此采用自适应判定而非一律去偏。
  - 通过零输入图像离线估计低秩位置子空间 U（SVD）；推理时计算参考-目标语义对齐分数 \(s_{\text{sem}} = \langle \mu_{\text{fg}}, \bar{\mathbf{f}}^t\rangle / \|\bar{\mathbf{f}}^t\|_2\)。
  - 仅当 \(s_{\text{sem}} < \theta\)（默认 θ=0.80）时，将所有 token 投影到 U 的正交补空间 \(P^\perp = I_C - UU^\top\) 上去除位置成分。
- **两阶段前景细化（Two-Stage Foreground Refinement, FR）**：
  - 构造前景原型（对参考前景 token 进行凝聚式层次聚类，得到 J 个簇原型 \(\mu_j\)）与“硬负样本背景原型”（选取与前景最相似的 top 20% 背景 token 的平均值 \(\mu_{\text{bg}}\)）。
  - **特征门控（Gate）**：基于温度缩放 log-sum-exp 聚合对前景簇的相似度并减去背景相似度，得到对比门控值 \(g(p) \in [0,1]\)，再与原始特征相乘得到门控特征 \(\hat{\mathbf{f}}(p)\)，用于后续整合阶段。
  - **前景语义匹配（Score 1）**：在“未门控”的去偏特征上进行原型匹配，并将背景方向相对前景方向正交化，得到 \(\mathbf{\mu}_{\text{bg}}^\perp\)，计算初始响应 \(S^{(1)}(p)\)。将门控与匹配解耦，保留完整去偏语义几何用于跨图像对应。

**阶段二：前景定位（Foreground Localization, FL）**

- **跨图像候选投票（Cross-image Candidate Voting）**：
  - 对每个目标位置 \(p\)，统计它在多少张参考图像中最匹配的 patch 位于参考前景掩码内，得到前景投票 \(V(p)\)；保留多数支持的位置构成候选集 C，并在粗空间网格上轻微稠密化。
- **多线索聚类与种子簇先验（Multi-cue Clustering & Seed-Cluster Prior）**：
  - 将目标 patch 用联合表示（DINO 特征 + RGB 颜色 + 2D 坐标）进行聚类，生成簇。
  - 若没有簇与 C 重叠则直接用候选集作为先验；否则选出与参考前景亲和度最高且与候选集重叠面积最大的种子簇 \(j^*\)。
  - 每个簇获得权重 \(\rho_j\)（跨图像亲和度 × 与种子簇的余弦相似度 × 候选重叠比例），归一化后得到密度化先验 \(P(p)\)。
- 聚合响应：\(S^{(2)} = S^{(1)} + (V - 1/2) + (P - 1/2)\)。

**阶段三：前景整合（Foreground Consolidation, FC）**

- **语义不一致惩罚（Semantic Disagreement Penalization, SDP)**：
  - 惩罚各阶段响应图之间的不一致（\(D(p)\)）以及前景-背景耦合（\(B(p)\)），并利用不确定性调制 \(U(p)\) 将修正集中在模糊 token 上；惩罚量 \(\Pi(p) = [D(p)+B(p)]\cdot U(p)\)。
- **语义重加权（Semantic Reweighting, SR)**：
  - 在门控特征 \(\hat{\mathbf{f}}^t\) 上重新聚类目标 patch，按每个簇的前景-背景分离程度计算簇级重加权因子 \(\Delta_j\)。
- 最终响应：\(S^{(3)} = S^{(2)} − \Pi + \Delta\)；再经二值化、双线性插值和 CRF 细化得到最终掩码。
