## 摘要
RGB和IR图像之间的互补信息可以显著增强极端条件下的目标检测性能。现有方法倾向于采用基于YOLO的双流CNN骨干网络进行特征提取，并专注于特征融合的设计。在本文中，我们引入了拉普拉斯解耦特征增强模块（LDFE），以融合来自双流CNN骨干网络不同阶段的特征。通过设计，LDFE通过依次执行全局-局部分解、去噪、融合和重构，同时考虑了模态和结构特征。LDFE首先基于拉普拉斯金字塔将特征分离为全局和局部分量，然后分别基于全局状态空间增强模块（GS2E）和局部卷积相关增强模块（LC2E）进行去噪和融合。具体而言，GS2E采用双分支架构处理主模态和辅助模态。它通过来自辅助模态的跨模态注意力动态抑制主模态中的噪声，同时使用状态空间模型捕获主模态全局特征表示中的长距离依赖。为了获得双向交互，两个模态系统地交替其主/辅助角色。此外，LC2E抑制局部特征中的噪声，并利用空间和通道维度以及三重卷积来提取细粒度细节以进行融合。这些创新设计实现了显著的性能提升，在M3FD、DroneVehicle、LLVIP、FLIR-Aligned、KAIST和VEDAI数据集上，mAP分别超过SOTA方法6.2%、3.7%、4.7%、2.3%、4.1%和2.0%。

## Abstract
The complementary information between RGB and IR images can significantly enhance object detection performance under extreme conditions. Existing methods prefer dual-stream CNN backbones built upon YOLO for feature extraction and focus on the design of feature fusion. In this paper, we introduce the Laplacian Decoupled Feature Enhancement block (LDFE) to fuse features from different stages of the dual-stream CNN backbone. By design, LDFE simultaneously considers the characteristics of modalities and structures for feature fusion by employing global-local decomposition, denoising, fusion, and reconstruction, sequentially. The LDFE first separates features into global and local components based on Laplacian Pyramid, and then performs denoising and fusion based on Global State Space Enhancement module (GS2E) and Local Convolutional Correlation Enhancement module (LC2E) separately. Specifically, the GS2E conducts a two-branch architecture for the main and auxiliary modalities. It dynamically suppresses noise in the main modality through cross-modal attention derived from the auxiliary modality, while employing a State Space Model to capture long-range dependencies within the global feature representations of the main modality. To obtain bidirectional interaction, the two modalities systematically alternate their main/auxiliary roles. Moreover, the LC2E suppresses noise in local features and leverages spatial and channel dimension along with triple convolution to extract fine-grained details for fusion. These innovative designs achieve a significant performance improvement, with mAP surpassing the SOTA methods 6.2%, 3.7%, 4.7%, 2.3%, 4.1% and 2.0% on M3FD, DroneVehicle, LLVIP, FLIR-Aligned, KAIST and VEDAI datasets,respectively.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：在低光照、恶劣天气等极端条件下，单一模态（RGB或IR）目标检测性能有限。RGB提供细节但受光照影响大，IR提供轮廓但缺乏细节。RGB-IR双流融合可互补，但现有融合方法（如基于CNN、Transformer、Mamba）往往直接融合两模态特征，未充分考虑模态内在差异（全局vs局部）和各自噪声特性，导致全局信息捕获不足或局部细节丢失。
- **动机**：作者认为，RGB和IR特征天然分别强调局部细节和全局结构，且各自携带模态特定噪声。若能将特征进行全局-局部分解，再针对性地去噪和融合，则可更高效利用互补信息。拉普拉斯金字塔是多尺度分解的有效工具，能与CNN骨干（擅长局部）和Mamba（擅长全局）的优势自然对齐。
- **整体含义**：提出Laplacian Decoupled Feature Enhancement block (LDFE)，通过**分解-去噪-融合-重建**四步范式，同时考虑模态和结构特性，显著提升RGB-IR目标检测性能。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将双流CNN中间特征经拉普拉斯金字塔分解为**全局（低频）**和**局部（高频）**分量，分别用不同的模块处理：全局用Global State Space Enhancement module (GS²E) 融合并捕获长程依赖，局部用Local Convolutional Correlation Enhancement module (LC²E) 提取细粒度细节，最后拉普拉斯重建得到增强特征。

- **关键技术细节**：
  - **LDFE整体流程**（图2）：
    1. **拉普拉斯分解**：对输入特征F（如RGB或IR）进行高斯平滑得到全局特征F_G；从F中减去F_G的上采样结果得到局部特征F_L。
    2. **通道交换（CS）**：将RGB和IR全局特征交换一半通道，实现初步信息交互。
    3. **全局处理（GS²E）**（图3）：采用双分支架构，主模态经归一化、卷积、分组卷积等提取特征；辅助模态经DW+PW卷积+SiLU产生注意力掩码，与主模态特征相乘实现去噪。两模态交替担任主/辅助角色实现双向交互。随后用状态空间模型（SS2D，来自Mamba）提取全局长程依赖，残差连接输出。
    4. **局部处理（LC²E）**（图4）：对RGB和IR局部特征分别进行L1归一化去噪，再经Softmax融合。融合后经三个1x1卷积提取特征，并分别与经空间注意力和通道注意力增强的原始局部特征相乘，最后加上残差。
    5. **拉普拉斯重建**：将处理后的全局和局部分量相加，得到增强特征。

- **骨干网络**：基于YOLOv8的双流CNN（可选用ResNet50、CSPDarknet53v5/v8），在第2、3、5阶段插入LDFE模块。最终特征求和后送入YOLOv8的neck和head。

- **损失函数**：采用标准YOLOv8损失（定位、置信度、分类损失）。

## 6. 主要结论与发现

- LDFE在所有六个数据集上均达到**最优或次优性能**，mAP50提升显著（如M3FD上6.2%、LLVIP上4.7%）。与第二好方法相比，平均mAP提升3.83%。

- 鲁棒性强：在不同天气、光照、过曝条件下性能下降最小。

## 7. 优点
