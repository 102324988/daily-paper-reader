## 摘要
纹理图像分类在计算机视觉应用中起着重要作用，包括工业检测、医学图像分析、遥感和目标识别。手工特征可以捕获局部纹理特征，但表示复杂视觉模式的能力可能有限。相比之下，深度学习模型自动学习判别性表示，但可能无法充分利用纹理图像中固有的多尺度空间频率信息。本文提出了一种混合特征融合框架，称为DWT_AlexNet_DNN，它将离散小波变换（DWT）特征与使用AlexNet提取的深度特征相结合，用于纹理图像分类。

## Abstract
Texture image classification plays a significant role in computer vision applications, including industrial inspection, medical image analysis, remote sensing, and object recognition. Handcrafted features can capture local texture characteristics but may have limited capability to represent complex visual patterns. In contrast, deep learning models automatically learn discriminative representations but may not fully exploit the multiscale spatial-frequency information inherent in texture images. This paper proposes a hybrid feature fusion framework, termed DWT_AlexNet_DNN, which combines Discrete Wavelet Transform (DWT) features with deep features extracted using AlexNet for texture image classification.

### 1. 论文的核心问题与整体含义（研究动机与背景）

纹理图像分类是计算机视觉中的基础且关键的任务，广泛应用于工业检测、医学图像分析、遥感监测和目标识别等领域。与常规目标分类不同，纹理分类更依赖局部模式、空间关系以及多尺度、多方向上的灰度或色彩变化，因此对特征表示的细致程度要求很高。

**研究动机源于两类主流方法的固有局限：**
- **手工特征**（如 GLCM、LBP、Gabor 滤波器、DWT 等）能够显式刻画局部纹理与频域特性，且具有良好的可解释性和计算效率，但对复杂、多变纹理的高层语义表达能力有限，且高度依赖人工参数选择。
- **深度特征**（如 CNN 学习到的表示）能够自动学习分层判别性特征，在复杂视觉任务中表现优异，但传统 CNN 主要在空间域操作，没有显式利用多尺度空间-频率信息，而这种信息对区分视觉上相似的纹理至关重要。

**论文的核心论点：** DWT（提供多分辨率空间-频率信息）与 CNN（提供高层分层视觉特征）具有天然的互补性，通过特征级融合可以构建更丰富、更具判别力的纹理表示，从而提升分类性能。这一思路为“手工特征+深度特征”融合提供了实证支持。

### 2. 论文提出的方法论

#### 核心思想
构建一个双通道并行特征提取框架，将 DWT 手工特征与 AlexNet 深度特征进行**特征级拼接**，然后送入深度神经网络（DNN）分类。论文共实现了三种可对比的模型：
- **DWT-DNN**：仅使用 DWT 特征作为分类输入；
- **AlexNet-DNN**：仅使用修改后 AlexNet 提取的深度特征；
- **DWT-AlexNet-DNN**：将两类特征拼接为融合特征后进行分类（即提案方法）。

#### 关键技术细节

**（1）DWT 特征提取路径：**
- 对输入图像（256 × 256）进行三级二维 DWT 分解，每级产生四个子带：近似（LL）、水平细节（LH）、垂直细节（HL）和对角细节（HH）。
- 对每个子带计算 16 个统计描述符（如均值、方差、能量、熵、标准差等）。
- 每级产生 4 × 16 = 64 维特征，三级共产生 **192 维** DWT 特征向量，记作 **f_DWT ∈ ℝ¹⁹²**。

**（2）AlexNet 深度特征提取路径：**
- 使用修改后的 AlexNet 架构（输入 227 × 227 × 3），将其全连接层 FC2 修改为 256 维输出，作为每个图像的深度特征向量，记作 **f_Alex ∈ ℝ²⁵⁶**。

**（3）特征融合与分类：**
- 将两类特征在特征层直接拼接，得到 448 维融合特征向量：
  **f_F = [f_DWT; f_Alex] ∈ ℝ⁴⁴⁸**
- 融合特征输入 DNN 分类器：网络结构为 FC(256) → ReLU → Dropout → FC(128) → ReLU → Dropout → FC(64) → ReLU → FC(10) → SoftMax。
- SoftMax 层将输出分数转换为类别概率，预测类别由最大后验概率决定；训练时使用分类交叉熵损失函数。
