## 摘要
人行道尺度的路径提取需要感知和规划在紧凑、低功耗硬件上于杂乱且地图稀疏的环境中可靠运行。我们提出了一种用于微出行系统的单目视觉人行道路径提取流程，该流程经过三次设计迭代，从骨架图基线到距离变换走廊规划，再到轻量级图像空间架构，并提供了五种路径规划方法在鸟瞰视图（BEV）和图像空间两个域中的系统比较。一个紧凑的SegFormer-B0学生模型，采用半监督教师-学生框架并使用OneFormer Swin-L伪标签进行训练，在每帧11.7毫秒下实现了手标注IoU为0.946，优于基线检查点（IoU 0.758，18.9毫秒）。在32个手标注帧的受控规划器比较中，图像空间中点规划实现了最低的横向中心误差（14.3像素）和2.2毫秒耗时，比BEV距离变换规划（926.8毫秒，65.0像素中心误差）快了421倍，同时保持了可比的掩膜-路径对齐（98.5%对98.6%）。在六个校园序列（22,679帧）上的全视频回放证实，改进后的分割将时间不稳定性从1.46%降低到0.33%，并将模板路径可用率从73.7%提高到79.3%。我们进一步表明，仅BEV的路径提取在单目设置中较为脆弱：在一次分析运行中，99.3%的帧未产生有效的BEV路径。最终推荐的架构是图像空间中点主、图像空间距离变换备选，BEV仅用于可视化，在CPU上每帧运行完整的感知到路径堆栈耗时低于50毫秒，使其适用于嵌入式行人速度微出行系统。

## Abstract
Sidewalk-scale path extraction demands perception and planning that run reliably on compact, low-power hardware in cluttered, map-sparse environments. We present a monocular vision pipeline for sidewalk path extraction in micromobility systems that progresses through three design iterations, from a skeleton-graph baseline through distance-transform corridor planning to a lightweight image-space architecture, and provides a systematic comparison of five path-planning methods across both bird's-eye-view (BEV) and image-space domains. A compact SegFormer-B0 student model, trained with a semi-supervised teacher-student framework using OneFormer Swin-L pseudo-labels, achieves a hand-annotated IoU of 0.946 at 11.7 ms per frame, improving over the baseline checkpoint (IoU 0.758, 18.9 ms). In a controlled planner comparison on 32 hand-labeled frames, image-space midpoint planning achieves the lowest lateral center error (14.3 px) at 2.2 ms, a 421x speedup over BEV distance-transform planning (926.8 ms, 65.0 px center error), while maintaining comparable mask-path alignment (98.5% versus 98.6%). A full-video replay across six campus sequences (22,679 frames) confirms that the improved segmentation reduces temporal instability from 1.46% to 0.33% and increases template-path availability from 73.7% to 79.3%. We further show that BEV-only path extraction is fragile in monocular settings: in one profiled run, 99.3% of frames produced no valid BEV path. The final recommended architecture, image-space midpoint primary, image-space distance-transform fallback, and BEV reserved for visualization, runs the full perception-to-path stack in under 50 ms per frame on CPU, making it suitable for embedded pedestrian-speed micromobility systems.

## 1. 核心问题与整体含义（研究动机与背景）

- 微出行系统（如配送小车、辅助代步车）需要在人行道上自主导航，但面对行人、标志、自行车、植被、不规则路缘等复杂环境，且对载荷、功耗、成本有严格限制。
- 人行道本身具有宽度变化、材质混杂、标线不一致、光照快速变化等感知难点，而高精度地图稀缺、GNSS 在树荫和城市峡谷中不可靠。
- 因此需要一种视觉优先、鲁棒、可解释、且能在单板计算机上高效运行的本地人行道路径提取方案。
- 论文的核心问题是：在单目相机、嵌入式 CPU 平台上，如何轻量、可靠地从图像中提取可通行的人行道路径，并系统比较不同规划域（BEV 与图像空间）的优劣。

## 2. 方法论

论文提出一套模块化单目视觉流水线，包含以下核心环节：

- **语义分割模块**：采用 SegFormer-B0（3.7M 参数）作为学生模型，通过半监督教师-学生框架训练。
  - 迭代 1：使用 SegFormer-B2 教师（24M 参数）在 300 张手标注帧上微调，为 2,300 张未标注帧生成伪标签。
  - 迭代 2：使用高容量 OneFormer Swin-L 教师（预训练于 ADE20K）为最多 1,419 张未标注帧生成二值伪标签。
  - 伪标签生成：教师输出 logits → softmax 概率 → 以阈值 τ=0.60 生成二值掩膜，再经连通域滤波和形态学平滑。
  - 混合训练集：手标注帧与伪标签帧合并，手标注优先级更高。
  - 损失函数：加权交叉熵损失 + Dice 损失。
  - 训练配置：输入分辨率 640×360，AdamW，初始学习率 5×10⁻⁵，批大小 4，训练 10 轮，权重衰减 1×10⁻⁴，使用 warm-up + 余弦衰减等。
- **分辨率权衡分析**：通过分辨率扫描（160×90 至 1280×720），选择 640×360 作为精度与速度的平衡点（CPU 推理约 46 ms）。
- **BEV 投影（可选）**：利用平面单应性矩阵 H 将图像像素映射到鸟瞰图坐标系，用于 BEV 域规划，但依赖平坦地面和固定相机位姿。
- **BEV 掩膜精化**：形态学开闭运算、连通域过滤（保留与 ego 锚点行相连的最大连通区域）、可选的孔洞填充与边界平滑。
- **五种路径规划方法**：
  1. **BEV 骨架图规划器**：Guo–Hall 细化算法提取骨架，构造图，Dijkstra 搜索候选路径，按曲率和横向偏移评分。
  2. **BEV 距离变换脊线规划器**：计算欧氏距离变换，构造代价场（距离倒数），用 Dijkstra 找最大净空路径，Savitzky–Golay 平滑。
  3. **BEV 模板弧规划器**：预定义弧线模板（直行、缓左、缓右、急左、急右），按走廊包含度和平滑度打分，低置信度时回退到 DT 脊线。
  4. **图像空间中点规划器**：直接在图像掩膜上逐行求左右边界中点，取中值并平滑，完全绕过 BEV。
  5. **图像空间距离变换规划器**：在图像平面计算 EDT，用带横向步长约束的动态规划追踪最大距离脊线。
- **时间平滑**：对路径多项式系数做指数移动平均（EMA），自适应平滑因子；航向角用圆形 EMA 处理 ±180° 跳变，并在突变时重置。

## 6. 主要结论与发现

- 分割改进：候选模型手标注 IoU 从 0.758 提升至 0.946，推理时间从 18.9 ms 降至 11.7 ms（加速 38%）。
- 在规划器对比中，**图像空间中点规划器**取得最低横向中心误差（14.3 px）和最快速度（2.2 ms），比 BEV 距离变换规划快 **421 倍**（926.8 ms），且掩膜-路径对齐相近（98.5% vs 98.6%）。
- **图像空间 DT 规划器**是最佳备选：inside-GT 比例最高（99.4%），108.1 ms，比 BEV DT 快 8.6 倍。
- BEV 方法在精度和速度上均不占优，即使使用 oracle 掩膜，BEV DT 仍不如图像空间方法，说明 BEV 域本身在单目场景下存在局限。

- 最终推荐架构：图像空间中点为主、图像空间 DT 为备选、BEV 仅用于可视化；完整感知-路径流程在 CPU 上 <50 ms/帧，可达 59 FPS。

## 7. 优点

- **模块化与可解释性**：流水线各阶段均可独立检查、调优，无需重新训练模型。
- **半监督训练策略实用**：利用高容量教师生成伪标签，显著提升轻量学生模型性能，减少对手标注数据依赖。
- **方法论对比系统全面**：首次在单目人行道导航中系统比较 BEV 与图像空间五种规划方法，并给出明确的性能与可靠性证据。

- **部署导向清晰**：以 CPU 延迟、FPS 等嵌入式相关指标为优化目标，最终方案在低功耗硬件上可行。
- **代码开源**：提供了 GitHub 仓库，便于复现。

## 8. 不足与局限

- **实验覆盖有限**：规划器比较仅 32 帧手标注，样本量较小，可能不足以涵盖所有人行道复杂拓扑（如多个连续路口、广场）。

- **时间稳定性指标简单**：基于帧间 IoU 的不稳定率无法完全反映路径平滑性对控制的实际影响。
- **算力细节缺失**：未报告训练时长、GPU 数量等，影响成本复现评估。
- **地图稀疏假设下缺少全局规划衔接**：仅做局部路径提取，未与全局路径规划集成验证。
