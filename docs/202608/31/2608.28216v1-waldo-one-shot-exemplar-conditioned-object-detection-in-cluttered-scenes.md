## 摘要
大型视觉-语言模型通常处理这样的任务：使用单个参考图像和简短描述在杂乱场景中定位特定物体实例，并报告该实例不存在的情况。我们质疑，是否可以从世界模型预训练目标已经学到的表示中以更低的成本获得相同的能力。我们提出了 WALDO，一个具有340万可训练参数的一次性样本和语言条件检测头，它读取冻结的 V-JEPA 2.1 特征，联合预测物体定位和目标存在性，对骨干网络没有梯度更新。由于样本条件的监督信息稀缺，我们从实例注释中合成训练片段，从真实边界框中挖掘样本，并构造排除参考实例但保留同类干扰物的缺席案例。这很容易出错：在明显的实现中，仅裁剪大小就能预测标签，一个在其上训练的头部在没有查看样本的情况下达到了0.9998的缺席AUROC，我们报告了关闭这一捷径的阴性对照。在35个保留的杂乱场景上，WALDO 在相同的评分器下实现了0.461的类别 AP@50，而基于提示的 Grounding DINO 基线为0.306。在匹配的576-token网格下，将 DINOv3 替换为 V-JEPA，会使类别内缺席 AUROC 从0.880降至0.726，实例 AP@50 从0.201降至0.141，从而将预训练目标而非输入分辨率作为增益的来源。然而，实例级别的 Success@1 仅达到0.190，而类别随机基线为0.190：世界模型特征可迁移到定位精度和缺席检测，但无法迁移到实例身份。

## Abstract
Locating a specific object instance in a cluttered scene using a single reference image and a short description, and reporting when that instance is absent, large vision-language models usually address this task. We ask whether the same capability is available far more cheaply, from representations already learned by a world-model pretraining objective. We present WALDO, a one-shot exemplar- and language-conditioned detection head with 3.4M trainable parameters that reads frozen V-JEPA 2.1 features to jointly predict object localization and target presence, with no gradient on the backbone. Because exemplar-conditioned supervision is scarce, we synthesize training episodes from instance annotations, mining exemplars from ground-truth boxes and constructing absence cases that exclude the referenced instance while leaving same-category distractors in view. This is easy to get wrong: in the obvious implementation, crop size alone predicts the label, and a head trained on it reaches 0.9998 absence AUROC without ever consulting the exemplar, and we report the negative controls that close the shortcut. On 35 held-out cluttered scenes, WALDO achieves a 0.461 catalogue AP@50, compared to 0.306 for a prompted Grounding DINO baseline under an identical scorer. Substituting DINOv3 for V-JEPA under a matched 576-token grid drops within-category absence AUROC from 0.880 to 0.726 and instance AP@50 from 0.201 to 0.141, isolating the pretraining objective rather than input resolution as the source of the gain. Instance-level Success@1, however, reaches only 0.190 against a 0.190 category-chance floor: world-model features transfer to localization precision and absence detection but not to instance identity.

## 1. 核心问题与整体含义

**研究动机：**
- 在杂乱场景中，给定一张参考图像（exemplar）和一句简短描述，定位**特定物体实例**（而非类别），并判断该实例是否不存在于场景中——这是机器人抓取、跨摄像头重识别、零售盘点等应用的基础能力。
- 这类任务通常依赖大型视觉语言模型，但成本高昂。作者质询：能否利用**世界模型预训练目标**（如 V-JEPA）已学到的表示，以**更廉价**的方式实现相同能力？

**核心问题：**
- 一次性的**实例级**定位与存在性判断，需要区分“某一辆特定的车”而非“任意一辆同型号的车”。
- 现有开放词汇检测器（GLIP、OWL-ViT、Grounding DINO）只回答**类别级**问题；单样本检测器（CoAE、OS2D）缺乏语言条件且假设查询一定可回答；指代表达理解（REC）方法则假设指称对象必然存在，从不训练“弃权”。
- **一句话概括**：世界模型预训练特征能否通过轻量头部迁移到空间上的实例级任务，包括定位精度和存在性判断？

## 2. 方法论

### 2.1 整体架构

WALDO 是一个**3.39M 参数的检测头**，读取**冻结**的 V-JEPA 2.1 ViT-L/16 特征，不更新骨干网络任何梯度。

### 2.2 训练片段合成（Episode Mining）

由于实例级监督数据稀缺，作者从标注的 ground-truth boxes 中**合成训练片段**，每类三种：

| 片段类型 | 构造方式 | 存在性标签 |
|---------|---------|-----------|
| 正样本（Positive） | 用 box i 的增强裁剪作为 exemplar，查询区域包含 box i，目标为 box i | 1 |
| 类内缺失（Within-category absent） | 同一 exemplar，查询区域**排除** box i 但仍含同类其他实例 | 0 |
| 跨类缺失（Cross-category absent） | 某类别 exemplar 对应另一类别场景 | 0 |

实际混合比例为 66% 正样本、19% 类内缺失、15% 跨类缺失。

### 2.3 防捷径设计与负控制

**关键陷阱**：朴素实现中正样本用整图、缺失用子图，导致区域面积几乎完美预测标签（AUROC 0.9998，且从未查看 exemplar）。修复方案：
- 区域尺度从**三种片段共享的同一分布**中先采样，再决定标签；
- 整图缺失路由到跨类缺失（唯一能表达整图缺失的类别）；
- 负控制验证：区域面积、宽、原点 x、宽高比与标签的 AUROC 分别为 0.529、0.529、0.442、0.491，接近随机水平 0.5；
- 单元测试保证 (存在/缺失) × (整图/裁剪) 四格全部有样本填充。

### 2.4 特征与条件化机制

- **冻结特征**：查询区域由冻结 V-JEPA 2.1 编码为 24×24=576 个 patch tokens（384px 输入）；exemplar 经同一编码器平均池化为向量；描述文本由冻结 SigLIP2 文本塔编码（V-JEPA 无文本编码器，此为结构性选择）。
- **相关性通道**：计算每个 patch 与 exemplar 向量的余弦相似度，作为额外输入特征拼接（在骨干原始空间计算，先于任何可学习投影）。
- **FiLM 条件化**：exemplar 和文本嵌入联合预测仿射调制参数 (γ, β)，应用于所有 token；最后层零初始化使模块初始为恒等映射。
- **预测头**：三个线性头分别输出逐 patch objectness、逐 patch 边界框、单个存在性 logit。存在性用**注意力池化**而非均值（避免背景 patch 淹没目标 patch 的投票）。
- **边界框解码**：中心偏移限制在 ±1 patch 宽度内（保证 objectness 图与框指同一位置），宽高自由在 [0,1]。

### 2.5 损失函数

采用焦点损失（focal loss，α=0.25, γ=2.0）+ L1 回归 + GIoU 损失 + 存在性 BCE 的联合损失，正样本按 patch 中心是否落在 GT 框内（且距框中心 ≤1.5 patch 宽）判定。

## 3. 实验设计

### 3.1 数据集

- **自建标注**：220 个密集场景（103 辆车、117 架飞机，512×512），763 个实例框；目标为一个深红色丰田 Highlander 和白色波音客机。
- **场景密度**：中位 3.5 个实例，最多 10 个；共 2,638 对场景内同类配对（实例级的硬负样本）。
- **按场景划分**（seed 0）：训练 150 场景/523 实例，验证 35/124，测试 35/116。
- **重要声明**：因公开 benchmark 缺乏实例级标注（类别级标注丢弃了区分实例所需信息），必须自建数据集。

### 3.2 骨干对比（受控消融）

| 骨干 | 编码器 | Patch | 输入 | 特征维 | 头部参数 |
|-----|--------|-------|------|-------|---------|
| V-JEPA 2.1 | ViT-L/16 | 16 | 384 | 1024 | 3.39M |
| DINOv3 | ViT-B/14 | 14 | 336 | 768 | 3.26M |
| SigLIP2 | ViT-SO400M/16 | 16 | 384 | 1152 | 3.45M |

**关键控制**：固定 24×24=576 token 网格（匹配 token 预算而非像素预算，DINOv3 因此像素更少且偏离预训练分辨率，均不利于 DINOv3）。

### 3.3 基线对比

- **Grounding DINO**：类别提示（含目标类名）和通用提示（不含目标类名）两种协议；后者匹配 WALDO 文本通道的信息量，前者给基线更多信息。
- **OWLv2**：文本+图像双条件，同样两种提示协议。
- 基线保持**冻结**、不微调、不加阈值（置信度 0.08 偏向召回）。

### 3.4 评估协议

三种判定设置：**类别级**（任意同类实例正确）、**实例级**（仅 exemplar 自己的框正确，同类其他实例是假阳性）、**缺失检测**（易负样本=跨类场景；难负样本=排除目标但保留同类实例）。推理为单次前向，NMS 由评估框架统一施加（IoU=0.5，上限 100）。

## 6. 主要结论与发现

1. **类别检索有效，实例检索失败**：类别级别上 SigLIP2 S@1 0.743、V-JEPA 0.629、DINOv3 0.600（差异在噪声内）；实例级别 S@1 仅 0.190–0.224，与“类别检索后随机猜实例”的基线（0.190–0.224）**统计不可区分**——模型找到了类别，但无法区分同类中的具体实例。
2. **缺失检测成功**：硬负样本 AUROC 上 V-JEPA 0.880 vs SigLIP2 0.831 vs DINOv3 0.726，这是三个表示唯一显著分离的指标；V-JEPA 的正负样本存在性概率间隔（0.862 vs 0.456）显著大于 DINOv3（0.667 vs 0.536）。
3. **骨干差异的本质**：SigLIP2 检索稍好，V-JEPA 定位更精确（AP@75 显著更高）且弃权更可靠——**世界模型预训练迁移到定位精度和存在性估计，而非检索准确率**。
4. **优于开放词汇基线**：WALDO (SigLIP2) AP@50 = 0.481 vs Grounding DINO（类别提示）0.306，约为 1.57×；类别 Success@1 0.743 vs 0.429。
5. **尺度效应**：飞机 AP@50 约 0.877，汽车仅约 0.166–0.210（差距 ~5×），归因于输入分辨率和物体密度而非表示质量。
6. **68.1% 的实例查询返回的 top-1 框与正确对象 IoU 恰好为零**——实例身份判别几乎完全未解决。

## 7. 优点

- **问题定义清晰**：明确区分类别级与实例级两种任务设置，报告了迁移差距，不混淆任务难度差异。
- **反捷径设计严谨**：对“裁剪尺寸泄漏”这一隐性陷阱做了系统化处理，附负控制 AUROC 和单元测试作为证据。
- **受控消融具有说服力**：在匹配 token 网格下替换骨干，隔离预训练目标（而非分辨率或 token 数）作为变量。
- **基线的公平性处理**：报告了类别提示和通用提示两种协议（后者信息量匹配 WALDO 的文本通道），并允许基线使用 0.08 低阈值偏向召回。
- **诚实的负面结果报告**：明确报告实例身份未解决（S@1 = 随机基线），且用精确统计检验（Poisson 二项、McNemar）支撑该结论，而非选择性报告成功指标。
- **多视角推理的可调用接口**：区域可调用设计为后续粗到细推理提供扩展性，虽然当前变体并无显著提升。

## 8. 不足与局限

- **实例身份未解决是核心局限**：模型在 68.1% 实例查询中完全定位错误，作者也将实例级表现视为“中心负面结果”。这说明当前 V-JEPA 等自监督特征缺乏实例级判别力，或需要更强大的 exemplar 匹配机制（而非简单的余弦相似度+轻量头部）。
- **数据集规模极小**：两个类别、220 场景、763 框，无法推广到更广泛的物体类别、更大场景变化；测试样本 n=35 场景导致统计功效有限。
- **语言通道近乎退化**：仅两条描述文本（1 比特信息），语言条件的实际贡献未被充分验证；无法检验多属性描述的累积条件化效果。
- **测试设置人为简化**：测试时 exemplar 是目标在**同一图像**中未增强的裁剪（自像素匹配），比真实跨视角再识别更易；作者也承认这一点。
- **骨干容量不匹配**：DINOv3 是容量更小的 ViT-B/14，不构成容量匹配竞争，且偏离其预训练输入分辨率（336 vs 原生）和 token 匹配牺牲了像素预算，虽被诚实声明但仍是消融的混杂因素。
- **多个辅助变量未受控**：特征维度（1024/768/1152）导致头部参数差异 6%，编码器容量不同，作者逐一承认但未完全消除。
- **基线对比的公平性局限**：基线冻结而 WALDO 头部训练过，对比本质是“训练过的轻量头部 vs 开箱即用检测器”，作者承认了这一框架差异。
- **训练不可完全复现**：cuDNN 非确定性导致重训波动（约 0.10–0.15 类别 S@1），作者给出了波动区间但未提供多种子完整统计。
