## 摘要
视觉Transformer检测器现在的准确率接近CNN，但仍然难以部署在NPU和微控制器上，因为包括可变形注意力、特征融合和非线性激活函数在内的关键组件本身并不兼容整数运算。现有的量化检测器要么保留Softmax、GELU和LayerNorm等算子，要么专注于重型骨干网络，使得轻量级检测Transformer缺乏端到端的整数实现。我们通过I-LW-DETR填补了这一空白，这是第一个完全整数化的轻量级DETR，其前向传播中的每个操作，包括Transformer的非线性，都以整数运算执行。I-LW-DETR基于三个关键组件：一种保持尺度的分裂卷积，为多尺度投影仪的每个分支分配独立的激活尺度；SD-ShiftGELU，一种依赖于符号的GELU近似，在避免精度下降的同时保持逐元素行为；以及一种约束的Shiftmax，以维持稳定的Softmax归一化。实验结果表明，所提出的量化流水线在不同的模型规模下都能持续生成高效的完全整数模型。在所有模型规模下，所提出的流水线仅带来适度的精度下降，同时将模型大小减少约3.6倍，计算成本降低一个数量级以上。

## Abstract
Vision Transformer detectors now approach the accuracy of CNNs but remain difficult to deploy on NPUs and microcontrollers because key components, including deformable attention, feature fusion, and nonlinear activation functions, are not natively compatible with integer arithmetic. Existing quantized detectors either retain operators such as Softmax, GELU, and LayerNorm or focus on heavyweight backbones, leaving lightweight detection transformers without an end-to-end integer implementation. We address this gap with I-LW-DETR, the first fully integer-only lightweight DETR, in which every operation in the forward pass, including transformer nonlinearities, is executed in integer arithmetic. I-LW-DETR is built upon three key components: a scale-preserving split convolution that assigns independent activation scale to each branch of the multi-scale projector; SD-ShiftGELU, a sign-dependent GELU approximation that preserves element-wise behavior while avoiding the accuracy degradation; and a constrained Shiftmax that maintains stable Softmax normalization. Experimental results demonstrate that the proposed quantization pipeline consistently produces efficient fully integer-only models across different model scales. Across all model scales, the proposed pipeline incurs only a moderate accuracy degradation while reducing the model size by approximately $3.6\times$ and the computational cost by more than one order of magnitude.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题背景**：视觉Transformer检测器（如DETR系列）在精度上已接近CNN，但其关键组件——可变形注意力、多尺度特征融合、非线性激活函数（Softmax、GELU、LayerNorm等）——本质上依赖浮点运算，难以部署在仅支持整数运算的NPU和微控制器上。
- **现有方法的不足**：
  - 多数量化检测器（如Q-DETR、AQ-DETR、QRT-DETR）仅量化线性层和激活，但将Softmax、GELU、LayerNorm等保留为浮点运算，不是真正意义上的“全整数”推理。
  - 已有的全整数方案（如EIQ-DETR）仅应用于重型骨干网络（如Swin-T），模型规模和计算成本显著高于轻量级模型，未覆盖轻量级DETR场景。
- **论文核心目标**：提出 I-LW-DETR，**首个完全整数（integer-only）推理的轻量级DETR**，使前向传播中的每一个操作（包括Transformer非线性）都以整数算术执行，填补该研究空白。

## 2. 论文提出的方法论：核心思想、关键技术细节

**总体思路**：不是简单地对现有LW-DETR进行通用量化，而是联合重新设计架构及其整数近似，使整个网络能在整数域执行推理。分为“量化就绪架构适配”和“整数算子设计”两部分。

### 2.1 量化就绪架构适配（QR-LW-DETR）

- **整数兼容的可变形注意力采样**：将双线性插值替换为最近邻采样，消除分数插值权重和相关浮点乘加运算。
- **可学习位置查询生成**：将正弦位置编码（依赖三角函数）替换为可学习的线性投影模块，使参考框坐标通过线性层直接映射为位置查询特征，便于统一量化。

### 2.2 线性操作的整数量化

- **标准线性算子**：采用I-ViT的对称量化方案，权重使用按通道（per-channel）量化，激活使用按张量（per-tensor）量化，矩阵乘累加完全在整数域完成，比例因子在累加后统一处理。
- **尺度保持分裂卷积（Scale-Preserving Split Convolution）**：针对LW-DETR投影器中多阶段特征图动态范围差异大、共享单一激活尺度导致低动态范围特征量化分辨率下降的问题，将投影器卷积拆分为多个独立卷积分支，各分支保留独立激活尺度；累加前通过固定的整数二进乘移位（dyadic multiply-and-shift）将各分支rescale到公共输出尺度。

### 2.3 非线性操作的整数近似

- **SD-ShiftGELU（Sign-Dependent ShiftGELU）**：
  - 分析发现I-ViT原始ShiftGELU依赖向量级最大值减法（`I∆ = Ip − max(Ip)`），导致大量激活被推入ShiftExp的高相对误差区域，精度急剧下降。
  - 利用Sigmoid的符号对称性，将Sigmoid重写为分段形式：`z≥0` 时用 `1/(1+exp(−z))`，`z<0` 时用 `exp(z)/(1+exp(z))`，两者等价但保证指数输入始终非正。对应的整数输入为 `I∆ = Ip − ReLU(Ip)`，逐元素独立处理，避免全局最大值操作。
- **约束Shiftmax（Constrained Shiftmax）**：
  - 原始I-ViT Shiftmax在Softmax归一化时，若注意力层的指数累加和 `S_sum` 超过32位整数精度，归一化因子会坍塌为零。
  - 提出在校准过程中为每个Shiftmax块自动校准一个分母移位参数 `s_d`：
    - 计算所需精度 `M_req = ⌈log2(S_sum)⌉`，加精度裕度 `M_target = M_req + m_p`（`m_p=4`）；
    - 分母移位 `s_d = max(M_target − 31, 0)`；
    - 采用商-余数累加方式恢复精确的移位后分母：`S_R = ΣQ_i + (Σr_i >> s_d) = ⌊S_sum / 2^s_d⌋`。
- **LayerNorm**：沿用I-ViT整数LayerNorm，但将牛顿迭代次数从10次增加到20次以提升解码器数值稳定性。

## 6. 论文的主要结论与发现

- **全整数推理可行**：首次在轻量级DETR上实现端到端全整数推理（不含任何浮点运算）。
- **精度与效率折中**：QAT后相对FP32基线仅损失4.3–5.4 mAP（COCO），同时模型体积减少约 **3.6×**，计算成本降低 **12.9–14.4×**。
- **模型规模效应**：模型越大，量化鲁棒性越好；Medium模型QAT后从FP32的50.8降至47.1 mAP，保留比例最高。
- **关键瓶颈确认**：I-ViT ShiftGELU在DETR上造成灾难性精度下降（如Tiny从42.0→0.0 mAP），证明分类ViT的量化方案不能直接迁移到检测任务。
- **跨域迁移**：在VisDrone上方法有效，但小目标检测对量化更敏感（AP_S显著下降），最近邻采样可能影响小目标定位。
- **硬件兼容性**：I-LW-DETR的算子能映射到Arm Ethos-U85等标准整数边缘NPU原语，具备实际部署基础。
