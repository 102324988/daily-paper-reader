## 摘要
由于其强大的泛化多模态处理与推理能力，多模态大语言模型（MLLMs）在作为通用图像检索器方面展现出显著潜力，能够有效处理各类真实世界的图像检索任务。然而，先驱性研究虽前景广阔，却忽视了细粒度上下文建模和解耦微调目标在提升MLLMs检索性能方面的潜力，尤其是在长文本到图像检索、视觉对话检索和组合图像检索（CIR）等复杂任务中。因此，在本工作中，我们提出了一种自动化的细粒度多模态五元组数据集构建流程，以及一种新颖的两阶段细粒度多模态微调策略。数据集生成流程产生了一个包含细粒度图像描述和修改文本的综合CIR数据集，有助于细粒度上下文建模。与先前纠缠的微调范式不同，我们的方法将微调过程分为两个不同阶段：（1）面向细粒度上下文推理的微调；（2）面向细粒度检索的微调。这两个阶段旨在依次增强模型的上下文理解能力和查询-目标对齐能力，从而提升检索性能。在涵盖多种复杂图像检索任务的五个数据集上进行的大量实验表明，即使在零样本检索设置下，我们的方法也显著优于现有方法，且所采用的多模态大语言模型骨干网络比那些方法更为轻量。

## Abstract
Due to their strong generalizable multimodal processing and reasoning capabilities, Multimodal Large Language Models (MLLMs) have demonstrated significant potential as universal image retrievers, effectively addressing diverse real-world image retrieval tasks. Nevertheless, pioneering studies, while promising, overlook the potential of fine-grained context modeling and disentangled fine-tuning objectives in enhancing MLLMs' retrieval performance, particularly for complex tasks such as long-text-to-image retrieval, visual dialog retrieval, and composed image retrieval (CIR). Therefore, in this work, we propose an automated fine-grained multimodal quintuple dataset construction pipeline and a novel two-stage fine-grained multimodal fine-tuning strategy. The dataset generation pipeline produces a comprehensive CIR dataset with fine-grained image captions and modification text, facilitating fine-grained context modeling. Beyond the previously entangled fine-tuning paradigm, our approach separates the fine-tuning process into two distinct stages: (1) fine-grained context reasoning-oriented fine-tuning and (2) fine-grained retrieval-oriented fine-tuning. These stages aim to sequentially enhance the model's context understanding and query-target alignment capabilities, thereby improving retrieval performance. Extensive experiments across five datasets encompassing diverse and complex image retrieval tasks demonstrate the remarkable superiority of our method over existing approaches in zero-shot retrieval settings, even with a more lightweight MLLM backbone compared to those methods.

- **研究背景**：多模态大语言模型（MLLMs）凭借其强大的多模态理解与推理能力，被越来越多地用作通用图像检索器（universal image retriever），用于处理多种图像检索任务。图像检索按照查询复杂度可分为：

  - **复杂任务**：长文本到图像检索（long-text-to-image retrieval）、视觉对话检索（dialog-based image retrieval）以及组合图像检索（CIR，即"参考图像 + 修改文本"的复合查询）。
- **现有方法的局限**：
  1. **缺乏细粒度上下文建模**：现有方法（如 MCL）依赖句子对或 `<参考图像, 短修改文本, 短目标描述>` 三元组数据，仅提供粗粒度信息；而真实场景中的复杂查询往往包含长文本和复合上下文，要求模型具备细粒度理解能力。
  2. **微调目标次优**：E5-V 只优化同质查询-目标对齐，忽略了多模态上下文理解能力的增强；MCL 则同时优化多模态检索与生成任务，这种纠缠式微调目标会干扰上下文理解与对齐能力的平衡，导致次优性能。
- **核心研究目标**：通过细粒度上下文学习将 MLLM 转化为强大的通用图像检索器，特别是在复杂图像检索任务中取得突破。

## 2. 论文提出的方法论

### 2.1 贡献一：自动化细粒度五元组数据集构建管道（FiGMaQ）

论文提出三条流水线阶段，生成格式为 `<参考图像, 参考细粒度描述, 修改文本, 目标图像, 目标细粒度描述>` 的五元组数据集（约 87K 样本）：

1. **CoT-based 细粒度描述生成（Step 1）**：
   - 使用 ImageNet1K 的 100K 无标签开放域图像作为初始数据集；
   - 设计链式思维（CoT）指令，引导 MLLM 分四步生成细粒度描述：
     - 主体导向推理（subject-oriented）：识别主体及其数量；
     - 属性导向推理（attribute-oriented）：描述外观、颜色、图案、显著特征、动作和交互六类属性；
     - 上下文导向推理（context-oriented）：提供场景设置和额外重要元素；
     - 总结导向推理（summary-oriented）：综合前三步生成连贯的描述。
   - 生成的描述平均超过 100 个 token。

2. **MLLM-based 图像对识别（Step 2）**：
   - 动机：视觉相似或粗粒度相似的图像对在语义上可能不相关（如风格相似但内容无关），不符合实际用户检索需求；
   - 方法：使用**细粒度语义相似度**而非传统视觉/粗粒度相似度；
   - 技术细节：由于现有 VLP 编码器难以处理过长的细粒度文本，改用 LLM 作为编码器。受生成式检索模型启发，在输入序列末尾追加 M 个 EOS token，取最后隐状态中这些 EOS token 的均值作为图像/文本的语义表征（式1）；随后用图像-文本对比损失微调 MLLM（式2）；
   - 阈值筛选：保留余弦相似度在 [θ_l=0.6, θ_h=0.83] 范围内的图像对（式3），排除过于相似或无关的配对。

3. **人类风格的细粒度修改文本生成（Step 3）**：
   - 现有方法的问题：a) 基于粗粒度描述难以修改细粒度属性；b) LLM 生成的修改文本过度精确（如"将十五个人改为七个人"），不符合真实用户模糊的表达习惯（如"少一些人"）；
   - 解决方案：输入细粒度描述对 + 设计**模糊引导指令（vagueness-guided instruction）**，让 LLM 模拟用户在不了解目标图像的情况下进行自然、可模糊的修改表达；提供三个手工示例进行少样本学习，使用 LLaMA 3.1-70B 作为生成模型。

### 2.2 贡献二：两阶段细粒度多模态微调策略（FiRE）

在 FiGMaQ 数据集上进行解耦式两阶段微调：

1. **阶段一：细粒度上下文推理导向微调**：
   - 任务形式：指令为"`<参考图像>` 根据修改文本进行修改，请描述新图像"（instruction），目标为细粒度目标描述（answer）；
   - 损失函数：标准生成损失（式4）；
   - 特点：与 MCL 不同，使用 MLLM 长序列 token embeddings 表示参考图像（而非单一 CLIP 特征），将图像类比于长文本，既促进细粒度推理又提升泛化能力。

2. **阶段二：细粒度检索导向微调**：
   - 任务形式：查询为"`<参考图像>` + 修改文本，请描述新图像"，目标为"`<目标图像>` 描述该图像"；即**多模态查询 → 多模态目标**对齐，而非 MCL 的多模态查询 → 单模态文本目标；
   - 损失函数（总损失式7）：
     - InfoNCE 损失（式5）：批次内查询-目标对比学习；
     - Recall@k 代理损失（式6）：直接约束正目标在批次内的排名，分别采用 Recall@1（β=0.4）和 Recall@5（β=0.15）。

### 2.3 推理阶段

- 统一编码：查询和候选目标图像分别编码，按相似度排序；
- 支持三类查询形式：纯文本、纯图像（"describe the image `<image>`"）、图像+文本组合（"describe the image `<image>` with `<text>`"）。

## 6. 论文的主要结论与发现

1. **细粒度数据 + 解耦微调显著提升复杂图像检索能力**：相比纠缠式微调（w/-OneStage）和仅有对齐微调（w/o-FirstStage），两阶段顺序微调在各类复杂检索任务中全面胜出；
2. **轻量模型也能超越大规模模型**：FiRE 使用 4B 参数的 BLIP-3，在多数据集上超越 8B 参数的 E5-V，证明数据质量和训练策略比模型规模更重要；
3. **细粒度上下文建模的必要性**：细粒度描述（w/-ShortCap 对比）显著优于粗粒度描述，尤其在需要精确推理的 CIR 与长文本检索任务中；
4. **CIR 任务作为微调场景的高价值**：CIR 自身融合了多模态复杂查询，能有效增强 MLLM 在视觉对话检索和长文本检索等未见任务上的泛化能力；
5. **数据质量是决定性因素**：FiGMaQ 仅 87K 样本，却优于 MCL 的 2.7M 和 MagicLens 的 36.7M 样本数据，佐证了细粒度语义筛选+人类风格修改文本的价值；
6. **Recall@k 代理损失有效增强判别能力**：直接约束排名显著提升检索准确率。

## 7. 优点

1. **数据管道自动化程度高**：完全无需人工标注，三阶段流程设计精巧——CoT 提示挖掘描述深度，细粒度语义相似度替代粗糙的视觉匹配，模糊引导指令使修改文本接近真人表达；
2. **五元组数据结构设计巧妙**：比传统三元组多出参考/目标细粒度描述，天然适配多种微调任务（上下文推理+检索对齐），兼顾灵活性与信息密度；
3. **解耦式两阶段微调范式**：将"上下文理解"与"查询-目标对齐"两个能力维度分离、顺序优化，训练目标清晰，计算资源占用低于纠缠式方案；
4. **轻量高效**：仅用 4×A100-40G 和 4B 模型即可达到 SOTA，实用性和可复现性较强；
5. **实验设计严谨**：覆盖任务类型广、消融对照组设计合理、对弱项（如 Flickr）有诚实的归因分析。
