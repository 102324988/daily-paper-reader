## 摘要
上下文学习（ICL）通过在特定任务的支持集中对图像-掩膜示例进行条件设定，无需重新训练即可使医学图像分割模型适应未见过的结构和新模态。由于支持集是模型唯一的任务特定信号，其组成直接影响分割性能。在本工作中，我们将支持集视为ICL可靠性的可控决定因素。首先，我们比较了随机采样与基于相似性的选择，后者根据示例与查询图像的视觉相似性进行检索。其次，我们训练了一个基于Transformer的分类器，仅从查询图像和支持图像预测分割结果是否会低于指定的交并比（IoU）阈值。利用结合DINOv3嵌入的MultiverSeg，在四个基准和三种成像模态上，我们展示了基于相似性的选择始终匹配或优于随机采样，在支持集规模最小时增益最大。此外，我们的分类器在全部四个基准上均能高于随机水平地预测分割失败。最终，这些结果表明，上下文分割的可靠性既可以通过明智的支持集选择来改进，也可以在使用前预先预见，为更安全的临床部署提供了实用机制。

## Abstract
In-context learning (ICL) adapts medical image segmentation models to unseen structures and modalities without retraining by conditioning on a task-specific support set of image-mask exemplars. Because this support set is the model's only task-specific signal, its composition directly influences segmentation performance. In this work, we investigate the support set as a controllable determinant of ICL reliability. First, we compare random sampling against similarity-based selection, where exemplars are retrieved based on their visual similarity to the query image. Second, we train a transformer-based classifier to predict, from the query and support images alone, whether a segmentation will fall below a specified Intersection-over-Union (IoU) threshold. Using MultiverSeg with DINOv3 embeddings across four benchmarks and three imaging modalities, we show that similarity-based selection consistently matches or outperforms random sampling, with the largest gains at the smallest support set sizes. Furthermore, our classifier predicts segmentation failure above chance on all four benchmarks. Ultimately, these results demonstrate that the reliability of in-context segmentation can be both improved via informed support selection and anticipated before use, providing practical mechanisms for safer clinical deployment.

- **研究背景**：上下文学习（In-context Learning, ICL）在医学图像分割中无需重新训练即可适应未见过的解剖结构或成像模态，其核心机制是通过一个由少量“图像–掩膜”示例组成的支持集（support set）来条件化模型。
- **核心问题**：支持集是模型唯一携带任务信息的信号，但它的组成如何影响分割性能，以及能否在分割执行前就预判结果是否可靠，这两个问题尚缺乏系统研究。

### 2. 方法论

- **核心思想**：
  1. 对比两种支持集构建策略——随机采样 vs. 基于查询图像嵌入的余弦相似度采样；

- **关键技术细节**：
  - 图像表示：使用冻结的 DINOv3 编码器 `g` 将每张图像映射为嵌入 `e = g(x)`；
  - 分割模型：使用 MultiverSeg 作为上下文分割模型 `f`，预测 `ŷ = f(x_q, S)`；
  - 相似性选择：计算查询嵌入 `e_q` 与所有支持池嵌入的余弦相似度，取 Top-K 构成支持集 `S`；
  - 失败检测问题定义：对于给定查询–支持对，定义二元标签 `b = 1[IoU(ŷ, y) < τ]`，其中 `τ` 取各数据集中位 IoU，以保证标签平衡；
  - 分类器结构：将查询嵌入加一个可学习的查询 token，支持嵌入加一个可学习的支持 token（支持 token 间不设位置编码以保持集合置换不变性），连同 `[CLS]` token 一起送入 Transformer 编码器，最后 `[CLS]` 输出经 MLP 分类头得到失败预测。

### 3. 实验设计

- **数据集**：共 4 个基准，覆盖 3 种成像模态：
  - EchoNet：超声心动图，左心室分割（转换为二值掩膜），随机抽取 500 个查询；
  - WBC：白细胞显微图像，细胞核分割；
  - HipXRay-Femur：髋关节 X 光，股骨分割；

- **对比方法**：
  - 随机采样（40 次独立重复取平均 IoU）；

### 6. 主要结论与发现

- **支持集选择**：相似性采样在全部 4 个基准和数据点上一致优于或匹配随机采样，表现为更高中位 IoU 和更窄的分布范围；当 K 最小时增益最大（EchoNet K=1 中位 IoU 提升 0.16，WBC 提升 0.14）；随着 K 增大，两种策略逐渐收敛。
- **失败检测**：分类器在所有数据集上的 AUROC 均超过随机水平（0.5），其中 EchoNet 最高（AUROC 0.80，AUPRC 0.79），WBC 和 HipXRay-Pelvis 较低（AUROC 约 0.69-0.71）；在 3 个数据集上，AUROC 随支持集规模增大而明显上升，HipXRay-Pelvis 是例外。
- **实用部署模式**：先按相似性检索支持集，再用轻量分类器标记高风险输出，从而避免不可靠的分割结果直接进入临床流程。

### 7. 优点

- **问题定位精准**：将支持集组成与失败检测作为两个互补的可靠性杠杆，直击 ICL 在实际部署中的关键薄弱点。
- **方法简洁实用**：相似性选择仅依赖图像嵌入，无需额外标注；失败检测分类器轻量，输入输出设计符合集合的置换不变性。
- **实验设计严谨**：查询/支持池分离、查询级训练/测试划分，有效防止信息泄漏；随机采样采用多次重复平均，比较公平。
- **结果呈现直观**：用箱线图展示 IoU 分布，清晰呈现相似性选择在提升“典型性能”和降低“低质量尾部”方面的优势。

### 8. 不足与局限

- **模型与编码器泛化有限**：仅评估了 MultiverSeg + DINOv3 组合，未验证其他分割架构（如 Tyche、UniverSeg）或医学专用编码器，结论普适性未知。
- **忽略掩膜信息**：选择与失败预测都完全基于图像嵌入，对目标结构的语义不敏感，可能漏掉仅从图像无法判断的困难案例。
- **阈值设定单一**：使用数据集级中位 IoU 作为失败阈值，不同任务或不同患者群的临床可接受阈值可能不同，缺乏多阈值分析。
- **数据划分固定**：仅用一次 20:80 划分，未做跨划分稳定性检验；EchoNet 只取 500 个查询子集，样本量相对有限。
- **缺乏 OOD 评估**：未验证在新型模态、新型解剖结构或不同数据分布下，支持集选择和失败检测是否依然有效。
- **分类器性能上限**：HipXRay-Pelvis 在大型支持集下 AUROC 趋近随机，提示某些任务中上下文信号不足以可靠预测失败，模型适用边界尚不明确。
