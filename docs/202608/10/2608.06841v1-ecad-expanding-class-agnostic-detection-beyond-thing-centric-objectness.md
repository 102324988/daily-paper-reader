## 摘要
物体检测是视觉感知中的一项基本任务，为识别、定位、推理和交互提供结构化的区域表示。然而，现有的检测范式在很大程度上继承了以物体为中心的客观性概念，即检测器主要被训练用于定位离散且可数的物体实例。因此，许多具有语义意义的视觉元素，如天空、道路、草地、水域和运动场，尽管对场景理解和空间推理很重要，却常常被归入背景。在本文中，我们提出了扩展类别无关检测（ECAD），这是一种旨在发现超越传统以物体为中心的物体的类别无关视觉候选的新设置。为了支持这一设置，我们构建了BTCO-Bench，一个超越以物体为中心的客观性基准，包含覆盖真实世界和跨域场景的类别无关框标注。我们进一步提出了ECADet，一种基于轻量级DETR的检测器，构建在冻结的DINOv3编码器之上，并引入了几何感知专家回归（GAER）和原型引导查询调制（PGQM），分别改善对不同视觉元素的定位和客观性估计。大量实验表明，ECADet在BTCO-Bench上始终优于代表性的类别无关和基于提议的检测器，证明了扩展客观性发现的有效性。代码和基准将发布。

## Abstract
Object detection is a fundamental task in visual perception, providing structured region representations for recognition, grounding, reasoning, and interaction. However, existing detection paradigms largely inherit a thing-centric notion of objectness, where detectors are mainly trained to localize discrete and countable object instances. Consequently, many semantically meaningful visual elements, such as sky, road, grassland, water, and sports courts, are often absorbed into the background despite their importance for scene understanding and spatial reasoning. In this paper, we formulate Expanded Class-Agnostic Detection (ECAD), a new setting that aims to discover category-agnostic visual candidates beyond conventional thing-centric objects. To support this setting, we construct BTCO-Bench, a Beyond Thing-Centric Objectness benchmark with category-agnostic box annotations covering both real-world and cross-domain scenarios. We further propose ECADet, a lightweight DETR-based detector built upon a frozen DINOv3 encoder, and introduce Geometry-Aware Expert Regression (GAER) and Prototype-Guided Query Modulation (PGQM) to improve localization and objectness estimation for diverse visual elements, respectively. Extensive experiments show that ECADet consistently outperforms representative class-agnostic and proposal-based detectors on BTCO-Bench, demonstrating the effectiveness of expanded objectness discovery. Code and benchmark will be released.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 总体框架
- 基于 RF-DETR 构建，采用**冻结的 DINOv3 大模型编码器**提取视觉特征，仅训练轻量级投影器（projector）、Transformer 解码器及两个面向客观性的模块，以保留预训练表示的可迁移性并防止在小数据上过拟合。
- 每层解码器产生查询特征 Q^l 和参考框 R^l，所有前景区域共享统一标签（object），但外观与几何高度多样，因此引入两个互补模块。

### 模块一：几何感知专家回归（GAER）
- **动机**：统一回归头需要以单一映射建模尺度、宽高比、形状和定位难度高度异质的区域，能力受限。
- **流程**：
  1. 原始回归头保持为主路径，预测**基础框偏移** Δb^l_base,i = RegHead(q^l_i)。
  2. 构建 6 维**几何描述子**：g^l_i = [cx, cy, log w, log h, log(wh), log(w/h)]，综合捕捉中心、尺度、面积和宽高比。
  3. 将查询特征与几何描述子分别投影到同一路由空间并相加，得到路由特征 t^l_i。
  4. 通过可学习的**框路由原型库** P_box = {p_k}（K 个专家原型）计算余弦相似度，经温度缩放 softmax 得到**专家路由权重** w^l_i,k。
  5. 每个专家从查询特征预测**专家特定框残差** Δb^l_expert,i,k，按路由权重加权聚合（尺度参数 η 控制）得到路由框残差。
  6. 最终框 = σ(参考框 + 基础偏移 + 路由残差)，即**在保留原始回归稳定性的基础上叠加查询自适应残差**。

### 模块二：原型引导查询调制（PGQM）
- **动机**：ECAD 将分类简化为无类别监督的客观性估计，单一分类器难以覆盖多样的前景模式。
- **流程**：
  1. 离线从训练集用冻结 DINOv3 抽取特征，按 GT 框裁剪并池化为物体级嵌入，聚类得到**离线客观性原型库** P_obj（M 个原型）。
  2. 查询特征投影到原型匹配空间后计算余弦相似度，经 softmax 得到**响应分布** π。
  3. 构造**置信度描述子** c（含归一化熵、top-1/top-2 响应间隔、池化响应、最大相似度、查询范数、置信分数等统计量），用于判断查询是置信地匹配前景原型还是模糊响应。
  4. **原型感知调制器**先构建熵感知响应分布（不确定时降权不可靠分配），再结合置信度门控生成**查询残差**，以残差方式增强查询特征。
  5. 增强查询送入原始分类头得到基客观性 logit；另用低容量**校准器**估计原型客观性先验，通过置信门控与 tanh 界定的有界残差校准得到最终客观性分数——整体保持“主路径 + 保守校准”的设计。

### 训练目标与实现
- 沿用 RF-DETR 的集合预测目标：匈牙利匹配后，优化分类损失、L1 回归损失和 GIoU 损失；GAER 与 PGQM 端到端训练，无需额外监督。

- **与类无关检测（CAD）的关系**：CAD 模型（如 CAOD、PF-RPN）已实现“框预测不依赖类别名称”，但其训练监督仍局限于传统 thing 实例。ECAD 的核心区别不在于“是否预测类别”，而在于**重新定义了监督信号的空间覆盖范围**——将 stuff 区域的框加入训练目标，从根源上改变模型对“什么值得检测”的认知。
- **与开放词汇/开放世界检测（OVD/OWD）的关系**：OVD 通过文本嵌入将类别空间扩展到任意名词，但极少数描述词涵盖“草地”“天空”这类区域；OWD 关注未知物体发现，但未知域仍被界定为“未标注的物体实例”。ECAD 则完全不依赖类别词汇，以纯视觉的客观性估计跨越语义鸿沟，与 OVD/OWD 在问题设定上正交，未来可结合使用。
- **与语义/全景分割的关系**：分割方法对 stuff 区域输出精确的像素级掩码，但无法输出稀疏、分层的候选框；ECAD 的框输出天然支持重叠结构（如“赛场上的球员”）。二者构成互补而非替代关系——分割回答“每个像素属于什么”，ECAD 回答“哪些区域在语义上值得作为整体被定位”。

## 10. 方法设计的深层解析与潜在风险

- **GAER 的深意**：将几何信息显式编码进路由机制，实质是让模型对不同形状统计特性（细长条招牌、大面积天空、紧凑物体）自动分配不同的回归先验。其风险在于：参考框本身由解码器产生，与几何描述子存在耦合，若参考框初始质量较差，路由信号也可能被带偏；论文通过保留主路径回归缓解了这一点。
- **PGQM 的深意**：离线聚类得到的原型库相当于从数据中提炼出的“客观性词典”，查询特征通过软匹配判断自己是否属于某个典型前景模式。置信度描述子中引入熵、top-1/top-2 间隔等统计量，使得模型能区分“确信的高响应”与“可疑的模糊响应”，从而抑制将背景噪声误判为前景。
- **潜在风险**：两个模块都需要维护原型库（框路由原型 + 客观性原型），虽然论文报告了超参敏感性分析，但跨数据集迁移时原型数是否需要重新搜索未知；此外，离线聚类使用冻结 DINOv3 特征，若骨干升级需重新聚类，存在一定维护成本。

## 11. 实验结果中值得注意的隐含信息

- **跨域增益远大于真实域增益**：ECADet 在 XDomain 上超出最佳对手 22.2 AP，显著高于 Real 上的 14.4 点。这说明 stuff 感知的客观性建模对分布偏移的鲁棒性提升十分显著——可能是由于 stuff 区域（天空、道路）在不同域（油画、铅笔画、恶劣天气）中的外观一致性远高于实例物体（形态多变），模型更易学到域不变的表征。
- **AP50 与 AP75 差距**：ECADet 在 Real 上的 AP75（39.3）远高于基线（约 24），但 AP50 与 AP75 之间仍有较大间距，说明框定位精度已达到较精细水平，但对完全精确的边界（尤其对于边界模糊的 stuff 区域）仍有提升空间。
- **DINOv3-S 变体的意义**：仅用小型骨干即可超过所有现有方法，说明性能提升主要来自任务重定义和模块设计，而非单纯依赖大模型容量，这为在资源受限场景中应用提供了有力支撑。
