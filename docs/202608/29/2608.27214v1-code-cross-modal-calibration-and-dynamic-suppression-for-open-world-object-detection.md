## 摘要
基于多模态基础模型的开放世界目标检测（OWOD）常常因单向文本到视觉匹配而导致语义歧义，而刚性的异常值惩罚可能会过度抑制已知类别决策边界附近的未知目标。我们提出了CODE（跨模态校准与动态抑制），一个统一的推理时框架，包含三个互补组件。跨模态联合置信度校准注入全局视觉原型以校准文本驱动的已知类别预测。不确定性引导的通用目标性增强通过局部视觉响应衡量分类犹豫，以增强潜在未知目标。基于置信度裕度的动态异常值抑制用裕度感知调整取代刚性抑制，保留模糊的分布外实例。在真实世界检测基准上的实验表明，使用OWL-ViT L/14骨干网络，CODE在任务1中实现了21.7 U-mAP和40.8 K-mAP，分别超越先前最先进技术2.6和2.3个百分点。

## Abstract
Open World Object Detection (OWOD) built on multimodal foundation models often suffers from semantic ambiguity caused by unidirectional text-to-vision matching, while rigid outlier penalties may over-suppress unknown objects near known-class decision boundaries. We propose CODE (Cross-Modal Calibration and Dynamic Suppression), a unified inference-time framework with three complementary components. Cross-Modal Joint Confidence Calibration injects global visual prototypes to calibrate text-driven known-class predictions. Uncertainty-Guided Universal Objectness Enhancement measures classification hesitation from local visual responses to strengthen potential unknown objects. Dynamic Outlier Suppression via Confidence Margin replaces rigid suppression with a margin-aware adjustment that preserves ambiguous out-of-distribution instances. Experiments on the Real-World Detection benchmark demonstrate that, with the OWL-ViT L/14 backbone, CODE achieves 21.7 U-mAP and 40.8 K-mAP in Task 1, surpassing the previous state of the art by 2.6 and 2.3 points, respectively.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 开放世界目标检测（OWOD）要求模型在识别已知类别的同时，能够定位并标记未知对象，且不能与背景或已知类混淆，这比传统封闭集检测更具挑战性。
- 多模态基础模型（如 CLIP、OWL-ViT）带来了开放词汇知识，近期方法（如 FOMO、PASS）通过 LLM 将类别分解为细粒度、类无关的属性作为中间语义表示，以实现未知对象的推理。
- 现有基于属性的 OWOD 范式存在三大局限：
  - **单向文本到视觉匹配的语义歧义**：遮挡、模糊、视角变化等会导致视觉属性不显著，而文本属性对难以区分的硬对象或背景区域不够具体。
  - **通用目标性估计不可靠**：基于最大属性响应得到的“通用目标性”无法将模糊未知对象与背景干扰可靠分离。
  - **刚性异常抑制（MCM）过度惩罚**：仅由最高已知类概率决定的惩罚项会把共享多个已知类属性的边界未知对象误删为背景。
- 论文提出 **CODE（Cross-Modal Calibration and Dynamic Suppression）**，一个统一的推理时框架，针对上述问题引入跨模态校准、不确定性引导增强和动态抑制，以提高未知对象召回率并保持已知类精度。

## 2. 方法论

CODE 基于属性驱动 OWL-ViT 基线，包含三个核心组件，整体推理流程见算法 1。

### 2.1 基线：属性化 OWOD
- 利用 LLM 生成候选属性，通过部分最优传输（POT）、交叉熵、MSE 和 L1 正则化优化属性嵌入 `A` 和映射权重 `W`。
- 候选区域视觉嵌入 `v` 的统一 logits 为：`Logit = sim(v, A) · W`，得到已知类 logits `Logit_K` 和未知类 logit `Logit_U`。
- 已知概率 `P_K = σ(Logit_K)`；未知概率 `P_U = σ(Logit_U) · p_ID · p_OOD`，其中 `p_ID = max σ(a_n^T v)`，`p_OOD` 基于 MCM 抑制。

### 2.2 跨模态联合置信度校准（CMJCC）
- 离线为每个已知类别计算视觉原型 `p_k = Norm(1/M_k Σ v_{k,i})`，构成原型库 `V_base`。
- 对候选区域 `v_i` 计算其与各原型的视觉相似度 `Sim_vis`，并通过动态阈值 `τ_i = max(mean(Sim_vis) + m, τ_min)` 和 ReLU 门控得到视觉增强项 `Logit_boost`。
- 利用反向温度 `S_scale = 1/τ_OWL-ViT` 将视觉增强映射到模型 logit 尺度，最终校准已知 logits：`Logit_calib_K = Logit_K + α · S_scale · Logit_boost`。

### 2.3 不确定性引导的通用目标性增强（UGUOE）
- 取候选区域与视觉原型的 Top-K_u 相似度组成局部集合 `S_local`，计算基础未知响应 `μ_unk = mean(S_local)`。
- 用局部响应的无偏方差 `σ²(S_local)` 度量分类“犹豫”程度；采用指数衰减函数计算不确定性权重 `W_unc = exp(-γ·σ²)`，并用 `[w_min, w_max]` 裁剪。
- 增强未知 logit：`Logit_enh_U = Logit_U + β · S_scale · W_unc · ReLU(μ_unk - τ_unk)`，从而提升位于“语义真空”中的潜在未知对象响应。

### 2.4 基于置信度边际的动态异常抑制（DOSCM）
- 对校准后的已知 logits 计算 Softmax 分布，提取 Top-1 与 Top-2 概率，得到置信度边际 `ΔS = S_top1 - S_top2`。
- 有效抑制惩罚 `MCM_eff = S_top1 · ΔS`，动态 OOD 分数 `p_dyn_OOD = 1 - MCM_eff`。
- 最终未知概率 `P_final_U = σ(Logit_enh_U) · p_ID · p_dyn_OOD`。
- 这种设计使得只有模型对某个已知类别具有绝对排他性置信时才施加强抑制，从而保护边界上的模糊未知对象。

## 7. 优点

- **推理时即插即用**：CODE 无需重新训练基础模型，只需预计算属性与视觉原型，轻量高效。
- **跨模态校准弥补文本缺口**：CMJCC 提供直接的视觉参考，缓解纯文本驱动的语义歧义。
- **不确定性建模新颖**：UGUOE 使用局部视觉响应方差衡量分类犹豫，能准确定位位于已知类“语义真空”的未知对象。
- **动态抑制更合理**：DOSCM 基于 Top-1/Top-2 概率差调整惩罚，保护边界未知而非一刀切删除。
- **验证充分、分析细致**：大量消融与敏感性实验，包括内部模块实验、原型样本数、属性数量、替代 OOD 分数等，并有丰富的定性可视化支持结论。

## 8. 不足与局限

- **依赖数据集特定视觉原型**：当数据极度稀缺、长尾分布、标注噪声或跨域分布偏移时，原型代表性可能下降；论文的 few-shot 实验仅隔离了样本稀少这一种情况。
- **单原型表示有限**：用类别单一质心难以充分建模类内多样性（如视角、遮挡变化），未来可探索多原型策略。
- **高相似类别仍困难**：Game 和 Surgery 中细粒度类别间高度重叠，CODE 的性能仍落后于 PASS，说明视觉校准的增益在极端语义混淆下有限。
- **受预训练模型上限制约**：CODE 是冻结 OWL-ViT 之上的校准层，因此整体性能天花板受制于基础模型的零样本能力。
- **存在过激活副作用**：UGUOE 可能将背景或已知对象误判为未知，CMJCC 也可能对共享结构的目标过度提升已知 logits，导致假阳性。
