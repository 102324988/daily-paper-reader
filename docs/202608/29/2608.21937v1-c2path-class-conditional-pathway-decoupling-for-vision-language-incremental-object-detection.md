## 摘要
增量目标检测（IOD）旨在使检测器能够持续学习新类别，同时保留先前获得的知识。然而，现有方法面临两种形式的\textbf{类知识耦合}：共享参数更新导致的类边界侵蚀，以及混合特征编码引起的类表示纠缠。我们认为，有效的增量学习需要类特定的计算路径，以实现隔离的参数更新和分离的类级注入。为此，我们提出\textbf{C$^2$Path}，一种用于视觉-语言增量目标检测的类条件路径解耦框架，利用令牌级类别线索为不同类别建立专用且可更新的计算路径。具体而言，C$^2$Path引入了类别专家库和类条件解耦模块。专家库由可学习的低秩计算节点组成，用于捕获类别特定知识，而解耦模块生成类感知路由信号，从这些专家中动态组合\textit{ClassLoRA}适配器，从而形成类特定的计算路径，实现跨类别的隔离更新和分离注入。在COCO 2017上多种增量学习设置下的大量实验表明，C$^2$Path始终优于最先进的方法，为视觉-语言检测器中的持续类别扩展提供了一种有效且可扩展的解决方案。

## Abstract
Incremental Object Detection (IOD) aims to enable detectors to continuously learn novel categories while preserving previously acquired knowledge. However, existing methods suffer from two forms of \textbf{class knowledge coupling}: class boundary erosion induced by shared parameter updates and class representation entanglement arising from mixed feature encoding. We argue that effective incremental learning requires class-specific computational pathways that enable isolated parameter updates and separated class-wise injection. To this end, we propose \textbf{C$^2$Path}, a class-conditional pathway decoupling framework for vision-language incremental object detection that leverages token-level class cues to establish dedicated and updatable computational pathways for different categories. Specifically, C$^2$Path introduces a category expert library and a class-conditional decoupling module. The expert library consists of learnable low-rank computational nodes that capture category-specific knowledge, while the decoupling module generates class-aware routing signals to dynamically compose \textit{ClassLoRA} adapters from these experts, thereby forming class-specific computational pathways for isolated updates and separated injection across categories. Extensive experiments on COCO 2017 under multiple incremental learning settings demonstrate that C$^2$Path consistently outperforms state-of-the-art methods, providing an effective and scalable solution for continual category expansion in vision-language detectors.

## 一、核心问题与研究动机

增量目标检测（Incremental Object Detection, IOD）旨在使检测器在持续学习新类别的同时，保留对已学类别的检测能力，避免灾难性遗忘。随着视觉-语言模型（VLM）在检测任务中的普及，该领域逐渐从封闭集检测走向开放、多模态环境下的持续类别扩展。

论文指出现有 IOD 方法普遍存在两类**类知识耦合（Class Knowledge Coupling）**问题：

- **类边界侵蚀（Class Boundary Erosion）**：共享参数更新过程中，新类别的梯度更新会覆盖或干扰已学类别的决策边界，导致旧类性能退化。
- **类表征纠缠（Class Representation Entanglement）**：多类别特征通过同一套编码和融合层混合编码，不同类别的语义在特征空间中相互混杂，降低了类间判别性。

作者认为，解决这两个问题的关键是要为不同类别建立**类特定的隔离计算路径（Class-Specific Computational Pathways）**，实现参数更新的隔离和类级注入的分离。为此提出 C^2Path 框架。

## 二、方法论

### 2.1 总体思想

C^2Path 基于 Grounding DINO 构建，借鉴 mixture-of-experts 的设计理念，利用文本侧 token 的类别语义线索，为每个类别动态生成专属的 **ClassLoRA** 适配器，并将这些适配器注入跨模态融合层的语言侧投影，形成类别条件化的计算路径。

核心组成包括两个模块：**类条件解耦模块（CCDM）** 和 **类别专家库（CEL）**。

### 2.2 类条件解耦模块（CCDM）

CCDM 将每个融合层中文本特征的第 t 个 token 表示 f_t 作为输入：

1. 先做 ℓ2 归一化，去除模长干扰、保留语义方向信息：
   \[ \tilde{f}_t = f_t / (\|f_t\|_2 + \epsilon) \]

2. 经两层门控投影捕捉语义非线性：
   \[ h_t = W_2 \cdot \text{GELU}(W_1 \tilde{f}_t) \in \mathbb{R}^M \]

3. 使用 TopK 稀疏选择生成稀疏路由分布：
   \[ \pi_t = \text{Softmax}(\text{TopK}(h_t, k)) \in \mathbb{R}^M \]

语义相近的 token 会产生相似的路由分布，不同类别则激活不同的专家子集，从而在不引入显式类别参数的情况下实现类别依赖的适应模式。

### 2.3 类别专家库（CEL）

- 专家库由可学习的低秩基张量 \(B_A \in \mathbb{R}^{M \times r \times d_{in}}\) 和 \(B_B \in \mathbb{R}^{M \times d_{out} \times r}\) 参数化，每对前切片构成一个低秩专家。
- 给定路由分布 \(\pi_t\)，token 专属的 ClassLoRA 矩阵通过稀疏加权合成：
  \[ A_t = \sum_{j \in S_t} \pi_{t,j} (B_A)_j, \quad B_t = \sum_{j \in S_t} \pi_{t,j} (B_B)_j \]

### 2.4 注入方式

合成的 ClassLoRA 只注入跨模态双向注意力的**语言侧投影**（key、value、query、output），视觉侧保持不变。原因在于：增量学习主要通过语言表示引入新类别语义，而低层视觉特征（边缘、纹理等）对类别差异不敏感。语言侧调制公式为：
\[ [\Phi^*(F_L)]_t = \gamma \cdot B_t^{*\top} A_t^{*\top} f_t \]

### 2.5 训练目标

\[ \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{cls}} + \mathcal{L}_{\text{reg}} + \mathcal{L}_{\text{distill}} \]

其中 \(\mathcal{L}_{\text{distill}}\) 沿用 GCD 的全局对齐蒸馏（CRD + CTD），包括响应蒸馏和拓扑蒸馏。

## 六、主要结论与发现

1. **主实验性能**：
   - 40+40 设置：C^2Path 达到 46.5 AP，超出 GCD 0.8 AP
   - 70+10 设置：C^2Path 达到 48.7 AP，超出 GCD 2.0 AP，且在 AP\(_{75}\) 和大目标检测上优势更为明显
2. **消融结论**：
   - 仅引入 CEL（均匀聚合专家）即可从 46.7 提升至 48.4 AP，说明低秩专家库提供了额外的适应容量
   - 再加入 CCDM 后提升至 48.7 AP，说明类别条件路由的引入带来进一步增益，且 AP\(_{75}\) 提升更大，表明类判别能力更强
3. **基类保持**：Phase 2 后基类 AP 仅下降 2.8（55.8→53.0），保留了约 95% 的初始性能
4. **特征分析**：t-SNE 和余弦距离矩阵显示，C^2Path 显著缓解了 GCD 中基类表征漂移和语义结构扭曲问题

## 七、优点

- **问题建模精准**：从参数更新和特征编码两个层面系统剖析增量检测中的知识耦合问题，动机清晰
- **类条件设计新颖**：与既有方法（任务级隔离、提示组合等）不同，C^2Path 从单个类别 token 的语义生成适配器，达到更细粒度的"软解耦"
- **参数高效**：共享专家库 + 稀疏 TopK 路由，类别数量增加时参数不线性增长，可扩展性好
- **注入位置合理**：只调制语言侧投影，保留视觉主干稳定性，且聚焦于跨模态融合的关键环节
- **可视化分析扎实**：t-SNE 和余弦距离矩阵从特征层面验证了方法缓解表征耦合的有效性
