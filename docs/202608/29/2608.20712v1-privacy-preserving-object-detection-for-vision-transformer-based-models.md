## 摘要
我们提出了一种新颖的目标检测方法，能够保护测试图像的敏感视觉信息。以往考虑视觉信息保护的研究集中于图像分类任务。本文首次提出使用感知加密的目标检测方法。所提方法利用视觉Transformer（ViT）的嵌入结构和带密钥的域自适应技术，可以达到与无任何保护模型几乎相同的准确率。实验中，在使用基于ViT的目标检测模型ViTdet时，验证了所提方法在准确性和视觉保护方面的有效性。

## Abstract
We propose a novel object detection method that enables us to protect sensitive visual information of test images. Previous studies considering visual information protection focus on image classification tasks. This paper proposes an object detection method using perceptual encryption for the first time. The proposed method can achieve almost the same accuracy as that of models without any protection by utilizing the embedding structure of the Vision Transformer (ViT) and a domain adaptation technique with keys. In experiments, the effectiveness of the proposed method is verified in terms of accuracy and visual protection under the use of ViTdet, which is a ViT-based object detection model.

## 1. 核心问题与研究动机

- **安全痛点**：在云端推理等深度学习应用中，测试图像中的敏感视觉信息（如人脸、车牌、隐私场景）可能被不可信服务器上的模型直接“看见”并泄露。现有针对视觉信息保护的隐私增强研究几乎全部聚焦于**图像分类任务**，而对**目标检测任务**的隐私保护仍是空白。
- **任务差异**：目标检测不仅需要分类，还需输出目标的边界框位置与尺度，对加密扰动更为敏感，不能直接将图像分类的加密方案移植过来。
- **核心贡献**：本文**首次提出适用于目标检测的感知加密（perceptual encryption）隐私保护方法**，利用Vision Transformer（ViT）的嵌入结构特性，使模型能够直接在加密图像上完成检测，同时保证精度几乎无损。

## 2. 方法论

### 2.1 核心思想

利用ViT的**Patch Embedding矩阵**作为天然“密钥载体”：通过一个随机置换矩阵 \(E_{enc}\) 同时加密**测试图像**（分块后用 \(E_{enc}\) 置换像素）和**模型的嵌入层**（用 \(E_{enc}\) 变换embedding矩阵）。由于 \(E_{enc}\) 是正交矩阵，图像加密与模型加密在嵌入层**精确抵消**，模型看到的输入序列与明文输入完全一致。

### 2.2 关键步骤

1. **密钥生成**：模型创建者用密钥 \(k\) 生成随机置换向量 \(l\)，并构造随机置换矩阵 \(E_{enc}∈R^{L×L}\)（\(L = p^2 c\)，\(p\) 为patch尺寸，\(c\) 为通道数）。该矩阵是正交矩阵，满足 \(E_{enc}^{-1} = E_{enc}^T\)。
2. **模型加密**：将原patch embedding矩阵 \(E\) 变换为 \(\hat{E} = E_{enc}E\)，发布加密模型至云端。
3. **图像加密**：将输入图像分块（块大小与ViT的patch大小一致），每块展平为向量 \(b_i\)，加密为 \(\hat{b}_i = b_i E_{enc}^T\)，再重组为加密图像。
4. **云端推理**：客户端上传加密图像至云服务器，服务器用加密模型推理并返回结果。服务器自始至终接触不到明文图像与密钥。

### 2.3 核心数学性质（精确抵消）

- 加密后第 \(i\) 个patch的投影为：\(\hat{x}_p^i \hat{E} = (x_p^i E_{enc}^T)(E_{enc}E) = x_p^i E\)（利用 \(E_{enc}^T E_{enc} = I\)）。
- 因此加密模型的输入序列 \(\hat{z}_0 = z_0\)，与明文模型完全等价，理论上检测精度不受加密影响。
