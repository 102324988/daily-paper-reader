## 摘要
状态空间模型，特别是视觉状态空间对偶（VSSD），已成为Transformer在密集视觉任务中的高效线性时间替代方案。然而，我们观察到VSSD将空间上下文压缩为全局聚合，抑制了高频响应，导致遥感语义分割中边界过度平滑。为解决这一问题，我们提出了CRISP，一个包含两个组件的标定框架。其核心——对偶标定算子（DCO）——通过残差注入和频率标定恢复局部对比度和边界响应，且不改变VSSD骨干网络的线性复杂度。为保留恢复的细节，一个正交多原型（OMP）头部为每个类别分配多个正交约束的原型，以建模较大的类内方差。在Potsdam、Vaihingen和LoveDA上的大量实验表明，在约30M参数下，CRISP在平均F1（mF）和mIoU上均取得了一致的提升，同时与最先进方法保持竞争力。代码可在https://github.com/crazylifeha/CRISP获取。

## Abstract
State space models, especially Visual State Space Duality (VSSD), have emerged as efficient linear-time alternatives to Transformers for dense visual tasks. However, we observe that VSSD compresses spatial context into a global aggregation that suppresses high-frequency responses, causing excessive boundary smoothing in remote sensing semantic segmentation. To address this, we propose CRISP, a calibration framework with two components. Its core, the Duality Calibration Operator (DCO), restores local contrast and boundary responses through residual injection and frequency calibration within the VSSD backbone, without altering its linear complexity. To retain the recovered detail, an Orthogonal Multi-Prototype (OMP) head assigns multiple orthogonally constrained prototypes per class to model large intra-class variance. Extensive experiments on Potsdam, Vaihingen, and LoveDA show that, with approximately 30M parameters, CRISP achieves consistent gains in mean F1 (mF) and mIoU while remaining competitive with state-of-the-art methods. Code is available at https://github.com/crazylifeha/CRISP.

- **VSSD 的引入与问题**：为克服 CNN 局部感受野受限和 Vision Transformer（ViT）自注意力二次方复杂度带来的内存/计算瓶颈，论文基于 Mamba-2 的 State Space Duality（SSD）理论，构建了视觉状态空间对偶（Visual State Space Duality，VSSD）骨干网络。VSSD 通过多方向扫描并融合为全局、位置无关的聚合来获得线性复杂度的视觉特征提取能力。
- **核心问题（观察）** ：论文通过实证研究发现，VSSD 的这种全局聚合等效于一个大窗口的低通平均算子，导致**高频响应被系统性抑制**，具体表现为：
  - 边界和小尺度物体的特征被过度平滑；
  - 不同骨干层的高频能量比（E_high/E_low）逐层衰减；
  - 边界敏感指标（Boundary F-score）下降。
- **解决思路**：提出 CRISP 标定框架，通过两个核心组件——**Duality Calibration Operator（DCO）** 和 **Orthogonal Multi-Prototype（OMP）** 头——在不牺牲 VSSD 线性复杂度的前提下，恢复并保留被衰减的高频细节与类内多模态结构。

## 2. 论文提出的方法论（方法、核心思想、公式与流程）

### 2.1 总体框架
CRISP 包含两个核心部分：

- **DCO（Duality Calibration Operator）** ：插入在每个 VSSD 块的融合操作之后，对全局聚合导致的高频衰减进行标定和恢复；
- **OMP（Orthogonal Multi-Prototype Head）** ：替换传统的单原型分类头（如 UPerHead），用正交约束的多原型匹配来保留类内多模态结构。

### 2.2 VSSD 中的高频抑制机制分析
论文将 VSSD 的多方向融合简化为全局归一化聚合近似：

- ŷ_i ≈ (Σ_{j=1}^{L} w_{i,j} v′_j) / (Σ_{j=1}^{L} w_{i,j})，其中 w_{i,j} = φ(⟨c_i, b_j⟩) ≥ 0 为非负融合权重；
- 每个 value 可分解为慢变项和局部高频扰动：v′_j = v_low_j + ε_j。
- **核心发现**：当融合权重在大感受野上平滑变化时，加权求和会平均掉振荡项 ε_j，造成高频能量衰减；在均匀极限下该聚合退化为全局平均算子，这正是过度平滑的机制根源。
- 由此得出关键结论：一旦聚合已衰减高频方向，仅靠位置相关的后调制无法恢复原始振幅，需要显式的高频补偿支路。

### 2.3 DCO（Duality Calibration Operator）
DCO 包含三个“近恒等”标定步骤，逐级恢复高频细节：

1. **状态级残差注入（Residual Injection）** ：
   - 提取原始 value 与离散化缩放后 value 的差分：Δv_j = v_j − v′_j；
   - 复用 VSSD 已有的 kernel 统计，计算 S_Δ = Σ_j k_j Δv_j^⊤（线性时间）；
   - 通过查询特征读回残差：r_i ≈ q_i^⊤ S_Δ；
   - 以小增益近恒等门控注入：ỹ_i = ŷ_i + (ε + λ_h) ⊙ r_i（λ_h 初始化为 0.01）。
2. **Token 级高通调制（High-pass Modulation）** ：
   - 使用去均值操作强化细粒度响应：y′_i = ỹ_i + ω_h ⊙ (ỹ_i − μ)；
   - 其中 μ 为全局均值，将输出分解为直流分量 Y_dc 和变化分量 Y_hc。
3. **通道级 DC/HC 重平衡（Rebalancing）** ：
   - 通过可学习门控 s、t 重新分配低频语义和高频细节：Y_out = (1+s) ⊙ Y_dc + (1+t) ⊙ Y_hc；
   - 所有门控初始化为 0.01，确保 DCO 起始为恒等映射，不扰动预训练骨干网络的稳定性。

### 2.4 OMP（Orthogonal Multi-Prototype Decoder）
- **动态 Token 生成**：通过双路径全局池化（max + average）提取通道统计量，经共享 MLP 生成内容自适应的查询权重，再与原型嵌入库通过加权 Einsum 生成动态类别 token。
- **超原型匹配（Hyper-prototype Matching）** ：超网络将精炼后的类别 token 映射为每类 K 个子原型 P ∈ R^{B×|C|×K×d_h}；像素描述子 Û 经 L2 归一化后，通过最大响应匹配计算类别置信度：z_{c,i} = max_{1≤k≤K} ⟨Û_i, P̂_{c,k}⟩。每个像素选择最接近的子原型，使不同子原型可特化于不同类内模式。
- **双重原型正则化**：
  - **类内正交约束**：L_orth = (1/(B|C|K(K−1))) Σ_{b,c} Σ_{k≠l} |⟨P̂_{b,c,k}, P̂_{b,c,l}⟩|，防止子原型冗余；
  - **类间角度间隔**：L_margin = (1/B) Σ_b Σ_{c≠c′} ReLU(⟨P̄̂_{b,c}, P̄̂_{b,c′}⟩ − (1−δ))，强制类中心间隔。
  - 总损失为 L_total = L_seg + λ_orth L_orth + λ_margin L_margin。

## 6. 主要结论与发现

1. **高频抑制机制首次量化**：论文通过频域能量比和边界敏感指标，系统性地揭示 VSSD 全局聚合的低通过滤特性，为状态空间模型中的过度平滑提供了机理级解释。
2. **DCO 在不改变线性复杂度前提下有效恢复细节**：DCO 通过复用聚合权重和三个近恒等标定步骤，使 mIoU 从基线 87.32 提升至 88.10（+0.78），且引入的参数量 < 10⁻³M、FLOPs 仅增加 3.19G。
3. **OMP 是 DCO 的必要补充**：仅有 OMP 无 DCO 时性能反而低于基线（85.63 vs 87.32），说明多原型匹配依赖由 DCO 恢复的类内多模态结构；二者协同取得最佳结果 88.25。
4. **精度与效率的平衡**：CRISP 以 32.32M 参数在三个数据集上均达到与 94M 参数 D2LS 相当或接近的精度，同时 FLOPs 远低于 VSSD 基线（64.80G vs 235.65G），实现了优越的精度-效率权衡。
5. **边界质量显著改善**：在 Potsdam、Vaihingen、LoveDA 上，CRISP 的类感知 mBF 相比 VSSD 基线分别提升 +0.0369、+0.0205、+0.0240。

## 7. 优点（方法与实验亮点）

- **保持线性复杂度**：DCO 复用 VSSD 已有的聚合统计量（k_j、q_i），通过 S_Δ 共享累加实现 O(L) 读回，没有引入二次方交互或额外的 FFT/DCT 分支，保持了状态空间模型的硬件友好连续性。
- **近恒等初始化**：所有门控（λ_h、ω_h、s、t）初始化为 0.01，DCO 起始为恒等映射，避免干扰预训练特征，训练稳定。
- **正交多原型设计具创新性**：将类内正交正则与类间角度间隔结合，端到端学习无需离线聚类，避免了传统多中心方法的优化复杂性和耦合问题。
- **频率-原型两级配套**：DCO 恢复高频信号，OMP 保留其多模态结构，形成从骨干到分类头的完整闭环；消融实验清晰展示了这种先后依赖性。
- **多维度评估**：除常规指标外还包含边界带诊断、跨数据集 mBF、资源分解等，增强了对方法效果的深入理解。
- **高效率模型设计**：用轻量 MultiProtoDecoder 替代重 UPerHead，使总 FLOPs 大幅降低，为部署到内存受限的机载平台提供了可能。

## 8. 不足与局限（续）

- **效率指标存在内在张力**：虽然 FLOPs 和参数量大幅下降，但延迟优势不明显，说明算法复杂度降低并未完全转化为实际运行速度提升，在实际部署时需权衡制造成本与运行效率。
- **理论分析仍以实证为主**：虽然论文从加权平均合并角度给出了频率抑制的解释，但尚未提供严格的数学上界（如对可达到的高频响应下界给出理论保证），机理分析偏定性。
- **对预训练骨干的依赖**：CRISP 的稳定性能建立在预训练的 VSSD 骨干之上，方法在从头训练或弱预训练条件下的表现未被检验，适用范围存在一定隐含限制。

## 9. 总体评价

CRISP 是遥感语义分割中针对状态空间对偶模型高频信息衰减问题的一次系统而有效的尝试。论文的核心贡献在于：**其一**，精准诊断出 VSSD 多方向融合的低通过滤机理，并给出可量化的频域证据；**其二**，设计出在不破坏线性复杂度前提下恢复高频细节的 DCO 算子；**其三**，提出正交多原型解码头以保留类内多模态结构，二者形成了“恢复—保持—建模”的完整体系。实验部分覆盖了三个主流数据集、多种方法对比以及多维度消融，统一训练协议增强了结果的公平与可信度。虽然论文在算力披露、边界分析适用范围、多次运行统计等方面有所保留，但整体上仍是一个**机理清晰、设计自洽、实践有效**的高质量工作，对后续状态空间模型在密集预测任务中的应用具有较好的借鉴意义。
