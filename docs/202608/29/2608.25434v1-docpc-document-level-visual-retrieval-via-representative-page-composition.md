## 摘要
视觉文档检索通过使用视觉语言模型编码页面截图而取得了进展，绕过了OCR流程。然而，现有方法仍然以页面为中心，与需要完整文档检索的真实场景不一致。简单的“先页面后文档”聚合方法面临线性索引成本，并且当相关性跨越多个页面时检索性能会下降。我们提出了DocPC，一种基于代表性页面组合的文档级视觉检索框架：选择代表性页面并将它们组合成单个网格图像进行文档级索引，将索引图像、向量和存储减少了10.1倍，端到端索引时间缩短了约7.7倍。为了处理文档级别普遍存在的多正样本监督，我们将多正样本对比学习与稀疏调度的列表式优化相结合。我们还引入了DocViRe，一个具有多正样本相关性标注的基准。DocPC-ColQwen在DocViRe上达到了44.09的NDCG@5，优于最强的页面级基线38.91，同时存储减少了10.1倍。代码可在https://anonymous.4open.science/r/DocPC-Document-Level-Visual-Retrieval-via-Representative-Page-Composition-1D52获取。数据可在https://huggingface.co/datasets/anonymous-7219/docpc获取。

## Abstract
Visual document retrieval has advanced by encoding page screenshots with vision-language models, bypassing OCR pipelines. However, existing methods remain page-centric, misaligned with real-world scenarios requiring complete document retrieval. A naive page-then-document aggregation suffers from linear indexing cost and degraded retrieval when relevance spans multiple pages. We propose DocPC, a document-level visual retrieval framework based on Representative Page Composition: selecting representative pages and composing them into a single grid image for document-level indexing, reducing indexed images, vectors, and storage by 10.1x and end-to-end indexing time by roughly 7.7x. To handle multi-positive supervision prevalent at the document level, we combine multi-positive contrastive learning with sparsely scheduled listwise optimization. We also introduce DocViRe, a benchmark with multi-positive relevance annotations. DocPC-ColQwen achieves NDCG@5 of 44.09 on DocViRe, outperforming the strongest page-level baseline at 38.91 while reducing storage by 10.1x. Code is available at https://anonymous.4open.science/r/DocPC-Document-Level-Visual-Retrieval-via-Representative-Page-Composition-1D52. Data is available at https://huggingface.co/datasets/anonymous-7219/docpc.

## 论文详细中文总结

### 1. 核心问题与整体含义

- **研究动机**：现有的视觉文档检索方法（如 ColPali、ColQwen）以页面为中心，即对单页截图进行编码和检索。然而真实应用场景（企业搜索、学术检索、法律审查）需要整篇文档级别的检索，现有方法与这一需求不匹配。
- **现有方案的缺陷**：朴素的"先页面后文档"聚合方法（如 MaxP）面临双重挑战：
  - **索引成本高**：索引规模随总页数线性增长；
  - **跨页相关性丢失**：当相关性分散在多个页面时，单页打分无法捕获全局语义。
- **核心问题**：跨文档的文档级视觉检索尚未被充分探索，缺乏专门的基准和系统性研究。

### 2. 方法论

#### 核心思想：Representative Page Composition（代表性页面组合）

将每篇文档压缩为**单个固定大小的网格图像**（默认 2×2），把文档级索引从 O(N) 降为 O(1)。

#### 关键技术细节

**页面选择策略**（选择 K 页构成网格）：
- **First-K**：取前 K 页（默认配置，实验发现前两页平均相关度排名最优）；
- **Boundary**：取前 K/2 页 + 后 K/2 页；
- **Uniform-K**：在文档中均匀采样 K 页；
- **Random-K**：随机采样 K 页；
- **Base-Clip**：用 CLIP 嵌入对候选页面聚类，动态选取代表性页面。

**索引与检索流程**：
1. 每篇文档将选中的页面拼接成网格图像（页面由 VLM 预处理管线缩放到统一分辨率）；
2. 用视觉语言模型（ColQwen）对网格进行一次前向传播，得到固定大小的多向量表示；
3. 查询时编码查询，通过晚期交互（MaxSim）计算相似度并排序。

#### 训练目标：结合两种损失

1. **Multi-Positive InfoNCE**（多正例对比损失）：
   - 公式：L = −log(SP / (SP + SN))，其中 SP = Σ exp(sim(q, d⁺)/τ)，SN = Σ exp(sim(q, d⁻)/τ)；
   - 解决文档级检索中一个查询对应多个相关文档的问题，避免将其他正例误当作负例。

2. **Top-K Listwise Loss**（基于 ApproxNDCG 的列表式损失）：
   - 公式：L = 1 − ApproxNDCG(y, r, K)；
   - 直接优化排名前 K 的排序质量。

3. **组合目标**：L = L_MP-InfoNCE + λ·L_top-k；
   - 多正例损失每步都应用，列表式损失**稀疏调度**（每 m=40 步应用一次），避免过早的排序优化干扰表示学习。

### 3. 实验设计

#### 数据集与基准：DocViRe

- 基于公开 PDFA 数据集构建，覆盖 **7 个领域**：生物学、教育、金融、政府、工业、法律、研究；
- **训练集**：10,884 个查询，4,438 篇文档（文档与测试集不相交）；
- **测试集**：2,237 个查询，3,850 篇文档；
- **多正例标注**：通过四步流水线构建——关键词提取（OCR + LLM）→ 文档分组（聚类）→ 查询生成（LLM）→ 质量验证（LLM 过滤 + 三人人工全量审查），标注一致性高（相关性三-way 一致率 92.5%，查询有效性一致率 99.0%）。

#### 对比方法

- **文本基线**：BM25、BGE-M3 及其 LLM 摘要变体；
- **页面级视觉基线**：零样本 ColQwen-page（All pages / Boundary）、DocViRe 微调的 ColQwen-page（All pages / Boundary，MaxP 聚合）、Jina-CLIP、Nomic-Embed；
- **文档级方法**：ColQwen (DocViRe-sft, First-4) 以及本文的 DocPC-ColQwen (First-4)。

#### 评估指标

- 主要指标：NDCG@5；
- 辅助指标：Recall@K，按文档而非页面计算。

### 6. 主要结论与发现

- **DocPC-ColQwen (First-4) 在 DocViRe 上 NDCG@5 达到 44.09**，显著优于最强页面级基线（ColQwen-page DocViRe-sft Boundary，38.91）；
- **索引效率大幅提升**：索引图像、向量、存储减少约 10.1×，端到端索引时间减少约 7.7×；
- **网格组合优于独立页面聚合**：相同 4 页预算下，网格比 MaxP 高 +6.41 NDCG@5，且在所有 7 个领域中均为正增益，工业领域增益最大（+21.08）；
- **4 页预算为最优折中**：更多页面（16 页）反而因分辨率下降而表现变差；
- **稀疏调度的列表式损失至关重要**：频率太密（m=1）干扰表示学习，太疏（m=50）排序优化不足，m=40 最优；
- **查询与文档关键词的词汇重叠度低**（平均 Jaccard 相似度仅 0.07），生成的查询具有自然多样性，非简单的关键词重组。

### 7. 优点

- **问题定位准确**：识别出页面级检索与真实文档级需求之间的鸿沟，提出明确的任务形式化定义；
- **方法简洁高效**：代表性页面组合无需额外模型复杂度，用 O(1) 索引替代 O(N) 索引；
- **多正例训练目标契合文档级检索特性**：MP-InfoNCE 解决假阴性问题，稀疏列表式损失在稳定表示后精细调优排序；
- **基准构建严谨**：DocViRe 经过 LLM 过滤 + 三人全量人工审查，标注质量高；训练/测试文档池不重叠，保证评测可靠性；
- **实验分析全面**：涵盖效率、消融、分辨率、池大小、策略泛化、定性分析等多个维度，分析细致。

### 8. 不足与局限

- **分辨率受限**：网格组合降低每页分辨率，小字号文本、密集表格等细节可能丢失（9.7% 的查询仅页面级成功即因此），需配合页面级重排序的混合方案；

- **语言和领域覆盖有限**：仅覆盖 7 个英文领域，多语言和跨类型文档未涵盖；
- **未覆盖下游任务**：基准未纳入 RAG 等下游应用场景；
