## 摘要
单目3D物体检测涵盖两种范式：在固定类别词汇表内运行的闭集检测器，以及通过利用深度基础模型获取3D几何信息来定位任意类别的开放词汇检测器。我们发现，当前的深度基础模型尽管具有强大的零样本泛化能力，却缺乏3D检测所需的物体级精度：用最先进的深度基础模型替代强检测器预测的深度会降低精度，甚至低于检测器自身的预测。我们不推动检测器或深度模型实现端到端的更高精度，而是将物体级深度精化视为独立任务，提出RefineAny3D，一种无需预测数值即可校正深度的视觉-语言模型。我们的关键洞察在于，深度误差在图像空间中具有直接的视觉特征：投影到图像上时，正确放置的框紧密包围物体，而过远的框投影过小，过近的框投影过大。因此，深度精化被简化为视觉对齐问题而非度量回归问题。我们通过扩展VLM的词汇表，用动作令牌替代数值深度输出以进行类别决策，并在大规模思维链数据集上监督模型，使每个决策都基于明确的视觉证据。作为单一的后处理步骤应用，RefineAny3D在闭集检测器、开放词汇检测器和3D自动标注工具上均带来一致的性能提升，并能在无需重新训练的情况下泛化到新类别、场景和相机。

## Abstract
Monocular 3D object detection spans two regimes: closed-set detectors operating within a fixed category vocabulary, and open-vocabulary detectors that localize arbitrary categories by leveraging depth foundation models for 3D geometry. We find that current depth foundation models, despite their strong zero-shot generalization, lack the object-level precision 3D detection demands: substituting a state-of-the-art depth foundation model for a strong detector's predicted depth degrades accuracy, even falling below the detector's own prediction. Rather than pushing detectors or depth models to be more accurate end-to-end, we treat object-level depth refinement as a stand-alone task and present RefineAny3D, a vision-language model that corrects depth without ever predicting a numerical value. Our key insight is that depth error has a direct visual signature in image space: when projected onto the image, a correctly placed box tightly encloses the object, while a too-far box projects too small and a too-close box projects too large. Depth refinement thus reduces to a visual alignment problem rather than a metric regression problem, which we instantiate by extending the VLM's vocabulary with action tokens that replace numerical depth output with categorical decisions, and by supervising the model on a large-scale chain-of-thought dataset that grounds each decision in explicit visual evidence. Applied as a single post-hoc step, RefineAny3D delivers consistent gains across closed-set detectors, open-vocabulary detectors, and 3D auto-labeling tools, and generalizes to novel categories, scenes, and cameras without retraining.

  - 深度基础模型虽然零样本泛化能力强，但缺乏3D检测所要求的**对象级度量精度**。
- **研究背景**：单目3D检测分为闭集检测器（固定类别词汇表）和开放词汇检测器（依赖深度基础模型获取3D几何）两大流派。开放词汇方法在跨域泛化方面受益于深度基础模型，但后者的对象级深度偏差会被所有下游管线继承，包括3D自动标注工具。
- **核心立场转变**：与其推动端到端检测器或深度模型更精确，不如**将对象级深度精化作为独立任务**进行后处理增强。由此提出RefineAny3D——一个无需预测数值深度即可校正深度的视觉-语言模型（VLM）。

### 2. 论文提出的方法论

#### 2.1 核心思想：深度精化作为语义对齐

- 关键洞察：**深度误差在图像空间中具有直接的视觉特征**。当候选3D框投影到图像平面时：
  - 正确放置的框能**紧密包围**目标物体；
  - 过远的框投影**过小**；
  - 过近的框投影**过大。

  因此深度精化被重构为**2D语义对齐问题**，而非度量回归问题。相机内参和度量尺度被投影本身吸收，模型只需从2D视觉证据判断对齐程度。

#### 2.2 动作令牌（Action Tokens）

为规避VLM在数值回归上的固有弱点，RefineAny3D扩展VLM词汇表，引入**6个专用动作令牌**：

| 类别 | 令牌 | 含义 |
|------|------|------|
| 方向令牌 | `<depth_closer>` | 框需移近相机（深度减小） |
| 方向令牌 | `<depth_farther>` | 框需移远相机（深度增大） |
| 方向令牌 | `<depth_ok>` | 无需校正 |
| 幅度令牌 | `<step_small>` | 移动 0.20×s_obj |
| 幅度令牌 | `<step_medium>` | 移动 0.55×s_obj |
| 幅度令牌 | `<step_large>` | 移动 1.10×s_obj |

- **方向令牌**映射为标量符号：closer=-1，ok=0，farther=+1；
- **幅度令牌**与物体自身尺度相关（s_obj = (w+h+l)/3），使同一动作在不同大小物体上保持语义一致；
- 深度更新为：Δd = dir(a_d) · mag(a_m, s_obj)。

#### 2.3 模型流程

- **推理循环**（Reason → Act → Refine）：
  1. 将当前3D框投影渲染为线框叠加到图像上；
  2. VLM 首先生成思维链推理（Identify → Recall → Evidence → Decision），随后输出动作令牌；
  3. 根据动作令牌计算深度更新并应用于3D框；
  4. 迭代直到模型输出`<depth_ok>`或达到步数上限T_max=2。
- **训练策略**：两阶段训练，均使用单步监督——
  - Stage 1（约1小时）：冻结所有transformer层，仅训练6个新令牌嵌入（语义初始化：用描述性短语的子词嵌入均值初始化）；
  - Stage 2（约90小时）：联合微调LLM骨干和动作令牌嵌入，**冻结视觉编码器**，保留预训练的广泛视觉先验以支持跨域泛化。

#### 2.4 数据构建（约300万训练样本）

- **来源**：基于Omni3D统一基准，涵盖6个子数据集（KITTI、nuScenes、Objectron、SUN RGB-D、ARKitScenes、Hypersim），原始约330万标注；
- **过滤**：几何过滤+VLM语义过滤（验证物体可见性、标签正确性、遮挡程度、图像质量），保留约33.5万标注；
- **扰动**：每标注生成9个样本，沿深度轴按物体相对尺度扰动，覆盖所有方向-幅度组合，并过采样`<depth_ok>`（占33.3%）以产生保守终止偏置；
- **思维链**：双模型管线生成——VLM负责目标识别描述，文本LLM负责组合世界知识、视觉证据和纠正决策；包含四种步骤：Identify（识别）、Recall（回忆物体典型尺寸）、Evidence（描述视觉错位证据）、Decision（作出纠正决策）。

### 6. 论文的主要结论与发现

- **深度是单目3D检测的首要瓶颈**：相比尺寸和朝向，深度对3D IoU精度影响最大（Oracle深度提升+29.92 AP）；
- **深度基础模型的对象级精度不足**：直接替换检测器深度反而降精度（-3.68 AP），说明其不适合直接作为对象级深度来源；
- **深度精化可以完全是语义对齐问题**：通过VLM判断投影框与目标物体的视觉对齐关系，用离散动作令牌迭代修正，无需数值回归即可恢复细粒度精度；
- **作为即插即用模块，RefineAny3D一致提升各类管线**：闭集检测器（+3.49 Moderate）、开放词汇检测器（+4.35）、自动标注工具（+2.37 Moderate），且无需重训练即可泛化到新类别、场景和相机；
- **通用视觉能力保持**：在CV-Bench上仅损失1.41分，证明冻结视觉编码器策略有效。

- **问题定义新颖且实用**：将深度精化形式化为独立任务，与上游检测器正交，即插即用；
- **视角转换巧妙**：将难以直接回归的度量深度问题转换为VLM擅长的视觉语义对齐问题，通过迭代链式分类决策恢复细粒度精度；
- **规避VLM数值回归弱点**：动作令牌的设计（方向×幅度因式化）不仅是干净的抽象，还提供了更密集的监督信号；
- **数据构建系统完整**：四阶段管线（选择→过滤→扰动→CoT），考虑了几何和语义两重过滤，扰动调度覆盖全部动作类别且平衡，CoT强制模型基于视觉证据推理；
- **训练-推理不对称的设计一致性论证充分**：单步监督映射的是“当前视觉状态→局部正确动作”的条件分布，自然泛化到多步推理；
- **对比实验扎实**：不仅对比强基线，还验证了较简单替代方案（几何拟合、判别分类器）失败的原因，强化了VLM+动作令牌组合的必要性论证；
- **对失败模式的深入分析**：附录A对几何拟合偏差的数学推导（式7）、判别分类器的分布偏移解释都非常清晰。

### 8. 不足与局限

- **依赖初始3D框质量**：方法假设上游检测器提供合理的初始3D框；若初始框的尺寸、朝向错误严重，纯深度修正的收益有限；
- **对遮挡/截断物体的可靠性不足**：论文自己在局限性部分承认，当视觉对齐信号因遮挡或截断而减弱时，精化可靠性下降，尤其在严格3D IoU阈值下；
- **推理开销较高**：单图像约2.8秒的额外延迟（约5.4个物体时），虽可接受于离线场景，但不适合实时应用；
- **误差线缺失**：由于训练成本高（每配置约90小时），未报告多次运行的方差统计；
- **开放词汇场景的增益受限**：在真实2D框条件下（+2.04）显著低于Oracle 2D框（+4.35），说明上游2D定位噪声会限制深度精化的头部空间；
- **数据构建的依赖**：依赖Omni3D的统一基准，数据过滤中使用了VLM语义检查，可能引入特定模型的偏差；CoT由双模型管线生成，其质量受生成模型限制；
- **迭代步数上限固定**：T_max=2限制了需要更多步精化的困难案例，附录F显示3步及以上性能略降，但更难的案例可能需要更精细的策略；
- **发布限制**：代码和数据在提交时未发布，影响可复现性验证；
- **未来的改进方向**：论文指出可结合场景上下文或时序一致性作为补充线索。
