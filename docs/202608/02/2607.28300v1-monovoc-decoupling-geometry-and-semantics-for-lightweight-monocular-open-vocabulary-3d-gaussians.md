## 摘要
开放词汇的3D场景理解对于下一代交互系统至关重要，它使用户能够使用自然语言直观地查询和导航重建的环境。然而，当前的3D高斯框架常常受到多视图采集要求的限制、场景特定优化的高成本以及存储密集语言特征所需的巨大内存开销的制约。我们提出了一种新颖的、无需训练的流程，通过明确地将3D几何重建与语义集成解耦，从根本上重新构想这一范式。以标准单目视频序列作为输入，我们的方法高效地输出一个紧凑、高度可解释且完全可搜索的对象级语义高斯地图。我们不在建图循环中纠缠于重型语言嵌入，而是独立提取几何，并通过轻量级模块化后处理框架来锚定语义。在Replica数据集上的广泛评估表明，这种解耦架构保持了强大的渲染保真度和有竞争力的分割精度。关键在于，通过将密集的逐高斯存储替换为模块化的对象级语义嵌入，我们的方法与最先进的基线相比，内存使用量减少了一个数量级。这为直接基于日常单目视频的开放词汇3D检索和问答提供了一种高效、可扩展且实用的解决方案。

## Abstract
Open vocabulary 3D scene understanding is essential for next-generation interactive systems, empowering users to intuitively query and navigate reconstructed environments using natural language. However, current 3D Gaussian frameworks are often bottlenecked by restrictive multiview capture requirements, costly scene-specific optimization, and the massive memory overhead of storing dense language features. We present a novel, training-free pipeline that fundamentally reimagines this paradigm by explicitly decoupling 3D geometric reconstruction from semantic integration. Given a standard monocular video sequence as input, our method efficiently outputs a compact, highly interpretable, and fully searchable object-level semantic Gaussian map. Rather than entangling heavy language embeddings within the mapping loop, we extract geometry independently and ground semantics through a lightweight, modular post-processing framework. Extensive evaluations on the Replica dataset demonstrate that this decoupled architecture preserves strong rendering fidelity and competitive segmentation accuracy. Crucially, by replacing dense per-Gaussian storage with modular, object-level semantic embeddings, our approach delivers an order-of-magnitude reduction in memory usage compared to SOTA baselines. This provides a highly efficient, scalable, and practical solution for open-vocabulary 3D retrieval and question answering directly from everyday monocular video.

## 1. 核心问题与研究动机

**研究背景：**
- 开放词汇（open-vocabulary）3D 场景理解对下一代交互系统（如 AR、机器人导航、工业巡检）至关重要，用户需要用自然语言（如"红色工具箱"、"桌子后面的椅子"）查询和导航重建环境，而非依赖固定类别集。
- 3D 高斯泼溅（3DGS）因其高效渲染而成为热门场景表示，已有工作（如 SceneSplat、OpenGaussian、ObjectGS、LangSplatV2 等）尝试将语言特征附加到高斯场景中实现语义搜索。

**核心痛点（三个瓶颈）：**
1. **采集约束强**：多数现有框架依赖多视角、良好标定的采集设置，难以应用于日常单目视频。
2. **优化成本高**：语义往往与重建耦合，需要进行场景特定的语义特征学习或优化。
3. **内存开销大**：稠密地在每个高斯上存储语言特征，导致地图体积巨大、难以编辑和解释。

**核心问题：** 是否存在一种轻量级单目 3DGS 框架，能够生成既可渲染、又可搜索/分割/查询的对象级语义地图，且不需要密集的逐高斯语言特征存储？本文给出肯定回答，提出 **MonoVoc**——一个将几何重建与语义集成完全解耦的训练无关（training-free）流程。

## 2. 方法论

### 2.1 核心思想
**"先重建几何，后添加语义"**——打破语义与重建耦合的范式，采用四阶段模块化流水线：

1. **几何重建**：使用 HI-SLAM2 从单目 RGB 视频重建几何感知的 3D 高斯地图（固定几何，不参与语义优化）。
2. **语义颜色解混（SCD）**：利用 alpha 合成逆过程，为每个高斯恢复语义颜色证据。
3. **调色板量化**：将解混后的颜色映射到离散的语义调色板，获得对象级身份。
4. **语言嵌入分配**：为每个对象（而非每个高斯）提取一个紧凑的语言嵌入。

### 2.2 关键技术细节

**前向渲染方程（第 3.2 节）：**
- 每个像素的颜色是高斯语义颜色的加权混合：`C(p) = Σᵢ wᵢ(p)sᵢ + T_N(p)b`
- 高斯像素级不透明度：`αᵢ(p) = min(0.99, oᵢ·exp(...))`
- 累积极透射率：`Tᵢ(p) = Π_{j<i}(1−αⱼ(p))`，权重 `wᵢ(p) = αᵢ(p)Tᵢ(p)`
- **关键性质（定理 1）**：权重满足 `Σwᵢ + T_{N+1} = 1`，即渲染是语义颜色的精确凸组合。

**SCD 算法（第 3.3 节）：**
- 对背景项进行减法后，逆向问题变为线性：`yₚ = Σᵢ wᵢ,ₚ sᵢ`
- 对每个高斯使用加权最小二乘求解，得到闭式解：
  `ŝᵢ = Σₚ wᵢ,ₚ yₚ / Σₚ wᵢ,ₚ`
- **理论保证**：非重叠情况下可精确恢复（定理 3）；重叠情况下存在可解析的混合偏差（定理 4）：`ŝᵢ = (Gᵢᵢ/Wᵢ)sᵢ + Σ_{j≠i}(Gᵢⱼ/Wᵢ)sⱼ`，其中 `Gᵢⱼ = Σₚ wᵢ,ₚwⱼ,ₚ` 度量高斯间的重叠程度。

**调色板量化：**
- 在 CIELAB 空间中使用 **CMC 距离**（`l=2.0, c=1.0`）将解混颜色吸附到最近的有效语义颜色：
  `s_qᵢ = argmin_{c∈P} d_CMC(Lab(ŝᵢ), Lab(c))`
- 对比了 CAM16、CIE94、CIEDE2000、CMC、DIN99o、RGB 欧氏距离共 6 种度量，CMC 最优。

**语言嵌入：**
- 每个语义颜色选择代表性关键帧（按该颜色在分割帧中的出现频率），对掩码区域提取嵌入。
- 嵌入后端模块化：支持 CLIP、Perception Encoder、Osprey 等，支持硬掩码（仅对象）和软掩码（保留少量上下文）。

- **Replica 数据集**（合成室内场景），使用单目 RGB 序列作为输入，对应语义分割作为 2D 监督。
- 使用 HI-SLAM2 的固定 Replica 配置进行重建，无额外训练/优化/数据集划分。

**对比方法：**
- **ObjectGS**：对象感知的单目高斯重建（与重建/优化耦合）
- **SceneSplat**：基于视觉-语言预训练的可泛化 3D 特征（训练成本高，不直接生成 3D 地图）

## 6. 主要结论与发现

1. **几何与语义无需联合学习**：用固定的 HI-SLAM2 几何骨干，后处理添加语义即可达到强渲染质量和有竞争力的分割精度，验证了解耦范式的可行性。
2. **对象级语义嵌入优于逐高斯稠密特征**：每个对象一个嵌入即可支持高效检索，无需在数万个高斯上各存一个语言特征，内存降低约一个数量级（14 MB vs 90–149 MB）。
3. **CMC 距离在 CIELAB 空间是最优量化度量**：比其他 5 种颜色距离度量产生更少的语义分配误差（非白像素误差 7.48%）。
4. **软掩码优于硬掩码**：保留少量上下文有助于对象识别（Perception Encoder 软掩码 Top-1 达 80%）。
5. **方法的模块化与可扩展性**：分割器、语言嵌入模型均可替换，不绑定特定实现。

## 7. 优点

- **范式创新**：首次提出训练无关、SLAM 驱动的单目 3DGS 开放词汇理解流水线，将语义完全后置，概念简洁且实用性强。
- **理论扎实**：为 SCD 提供了严格的数学推导（4 个定理 + 附录完整证明），包括精确恢复条件和重叠偏差的解析形式，具较高学术严谨性。
- **内存效率突出**：对象级共享嵌入替代逐高斯特征，地图从 ~100 MB 降至 14 MB，具有实际部署价值。
- **可解释性**：生成的语义地图是"可读的"对象级表示，每个高斯直接对应一个离散对象身份，而非模糊的高维语义特征。
- **模块化设计**：语义来源（任意分割器）、嵌入模型（CLIP/DINO/Perception Encoder/Osprey）、量化度量均可灵活替换。

## 8. 不足与局限

- **量化歧义**：当调色板中对象颜色过于接近时，最近颜色决策可能出错，尽管使用 CMC 距离缓解但仍存在本质歧义。
- **SCD 为近似求解**：采用逐高斯加权平均而非全局逆问题求解，在对象边界或高度重叠区域可能产生语义颜色偏差；量化操作只能部分纠正。
- **依赖 2D 分割质量**：分割噪声（尤其边界噪声）会被多帧累集放大并传播到 3D 地图中（附录 C 实验证实），实际应用中分割模型的质量是关键前置条件。
- **实验覆盖有限**：仅 Replica 合成室内场景、15 个文本查询、2 个对比方法，缺乏真实世界数据验证和更广泛的基准对比。
- **潜在偏差风险**：单次运行实验、自选 A100 GPU，未报告多次运行的平均/方差；语言检索的 Top-1 精度 80% 尚未达到可完全信赖的交互系统水平。
- **应用限制**：依赖颜色作为对象标识符，天然受限于颜色可分性；对遮挡、稀疏视角、动态场景的鲁棒性尚未验证。隐私方面，对敏感室内空间的非同意建图可能引发隐私担忧（作者在附录 D 中已指出）。
