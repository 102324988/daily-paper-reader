## 摘要
检测Transformer模型，包括DETR及其扩展，学习输出一组对象级嵌入，可以同时解码为2D边界框和类别分布。在本文中，我们研究了预训练的2D检测Transformer对物体3D属性的理解程度。具体来说，我们使用线性和非线性探针调查了从对象级嵌入中恢复物体相对于相机的深度和3D位置等属性的程度。在一系列检测Transformer模型中，我们的结果显示出2D DETR模型在表示物体3D属性的有用信息方面具有惊人的、先前未知的能力，尽管在模型预训练期间完全缺乏3D监督。

## Abstract
Detection transformer models, including DETR and its extensions, learn to output a set of object-level embeddings that can be simultaneously decoded into 2D bounding boxes and class distributions. In this paper, we investigate what pre-trained 2D detection transformers understand about the 3D properties of objects. Specifically, we investigate the extent to which properties including the depth of objects from the camera and the 3D location of objects relative to the camera can be recovered from object-level embeddings using linear and non-linear probes. Across a range of detection transformer models, our results show a surprisingly strong and previously unknown ability of 2D DETR models to represent useful information about the 3D properties of objects, despite the complete lack of 3D supervision during model pre-training.

- **核心研究问题**：预训练的 2D 检测 Transformer（DETR 及其变体）虽然在训练过程中完全未使用任何 3D 标注（仅使用 2D 边界框和类别标签），但其对象级嵌入（object-level embeddings）中是否隐含编码了物体的 3D 属性信息？

- **研究动机**：
  - DETR 家族模型在 2D 检测任务上取得了巨大成功，其架构输出的查询嵌入（query embeddings）是后续各类任务（如分割、姿态估计、3D 检测）共享的基础表示，但此前无人系统考察过该嵌入的 3D 信息蕴含程度。

- **整体含义**：该研究发现 2D DETR 模型在无 3D 监督的情况下，其对象嵌入中蕴含了出人意料的丰富 3D 几何信息，这暗示了 DETR 家族模型有潜力作为通用的 3D 感知预训练模型，为后续 3D 任务提供初始化基础。

### 二、论文提出的方法论

#### 核心思想
采用**探针（probing）**范式：冻结预训练检测器的所有权重，仅训练一个简单的探针模型（线性层或两层 MLP），从检测器的对象嵌入中回归目标 3D 属性。如果探针能在测试集上以较低误差完成任务，则说明嵌入中确实编码了可提取的 3D 信息。

#### 关键技术细节

**1. 对象嵌入的获取**
- 对每一张输入图像，运行预训练的 2D DETR 模型，得到 N 个查询嵌入 \( q_i \in \mathbb{R}^D \)（D=256，LW-DETR 为 384）。
- 设置物体性阈值 τ=0.5，保留类别概率超过阈值的嵌入作为有效对象候选。

**2. 探针模型设计**
- **线性探针**：单个仿射映射 \( f_\theta: \mathbb{R}^D \to \mathcal{P} \)，即一层线性层。
- **非线性探针**：两层 MLP，ReLU 激活，隐藏维度 256。
- 训练配置：batch size 512、学习率 1e-3、Adam 优化器、MSE 损失；MLP 深度实验训练 1000 epochs（20 epochs 预热 + 余弦衰减）。

**3. 探测数据集构建（关键流程）**
- **深度估计任务**：在虚拟 KITTI 2 和 NYUv2 数据集中，将检测框中心点的真值深度值作为监督信号，形成训练对 \((q_i, d_i)\)。
- **3D 位置预测任务**：在 KITTI 数据集中，将检测框与真值 2D 框按 IoU≥0.5 进行贪心匹配，取匹配真值对象的 3D 框中心（相机坐标系下的 \(x, y, z\)）作为监督信号。
- **数据集对齐（Dataset Alignment）**：以 DETR 为锚点模型，在 IoU≥0.5 条件下进行贪心匹配，仅保留所有模型都检测到的对象交集，以控制不同检测器检测集合差异带来的偏差，保证模型间可比性。

### 六、论文的主要结论与发现

1. **DETR 家族嵌入蕴含强 3D 信息**：在完全无 3D 监督的预训练下，DETR 家族的对象嵌入中可解码出高精度的物体深度和 3D 位置信息。
2. **非线性探针显著优于线性探针**：MLP 探针在深度估计上远胜线性探针（如 Virtual KITTI 2 上 MAE 从 1.01 降至 0.54），表明嵌入中 3D 信息的编码方式是非线性的。
3. **超越零样本 3D 基础模型**：DETR+MLP 探针在深度估计上优于零样本 Depth Anything 2 和零样本 MonoDETR（如 Virtual KITTI 2 MAE：DETR 0.54 vs DA2 1.49 vs MonoDETR 3.83）；即使与微调后的 Depth Anything 2（0.50）和 MonoDETR（0.47）相比仍处于同一量级。
4. **逼近专用 3D 模型的定位精度**：在 KITTI 3D 位置预测中，DETR+MLP 探针的整体 MAE（0.50m）与 MonoDETR（0.30m）仅差 0.2m；在测试集中位距离 25.3m 的设定下，AbsRel 差距仅约 1%。
5. **实时/轻量变体的 3D 信息表征能力较弱**：RT-DETR v2 和 LW-DETR 在深度和 3D 位置两个任务上均明显落后于 DETR、Deformable DETR、Conditional DETR，推测与减少层数/容量以满足延迟约束有关。
6. **深度信息集中在低维子空间**：PCA 压缩实验显示，嵌入维度压缩到约 60-100 维时性能即趋于饱和，实时变体需要更多维度才能达到同等性能。
7. **嵌入信息远超 2D 框表征**：同一 DETR 模型，嵌入探针的深度估计误差远低于仅基于 2D 框坐标的探针（Virtual KITTI 2 MLP：MAE 0.54 vs 1.02），说明嵌入中含有框坐标之外的丰富语义/上下文深度线索。

### 七、优点

- **研究对象新颖**：首次系统性地探测 DETR 家族检测器的对象级查询嵌入，填补了以往仅探测 CNN 检测器特征或骨干网络特征的空白。
- **方法设计严谨**：数据集对齐策略有效控制了不同检测器检测集合差异的干扰；锚点模型+贪心匹配的方案提高了多模型对比的公平性。

- **结论具有实用启示**：发现实时/轻量变体 3D 表征能力偏弱，对 DETR 架构设计有直接指导意义；揭示 DETR 可作为 3D 预训练模型的潜力。
- **代码开源**：提供了可复现的实验配置和代码仓库。

### 八、不足与局限

- **3D 位置实验覆盖范围偏窄**：仅在 KITTI 单数据集上进行，未在室内场景或其他室外数据集（如 nuScenes）上验证，泛化性结论有限。
- **深度估计算法公平性的潜在争议**：DETR 探针是有监督训练（在目标任务上有标签），而 Depth Anything 2 和 MonoDETR 的零样本评估是直接迁移，公平性会被质疑；微调 MLP 头虽弥补了一部分，但 DETR 探针本质上也是在目标任务上训练的，这种不对称使得“超越 Zero-shot DA2”的宣称需要更谨慎解读。
- **未报告统计不确定性**：文中没有多次运行实验的均值/方差，也没有显著性检验，无法确认模型间差异是否统计显著。
- **计算资源未交代**：未说明训练所用 GPU 等硬件信息，影响复现便利性和效率评估。
- **结果解释较为推测性**：对实时变体表现弱的原因（层数少、容量小）仅做了推测性说明，未通过严格的对照实验（如控制其他变量）加以验证。
- **仅考察两类 3D 属性**：未探测朝向（yaw/pitch/roll）、3D 尺寸（长宽高）、速度等其他 3D 属性；深度目标仅取框中心单点，未考虑对象内部深度分布。
- **类别分布不均衡**：Virtual KITTI 2 仅保留 car 类，NYUv2 各类别样本量差异可能影响类别-wise 分析结论的稳健性。
