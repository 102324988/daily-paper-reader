## 摘要
无需训练的开词汇语义分割（OVSS）根据任意文本描述将图像划分为语义上不同的区域，且不学习任何额外参数。然而，现有方法通常侧重于改善视觉表示，而将仅编码通用类别概念的文本嵌入视为固定的分类参考。这些通用概念与捕获目标实例特定外观的视觉表示之间产生的语义差距，往往导致不完整的掩码和非目标区域的错误预测。受感知锚定中符号-感知对应关系的启发，我们提出了用于无需训练OVSS的原型引导文本校准（PTC）。在感知阶段，PTC根据初始匹配分数选择可靠的视觉证据，以构建类别特定的视觉原型。在锚定阶段，PTC使用这些原型来校准其对应的文本嵌入，校准强度根据视觉证据的数量自适应调整。因此，校准后的文本嵌入能更准确地与实例特定的视觉表示对齐，同时保留通用类别语义和开词汇泛化能力。此外，PTC既不需要额外训练，也不需要外部模型，可作为即插即用模块用于现有方法。在八个基准上的大量实验表明，PTC显著提升了六种代表性方法的性能，并产生更完整、更准确的分割结果。这些结果验证了PTC作为一种改善视觉-文本对齐的简单有效方法。

## Abstract
Training-free open-vocabulary semantic segmentation (OVSS) partitions an image into semantically distinct regions based on arbitrary text descriptions, without learning any additional parameters. However, existing methods typically focus on improving visual representations while treating text embeddings that encode only generic category concepts as fixed classification references. The resulting semantic gap between these generic concepts and the visual representations that capture the specific appearances of target instances often causes incomplete masks and erroneous predictions in non-target regions. Inspired by the symbol-percept correspondence underlying perceptual anchoring, we propose Prototype-Guided Text Calibration (PTC) for training-free OVSS. In the Perceiving stage, PTC selects reliable visual evidence based on initial matching scores to construct category-specific visual prototypes. In the Anchoring stage, PTC uses these prototypes to calibrate their corresponding text embeddings, with the calibration strength adaptively adjusted based on the amount of visual evidence. Consequently, the calibrated text embeddings align more accurately with instance-specific visual representations while preserving generic category semantics and open-vocabulary generalization. Moreover, PTC requires neither additional training nor external models and can serve as a plug-and-play module for existing methods. Extensive experiments across eight benchmarks show that PTC significantly enhances the performance of six representative methods and yields more complete and accurate segmentation results. These results validate PTC as a simple and effective approach to improving visual-text alignment.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：开放词汇语义分割（OVSS）旨在根据任意文本描述将图像划分为语义区域，无需预先定义封闭类别集合。大规模视觉-语言预训练模型（如 CLIP）具有良好的零样本迁移能力，被广泛应用于 OVSS。
- **现有方法局限**：现有训练无关 OVSS 方法大多聚焦于增强视觉表示（如改进自注意力、利用外部视觉基础模型的空间一致性），但普遍将类别文本嵌入视为固定的零样本分类器，忽略了文本嵌入与视觉嵌入之间的语义鸿沟：
  - 文本嵌入由预训练 LLM 生成，编码的是**通用、与输入无关的类别概念**；
  - 视觉特征直接从输入图像提取，表征的是**特定实例在特定姿态、视角和成像条件下的具体外观**；
  - 直接匹配两者会造成语义错位，表现为：
    - 仅识别类别高代表性局部区域，导致掩码不完整；
    - 将通用文本嵌入错误匹配到视觉相似的背景或共现类别区域，导致错误分割。
- **核心研究问题**：能否通过建立文本符号与具体视觉感知之间的“锚定”关系，缩小通用类别语义与实例特定视觉外观之间的鸿沟，从而提升训练无关 OVSS 的视觉-文本对齐精度。

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 2.1 核心思想
- **灵感来源**：认知机器人学中的“感知锚定”（Perceptual Anchoring）概念——将抽象符号与具体感知对象联系，使符号指向特定实体。
- **核心主张**：类别文本嵌入不应始终是固定分类参考，而应通过输入图像中的可靠视觉证据，与目标实例的具体外观建立感知联系，实现“锚定”。

#### 2.2 方法整体流程（PTC 包含两大阶段）

**阶段一：Perceiving（感知）—— 可靠视觉原型构建**

- **候选集构造**：根据初始匹配分数 S，将每个视觉 token 分配给得分最高的类别，形成类别 c 的候选 token 集 Ωc。
- **基于边际的可靠性评估**（Margin-based Reliability Assessment）：
  - 计算每个 token 的分数边际 Δi = 最高分 − 次高分；
  - 边际越大表明类别分配越不模糊、越可靠；
  - 相比单一类别的绝对置信度，边际能有效过滤掉虽然绝对分数高但对多个类别反应强烈的歧义 token。
- **混合证据量确定策略**（Hybrid Evidence-Quantity Determination）：
  - 目标证据数 Kc = min(Nc, max(Kmin, ⌊ρNc⌋))；
  - Kmin 保证小候选集类别的原型代表性（最低证据量）；
  - ρNc 按比例缩放以适应大候选集类别的尺度变化；
  - Nc 为候选 token 总数上限；
  - Nc < Kmin 的类别视为证据不足，跳过原型构建与校准。
- **原型聚合**：选取边际最大的 Kc 个 token，按其边际归一化加权求和得到视觉原型 Vproto_c。

**阶段二：Anchoring（锚定）—— 证据驱动的文本校准**

- **有效性类别筛选**：证据量 ≥ Kmin 的类别进入校准集合 Cvalid。
- **自适应校准强度**：μc = μ · αc，其中 αc = min{1, log(1+nev_c)/log(1+λKmin)}，λ 控制达到上限所需证据量；证据量越少校准越保守，证据量充足后强度饱和，防止大目标因证据多而过度偏离原始语义。
- **文本嵌入更新**：
  - 对 Cvalid 中的类别：tcal_c = (1−μc)·tc + μc·Vproto_c；
  - 其余类别保持不变。
- **最终预测**：用校准后的文本嵌入重新计算匹配分数并取 argmax 得到分割图。

#### 2.3 方法特性
- 无需额外训练，无需外部模型；
- 即插即用模块，可集成到任意训练无关 OVSS 方法；
- 保留原始类别通用语义的同时，融入实例特定视觉线索。

### 6. 论文的主要结论与发现

- PTC 在六个代表性训练无关 OVSS 方法上带来一致性能提升：
  - SCLIP +1.5、ClearCLIP +1.0、NACLIP +2.2、ResCLIP +0.8、ProxyCLIP +1.9、CorrCLIP +0.9（平均 mIoU 百分点）；
  - ProxyCLIP + PTC 平均 mIoU 从 42.3% 提升到 44.2%；
  - CorrCLIP + PTC 从 51.0% 提升到 51.9%。
- 定性可视化表明：PTC 能有效缓解掩码不完整问题、抑制背景干扰和类别混淆、提升小目标和低显著性物体的识别能力。
- 消融实验验证了三项核心设计的必要性：边际评估优于置信度阈值、混合证据量策略优于固定/纯比例策略、证据自适应校准优于统一强度。
- 方法对不同视觉基础模型（SAM/DINO/DINOv2）和不同 CLIP 骨干（ViT-B/L/H）具有泛化能力。
- 核心结论：通过连接通用类别文本嵌入与实例特定视觉外观，可以有效缓解语义鸿沟，改善视觉-文本对齐，提升分割精度。

### 8. 不足与局限

1. **依赖初始匹配质量**：PTC 的视觉原型构建依赖于初始类间匹配分数，若基线初始预测噪声较大（如复杂场景、密集小目标），证据污染风险仍存在。作者在文中也承认性能依赖原型质量。
2. **超参数敏感性**：
   - Kmin 和 μ 的最优值在不同数据集乃至不同基线上差异明显（如 VOC21 最优 Kmin=100 vs. Cityscapes 最优 Kmin=2）；
   - 需要按数据集/基线分别调参，实用中增加使用成本；
   - 对选择过程的说明不足，存在对测试集调参的嫌疑。
3. **绝对增益有限**：对于本身较强的基线（如 CorrCLIP、ResCLIP），PTC 的平均增益相对较小（≤1%），部分数据集增益接近 0。
4. **少量负面案例**：在 ViT-L/14 骨干上，COCO-Object 数据集出现性能下降（39.2→38.8），说明在目标词汇量大且背景干扰强的场景中，原型可靠性下降会削弱方法效果。
5. **未报告计算开销**：论文未量化 PTC 带来的额外推理时间和内存开销，对于“即插即用”的宣称缺乏效率证据。
6. **缺少更大规模或更细粒度的基准验证**：未涉及大规模长尾或开放场景数据集（如 LVIS、OpenImages），也未在零样本跨数据集迁移场景中测试。
7. **可视化分析有限**：定性结果仅基于 ProxyCLIP 单个基线，未展示其他基线（如 CorrCLIP）加入 PTC 前后的可视化对比。
