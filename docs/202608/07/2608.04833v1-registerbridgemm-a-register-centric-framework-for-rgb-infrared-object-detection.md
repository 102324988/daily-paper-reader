## 摘要
RGB-红外（RGB-IR）目标检测受益于可见光与热成像线索的互补性，但在光照变化、天气变化和杂乱场景下，有效融合仍然具有挑战性。现有的RGB-IR融合方法往往以具有表达力的patch级交互为代价，换取更轻量但更受约束的自适应机制。我们通过实验观察到，在配对的RGB-IR输入上，预训练的寄存器令牌同时包含模态共享和模态特定信息，这表明它们可以作为跨模态通信的紧凑基础。基于这一观察，我们提出了RegisterBridgeMM，一个以寄存器为媒介的融合框架，组织为三阶段寄存器生命周期。聚合阶段保留从预训练中继承的每个模态的寄存器摘要；桥接阶段在共识残差调节下执行双向的寄存器到patch的读取；投影阶段将得到的寄存器摘要转化为patch特征的空间自适应校准。这种寄存器路径避免了密集的patch到patch的跨模态交互，同时保留了预训练的patch表示。在两个骨干流都冻结的情况下，RegisterBridgeMM在所有四个基准（LLVIP、M3FD、DroneVehicle和FLIR-Aligned）上取得了评估方法中最高的mAP50-95。

## Abstract
RGB-infrared (RGB-IR) object detection benefits from complementary visible and thermal cues, but effective fusion remains challenging under illumination changes, weather variation, and cluttered scenes. Existing RGB-IR fusion methods often trade expressive patch-level interaction for lighter but more constrained adaptation mechanisms. We empirically observe that pretrained register tokens contain both modality-shared and modality-specific information on paired RGB-IR inputs, suggesting that they can serve as a compact substrate for cross-modal communication. Building on this observation, we propose RegisterBridgeMM, a register-mediated fusion framework organized as a three-stage register lifecycle. Aggregate preserves per-modality register summarization inherited from pretraining; Bridge performs bidirectional register-to-patch reading with consensus-residual regulation; and Project translates the resulting register summary into spatially adaptive calibration of patch features. This register pathway avoids dense patch-to-patch cross-modal interaction while preserving the pretrained patch representation. With both backbone streams frozen, RegisterBridgeMM achieves the highest mAP50-95 among the evaluated methods on all four benchmarks: LLVIP, M3FD, DroneVehicle, and FLIR-Aligned.

### 2. 方法论：核心思想、关键技术细节、公式或算法流程

**总体框架**：双流 DINOv3-B 骨干（完全冻结），将寄存器令牌组织为 **三阶段寄存器生命周期**：Aggregate（聚合）→ Bridge（桥接）→ Project（投影）。

#### 阶段一：Aggregate（聚合）

- 不引入新模块，利用冻结的 DINOv3 自注意力中寄存器令牌的预训练摘要能力。
- 公式（每层更新）：rₘ,ℓ+1 = SA_ℓ([cₘ,ℓ；rₘ,ℓ；pₘ,ℓ])|_reg
- 冻结原因：预训练寄存器已含模态共享/特定编码结构，可学习干预会削弱该结构。

#### 阶段二：Bridge（桥接）

该阶段包含两个关键模块，注入在浅层到中间层 S={2, 5, 8}（而非最深读出层 11）：

**（1）RWPR（寄存器写-补丁读，Register-Write Patch-Read）**

- 核心思想：利用寄存器与 patch 的不对称性，以 O(kN) 成本实现双向跨模态信息交换（patch-to-patch 需 O(N²)）。
- 计算公式：
  - Δ_R = CA_R→T(r_R,ℓ, p_T,ℓ, p_T,ℓ)
  - Δ_T = CA_T→R(r_T,ℓ, p_R,ℓ, p_R,ℓ)
  - r̃ₘ,ℓ = LN(rₘ,ℓ + α_ℓ·Δₘ)，其中 α_ℓ = α_max·σ(ᾱ_ℓ)，初始化为 0.1（近恒等映射）。
- 三个特性：复杂度 O(kND)、深度依赖读出的选择性、只更新寄存器而保持 patch token 只读。

**（2）RCRS（寄存器共识/残差分裂，Register-Consensus / Residual-Split）**

- 核心思想：防止两个模态的寄存器在信息互换后陷入"无约束共识"（模态特有信号被稀释），将桥接后的寄存器显式分解为共识与模态特定残差。
- 计算公式：
  - c_ℓ = (r̃_R,ℓ + r̃_T,ℓ)/2（共识）
  - r′ₘ,ℓ = c_ℓ + β_ℓ·(r̃ₘ,ℓ − c_ℓ)（重新参数化）
  - β_ℓ = σ(β̃_ℓ)，初始化为 0.5 的标量门控。
- 含义：β→0 完全共识（遗弃模态特定信息），β→1 保留原始残差。

#### 阶段三：Project（投影）

- 核心模块为 **MAC（模态感知校准，Modality-Aware Calibration）**，将寄存器级跨模态摘要转化为空间自适应仿射参数。
- 构建 CR 摘要向量：s_CR = [c̄⋆；|r⋆_R − c⋆|；|r⋆_T − c⋆|] ∈ R³ᴰ
- 生成空间条件场：
  - 全局仿射种子：seed_s = W_s·Φ(s_CR)
  - 空间 gap 代理：gap_s = Conv_1×1(F̂_R − F̂_T)
  - 条件场：field_s = seed_s + gap_s
- 仿射输出：通过零初始化的 1×1 卷积头输出 4C_s 通道，按模态切分为 SPADE 风格参数 (γₛ, βₛ)，然后：
  - F̃ₛₘ = Fₛₘ + αₛ(γₛₘ ⊙ F̂ₛₘ + βₛₘ)，αₛ 初始为 0.1
- 金字塔融合：逐级拼接（1×1 卷积）+ 自上而下残差传播（双线性上采样 + sigmoid 门控），最终送入 RT-DETR 检测头。

### 6. 主要结论与发现

1. **预训练寄存器令牌具有跨模态通信的天然结构**：未经过多模态训练的 DINOv3 寄存器在配对 RGB-IR 上呈现 3+1 的模态共享/模态特定划分，可被利用为融合媒介。
2. **以寄存器为瓶颈的融合可达到 SOTA**：在双流骨干完全冻结的前提下，RegisterBridgeMM 在全部 4 个基准上取得最高 mAP_50-95，证明紧凑的寄存器路径足以承载有效的跨模态信息交换。
3. **训练后的桥接行为具有深度选择性**：寄存器到对面模态 patch 的注意力熵从第 5 层的 26% 降至第 11 层的 <1%，呈现粗糙到精细的对称选择性，说明深度越深寄存器读出越具选择性。
4. **RCRS 显式的共识-残差分解是有效的**：学习到的残差能量随深度增加，说明深层寄存器保留的模态特定信息更丰富，且可学习 β 优于完全共识（β=0）。
5. **冻结骨干优于全量微调**：冻结 DINOv3-B + 可训练桥接（70.5 mAP_50-95）略优于全量微调（70.3），验证了保留预训练寄存器先验的价值。

### 7. 优点

- **方法设计有据可依**：不是凭空提出新模块，而是基于对预训练模型行为的实证诊断（3+1 结构）推导设计，逻辑链条清晰。
- **参数效率高**：在四个数据集上以 27.8M 可训练参数超越数百 M 参数的密集融合方法，展示了冻结基础模型 + 轻量通路的优越性。
- **保留预训练表示**：patch token 只读，只更新寄存器，既避免破坏预训练特征流形，又实现了跨模态影响，是一种结构优雅的适配。
- **恒等初始化设计安全**：RWPR 的 α 初始 0.1、MAC 的零初始化仿射头、RCRS 的 β 初始 0.5 均保证各模块在训练初期近似恒等映射，不破坏预训练能力。
- **跨基准一致性优势**：四个数据集分别覆盖低光、多天气、小目标密集航拍和杂乱驾驶场景，结果均一致提升 mAP_50 和 mAP_50-95（后者更敏感于定位质量），说明增益不局限于单类场景。
- **实验设计细致**：注入层选择有充分验证（区分"深度读出"与"早期注入"两个概念），消融实验将每个设计点的贡献量化为具体数值。
