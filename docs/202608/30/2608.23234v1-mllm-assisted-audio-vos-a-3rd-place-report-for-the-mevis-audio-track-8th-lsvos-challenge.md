## 摘要
在本技术报告中，我们提出了一种无需训练的音频引导视频对象分割框架，该框架将多模态大语言模型（MLLMs）与基于SAM的分割模型相结合。我们将任务分解为多个阶段，并为每个阶段确定合适的基座模型。在不引入额外模型训练或任务特定微调的情况下，我们的方法利用MLLMs强大的多模态推理能力来建模文本-视觉对应关系，并使用基于SAM的模型生成精确的对象掩码。所提出的框架展示了利用基座模型进行音频引导视频分割的有效性，并在第八届LSVOS挑战赛的MeViS-Audio赛道中取得了有竞争力的性能。

## Abstract
In this technical report, we present a training-free framework for audio-guided video object segmentation, which integrates Multimodal Large Language Models (MLLMs) with SAM-based segmentation models. We decompose the task into several stages and identify suitable foundation models for each stage. Without introducing additional model training or task-specific fine-tuning, our approach leverages the strong multimodal reasoning capabilities of MLLMs to model text-visual correspondence and employs SAM-based models for accurate object mask generation. The proposed framework demonstrates the effectiveness of leveraging foundation models for audio-guided video segmentation and achieves competitive performance in the MeViS-Audio Track of the 8th LSVOS Challenge.

### 2. 方法论：核心思想、关键技术细节与算法流程

本文提出一个四阶段的训练无关流水线，核心思想是**任务分解 + 基座模型即插即用**：

**阶段 1：音频到文本转换（Audio-to-Text Conversion）**
- 使用 ASR 模型（Qwen3-ASR-1.7B）将输入音频转录为文本描述：q = Φ_ASR(A)。
- 目的：将音频引导任务"降维"为文本条件任务，从而复用既有文本-视觉理解与分割模型。
- 局限：ASR 转录可能只是粗粒度描述，在涉及多目标、细粒度属性、复杂时空线索时信息不足，因此需要下一阶段进行精化。

**阶段 2：视频-文本联合分析（Video-Text Joint Analysis）**
- 使用多模态大语言模型（Gemini-3-Flash-Preview）对转录文本和视频画面进行联合推理。
- 具体输出：确定目标实例数量；为每个目标实例生成结构化的三元组 o_i = (d_i, k_i)，其中 d_i 为细粒度指代提示（refining referring prompt），k_i 为代表性关键帧索引（用于后续跟踪的初始化）。

**阶段 3：基于文本的视频分割与掩码跟踪（Text-based Segmentation & Mask-based Tracking）**
- 先用 **MomentSeg** 对全视频进行基于文本的指代视频分割，得到粗粒度掩码序列：M̃_i = {m̃_i,t} = Φ_MomentSeg(V, d_i)。
- 取 MLLM 选定的关键帧 k_i 上的预测掩码 m̃_i,k_i，作为初始掩码输入 **DAM4SAM**（基于 SAM2 的干扰物感知记忆模型），进行**双向传播与细化**，得到高质量掩码序列：M̂_i = Φ_DAM4SAM(V, m̃_i,k_i, k_i)。
- 多目标场景下，每个实例独立执行上述流程后再聚合最终掩码。

**阶段 4：掩码-文本一致性验证（Mask-Text Consistency Verification）**
- 将各实例预测掩码合并叠加到原视频帧上，与转录文本 q 一同送入 Gemini-3-Flash-Preview 进行语义一致性核查。
- 若预测掩码与查询语义不一致（如发生漂移或被遮挡），则该帧掩码被置空丢弃；一致则保留。
- 该模块有效抑制了传播过程向相似干扰物漂移的问题。

### 6. 主要结论与发现

- **主要发现一**：无需任务特定训练，仅通过组合 ASR + MLLM + RVOS + SAM-based 跟踪模型即可在音频引导视频分割任务中获得有竞争力的性能（最终得分 66.80，位列第三名）。
- **主要发现二**：DAM4SAM 的掩码传播与细化能显著提升像素级分割质量（J&F 从 53.09% 提升至 56.72%）。
- **主要发现三**：MLLM 一致性验证虽然会使像素级指标（J/F）下降（由于更严格的语义过滤会导致部分正确掩码被丢弃），但**将 N-acc. 从 41.38% 大幅提升至 96.55%**，显著增强了模型区分"有目标/无目标"表达的能力，最终综合得分从 63.54% 提升至 66.80%——说明语义验证对音频引导场景的价值主要在于**整体决策鲁棒性**而非纯像素精度。
- **总体结论**：MLLM 与 SAM 系列模型的即插即用组合为音频引导视频分割提供了无需训练的新范式参考。

### 7. 优点

- **创新范式**：提出无训练的模块化流水线，无需任务特定微调即可解决跨模态（音频→文本→视觉）的复杂分割任务，思路简洁且具备可迁移性。
- **阶段分解合理**：将"听音频→理解语义→定位目标→精细分割→语义校验"分解为清晰子任务，各阶段选用最合适的基座模型，工程实践指导性强。
- **有效利用 MLLM**：MLLM 不仅用于指代精化，还承担了关键帧选择与语义验证的双重角色，体现了大模型在视频分割中的多面价值。
- **消融结论有洞察力**：揭示了"像素级指标下降但整体分数上升"这一非直观现象，说明在含无目标样本的任务中，语义过滤是整体鲁棒性的关键保障。

### 8. 不足与局限

- **实验覆盖不足**：缺乏多数据集与外部 SOTA 方法对比，结论的泛化性未得到充分验证；ASR 错误传播、关键帧选择敏感性等关键变量未被消融分析。
- **像素精度与语义过滤存在内在张力**：一致性验证在提升 N-acc. 的同时显著拉低了 J/F，说明该方法偏向"保守策略"——宁可漏检也不误检；在实际应用中若目标连续性对精度要求较高，这种取舍不一定友好。
- **推理成本可能过高**：多阶段调用了多个大模型，MLLM 需要对视频多帧往复交互可视化结果，推理开销可能远超端到端方法，但论文未做效率分析。
- **依赖外部闭源 API**：Gemini-3-Flash-Preview 为闭源模型，实验的可复现性受限于 API 可用性与版本迭代。
