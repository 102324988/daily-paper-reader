## 摘要
度量3D目标检测是具身智能体的核心能力，然而多数可靠系统依赖深度传感器，牺牲了成本、功耗和集成简易性。这推动了单目3D检测的发展，它避免了额外约束，但面临一个主要障碍：从单张图像中，深度尤其是绝对尺度是欠约束的。因此，先进行2D检测再预测3D属性的主流模式往往脆弱，因为适度的距离误差就可能主导3D定位，且当相机、运动或环境发生域偏移时，学习到的尺度先验可能失效。为解决此问题，我们提出Map-Det3D，一种在线多视图3D目标检测模型，将检测直接引入从RGB重建的3D空间。我们将短时间窗口映射到多个视图，并重新利用前馈度量3D重建模型作为几何骨干，同时调整其目标感知能力。基于该表示，Map-Det3D直接在度量3D空间中预测框，无需广泛使用的2D到3D提升。跨不同基准的实验表明，该设计支持强在线性能和无需适应的鲁棒迁移，表明为检测训练重建先验是从单目视频实现稳定度量3D检测的实用途径。代码和模型可在https://royyang0714.github.io/Map-Det3D获取。

## Abstract
Metric 3D object detection is a core capability for embodied agents, yet most reliable systems lean on depth sensors, trading away cost, power, and integration simplicity. This motivates monocular 3D detection, which avoids additional constraints, yet it faces a major obstacle: from a single image, depth, and especially absolute scale, are underconstrained. As a result, the prevailing pattern of detecting in 2D and then predicting 3D attributes is often brittle, since modest range errors can dominate 3D localization, and the learned scale prior can fail when cameras, motion, or environments undergo domain shifts. To address this, we propose Map-Det3D, an online multi-view 3D object detection model that brings detection directly into a 3D space reconstructed from RGB. We map a short temporal window into multiple views and repurpose a feed-forward metric 3D reconstruction model as our geometric backbone while tuning its object-aware capabilities. Building on this representation, Map-Det3D directly predicts boxes in metric 3D space, without the widely used 2D-to-3D lifting. Experiments across different benchmarks show that this design supports strong online performance and robust transfer without adaptation, suggesting that training reconstruction priors for detection is a practical route to stable metric 3D detection from monocular video. Code and models are available at https://royyang0714.github.io/Map-Det3D.

- **核心挑战**：从单张图像中，深度和绝对尺度是欠约束的，导致传统“先2D检测、再回归3D属性（深度、尺寸、朝向）”的2D-to-3D提升范式十分脆弱：微小距离误差即可主导3D定位误差；且模型依赖的尺度先验在相机内参、运动模式或场景统计发生变化时容易失效。
- **现有方案的不足**：
  - 单目方法受固有尺度模糊性限制；
  - 点云/深度传感器方法泛化依赖传感器特性和密度；
  - 离线多视图重建方法无法满足流式、因果在线感知需求。
- **本文动机**：利用前馈度量3D重建（Feed-Forward Metric 3D Reconstruction, FF3R）模型提供的几何先验，将检测直接置于重建出的3D空间中，从而绕开2D-to-3D提升路径，增强尺度稳定性与跨域鲁棒性。

## 2. 方法论：Map-Det3D

- **总体思想**：将短期时间窗口内的多帧RGB视为多视角输入，采用MapAnything作为度量FF3R骨干，提取融合特征并预测尺度因子；随后基于DETR风格检测头直接在3D空间解码边界框，输出度量尺度下的3D框。
- **核心组件与关键技术细节**：
  1. **FF3R骨干**：
     - 使用MapAnything作为几何编码器，输出多视图融合的多尺度特征图 \(F_t = \{F_E, F_7, F_{11}, F_{15}\}\) 和每个窗口的尺度因子 \(\rho_t\)；
     - 骨干可处理有/无相机内外参的情况，缺少位姿时可内部估计。
  2. **检测Transformer架构**：
     - 将多尺度特征按视图拆分、投影至256维并拼接成每视图的token序列 \(Q_{IMG}\)；
     - 用密集2D锚点生成提案，选取Top-M位置作为初始3D检测查询 \(Q_0\)；
     - 多层可变形解码器迭代精化查询，并输出每层对应2D参考框用于匹配与损失计算。
  3. **Up-to-Scale 3D Box Head（核心创新）**：
     - 在所有解码层，3D头部以查询 \(Q_k\) 和尺度因子 \(\rho\) 为输入，回归**未缩放（up-to-scale）**的3D框属性；
     - 中心点：\((x,y,z) = (\rho \tilde{x}, \rho \tilde{y}, \rho \exp(\tilde{d}))\)；
     - 尺寸：\((w,l,h) = (\rho \exp(\tilde{s}_w), \rho \exp(\tilde{s}_l), \rho \exp(\tilde{s}_h))\)；
     - 朝向：回归连续6D旋转表示（allocentric），再结合中心方向转为egocentric；
     - 置信度：单层MLP预测二值objectness logit。
  4. **在线推理**：
     - 因果滑窗：时间 \(t\) 时用当前帧和前 \(T-1\) 帧作为多视图输入，只输出当前帧检测；
     - 训练时视图数量从1到最大窗口 \(T\) 随机采样，增强对不同时间上下文的鲁棒性。
- **训练损失**：
  - 匈牙利匹配基于辅助2D框；
  - 2D损失：Focal loss + L1/GIoU；
  - 3D损失：采用解耦角点损失（Cube R-CNN式），分别计算中心平面 \(L_{xy}\)、深度 \(L_z\)、尺寸 \(L_{dim}\)、朝向 \(L_{rot}\)（Chamfer距离），并与2D损失加权求和；
  - 对提案层和所有解码层施加深度监督。

## 6. 主要结论与发现

- Map-Det3D在**CA-1M内域验证**上达到16.9 AP25和3.5 AP50，显著优于单目基线CuTR（13.5/2.4）和Cube R-CNN（4.6/1.0），也超过离线多视图方法ImVoxelNet（10.1/2.3），证明在线多视图滑窗设计有效。
- 在**ScanNet200零样本**设置下，Map-Det3D以15.2 AP15 / 9.7 AP25超过其他所有单目/开放词表方法；与同样在CA-1M训练的CuTR（4.3/2.1）相比，优势显著，表明性能提升来自模型设计而非训练数据。
- 在**ScanNetV2逐场景在线评估**中，无需GT深度、仅用RGB，Map-Det3D以27.6 AP15 / 22.7 AP25 / 6.2 AP50刷新了RGB-only方法的SOTA，优于BoxFusion的RGB only（18.5/11.8/1.0），甚至在某些指标上超越使用GT深度的方法。
- 消融分析显示：
  - 仅使用多视图而冻结FF3R骨干几乎无提升；
  - 微调多视图Transformer是最大增益来源；
  - 相机外参条件大幅提升性能（+4.7 AP15）；
  - 直接3D预测相比非直接预测有效（表2）；
  - 时间窗口（多视图）在测试时带来稳定提升，T=5为最佳折中。

## 7. 优点与亮点

- **方法设计新颖**：首次将前馈度量3D重建模型（MapAnything）改造为检测Transformer的几何骨干，将检测直接置于3D空间，绕开2D-to-3D提升带来的误差放大。
- **尺度处理巧妙**：采用up-to-scale 3D bounding box head，显式利用FF3R预测的尺度因子恢复度量单位，避免直接回归绝对深度，减少了学习负担和尺度漂移。
- **严格因果在线**：滑窗推理保证因果性，训练时随机视点和帧率增强，与实际流式应用一致。
- **泛化能力强**：无需微调即可迁移到ScanNetV2，在零样本上取得SOTA，且与点云方法差距显著缩小。
- **消融设计清晰**：逐步验证了多视图、微调、相机条件、直接3D预测等因素的贡献，具有较高可解释性。

## 8. 不足与局限

- **场景局限**：仅在室内场景训练和评估（CA-1M、ScanNet），对室外/驾驶场景适应性未知。
- **类别限制**：当前聚焦类无关检测，不做语义/开放词表识别；若要落地实际应用需扩展语义头或结合VLM进行后匹配。
- **训练数据单一**：只使用CA-1M训练，未见使用更多元数据增强多样性的尝试（如ScanNet训练集）。
- **评估偏差**：
  - 部分对比方法（开放词表类）与类无关设置不严格对等；
  - 表5中对比方法多数未在CA-1M上训练，而作者专门训练了CuTR作为公平对照，但其他方法可能未完全适配类无关评估。
- **性能局限**：在严格阈值AP50上仍明显低于点云方法（3.5 vs 11.2 FCAF），距离实际部署还有差距。
- **依赖基础模型**：性能强烈依赖MapAnything的几何先验质量，而MapAnything在部分边缘输入下可能出现几何不稳定。
