## 摘要
尽管在过去几十年中取得了显著进展，但准确识别小目标仍然具有挑战性，因为它们缺乏足够的视觉线索。以往的工作通常尝试构建小目标的判别性表示。然而，广泛的频域噪声和标签模糊性在很大程度上被忽视，这严重阻碍了精确定位。为了解决这些问题，我们提出了一种新颖的小目标检测（SOD）检测器，称为DyFrDet，它能够通过在频域中动态抑制背景干扰来精确定位小目标。具体来说，我们提出了一种动态频率感知特征金字塔网络（DyFrFPN），以自适应地抑制低频冗余和过多的高频噪声。DyFrFPN将层次特征转换为频域表示，并引入动态频带预测器（DBP）来保留用于小目标识别的判别性成分。之后，我们提出了一种新颖的标签消歧模块（LDM），它利用概率分布显式建模并减轻目标标签的固有模糊性，从而有效提高低分辨率小目标的定位精度。大量实验表明，DyFrDet在多个基准上取得了最先进的性能，证明了其在各种挑战性场景中的有效性和鲁棒性。我们的代码可在 https://github.com/ManOfStory/DyFrDet 获取。

## Abstract
Despite the remarkable progress over the past decades, accurately identifying small objects remains challenging because of their insufficient visual cues. Previous works typically attempt to construct discriminative representation of the small objects. However, the wide range frequency domain noises and label ambiguities have been greatly overlooked, which significantly hinders the accurate localization. To address these issues, we propose a novel small object detection (SOD) detector termed DyFrDet, which is able to precisely localize the small object by dynamically suppressing the background distractions in frequency domain. Specifically, we propose a Dynamic Frequency-aware Feature Pyramid Network (DyFrFPN) to adaptively suppress low-frequency redundancy and excessive high-frequency noises. The DyFrFPN transforms the hierarchical features into frequency domain representation, and introduces a Dynamic Band Predictor (DBP) to preserve the discriminative components for small object identification. Afterwards, we present a novel Label Disambiguation Module (LDM), which leverages probabilistic distributions to explicitly model and alleviate the inherent ambiguity of target labels, yielding efficient improvement in localization precision of the small objects with low-resolution. Extensive experiments demonstrate that DyFrDet achieves state-of-the-art performance across multiple benchmarks, indicating its effectiveness and robustness in various challenging scenarios. Our code is available at https://github.com/ManOfStory/DyFrDet.

## 2. 论文提出的方法论

### 2.1 总体架构
DyFrDet 是一个两阶段检测器，由两大核心模块构成：
- **动态频率感知特征金字塔网络（DyFrFPN）**
- **标签消歧模块（LDM）**

整体流程：输入图像 → ResNet-50 骨干提取多尺度特征 {c2, c3, c4, c5} → 标准 FPN 获得金字塔特征 {p2, p3, p4, p5} → DyFrFPN 进行频域噪声抑制 → RoI Align 提取候选区域特征 → LDM 完成标签消歧与精确定位。

### 2.2 DyFrFPN：动态频率感知特征金字塔网络

**核心思想**：将金字塔特征变换到频域，动态预测每个通道的频带抑制范围，同时压制低频冗余和高频噪声。

**关键步骤**：

1. **傅里叶变换**：将空间域金字塔特征 \(p_i\) 通过 FFT 变换为频域表示 \(P_i\)（公式 1）。
2. **幅度/相位分解**：将复数频域特征拆分为幅度谱 \(A(u,v)\) 和相位谱 \(\Phi(u,v)\)（公式 2）。
3. **频域特征聚合**：分别对幅度和相位经过卷积块处理，再经 IFFT 变换回空间域得到特征 \(f\)（公式 3）。
4. **动态频带预测器（DBP）**：
   - 对频域特征 \(f\) 和空间域特征 \(p\) 分别进行 GMP 和 GAP 池化并拼接，得到紧凑表示 \(f'\) 和 \(p'\)。
   - 将二者分别投影为 Query、Key、Value，执行缩放点积注意力（公式 5）。
   - 经 FFN 预测两个阈值 \(d_{\alpha_1}\) 和 \(d_{\alpha_2}\)，通过指数参数化确保正数并灵活缩放：\(\alpha_1 = \alpha_l \cdot e^{d_{\alpha_1}}\)，\(\alpha_2 = \alpha_h \cdot e^{d_{\alpha_2}}\)（公式 6）。
5. **掩码生成与频带抑制**：根据预测的通道级阈值 \(\alpha_1\)、\(\alpha_2\) 构造空间掩码 \(M\)，将左上角低频冗余区域和右下角高频噪声区域置 0（公式 7），随后按 P′ = P − β·(P ⊙ (1−M)) 进行抑制（公式 8），其中 β 控制抑制强度。
6. **逆变换**：将抑制后的频域特征经 IFFT 还原为增强的空间域金字塔特征。

**创新点**：与 HS-FPN 仅静态抑制低频相比，DBP 采用通道级动态预测，可同时自适应抑制低/高频干扰，灵活度更高。

### 2.3 LDM：标签消歧模块

**核心思想**：将边界框回归的任务从确定性坐标预测改为概率分布预测，从而显式建模标签不确定性。

**关键步骤**：
1. **分布建模**（公式 10）：将预测偏移量建模为高斯分布 \(P_\theta(x) = \mathcal{N}(\mu_\theta, \sigma)\)，将真值偏移量建模为 Dirac delta 分布 \(Q_{gt}(x) = \delta(x - x_{gt})\)。
2. **KL 散度损失**（公式 11）：最小化预测分布与真值分布之间的 KL 散度，得到损失 \(L_{LDM}\)，与预测均值和协方差相关。
3. **不确定性度量**：通过协方差的最大值 \(\sigma_m\) 反映标签质量——\(\sigma_m\) 越大，目标边界越模糊（Fig. 3 可视化验证）。
4. **加权函数**（公式 12）：设计分段权重函数 \(\omega(\sigma_m)\)，对高置信度样本（\(\sigma_m \le \rho\)）保持权重为 1，对高模糊度样本（\(\sigma_m \to 1\)）将权重降至 \(\varepsilon\)，从而抑制歧义样本的负面影响。
5. **总损失**（公式 13）：\(L = \gamma L_{IoU} + L_{CLS} + \omega(\sigma_m) \cdot L_{LDM}\)。

## 6. 论文的主要结论与发现

1. **双频抑制有效**：同时抑制低频冗余和高频噪声比仅抑制低频能带来更大性能提升（AP 从 24.9 提升至 25.3，动态策略进一步提升至 26.0）。
2. **动态优于静态**：通道级动态预测频带阈值（DBP）优于固定阈值静态抑制，证明了自适应策略的必要性。
3. **标签消歧有效**：将边界框回归建模为分布并加权抑制高歧义样本，可显著提升定位精度（AP 从 23.6 提升至 24.4）。
4. **组合最优**：DyFrFPN 和 LDM 的组合在 AI-TOD 上达到最优 AP 26.0%（使用 SAC 时 28.7%），二者互补。
5. **SOTA 性能**：在 AI-TOD、SODA-D、SODA-A 上均取得最佳或领先性能。例如在 AI-TOD 上比 HS-FPN 提升 AP 3.6%，在 SODA-A 上超过 GauCho 4.6% AP。
