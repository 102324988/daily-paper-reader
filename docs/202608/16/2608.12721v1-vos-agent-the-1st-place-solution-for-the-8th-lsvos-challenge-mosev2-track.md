## 摘要
复杂视频目标分割需要在严重遮挡、消失和重现情况下进行稳健的目标传播。尽管SAM3提供了强大的可提示掩码传播，但对于视觉证据不足的微小目标和依赖显式属性来识别身份的语义主导目标，统一的推理路径仍然不可靠。为此，我们提出了VOS-Agent，一个协作框架，保留SAM3作为共享的密集分割模块，并根据目标特征有条件地激活专门的代理。目标感知与路由代理将每个序列分配到常规、微小或语义主导的路线。微小目标由视觉跟踪代理通过置信度感知的框提示支持，而语义主导的目标由基于MLLM的语义代理通过描述引导的定位和候选验证来处理。在MOSEv2测试集上，VOS-Agent在官方$\mathcal{J}\&\dot{\mathcal{F}}$指标上达到69.82%，并在ECCV 2026的第8届LSVOS挑战赛MOSEv2赛道中排名第一。

## Abstract
Complex video object segmentation requires robust target propagation under severe occlusion, disappearance and reappearance. Although SAM3 provides strong promptable mask propagation, a uniform inference path remains unreliable for tiny targets with insufficient visual evidence and semantic-dominated targets whose identities depend on explicit attributes. To this end, we present VOS-Agent, a collaborative framework that retains SAM3 as the shared dense segmentation module and conditionally activates specialized agents according to target characteristics. A Target Perception and Routing Agent assigns each sequence to a regular, tiny, or semantic-dominated route. Tiny targets are supported by a Visual Tracking Agent through confidence-aware box prompts, while semantic-dominated targets are handled by an MLLM-based Semantic Agent through description-guided localization and candidate verification. On the MOSEv2 test set, VOS-Agent achieves 69.82% on the official $\mathcal{J}\&\dot{\mathcal{F}}$ metric and ranks first in the MOSEv2 Track of the 8th LSVOS Challenge at ECCV 2026.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：视频目标分割（VOS）旨在根据首帧给定的目标掩码，在整段视频中持续分割出同一目标。常规VOS方法（如XMem、Cutie、SAM2、SAM3等）已在传统基准上表现优异，但在真实复杂场景中仍面临严峻挑战。
- **核心问题**：MOSEv2数据集引入了遮挡、消失与重现、小目标、伪装目标、恶劣天气、光照异常、相似干扰物等多种复杂情况。论文指出，即使强大的SAM3（基于概念条件检测与视频掩码传播）也存在两类典型失效模式：
  1. **微小目标**：仅占据几个像素，视觉证据不足，难以进行稳定的长程对应和定位，容易因背景干扰、遮挡和累积误差而丢失。
  2. **语义主导目标**：目标面积足够，但多个邻近实例具有相似的低层外观，其身份需要依赖显式语义属性（如文字、标志、颜色、特殊衣物等）才能区分，而纯视觉对应难以保持身份一致性。
- **核心观点**：这两类失败源自统一推理路径的本质局限——SAM3仅通过提示条件化的视觉特征和时序记忆传播目标，当目标表征严重欠解析或视觉模糊时，缺乏足够的证据确定目标位置或保留目标身份。因此，单一的统一推理路径无法解决异构的失效模式。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想

提出 **VOS-Agent**：一种面向任务的协作式多代理框架，保留SAM3作为共享的密集分割与时间传播模块，并根据目标特征**有条件地激活**专门代理，实现自适应路由推理。整个框架无需微调SAM3，属于训练免费（training-free）模块化设计。

### 2.2 框架组成

VOS-Agent包含四个核心组件：

1. **目标感知与路由代理（Target Perception and Routing Agent）**
   - 分析首帧目标的**空间尺度**和**语义区分度**，将序列分配到三条路线之一：常规（regular）、微小（tiny）、语义主导（semantic）。
   - **空间尺度分析**：计算归一化目标面积 $r_{\text{area}} = A(M_1)/A(I_1)$，当 $r_{\text{area}} < \tau_{\text{area}}$ 时判定为微小目标（阈值在验证集上选择）。
   - **语义区分度分析**：对非微小目标，使用多模态大语言模型（MLLM）判断是否必须依赖显式语义属性才能与相似实例区分：$s_{\text{sem}} = \mathcal{A}^{\text{sem-cls}}(I_1, M_1)$。
   - **最终路由决策**：
     $$
     z = \begin{cases}
     \text{tiny}, & r_{\text{area}} < \tau_{\text{area}} \\
     \text{semantic}, & r_{\text{area}} \ge \tau_{\text{area}} \text{ 且 } s_{\text{sem}} = 1 \\
     \text{regular}, & \text{otherwise}
     \end{cases}
     $$

2. **SAM3分割代理（SAM3 Segmentation Agent）**
   - 作为所有路线共用的密集掩码生成和时间传播模块。首帧掩码初始化目标掩码流及条件记忆，之后通过记忆库进行标准掩码传播。
   - 对微小/语义目标，接收专门代理提供的边界框提示，用于在当前帧修正掩码并更新后续传播的条件状态。

3. **视觉跟踪代理（Visual Tracking Agent）— 用于微小目标**
   - 使用SUTrack（基于视觉模板的递归单目标跟踪器）。初始化静态模板 $Z^{\text{sta}} = \text{Crop}(I_1, B(M_1))$，并在线更新动态模板。
   - 对每帧，裁剪以先前跟踪结果为中心的搜索区域，得到当前预测框与置信度：$(B^{\text{trk}}_t, c^{\text{trk}}_t) = \mathcal{A}^{\text{trk}}(Z^{\text{sta}}, Z^{\text{dyn}}_{t-1}, X_t)$。
   - **协作机制**：计算跟踪框与SAM3原生掩码框的IoU作为一致性指标 $q^{\text{trk}}_t = \text{IoU}(B^{\text{sam}}_t, B^{\text{trk}}_t)$。仅当两者不一致（$q^{\text{trk}}_t < \tau_{\text{iou}}$）且跟踪置信度足够高（$c^{\text{trk}}_t \ge \tau_{\text{conf}}$）时，才接受跟踪框作为提示注入SAM3进行修正。否则保留SAM3的原始预测。

4. **MLLM语义代理（Semantic Agent）— 用于语义主导目标**
   - 首帧生成区分性描述：$D = \mathcal{A}^{\text{desc}}_{\text{sem}}(I_1, M_1)$。
   - 对每帧进行语言引导定位：$B^{\text{sem}}_t = \mathcal{A}^{\text{loc}}_{\text{sem}}(I_t, D)$。
   - 计算与SAM3预测框的重叠度 $q^{\text{sem}}_t = \text{IoU}(B^{\text{sam}}_t, B^{\text{sem}}_t)$。当 $q^{\text{sem}}_t < \tau_{\text{sem}}$ 时，进行显式候选验证：裁剪参考目标、SAM3候选框、语义候选框，由MLLM判断哪个候选更符合原始目标及描述：$y^{\text{sem}}_t = \mathcal{A}^{\text{judge}}_{\text{sem}}(R^{\text{ref}}_1, D, R^{\text{sam}}_t, R^{\text{sem}}_t)$。
   - 仅当两者不一致且语义候选被判定为更一致时，接受语义框提示注入SAM3。

### 2.3 算法流程概括

- 输入：视频帧、首帧掩码。
- 路由代理判断目标类型。
- 常规目标：SAM3直接传播。
- 微小目标：跟踪代理并行估计位置，当高置信度跟踪框与SAM3不一致时注入框提示修正。
- 语义目标：语义代理描述引导定位，与SAM3不一致时进行候选验证并择优提示。
- 最终由SAM3将接受的粗框转换为密集掩码并继续传播。

## 6. 论文的主要结论与发现

- **主要结论**：将异构目标路由到专门化代理（跟踪代理处理微小目标、语义代理处理语义主导目标），同时保留SAM3作为共享掩码传播模块，能有效解决复杂VOS中目标丢失、身份模糊和重现问题。
- **量化结果**：完整VOS-Agent在MOSEv2测试集上达到 $\mathcal{J}\&\dot{\mathcal{F}} = 69.82\%$，排名第一。相比单独使用SAM3（62.49%）提升了7.33个百分点；引入路由+语义代理后提升至67.07%，进一步加入跟踪代理后提升至69.82%。

  - 定性结果验证了跟踪与分割轮廓对微小目标和语义目标保持清晰、紧凑和时间稳定。

## 7. 优点

- **任务剖析精准**：明确识别出统一推理路径面对的两类异构失效模式（微小目标、语义主导目标），切入角度清晰。
