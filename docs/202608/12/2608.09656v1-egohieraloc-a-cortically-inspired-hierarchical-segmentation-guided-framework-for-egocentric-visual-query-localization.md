## 摘要
视觉查询定位（VQL）旨在从自我中心视频中检索并重新定位查询对象，但当对象边界模糊且全局上下文无法有效引导细粒度定位时，这一问题仍然具有挑战性。人类视觉通过一个层次化过程来处理这种模糊性：它快速筛选前景候选，在干扰物中选择性注意目标，通过全局上下文与局部细节之间的反馈来精化感知，并且当单一视图不可靠时，根据其可信度跨视角整合证据。受这些能力的启发，我们提出了\textbf{EgoHieraLoc}，一个用于VQL-2D和VQL-3D的统一框架。判别式解析模块首先利用分割先验提取前景感知的查询表示；查询感知模块随后通过带可变形建模的判别式相关滤波进行稳健的目标定位；区域适应模块将多尺度上下文反馈到局部区域以恢复精确的对象边界。为了将此感知层次扩展到3D定位，我们引入了几何-语义联合置信度（GSJC），它将分割置信度与局部深度一致性、多视图反投影一致性以及三角测量基线质量相乘耦合，使得仅当视点在语义和几何上均可信时才为3D估计做出贡献。大量实验表明，在VQL-2D和VQL-3D基准上均达到了最先进的性能。

## Abstract
Visual query localization (VQL) aims to retrieve and re-localize a queried object in egocentric videos, yet remains challenging when object boundaries are ambiguous and global context cannot effectively guide fine-grained localization. Human vision handles such ambiguity through a hierarchical process: it rapidly screens foreground candidates, selectively attends to the target despite distractors, refines perception via feedback between global context and local detail, and, when a single view is unreliable, integrates evidence across viewpoints according to its credibility. Inspired by these competencies, we propose \textbf{EgoHieraLoc}, a unified framework for VQL-2D and VQL-3D. A Discriminative Parsing Module first extracts foreground-aware query representations using segmentation priors; a Query-Aware Module then performs robust target localization through discriminative correlation filtering with deformable modeling; and a Regional Adaptation Module feeds multi-scale context back into local regions to recover precise object boundaries. To extend this perceptual hierarchy to 3D localization, we introduce Geometric-Semantic Joint Confidence (GSJC), which multiplicatively couples segmentation confidence with local depth consistency, multi-view back-projection consistency, and triangulation-baseline quality, so that a viewpoint contributes to the 3D estimate only when it is credible both semantically and geometrically. Extensive experiments demonstrate state-of-the-art performance on both VQL-2D and -3D benchmarks.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 总体架构

EgoHieraLoc 由三个 2D 模块（DPM、QAM、RAM）和一个 3D 融合方案（GSJC 加权多视图聚合）组成。2D 分支同时输出定位结果与逐视图语义置信度；3D 分支将该置信度与三个几何可信度因子结合，通过 GSJC 决定各视角对最终 3D 估计的贡献。信息流是**单向的**（2D 语义 → 3D 几何），不做 3D 对 2D 的反向优化，保证了每阶段输入-输出契约的可解释性并消除了循环依赖。

### 判别式解析模块（DPM）——实现"快速前景筛选"

- 利用 SAM（Segment Anything Model）的强先验对查询 Q 生成二值分割掩码 S(Q)，将查询特征划分为前景特征集 M_O 与背景特征集 M_B（公式 1）。
- 搜索区域特征经两层 CBN（Conv-BN-ReLU）处理后，逐空间位置分别计算与 M_O 和 M_B 中每个特征向量的余弦相似度（公式 2），再通过 Top-K 平均（K_DPM = 3）聚合得到前景响应 O 与背景响应 B（公式 3），经 softmax 得似然通道图 Z。
- **意义**：以像素级边界感知的表征把目标从杂波背景中分离出来，避免因边界模糊导致特征污染。

### 查询感知模块（QAM）——实现"选择性注意"

- 在查询特征上求解判别式相关滤波器（DCF），以岭回归目标（公式 4）在频域获得闭式解（公式 5）。滤波器并非迭代优化得到，而是每次从查询特征解析计算；端到端训练时，DCF 损失的残差只反传到共享骨干网络，促使其学得使闭式滤波器产生尖锐高斯响应的判别性特征。
- 对每一帧利用解析滤波器得到响应图 R_{vi}（公式 6），采用**自适应阈值二值化 + 8连通域多峰检测**（不依赖单峰选择），保留 Top-5 峰值候选，并按"响应强度 × 连通域面积"加权选出主候选（公式 8）。

### 区域适应模块（RAM）——实现"反馈式精化"

- 模拟高级皮层的自顶向下-自底向上信号整合，采用 PVT（金字塔视觉 Transformer）骨干提取四个尺度的层次化特征（F1-F4）。

- 将 DPM 前景图与 QAM 定位响应图与多尺度特征融合，通过卷积与上采样逐步恢复到原始分辨率，精化并恢复最终细分结果。

### 2D 到 3D 的反投影

- 利用预测分割掩码内的**逐像素深度置信度加权聚合**获得稳健深度估计（公式 21），再结合相机内参 K 与位姿 T_i 反投影到 3D 世界坐标（公式 22）。
- 采用冻结的 Depth Anything-Large 估计相对深度（up-to-scale）；因目标是相对位移偏移量且 COLMAP 提供全局一致的相对尺度，无需绝对度量深度。

### 几何-语义联合置信度（GSJC）——实现"可信度加权整合"

GSJC 为每个候选视角计算综合置信度，由四类互补因子构成：

1. **语义分割置信度 ϑ_sem**（公式 23-24）：由掩码平均概率 P_ave、高置信像素占比 P_thr、峰值概率 P_max 三者的均值组成。
2. **局部深度一致性 ϖ_depth**（公式 25-26）：目标区域深度方差越低，权重越接近 1，指数衰减抑制高方差区域。
3. **多视图重投影一致性 ϖ_reproj**（公式 27-28）：对候选帧三角化得 3D 均值点，重投影回原帧，重投影误差按目标尺寸自适应容忍度做指数衰减。
4. **三角测量基线质量 ϖ_tri**（公式 29-30）：光线方向与平均方向夹角的正弦值（最小钳位 0.01），正交光线对深度噪声更鲁棒。

- **乘法融合**（公式 30）：ϑ_sem × ϖ_depth × ϖ_reproj × ϖ_tri，任何单一因素显著不可靠都会抑制该帧贡献，并设最小钳位 ε_w = 10⁻⁶ 防数值下溢。
- **置信度加权聚合**（公式 31）：最终 3D 位置为各帧反投影点的置信度加权平均；当所有帧都不可靠时自然退化为均匀平均。
- 最后通过查询帧逆位姿将聚合的世界坐标转为局部坐标系偏移量（公式 32）。

- **潜在不足**：Ego4D-VQ 是唯一公开 VQL 基准，跨基准验证需借道 VOT 任务；部分 SOTA 对比结果来自原论文报告值而非统一复现，算法细节/训练数据可能存在差异；QwP 指标因受限于前置 COLMAP 位姿估计而保持不变，无法反映 GSJC 对姿态估计本身的贡献。总体而言实验量充足、归因较清晰，但跨数据集与大一统复现的泛化验证仍有限。

## 6. 论文的主要结论与发现

- **VQ2D 结果**：EgoHieraLoc 在测试集上 tAP25 达 0.44、stAP25 达 0.37、Rec. 51.28%、Succ. 61.33%；验证集上 Succ. 达 62.30%，较 RELOCATE 提升 4.26 个百分点；验证集与测试集之间性能衰减极小（tAP25: 0.43→0.44；Rec.: 51.52% vs. 51.28%），表明泛化能力强。
- **VQ3D 结果**：验证集 Succ. 82.25%（较 EgoLoc 提升 1.76）、Succ*. 98.22%、L2 误差 1.30（较 EgoLoc 降低 0.15）、QwP 84.48%；测试服务器 Succ. 87.50、QwP 90.91，全面刷新 SOTA。
- **模块贡献排序**：消融表明 DPM 比 QAM 对性能更关键且二者缺一不可；GSJC 中语义分量 P_max（峰值概率）贡献最大，几何分量中重投影一致性对 Succ*. 贡献最大；完整 GSJC 较无聚合基线在 Succ. 上累计提升 4.12%、L2 误差降低 21.7%。
- **机制理解**：层次化解析、注意力式相关滤波与多尺度反馈融合在自我中心视频的模糊边界、遮挡与复杂背景下能显著优于纯检测-追踪范式；可信度加权的多视图融合可有效抑制低质量视角对 3D 估计的干扰。

## 7. 优点

- **认知启发的框架设计**：将人类视觉系统的四个关键能力（前景筛选、选择性注意、反馈精化、可信度加权整合）逐一映射为可计算模块，提供了一条清晰且原理驱动的技术路线，而非简单的模块堆叠。
- **统一 2D 与 3D**：通过 GSJC 实现 2D 语义置信度对 3D 几何融合的单向调节，兼具可解释性（每阶段输入-输出契约清晰）与鲁棒性（无循环依赖导致的不稳定）；

- **模块级可解释性**：DPM、QAM、RAM 每一步都有明确的中间输出（前景/背景似然图、定位响应图、细分割掩码），便于逐模块诊断错误来源；GSJC 的置信度因子均为语义明确的物理量（遮挡、模糊、基线、重投影误差），而非黑箱注意力权重。
- **工程实用性强**：推理速度达 41 FPS，满足实时性要求；SAM 失败时具有回退机制，模型规模（150M 参数）适中，训练仅需单卡级资源即可复现。
- **实验归因严谨**：不仅做逐模块消融，还区分了数据增益与架构增益，并用多随机种子统计检验保证结论不依赖偶然性；对 VISOR 数据的贡献做了独立分解，避免了“加数据刷分”的混淆。

## 8. 缺点与局限性

- **基准单一性**：Ego4D-VQ 是唯一公开的 VQL 基准，论文未在第二个 VQL 数据集上验证；对 EgoTracks/TREK-150 的迁移测试只能说明 VOT 能力，不能完全等价于 VQL 泛化。VQL 的“查询—搜索”跨帧检索特性与单目标跟踪在任务定义上仍有本质区别。
- **对比公平性存疑**：多数 SOTA 结果引用原论文报告值而非在完全一致的骨干、训练数据与协议下复现；不同方法可能使用不同的预训练权重、数据增强甚至测试时策略，性能差距中包含实现差异成分。
- **3D 流水线对离线先验的依赖**：GSJC 的几何因子（重投影一致性、三角化基线）依赖 COLMAP 提供的相机位姿与 Depth Anything 提供的相对深度。当场景纹理稀疏、快速运动导致位姿估计漂移时，3D 定位性能的上限被外部模块锁定；论文对位姿误差的鲁棒性未做专门分析（如加入位姿噪声的敏感性实验）。
- **SAM 依赖的隐式风险**：DPM 的分割质量直接决定前景/背景特征分离效果，论文只提到“SAM 失败回退机制”，但未量化 SAM 分割错误（如漏分割、过分割）对最终定位精度的具体影响曲线。
- **计算开销分析不完整**：论文报告了 2D 分支的 FPS 与 FLOPs，但 3D 分支中 COLMAP 位姿估计、Depth Anything 推理、GSJC 的逐帧三角化与重投影计算均未纳入端到端时延统计；在实际机器人/AR 场景中这些离线步骤可能成为瓶颈。
- **QwP 指标失效问题**：由于 QwP 受限于前置位姿估计精度，论文中 QwP 数值在消融中保持不变，说明该指标无法敏感捕捉 GSJC 的改进，论文也未能提出替代性几何评测指标来弥补这一盲区。
- **语义与几何的单向耦合**：信息流被刻意设计为单向（2D→3D），虽然保证可解释性和稳定性，但也放弃了 3D 几何约束反向校正 2D 定位错误的可能性——例如当多视图几何强烈一致而 2D 响应较弱时，理论上存在进一步精化 2D 结果的空间。

## 9. 改进方向与未来工作建议

- **构建多基准验证体系**：在更多自我中心数据集（如 EPIC-KITCHENS 的查询式任务、Aria 数据集）上建立 VQL 协议，减少对单一 Ego4D-VQ 的依赖。
- **实现完全统一的联合建模**：将 2D 语义与 3D 几何置于共享的 Transformer/扩散框架中做双向交互（如 3D 一致性的梯度回传修正 2D 响应），探索单向耦合到闭环精化的升级。
- **端到端几何先验学习**：用可学习的位姿精化网络替代固定 COLMAP 结果，将位姿不确定性显式建模为 GSJC 的第五个置信度因子，使系统对位姿噪声更鲁棒。
- **在线自适应置信度学习**：当前 GSJC 因子均为手工设计的启发式度量，可引入轻量元网络学习各因子的最优组合权重，实现在线适配不同场景（快速运动、遮挡密集、长时漂移）。
- **评估指标完善**：提出对位姿误差不敏感的 3D 定位指标（如相对于局部场景结构的归一化位移误差），避免 QwP 失效问题。

## 10. 综合评价

EgoHieraLoc 是一项方法系统性强、实验扎实、写作层次分明的工作。它最大的贡献不在于单一模块的突破，而在于提出了一条由人类视觉机制驱动的 2D→3D 统一感知流水线，并以充分的消融实验证明了每一设计决策的边际收益。其“语义置信度调节几何融合”的思想对后续 VQL、乃至通用视频目标重定位任务具有借鉴意义。同时，论文在基准泛化、对比公平性与评估指标上的不足也反映了当前 VQL 领域基础设施尚不成熟的现实。总体而言，这是一篇值得精读的具身感知方向代表性工作，其架构理念与实验方法论的启示价值大于具体数值的刷新意义。
