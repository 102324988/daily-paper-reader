## 摘要
可见光-红外目标检测依赖于RGB和热成像的互补线索，但其性能常因跨模态空间错位而下降。现有方法大多依赖隐式特征自适应来处理弱错位场景，而大偏移几何差异仍未得到充分解决。本文提出一种联合特征域配准与检测网络（JFRDet），这是一种针对严重跨模态几何差异的端到端可见光-红外定向目标检测器。JFRDet引入跨模态仿射对齐（CMAA）模块，估计图像级仿射变换以实现显式的多级特征对齐。注意到光照变化直接影响RGB线索的可靠性，光照引导互补融合（IGCF）模块在不同光照条件下自适应利用模态可靠性进行跨模态融合。此外，对齐质量一致性门控（AQCG）策略通过根据对齐可靠性和梯度一致性调整检测监督，稳定联合优化。我们还构建了DroneVehicle Misaligned（DVMA）基准，用于评估严重跨模态几何错位下的可见光-红外定向目标检测。所提出的JFRDet在DVMA上达到69.7%的mAP50，代表了最先进的性能。代码和数据集将发布在GitHub上。

## Abstract
Visible-infrared object detection relies on complementary RGB and thermal cues, but its performance is often degraded by cross-modal spatial misalignment. Most existing methods rely on implicit feature adaptation to handle weakly misaligned scenarios, while large-offset geometric discrepancies remain insufficiently addressed. In this paper, we propose a Joint Feature-domain Registration and Detection network (JFRDet), an end-to-end visible-infrared oriented object detector tailored for severely cross-modal geometric discrepancies. JFRDet introduces a Cross-Modal Affine Alignment (CMAA) module to estimate an image-level affine transformation for explicit multi-level feature alignment. Note that illumination changes directly affect the reliability of RGB cues, an Illumination-Guided Complementary Fusion (IGCF) module adaptively exploits modality reliability under varying illumination conditions for cross-modal fusion. Then, an Alignment Quality-Consistency Gating (AQCG) strategy stabilizes joint optimization by modulating detection supervision according to alignment reliability and gradient consistency. We further construct DroneVehicle Misaligned (DVMA), a benchmark for evaluating visible-infrared oriented object detection under severe cross-modal geometric misalignment. The proposed JFRDet achieves 69.7\% $\mathrm{mAP}_{50}$ on DVMA, which represents state-of-the-art (SOTA) performance. The code and dataset will be available on GitHub.

### 一、论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：可见光-红外目标检测（VIOD）通过融合RGB图像丰富的纹理外观信息与红外图像对光照不敏感的优势，在监控、自动驾驶等场景具有重要应用价值。然而，由于传感器位置、视角差异或平台运动，可见光与红外图像对常存在空间几何错位（包括平移、旋转、尺度变化），严重损害跨模态特征融合的效果。
- **核心问题**：现有跨模态错位处理方法主要针对**弱错位场景**，大多依赖隐式特征自适应（如可变形注意力、偏移引导采样），其局限性体现在两方面：
  - **严重跨模态错位缺乏探索**——多数方法在已对齐或仅弱错位的数据集上评估，难以证明对大幅偏移的鲁棒性。
  - **特征降采样掩盖弱错位**——骨干网络的反复降采样将小像素偏移映射为低分辨率特征图上几乎不可区分的位移，变相形成了近对齐的训练条件，使模型未能学到真正的跨模态几何差异消解能力。
- **整体含义**：论文主张通过**显式的特征域仿射配准**来弥合严重跨模态几何错位，即在融合之前直接估计并校正模态间的全局几何变换，而非依赖隐式适应，从而为大偏移场景下的可见光-红外定向目标检测提供新的解决范式。

### 二、论文提出的方法论

论文提出**JFRDet（Joint Feature-domain Registration and Detection Network）**，一个端到端的联合特征配准与检测网络，核心包含三大模块：

1. **跨模态仿射对齐模块（CMAA，Cross-Modal Affine Alignment）**
   - **核心思想**：估计从红外到可见光的图像级仿射变换 $T_{ir \rightarrow rgb} \in \mathbb{R}^{2 \times 3}$，并将该变换逐步应用于红外特征金字塔的各层特征，实现显式的多尺度特征配准。
   - **粗粒度匹配（Coarse-Grained Matching）**：在1/16分辨率的红外和可见光特征上进行，经位置编码和展平后，通过交替的模态内自注意力和跨模态交叉注意力捕获长程上下文与跨模态对应关系。计算温度缩放相似度矩阵 $S(i,j)$，通过双向Softmax得到双向置信矩阵，保留置信度高于阈值 $\theta_c$ 的候选匹配。该双向策略保留一对多候选，以增强对大幅几何差异的鲁棒性。
   - **细粒度匹配（Fine-Grained Matching）**：针对每个粗匹配，以1×1、3×3、5×5三种局部窗口进行由粗到细的局部特征精炼，借助双Softmax得到局部置信矩阵后筛选可靠匹配，再通过轻量回归头预测坐标偏移以降低离散化误差。
   - **特征仿射配准（Feature Affine Registration）**：对筛选后的匹配对进行置信度加权仿射拟合求解最优变换，将变换映射到各特征层坐标系，通过双线性采样网格进行可微仿射扭曲，得到对齐后的红外特征金字塔 $\tilde{F}_{ir}$。
2. **光照引导互补融合模块（IGCF，Illumination-Guided Complementary Fusion）**
   - **核心思想**：根据光照条件自适应调节可见光与红外特征的融合权重——弱光下抑制不可靠的可见光响应、增强红外互补信息，光照充足时保留可见光的丰富外观细节。
   - **光照估计**：无需额外标注，直接从可见光图像的平均强度计算光照分数 $\eta$，并推导黑暗感知因子 $d(\eta)$。
   - **融合机制**：利用模态间响应差异生成空间门控图 $G_l$，同时建模模态间的共享线索与互补线索 $R_{cc}$，最终融合特征同时保留原始对齐特征、门控调节后的增强特征和互补线索，并对红外扭曲后的无效区域进行掩码。
3. **对齐质量一致性门控策略（AQCG，Alignment Quality-Consistency Gating）**
   - **核心思想**：训练早期仿射变换估计不可靠，若此时施加强检测监督可能误导检测器优化；AQC通过对齐质量和梯度一致性自适应调节检测损失权重，稳定端到端的联合优化。
   - **对齐质量计算**：维护对齐损失的指数移动平均，映射为对齐质量分数 $Q_t$，再通过双曲正切变换得到带符号的门控信号。
   - **梯度一致性计算**：测量对齐损失与检测损失关于预测仿射变换的梯度余弦相似度，以判断两个优化目标是否一致。
   - **门控机制**：综合质量分数与梯度一致性得到门控分数，将检测损失权重限制在 $[0.5, 2.0]$ 区间内；权重在反向传播中截断，仅作为训练期调节器。

### 三、实验设计

- **自建基准数据集 DVMA（DroneVehicle Misaligned）**：

  - 通过中心裁剪可见光图像，对红外图像施加旋转（15°–30°）、各向异性缩放（0.90–1.10）和平移组合变换，构造数十至数百像素级别的严重跨模态偏移，保留重叠IoU在0.70–0.80之间的图像对。
  - 与现有数据集（VEDAI、KAIST、CVC14、FLIR、LLVIP、DroneVehicle、M3FD、DVTOD）相比，DVMA是首个面向严重错位且提供显式对齐标注（Alignment GT）的可见光-红外定向检测数据集。

- **对比方法**：

### 六、论文的主要结论与发现

1. **显式仿射配准有效解决严重错位问题**：CMAA模块通过粗到细的跨模态匹配估计图像级仿射变换并显式对齐多尺度特征，显著改善了严重错位下的融合质量。
2. **光照自适应融合提升跨模态互补利用**：IGCF根据光照条件自适应平衡可见光与红外线索，在低光照和良好光照场景下均优于固定权重融合。
3. **对齐质量感知的联合优化稳定训练**：AQCG基于对齐可靠性和梯度一致性动态调节检测监督权重，避免不可靠配准对检测器造成误导。
4. **JFRDet达到SOTA性能**：在DVMA上以69.7% $\mathrm{mAP}_{50}$ 和36.1% $\mathrm{mAP}_{50:95}$ 领先所有对比方法，尤其在卡车（66.7% AP₅₀）和货车（55.4% AP₅₀）等大目标类别上提升显著。
5. **现有方法在严重错位下表现不足**：即使先进的可见光-红外方法（如DMM+S²ANet）在DVMA上的表现仍明显低于JFRDet，说明加入第二模态不一定带来增益，显式几何校正是必要的。

### 七、优点

- **问题选取具有挑战性与实际意义**：聚焦现有方法普遍忽视的严重跨模态几何错位场景，填补了该方向的研究空白。
- **方法设计合理、各组件互补性强**：显式配准（CMAA）解决几何错位、光照自适应融合（IGCF）解决模态可靠性差异、训练门控（AQCG）解决联合优化稳定问题，三者环环相扣，逻辑自洽。
- **技术细节扎实**：粗到细的匹配策略、双向置信保持一对多候选、置信度加权仿射拟合、可微网格采样、门控权重的梯度截断等，均体现了较强的技术完成度。
- **高质量benchmark构建**：DVMA通过可控仿射扰动生成严重错位数据，同时保留精确的对齐标注（可自动生成各特征分辨率的对应关系），为后续研究提供了一个可复用的评测平台；在数据集对比表中明确了DVMA相对于现有数据集的差异化价值。
- **充分的消融与敏感性验证**：不仅验证了各模块的有效性，还探索了关键超参数的影响范围，提升了方法结论的可靠性。
- **可视化验证直观有力**：特征图可视化清晰展示了CMAA配准前后的效果差异。

### 八、不足与局限

- **实验覆盖范围有限**：核心实验仅在自建DVMA基准上进行，虽然DVMA设计合理，但缺乏在**自然采集的真实错位数据**（非人工合成）上的验证；也缺少在主流对齐/弱错位数据集（如LLVIP、FLIR、M3FD）上的泛化实验和与更多最新方法的横向对比。
- **合成错位与现实差异风险**：DVMA的错位是通过受控仿射扰动合成的，虽覆盖大偏移范围，但真实场景中的错位可能包含非刚性形变、局部视差、传感器差异等更复杂因素，DVMA上的性能优势是否可直接迁移到真实严重错位场景仍待验证。
- **光照估计方式较简化**：IGCF的光照分数仅基于可见光图像的全局平均强度，对光照分布不均或局部阴影场景可能不够精确；基于特征差的门控依赖模态间响应差异的有效性，在极端场景下可能存在偏差。
- **仿射变换的全局性限制**：全局仿射变换只能描述整体平移、旋转和均匀/各向异性缩放，无法处理同一场景内不同深度目标具有不同局部视差的情况，限制了方法的适用范围。
- **缺乏计算开销与效率分析**：CMAA的粗-细匹配涉及自注意力/交叉注意力迭代和逐窗口计算，但论文未报告推理速度、参数量、FLOPs等效率指标，也未与对比方法在效率上进行公平比较，实际工程部署的可行性尚不明确。
- **面向对象的适用性**：方法针对定向目标检测验证，其在水平框检测任务和行人等非刚性目标上的有效性未讨论。
