## 摘要
我们提出了第8届大规模视频目标分割（LSVOS）挑战赛2026中MeViS-Text赛道的第一名解决方案：由书面运动表达引导的指涉视频目标分割，包括具有欺骗性的无目标表达——这些表达与视频中的任何目标都不匹配，必须生成全帧空掩膜。我们的流水线SSUPER将每个表达解析为视觉概念，使用SAM~3.1生成全视频候选掩膜片段，并选择目标ID。在每个推理阶段，三个异构多模态大语言模型独立执行相同的阶段特定提示，随后一次综合传递提交一个通过模式验证的判定。尽管该系统在验证集上拒绝了所有无目标表达，但排行榜显示，测试集中相当一部分无目标案例仍然漏过。其原因是，硬负样本命名了一个看似合理的对象，仅在完整的时间谓词下才失败，因此当选择和存在性同时决定时，一个类别合理的掩膜片段会锚定判定。因此，我们将存在性验证解耦为一个独立的、针对完整谓词（类别、计数、动作、轨迹、事件顺序和语义角色）的多智能体审计，该审计区分缺失与暂时不可见，折扣由相机运动引起的表观运动，并要求存在矛盾证据而不仅仅是不确定性才能作出无目标判定。在没有任何新的分割调用的情况下，该审计恢复了大部分残留的无目标错误。随后，一个仅使用训练数据的StyleRefiner将掩膜几何与MeViSv2的注释风格对齐，同时通过构造保留每个存在性判定，表明一旦语义固定，剩余错误的一部分是风格性的而非语义性的。完整系统在官方挑战排行榜上达到最终得分0.9081339614。

## Abstract
We present the first-place solution to the MeViS-Text track of the 8th Large-scale Video Object Segmentation (LSVOS) Challenge 2026: referring video object segmentation guided by written motion expressions, including deceptive no-target expressions that match no object in the video and must yield empty masks in every frame. Our pipeline, SSUPER, resolves each expression into a visual concept, generates full-video candidate masklets with SAM~3.1, and selects target IDs. At every reasoning stage, three heterogeneous multimodal large language models independently execute the same stage-specific prompt before a single synthesis pass commits one schema-validated verdict. Although this system rejects every no-target expression in validation, the leaderboard reveals that a substantial share of test no-target cases still slips through. The reason is that hard negatives name a plausible object and fail only under the complete temporal predicate, so when selection and existence are decided together, a category-plausible masklet anchors the verdict. Hence, we decouple existence verification into an independent multi-agent audit of the full predicate (category, count, action, trajectory, event order, and semantic role) that distinguishes absence from temporary invisibility, discounts apparent motion caused by camera movement, and requires contradicting evidence rather than mere uncertainty for a no-target verdict. Without any new segmentation call, this audit recovers most of the residual no-target errors. A training-data-only StyleRefiner then aligns mask geometry with the annotation style of MeViSv2 while preserving every presence decision by construction, showing that once the semantics are fixed, part of the remaining error is stylistic rather than semantic. The complete system reaches a Final score of 0.9081339614 on the official challenge leaderboard.

  - MeViSv2 引入了**欺骗性无目标表达式（no-target expressions）**：这类表达式描述了一个看似合理的对象，但视频中实际不存在满足全部条件的目标，系统必须输出全帧空掩膜。
- **关键矛盾（研究动机）**：作者最初构建的端到端系统在验证集上能拒绝全部 38 个无目标表达式（N-accuracy = 1.0），但在隐藏测试集上 N-accuracy 仅 0.8056，暴露出验证集与测试集之间的显著差距。
- **根本原因诊断**：硬负样本（hard negatives）通常命名一个类别上看似合理的对象，但仅在**完整的时间谓词**（如轨迹、事件顺序、语义角色等）下才被证伪。当候选掩膜选择与目标存在性判定被合并在同一判断中时，一个类别看似匹配的掩膜片段会"锚定"模型的判定偏向接受，导致漏检。
- **核心解决思路**：将**存在性验证**从联合的"选择-存在性"判断中解耦出来，作为一个独立的、基于完整谓词审计的多智能体过程；并进一步提出仅依赖训练数据的掩膜几何细化器（StyleRefiner），将剩余误差从语义问题中分离为风格问题。

## 二、方法论：核心思想、关键技术细节与算法流程

### 总体流水线（SSUPER）

整个系统分为四个推理阶段加一个后处理模块：

1. **Stage A：视觉概念解析（Visual Concept Resolution）**
   - 三个异构 MLLM 独立对同一表达式应用相同的概念解析提示（text-only，即 A-1），随后由 GPT-5.6 Sol 合成（A-3）一个简短的**名词短语**（供 SAM 3.1 使用）或返回 `unresolved`。
   - 若文本解析未决（如无语义名词、含回指等），则进入 A-2：三个 MLLM 基于最多 14 帧均匀采样的视频概述帧重新评审，再由 A-3 合成。
   - 动作、方向、顺序、计数和语义关系等谓词信息保留在原表达式中供 Stage C 使用。

2. **Stage B：候选掩膜片段生成（Candidate Masklet Generation）**
   - 使用 SAM 3.1 视频预测器（配合 Object Multiplex）将 Stage A 解析出的名词概念提示为**全视频候选掩膜片段**，记录稳定 ID、逐帧掩膜、边界框和置信度。
   - Stage B 本身不做指代选择；晚期出现或被遮挡通过"帧级空区域"表示，而非直接判定为无目标。

3. **Stage C：候选条件化选择（Candidate-Conditioned Selection）**
   - 三个 MLLM 各自接收原始表达式、有序 RGB 证据、编号掩膜片段覆盖图，比较外观与时间行为后返回一个或多个 ID、`no_target` 或 `unresolved`。
   - 合成传递（Synthesis Pass）做最终裁决。此处**选择与存在性被同时判定**，但临时选中的候选 ID 集合会被存档，供 Stage D 使用。

4. **Stage D：解耦的多智能体存在性验证（Decoupled Multi-Agent Existence Verification）**
   - 三个 MLLM 独立接收相同的存在性验证提示和有序证据，覆盖视频的开始、中间和结尾，输出带引用帧和谓词依据的结构化判定。
   - **判定规则**：区分"目标缺失"与"暂时不可见"；仅有相机运动造成的表观运动不计为对象运动；`no_target` 判定必须基于与表 1 中某类谓词（类别、数量、动作、轨迹、事件顺序、语义角色）相矛盾的证据，而非单纯的不确定性。
   - 合成传递最终裁决；`no_target` 导出空掩膜序列；`target` 保留非空 Stage C 结果；Stage D 不调用 SAM、不创建任何新候选，全程不产生几何。
   - 谓词分类体系（表 1）完全从标注训练数据中归纳，验证集仅用于离线评估，不参与构建。

5. **StyleRefiner：掩膜几何细化（训练数据限定）**
   - **训练**：对 MeViSv2 训练集每个可见对象帧，用标注（GT）引导 SAM 3.1 生成掩膜，与标注构成训练对（共 369,696 对），输入为归一化 RGB + SAM 掩膜先验 + 符号距离变换（5 通道），输出为目标标注。
   - **网络结构**：ConvNeXt-S 主干（stem 从 3 通道扩展为 5 通道，RGB 通道继承预训练权重，新增通道零初始化）+ 高分辨率细节 stem + DINOv3 蒸馏编码器 + U-Net 解码器，共 56.6M 参数。
   - **损失函数**：边界加权 BCE、软 Dice、可微边界 F 值及辅助损失。
   - **推理**：将 Stage D 输出的完整掩膜按连通分量裁剪（≥64 像素），细化后贴回原分辨率；空帧与过小分量直接复制；**用不变约束保证 Stage D 的目标存在性判定在细化后不被破坏**。
   - 训练与验证集按**视频级别**切分（1,413 训练 / 249 开发视频），保证相邻帧不会跨切分边界。

### 多智能体协议

- 每个推理阶段使用"评审-合成"（review–synthesis）模块：三个异构模型（GPT-5.6 Sol、Claude Fable 5、Gemini 3.1 Pro）接收到**完全相同的提示与证据**，各自输出符合模式（schema）的结果；随后一个 GPT-5.6 Sol 合成调用以固定顺序接收三方响应并提交最终结果，可解决分歧但不能引入阶段 B 之外的新候选 ID。

## 六、主要结论与发现

- Stage D（解耦存在性验证）在**不调用任何新分割**的情况下，将测试集 N-accuracy 从 0.8056 提升至 0.9444（+0.1389），T-accuracy 从 0.9779 提升至 0.9877（+0.0098），Final 提升 +0.0555，验证了"选择与存在性需解耦"的核心假设。
- StyleRefiner 在 768 分辨率下将 J&F 从 0.7787 提升至 0.7922（+0.0135），其中 F 增益（+0.0203）明显大于 J 增益（+0.0068），证明其细化效果以**轮廓修正**为主；同时在数学上保持不变式约束，确保存在性判定零翻转，说明"语义正确之后，部分剩余误差是风格性的而非语义性的"。
- 完整系统测试集成绩：J&F = 0.792212，N-acc = 0.944444，T-acc = 0.987745，在官方排行榜取得最终得分 **0.9081339614**，位列 MeViS-Text 赛道第一名。
- 定性案例展示了三种典型的 SAM 几何失败模式——区域补全（同类遮挡导致截断）、细轮廓恢复（低对比度薄结构过平滑）、边界清理（锯齿边界）——均可被 StyleRefiner 有效修正。

## 七、优点

- **问题洞察深刻**：从验证集与测试集的性能鸿沟出发，定位到"类别合理掩膜锚定判定"这一系统化失败模式，而非简单地堆叠模型或调参。
- **解耦设计思想清晰**：将存在性验证从联合判定中独立出来，且不产生新几何，使消融实验能够纯净地隔离"存在性推理"的贡献。谓词审计要求"矛盾证据"而非"不确定性即可判定无目标"，这一判定准则设计严谨。
- **多智能体协议有冗余保障**：三个异构 MLLM 独立评审 + 显式合成传递，降低单一模型偏见被静默采纳的风险；合成传递被限制在已有候选 ID 范围内，防止引入新错误。
- **训练数据限定原则严格**：谓词分类体系与 StyleRefiner 均只使用训练集；开发集按视频划分；valid_u 与测试集仅用于评估，避免了数据泄漏。
- **"风格性错误"这一概念具有洞察力**：在语义判定固定后，用纯数据驱动的方式学习标注风格，提示错误结构性分解的新视角。
- **工程可部署性好**：Stage D 不增加分割计算，StyleRefiner 推理无需文本、无候选 ID、无新 SAM 调用，结构简洁。

## 八、不足与局限

- **无法恢复缺失几何**：若某个目标在 Stage B 中未被 SAM 3.1 生成候选掩膜，Stage D 和 StyleRefiner 均无力回天——存在性验证只能在现有候选集内判断，系统存在"检测瓶颈先于推理"的固有上限。
- **依赖托管模型**：GPT/Claude/Gemini 的 API 版本漂移导致实验不可完全复现，重放需要归档提示词、响应和模型元数据；多模型并行使成本显著上升（文中未量化）。
