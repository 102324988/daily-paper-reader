## 摘要
联合使用RGB和红外（IR）图像可以改善无人机视角下的目标检测，但大多数现有方法以静态或固定权重融合多模态特征，因此忽略了空间变化的模态可靠性。我们提出了EGM-Det，一种用于RGB-IR目标检测的熵引导多模态自适应融合框架。EGM-Det采用双流架构以保留模态特定表示，并引入熵偏移门控融合模块用于自适应多尺度融合。该模块从输入强度、局部熵和跨模态差异中提取浅层熵先验，并用其指导局部偏移对齐和空间通道门控融合。因此，它选择性地聚合可靠的RGB和红外线索，而不是统一组合异构特征。我们还引入了跨模态蒸馏来正则化学习到的融合门控，并减少融合退化。每个学生分支从与主分支匹配的跨模态教师分支中提取互补知识，而熵自适应监督则强调不确定的模态决策。在DroneVehicle、LLVIP和VEDAI上的实验表明，EGM-Det在所有三个基准上都达到了最先进的性能；特别是在VEDAI上，EGM-Det比先前方法高出超过10个百分点。

## Abstract
Joint use of RGB and infrared (IR) imagery can improve UAV-view object detection, but most existing methods fuse multimodal features with static or fixed weights and therefore overlook spatially varying modality reliability. We propose EGM-Det, an entropy-guided multimodal adaptive fusion framework for RGB-IR object detection. EGM-Det employs a dual-stream architecture to preserve modality-specific representations and introduces an Entropy Offset Gate Fusion module for adaptive multi-scale fusion. The module derives shallow entropy priors from input intensity, local entropy, and cross-modal discrepancy, and uses them to guide local offset alignment and spatial-channel gated fusion. It therefore selectively aggregates reliable RGB and infrared cues instead of uniformly combining heterogeneous features. We further introduce cross-modal distillation to regularize the learned fusion gates and reduce fusion degradation. Each student branch extracts complementary knowledge from the cross-modality teacher branch matched to the main branch, while entropy-adaptive supervision emphasizes uncertain modality decisions. Experiments on DroneVehicle, LLVIP, and VEDAI demonstrate state-of-the-art performance across all three benchmarks; in particular, EGM-Det outperforms prior approaches by more than 10 percentage points on VEDAI.

## 二、论文提出的方法论

### 2.1 总体架构（Overview）

EGM-Det采用**双流（dual-stream）架构**，包含三个核心组成部分：

1. **双流特征提取**：RGB和IR图像分别通过两个对称的模态特定分支提取多尺度特征（F_rgb和F_ir），保留模态特定表示。
2. **多尺度熵偏移门控融合（EOGF）**：在选定的特征层级（P3、P4、P5），通过熵引导的对齐和门控融合实现跨模态自适应融合。
3. **选择性多模态蒸馏**：训练阶段，使用两个冻结的单模态教师（RGB教师和IR教师）提供密集置信度图，构建模态偏好目标和可靠性权重，监督学生网络的空间门控。

> 推理阶段仅保留双流检测器，教师网络不参与推理。

### 2.2 熵偏移门控融合模块（EOGF, Entropy Offset Gate Fusion）

EOGF模块在每一融合层级执行三个步骤：

**（1）熵先验构建（Entropy Prior）**
- 输入：归一化强度图（I_rgb, I_ir）、局部熵图（H_rgb, H_ir）、跨模态差异图（I_rgb − I_ir）
- 通过轻量级先验估计器Φ_prior生成熵先验P，编码局部结构复杂度、模态显著性和跨模态差异。
- 先验被调整到每个融合层级的大小，仅用于条件化后续的对齐和门控，而非预定模态选择掩码。

**（2）偏移对齐（Offset Alignment）**
- 将F_rgb和F_ir投影到共享嵌入空间（Z_rgb, Z_ir）
- 利用偏移预测器Φ_align预测偏移场Δ和其对置信度C：
  ```
  (Δ, C) = Φ_align(Z_rgb, Z_ir, Z_rgb − Z_ir, P)
  ```
- 使用可微分的空间变换网络（STN）将RGB特征对齐到IR参考（W(F_rgb, Δ)），实现特征空间中的局部校正。
- 对齐置信度C传递给后续门控估计器，使模态选择能考虑对应关系的可靠性。

**（3）空间-通道门控融合（Spatial-Channel Gated Fusion）**
- 空间门控（Spatial Gate）：
  ```
  G = [g_rgb, g_ir] = Softmax(Φ_gate(Z_rgb_对齐, Z_ir, H_rgb, H_ir, P, C))
  ```
  每个空间位置上满足 g_rgb + g_ir = 1，表示RGB和IR的模态偏好分布。
- 通道门控（Channel Gates）：c_rgb和c_ir分别估计各特征通道的重要性。
- 融合特征计算：
  ```
  F_fusion = g_rgb ⊙ c_rgb ⊙ F_rgb_对齐 + g_ir ⊙ c_ir ⊙ F_ir
  ```
  其中⊙表示逐元素乘法。

### 2.3 选择性多模态蒸馏（Selective Multimodal Distillation）

**（1）教师模态偏好目标构建**

对每个教师m ∈ {rgb, ir}，从分类输出中计算密集置信度图：
```
M_m(x,y) = max_{c∈C} σ(s_{m,c}(x,y))
```
其中s_{m,c}是类别c的逻辑值，σ是sigmoid函数。

两个教师响应的相对大小被归一化为软模态偏好分布：
```
q_m(x,y) = max(M̄_m(x,y), ε) / Σ_{n∈M} max(M̄_n(x,y), ε)
```
其中Q = [q_rgb, q_ir]即为教师导出的模态偏好目标。

**（2）教师目标可靠性**
```
R(x,y) = max(M̄_rgb(x,y), M̄_ir(x,y))
```
两个教师响应都弱的位置对门控蒸馏贡献较小。

**（3）学生不确定性加权**
学生空间门控G的归一化熵：
```
H(x,y) = −(1/log2) Σ_{m∈M} g_m(x,y) log(g_m(x,y) + ε)
```
像素级自适应权重：
```
ω(x,y) = clip[1 + β_pos[sg(H) − τ]_+ − β_neg[τ − sg(H)]_+, ω_min, ω_max]
```
其中sg表示停止梯度。当模态决策模糊时权重增大，门控变得置信后权重降低。

**（4）自适应门控蒸馏损失**
```
L_adapt_gate = Σ_l Σ_{x,y} R·ω·KL(Q ∥ G) / (Σ_{x,y} R·ω + ε)
```
教师可靠且学生决策模糊的位置对门控监督贡献最大。

**（5）分支蒸馏损失**
- **同模态分支蒸馏（L_branch）**：通过通道-wise空间KL散度，将学生RGB特征向RGB教师特征对齐、学生IR特征向IR教师特征对齐。
- **跨模态特征蒸馏（L_cross）**：通过注意力加权后的Pearson相关系数，将学生RGB特征向IR教师特征对齐、学生IR特征向RGB教师特征对齐，传递互补知识。

**（6）总训练目标**
```
L_total = L_det + α·λ(e)·(L_branch + L_cross + L_adapt_gate)
```
其中L_det为标准检测损失，α是全局蒸馏权重，λ(e)控制蒸馏贡献随训练epoch的变化。

## 六、论文的主要结论与发现

1. **熵引导的自适应融合优于静态融合**：EGM-Det通过信息熵先验和门控机制显式建模空间变化的模态可靠性，在三个基准上均取得最优性能，显著优于采用固定或静态权重的融合方法。

2. **严格IoU阈值下优势更明显**：在DroneVehicle上，EGM-Det的最强优势体现在mAP50-95（71.4%，超COMO 5.9个百分点），说明EGM-Det不仅能检测到目标，更重要的是提升了**定位精度和边界框质量**，这正好对应无人机小目标、密集排列、任意朝向场景的核心需求。

3. **选择性蒸馏比全量模仿更有效**：从教师置信度构建软模态偏好目标、以学生门熵自适应加权、仅监督空间门控的设计，比传统的全量预测模仿或特征模仿更有效，避免了教师不可靠预测对学生的不利影响。

4. **标注质量对多模态检测影响显著**：DroneVehicle原始标注中的跨模态不一致和类别混淆会同时影响检测监督和教师置信度图；精化后性能大幅提升，表明**配对标注一致性对多模态训练和评估至关重要**。

5. **熵引导融合架构贡献主导，蒸馏提供补充**：消融实验表明，EOGF架构提供了大部分性能提升（mAP50-95从68.4%提升到70.4%），而双教师蒸馏和熵加权分别提供了进一步补充（各约+0.8%~+1.0%）。

## 七、优点（论文亮点）

### 7.1 方法设计亮点
1. **显式的模态可靠性建模**：不同于现有方法将模态选择隐式地交给检测损失优化，EGM-Det通过熵先验、门控机制和蒸馏监督，将“哪个模态在哪个位置更可靠”作为**显式学习目标**。
2. **信息熵的巧妙贯穿**：从输入级熵先验（强度+局部熵+跨模态差异）到门控熵（学生不确定性加权），信息熵在融合的先验构建和监督加权两个层面形成了统一指导，设计逻辑完整闭环。
3. **轻量且合理的双教师蒸馏**：
   - 将教师密集置信度转化为软模态偏好目标，避免了对检测框的额外处理
   - 同时考虑教师可靠性和学生不确定性，自适应加权门控损失
   - stop-gradient防止学生操纵熵来规避监督
   - 特征蒸馏同时包含同模态和跨模态两种形式，兼顾模态特性和互补知识
4. **精心设计的选择性蒸馏策略**：明确排除检测头蒸馏和伪融合蒸馏，避免引入矛盾的监督信号；仅在三层EOGF空间门上施加偏好监督，通道门仍由检测目标优化——**监督的针对性强、引入噪声少**。

### 7.2 实验设计亮点
1. **标注精化工作细致**：对DroneVehicle进行了系统性的跨模态一致性和类别级精化，进行了多审阅者质量控制，并将精化记录开源。这种**对基准数据集本身质量的把关**在多模态检测研究中较为少见。
2. **统一协议下的公平对比**：所有对比方法在同一数据划分、同一评估脚本下重训练，排除了不同实现细节带来的不公平比较。
3. **消融设计层次清晰**：从最简化基线逐步添加组件，能清晰归因每个设计的独立贡献。

## 八、不足与局限

### 8.1 方法论层面的局限
1. **教师置信度仅为可靠性代理**：教师置信度并不完全等同于模态可靠性，当教师校准不良或遇到分布外场景时会产生偏差；对教师质量的依赖是一个潜在风险。
2. **双教师增加训练成本**：训练阶段需训练和存储两个独立的单模态教师，训练开销较高。虽然推理时仅保留学生网络，但训练成本仍是实际部署中的考虑因素。
3. **门熵只刻画模态选择不确定性**：门熵不能覆盖传感器噪声、域偏移或标注歧义等更广泛的不确定性来源。
4. **类别判别能力仍有短板**：在DroneVehicle上，EGM-Det对bus和van类别的AP50不及某些对比方法（CALNet和LCAFNet），说明类别级判别仍可改进。

### 8.2 实验层面的局限
1. **LLVIP优势过小**：在LLVIP上对最强对比方法的领先仅0.1个百分点，统计显著性存疑。
2. **VEDAI对比不完整**：部分方法在VEDAI上的结果缺失（用"—"表示），削弱了对比的完整性。
3. **未报告训练成本和效率对比**：未提供计算量（FLOPs）、参数量对比之外的效率指标（如推理速度、训练耗时）。
4. **缺乏统计显著性检验**：未报告多次运行的方差或标准偏差。
5. **场景覆盖面有限**：虽然验证了三个数据集，但均为车辆/行人检测场景，未在更广泛的多模态检测任务（如多光谱行人检测、语义分割等）上验证泛化性。

### 8.3 应用层面的限制
1. **对配对数据质量敏感**：框架依赖良好的RGB-IR配对质量；当两模态之间存在严重的视角差异、时间延迟或未对齐时，偏移对齐机制的有效性需要进一步验证。

## 九、综合评价与参考价值

### 9.1 总体评价

EGM-Det是一篇**方法设计扎实、实验分析细致**的多模态目标检测工作。其核心贡献在于将信息熵引入跨模态融合的**先验构建**和**监督加权**两个环节，实现了对空间变化模态可靠性的显式建模，并配合精心设计的双教师蒸馏策略，在三个颇具挑战的航拍基准上取得了具有说服力的性能提升。论文的写作逻辑清晰，从问题动机到方法设计再到实验验证均围绕“模态可靠性动态变化”这一核心线索展开，可读性强。

### 9.2 学术参考价值

- **理论层面**：为多模态融合中的“模态选择”问题提供了一种新的显式建模范式，即用熵刻画模态不确定性与互补性，而非仅依赖隐式学习。
- **实验层面**：对基准数据集标注质量的细致精化以及对统一评测协议的强调，为后续研究提供了值得借鉴的评估方法论。
- **工程层面**：EOGF模块设计轻量，推理时无需额外分支，具备较好的集成潜力。

### 9.3 可借鉴的改进方向

1. 将熵先验扩展到**时间维**（如视频序列中的时序一致性）或**传感器不确定性**。
2. 探索**无监督或自监督**的门控蒸馏，降低对教师标注质量的依赖。
3. 在更大规模、更复杂的多模态数据集上进行验证，并补充效率指标以增强实际部署价值。

---

## 十、结论

EGM-Det通过熵引导的门控融合与选择性多模态蒸馏，有效解决了无人机视角下RGB-IR目标检测中模态可靠性动态变化的问题，并在DroneVehicle、LLVIP和VEDAI基准上取得了领先性能，尤其在大幅提升严格IoU指标（mAP50-95）方面优势显著。尽管存在对教师质量依赖、LLVIP优势较小及效率分析缺失等不足，其方法论上的贡献和实验设计的严谨性使其成为多模态检测领域一篇值得深入研读的高质量工作。
