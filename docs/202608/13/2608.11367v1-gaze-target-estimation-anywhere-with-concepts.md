## 摘要
从真实场景图像中估计人类凝视目标是一项重要且艰巨的任务。现有方法主要采用脆弱的、多阶段的流水线，需要显式输入（如头部边界框和人体姿态）来识别凝视分析的对象。因此，检测错误可能级联并导致失败。此外，这些先前的工作缺乏通过自然语言提示指定凝视分析任务的灵活性，而这种方法已被证明在其他图像分析任务中具有显著的便利性和可扩展性优势。为了克服这些限制，我们提出了可提示凝视目标估计（PGE）任务，一种新的端到端、概念驱动的凝视分析范式。PGE 以灵活的用户文本或视觉提示（例如，“穿红衬衫的男孩”或“位于 [0.52, 0.48] 点的人”）为条件，进行凝视预测，以识别凝视分析的特定主体。该方法将主体定位与凝视估计集成在一起，并消除了对中间分析阶段的刚性依赖。我们开发了一个可扩展的数据引擎来生成 Gaze-Co（基于概念的凝视估计），这是一个包含 120K 个高质量、带提示注释的图像对的数据集和基准。我们还提出了 GazeAnywhere，这是第一个专为 PGE 设计的模型。GazeAnywhere 使用基于 Transformer 的检测器来融合来自冻结编码器的特征，并同时解决主体定位、帧内/帧外存在性以及凝视目标热图估计。GazeAnywhere 在多个 PGE 基准上取得了最先进的性能，即使在一个困难的跨领域、真实世界临床数据集上，也为这个新问题设定了强大的基线。GazeAnywhere 已在 github.com/IrohXu/GazeAnywhere 开源。

## Abstract
Estimating human gaze targets from images in-the-wild is an important and formidable task. Existing approaches primarily employ brittle, multi-stage pipelines that require explicit inputs, like head bounding boxes and human pose, in order to identify the subject of gaze analysis. As a result, detection errors can cascade and lead to failure. Moreover, these prior works lack the flexibility of specifying the gaze analysis task via natural language prompting, an approach which has been shown to have significant benefits in convenience and scalability for other image analysis tasks. To overcome these limitations, we introduce the Promptable Gaze Target Estimation (PGE) task, a new end-to-end, concept-driven paradigm for gaze analysis. PGE conditions gaze prediction on flexible user text or visual prompts (e.g., "the boy in the red shirt" or "person in point [0.52, 0.48]") to identify a specific subject for gaze analysis. This approach integrates subject localization with gaze estimation, and eliminates the rigid dependency on intermediate analysis stages. We develop a scalable data engine to generate Gaze-Co (Gaze Estimation with Concepts), a dataset and benchmark of 120K high-quality, prompt-annotated image pairs. We also propose GazeAnywhere, the first model designed for PGE. GazeAnywhere uses a transformer-based detector to fuse features from frozen encoders and simultaneously solves subject localization, in/out-of-frame presence, and gaze target heatmap estimation. GazeAnywhere achieves state-of-the-art performance on multiple PGE benchmarks, setting a strong baseline for this new problem even on a difficult out-of-domain, real-world clinical dataset. GazeAnywhere is open-sourced in github.com/IrohXu/GazeAnywhere.

### 一、论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：在真实开放场景（in-the-wild）中估计人类注视目标（gaze target）是一项重要但极具挑战的任务。现有方法几乎都采用**多阶段级联流水线**，必须先通过目标检测、姿态估计等模块获取头部边界框、人体关键点等显式中间输入，再送入注视估计模型。
- **关键痛点**：
  1. **误差级联**：前端检测器（尤其在拥挤场景、光线不佳、儿童面部检测等困难情况下）产生的错误会向后传递，导致整个系统失效；
  2. **缺乏灵活性**：用户无法通过自然语言指定"分析谁"，只能依赖检测器输出的边界框；
  3. **缺乏身份关联**：现有端到端方法只能输出场景中所有人的注视，但无法回答"某个特定人的注视目标是什么"这一问题。
- **任务含义**：论文提出**可提示注视目标估计（PGE）**任务，将注视估计从"需显式定位输入"的刚性范式，转变为"基于概念（文本或视觉提示）灵活指定分析对象"的端到端范式。这借鉴了开放词汇检测（OVD）和 SAM 系列模型中"概念即提示"的思想，是注视估计领域的一次范式转变。

### 二、论文提出的方法论

1. **PGE 任务定义**：
   - 输入：RGB 图像 $I \in \mathbb{R}^{3 \times H \times W}$ + 提示 $P$（文本描述或视觉坐标）；
   - 输出：注视热图 $\hat{H} \in \mathbb{R}^{H_{\text{out}} \times W_{\text{out}}}$，每个像素值表示该位置被注视的概率；
   - 要求：模型必须**端到端联合完成**主体识别、主体定位和注视估计，不可使用中间辅助输入。
   - 文本提示分为四类：**外观（Appearance）**、**位置（Location）**、**姿态（Pose）**、**动作（Action）**。

2. **GazeAnywhere 模型架构**：
   - **冻结图像编码器**（CLIP-L 或 DINOv3-L）：提取图像 patch 特征；
   - **冻结文本编码器**（dino.txt）：提取文本 token 特征；
   - **可训练投影层**：将视觉/文本特征投影到统一维度 $D$；
   - **任务专属 Token**：头部 Token（头框定位）、注视存在性 Token（帧内/帧外判断），分别用文本 [EOS] 和视觉 [CLS] 初始化；
   - **检测器 Transformer**（基于 DINOv3 的 Transformer block 堆叠，$k$ 层）：融合视觉和文本 token 序列；
   - **三个解码头**：
     - Gaze Tracker（转置卷积上采样到 64×64 热图）； 
     - Head Tracker（3层 FFN 回归头部框 [x, y, w, h]）；
     - Presence Predictor（2层 FFN 输出帧内/帧外二分类 logit）。

3. **联合学习目标**：
   - $L_{\text{total}} = L_{\text{gaze}} + L_{\text{presence}} + L_{\text{head}}$
   - $L_{\text{gaze}}$：像素级二值交叉熵（BCE），监督目标为以真实注视点为中心、$\sigma=3$ 的二维高斯热图；
   - $L_{\text{presence}}$：Focal Loss，用于帧内/帧外二分类；
   - $L_{\text{head}}$：L1 损失 + GIoU 损失（$\lambda_{l1}=5$，$\lambda_{\text{iou}}=2$，遵循 DETR 的设置）。

4. **数据引擎（Data Engine）**：
   - 三阶段流程：**数据对齐与过滤**（统一坐标 schema，过滤小尺寸/模糊/比例异常的样本）→ **概念生成**（调用 Gemini 2.5 Pro API 批量生成包含外观、位置、动作、姿态四类属性的概念短语）→ **验证**（MLLM 初筛 + 人工抽检，批次错误率控制在 ≤1%）；
   - 生成 Gaze-Co 数据集：约 12 万训练样本，来源于 GazeFollow、VideoAttentionTarget（VAT）、ChildPlay 三个公开数据集。

### 三、实验设计

- **数据集与 Benchmark**：
  - **训练**：Gaze-Co（119,525 个样本，69.6% 来自 GazeFollow，19.6% 来自 VAT，10.8% 来自 ChildPlay）；
  - **测试**：GazeFollow-Concept（2,436 条）、VAT-Concept（5,301 条）、ChildPlay-Concept（1,238 条），均转为 PGE 格式，概念注释经人工全量验证；
  - **域外（OOD）数据集**：私有 Child-SC 数据集（40 名儿童、326 个视频片段、151,533 帧，IRB 批准，用于儿童社交沟通评估），人工标注概念短语，不经过云端 MLLM。

- **对比方法**：
  - 三种 SOTA 注视模型（ViTGaze、Sharingan、Gaze-LLE）× 三种/四种 OVD 检测器（GroundingDINO-B、LLMDet-L、OWLv2-L、RexSeek）组成的两阶段基线；
  - 通用多模态大模型基线：Qwen3-VL-8B、Gemini 2.5 Flash（零样本）；
  - 消融：损失组件、编码器选择、提示策略（视觉/文本/无提示）、冻结策略、检测器维度与层数。

- **评估指标**：AUC（热图 ROC）、Avg L2、Min L2、像素级 L2、AP（平均精度，联合评估定位和帧内/帧外分类）。

### 四、资源与算力

- 文中明确说明：**训练使用 4 块 NVIDIA H100 GPU**，推理使用 **1 块 NVIDIA L40S GPU**；

### 六、论文的主要结论与发现

1. **PGE 任务可行且优越**：概念驱动的端到端范式可以取代传统的"检测→估计"两阶段流水线，消除级联误差；
2. **GazeAnywhere 全面 SOTA**：在 GazeFollow-Concept、VAT-Concept、ChildPlay-Concept 及 OOD 数据集 Child-SC 上，文本提示设置下所有指标均优于两阶段基线；
3. **文本提示可媲美视觉提示**：完整的四类文本提示（外观+位置+动作+姿态）性能与坐标式视觉提示相当（Avg L2 0.099 vs 0.100），其中**外观和姿态是最关键的提示维度**；
4. **DINOv3 编码器最佳**：优于 CLIP-L、SigLIP2-L、MetaCLIP2-H 等候选骨干；
5. **头部定位辅助损失显著有效**：移除 Head Loss 后性能明显下降，而 Presence Loss 主要服务于辅助的帧内/帧外预测；
6. **冻结编码器是关键设计**：微调视觉或文本编码器均导致性能下降；检测器维度 $D=256$、层数 3 是精度/成本最优平衡点；
7. **GazeAnywhere Agent 实用**：集成 MLLM 后，在真实 AR 场景中显著优于纯 MLLM 方案（Gaze shift MAE 从 9.247 降至 2.337/min）。

### 七、优点

1. **范式创新强**：首次将"概念提示"引入注视目标估计，定义 PGE 新任务，填补了"特定人物的注视分析需自然语言指定"的研究空白；
2. **方法简洁有效**：单一端到端 Transformer 架构同时解决主体定位、帧内/帧外判断、注视热图估计三个子任务，无需任何中间辅助模块；
3. **鲁棒性突出**：在 OOD 临床数据集（儿童社交沟通视频）上表现优异——当 SOTA OVD（OWLv2）在儿童头部检测上准确率仅约 70% 时，GazeAnywhere 仍能保持稳定的注视估计性能；
4. **数据引擎设计精巧**：MLLM 生成 + 双重验证（MLLM+人工）的可扩展流程，在保证质量（错误率 ≤1%）的同时实现大规模概念标注；
5. **实验体系完整**：涵盖域内/域外、公开/私有、模型对比/消融/实际部署，且全量人工验证测试集注释；
6. **应用导向明确**：展示 AR 眼镜 + GazeAnywhere + MLLM 的完整智能体系统，对自闭症儿童社交行为分析等临床场景有直接应用价值；
7. **开源开放**：代码和模型已开源，方便后续研究。

### 八、不足与局限

1. **数据来源受限**：120K 训练数据全部从三个现有注视数据集转化而来，概念短语由 MLLM 生成（尽管有人工抽检），可能引入 MLLM 的偏差（如对特定人群外观描述的刻板印象）；且数据分布不均衡——"man"占 51.0%，"woman"占 32.2%，儿童类别占比偏少；
2. **文本内在歧义未完全解决**：虽然设计了四类结构化提示以降低歧义，但"穿红衬衫的人"这类描述在多人同衣着的场景下仍可能产生歧义，论文未充分讨论这种情况下的失败模式；
3. **未与最先进的跟踪类方法对比**：实验中的两阶段基线均在单帧上运行（检测+估计），未与带时序跟踪器的完整视频级流水线（如 Tracking + gaze）进行端到端对比；
4. **OOD 评估规模有限**：Child-SC 虽具有真实临床价值，但视频片段仅 326 个、40 名儿童，且概念注释由人工完成，无法完全排除注释主观性；文中也说明由于隐私限制，无法用云端 MLLM 处理该数据；
5. **与 SOTA VLM 对比不够全面**：仅与 Qwen3-VL-8B 和 Gemini 2.5 Flash 对比，未测试更大参数量的 VLM（如 70B+ 或闭源最强推理模型）；VLM 零样本性能可能因提示工程不同而有所波动；
6. **主观标签的伦理问题未深入探讨**：论文使用"man/woman/boy/girl"等**表观感知性别/年龄**标签来构建文本提示，作者声明这些仅作为"视觉类别线索"而非身份标签，但未分析这种标签在真实应用中可能带来的社会偏见或误用风险；
7. **计算成本与部署**：完整模型约 870M 参数（DINOv3-L + 检测器），虽推理仅 96 ms/帧，但若要部署在资源受限的边缘设备（如智能眼镜本身而非云端）仍需进一步模型压缩与蒸馏。
