## 摘要
指代遥感图像分割（RRSIS）旨在描绘遥感图像中由自然语言表达指定的目标。现有方法主要采用联合融合分割（JFS）或解耦提示分割（DPS）。JFS效率高，但常因指代对象定位与掩膜描绘在统一目标下优化而精度受限；而DPS利用空间提示和基础分割器将定位与掩膜生成分离，但代价是更高的内存消耗和推理延迟。为弥补这一差距，我们提出DiCoR，一种构建于高效JFS流程上的解耦指代消歧与轮廓重校准框架。DiCoR解决两个关键挑战：从模糊候选中区分正确指代对象，以及在定位后细化粗糙掩膜。一种消歧感知的定位引导策略利用自适应语言线索对显著候选区域进行排序，并将所得定位先验注入融合特征。一个轻量级轮廓重校准模块在局部轮廓监督下进一步预测对粗糙logits的残差修正，以有限的计算开销提高掩膜质量。在RefSegRS、RRSIS-D和RISBench上的实验表明，DiCoR在所有三个基准上均取得最佳分割精度。在RefSegRS上，相较于有竞争力的JFS方法，mIoU和gIoU分别提升5.28%和2.87%，同时比代表性DPS方法运行快4.7%，展现出良好的精度-效率权衡。代码可在https://github.com/zyGao1126/DiCoR获取。

## Abstract
Referring remote sensing image segmentation (RRSIS) aims to delineate targets specified by natural language expressions in remote sensing imagery. Existing methods mainly follow joint fusion segmentation (JFS) or decoupled prompt segmentation (DPS). JFS is efficient but often suffers from limited accuracy because referent localization and mask delineation are optimized under a unified objective, whereas DPS separates localization from mask generation using spatial prompts and foundation segmenters at the cost of higher memory consumption and inference latency. To bridge this gap, we propose DiCoR, a decoupled referent disambiguation and contour recalibration framework built on an efficient JFS pipeline. DiCoR addresses two key challenges: distinguishing the correct referent from ambiguous candidates and refining coarse masks after localization. A disambiguation-aware localization guidance strategy ranks salient candidate regions with adaptive linguistic cues and injects the resulting localization prior into fused features. A lightweight contour recalibration module further predicts residual corrections to coarse logits under localized contour supervision, improving mask quality with limited computational overhead. Experiments on RefSegRS, RRSIS-D, and RISBench show that DiCoR achieves the best segmentation accuracy across all three benchmarks. On RefSegRS, it improves mIoU and gIoU by 5.28% and 2.87% over a competitive JFS method while running 4.7% faster than a representative DPS method, demonstrating a favorable accuracy-efficiency trade-off. Code is available at https://github.com/zyGao1126/DiCoR.

### 研究动机与背景

- **任务定义**：指代遥感图像分割（Referring Remote Sensing Image Segmentation, RRSIS）旨在根据自然语言表达在遥感图像中定位并分割出指定目标，是视觉-语言理解与地球观测交叉领域的关键任务。
- **两大范式及其困境**：
  - **JFS（联合融合分割）**：端到端注入语言特征进行跨模态融合，推理高效，但指代目标定位与掩膜描绘在统一像素级目标下联合优化，容易偏向粗定位误差而忽略细粒度边界修正，在遥感图像小目标密集、轮廓偏差影响大的场景下精度受限。
  - **DPS（解耦提示分割）**：先产生空间提示，再借助SAM等基础分割模型生成掩膜，定位与生成分离、掩膜质量较高，但引入基础模型导致显著的内存开销与推理延迟，且对遥感域差异敏感。
- **核心研究问题**：能否在保留 JFS 高效推理优势的同时，吸收 DPS 的“解耦”思想，提升指代定位的可靠性（消歧）与掩膜轮廓的精细度（校准）？
- **论文提出的解决方案**：提出 DiCoR 框架，以轻量模块和任务专属监督实现“解耦”，而非依赖重型基础模型，实现精度与效率的良好平衡。

## 二、论文提出的方法论

### 核心思想

DiCoR 建立在高效 JFS 管线之上，通过两个关键模块分别解决两大挑战：
1. **指代消歧**——通过候选竞争机制识别正确指代目标；
2. **轮廓校准**——通过残差修正改善粗分割掩膜的边界质量。

### 技术细节

#### 1. 多尺度联合融合骨干（Multi-Scale Joint Fusion Backbone）

- 视觉编码器采用 Swin Transformer，语言编码器采用 BERT，经四个视觉-语言融合（VLF）块渐进集成得到多层级多模态特征。
- 多尺度聚合（MSA）模块引入**双向视觉-语言注意力**：L2V 注意力以语言引导视觉序列，V2L 注意力以视觉证据更新语言表示，再经视觉自注意力建模长程依赖，最后通过尺度感知门控融合回各层特征。

#### 2. 消歧感知定位引导（DLG，Disambiguation-aware Localization Guidance）

将指代定位重构为**候选级竞争**问题，三个子阶段：

- **密集响应估计器**：基于第三级融合特征 X₃ 预测响应图 R。
- **候选生成器**：通过局部极大值选择、NMS 和 Top-K 选择提取候选峰值，并用高斯门控响应聚合构建候选支持区域，同时构建视觉特征和几何特征。
- **候选排序器**：
  - 候选嵌入与语言特征交互，经路由网络生成**候选自适应的 token 权重**，得到候选特定文本表示；
  - 通过语义相似度与几何一致性联合计算候选置信度，选出最优候选；
  - 将选中候选的定位先验通过残差空间重校准注入回 X₃。
- **训练监督**：包含响应监督（分目标正前景 P、干净背景 B、困难实例背景 H 三区域，H 由离线 SAM3 挖掘的难负样本构成）和排序监督（交叉熵损失强制候选竞争）。

#### 3. 轻量轮廓重校准（LCR，Lightweight Contour Recalibration）

- 以输入图像和粗预测为输入，预测对粗 logits 的**残差修正**，最终掩膜 = 粗 logits + 残差修正。
- 采用轻量编码器-解码器结构，配镜像跳跃连接保留细节。
- 训练数据构造：从多个中间 checkpoint 收集粗预测，按定位质量过滤（IoU ∈ [0.5, 0.95)），并用形态学膨胀/腐蚀扩充边界偏差多样性。
- 区域感知损失：对预测轮廓附近的像素赋予更高权重，抑制置信区域的不必要响应。

#### 4. 解耦训练策略

- 先训练融合骨干与粗解码器；
- 再从中间 checkpoint 采数据预训练 DLG 与 LCR；
- DLG 再与分割模型进行联合微调；LCR 预训练后直接插入。

## 六、论文的主要结论与发现

1. **DiCoR 在所有三个 RRSIS 基准上均取得最佳精度**，验证了解耦式优化机制在高效 JFS 管线中的有效性。
2. **指代消歧有效**：以候选竞争范式 + SAM3 挖掘的难负样本监督，能显著提升复杂场景下的目标定位可靠性（如 RISBench 上的 Pr@0.5 最优）。
3. **轮廓校准有效**：残差式轻量校准配合区域感知监督，大幅提升高阈值指标（如 RefSegRS 上 Pr@0.9 比 MCD-Net 提升 21.25%），尤其对遥感小目标边界恢复贡献显著。
4. **精度-效率平衡优越**：DiCoR 在保持 JFS 推理速度（25.54 FPS，接近 LAVT）的同时达到接近 DPS 方法的精度，AEI 指数在所有对比方法中最高（62.19）。
5. **解耦训练策略有效**：多 checkpoint 采样 + 定位质量过滤 + 形态学扰动提升了 LCR 的鲁棒性；DLG 的联合微调保证了与下游分割模型的兼容性。

## 七、优点

1. **问题定位精准**：明确指出现有 JFS 范式的两个核心痛点（指代歧义与轮廓不精细），并针对性地设计解耦模块，动机清晰。
2. **轻量解耦设计**：以轻量模块在推理阶段替代重型基础模型，保留了 JFS 的效率优势，兼顾 DPS 的解耦思路，实用性强。
3. **候选竞争新视角**：将指代定位转化为候选排序问题，引入候选自适应语言提示和几何一致性，方法上有新意。
4. **难负样本挖掘策略**：利用 SAM3 离线挖掘与目标相似的干扰物作为困难负样本，为消歧提供明确的结构化监督。
5. **残差轮廓校准思路**：以“粗预测 + 残差修正”方式避免重复分割，配合区域感知加权损失，计算开销小且针对性强。
6. **实验体系完整**：多数据集、多指标（尤其高阈值 Pr 指标）、效率综合评估（AEI）、多维消融互为支撑，说服力较强。
7. **代码开源**：便于复现与后续研究。

## 八、不足与局限

1. **对初始响应图质量依赖较强**：若 DLG 的响应估计器未在真实目标附近产生激活，后续候选生成与排序难以恢复正确目标，空间先验注入存在性能上限。
2. **LCR 对大目标的改进有限**：大目标轮廓误差通常涉及长距离轮廓和全局结构不一致，仅靠局部残差校准难以充分修正；实验也表明 LCR 优势主要体现在小目标上。
3. **消融实验范围有限**：主要消融在 RISBench 上完成，未在 RefSegRS 和 RRSIS-D 上重复验证；部分近两年方法的指标报告不完整（如 SegEarth-R2 缺多项 Pr 指标）。
4. **算力细节不透明**：未报告 GPU 数量、总训练时间和能耗等具体信息，实际部署成本难以准确评估。
5. **SAM3 产生额外依赖**：离线难负样本挖掘依赖 SAM3，其引入整体流程中的额外数据和流程成本未充分讨论。
6. **应用边界**：对表达本身过于模糊或早期定位阶段就失败的情况，方法可能失效；大范围场景下多尺度目标同时出现时的鲁棒性尚需更多验证。
