## 摘要
开放词汇目标检测测试时适应（OVOD-TTA）旨在解决预训练基础模型在遇到图像域偏移时出现的性能下降问题。现有的无源OVOD-TTA方法要么依赖精细的测试时信息进行重新评分，要么依赖伪标签进行自训练，这导致初始预测不佳时精度显著下降。同时，大多数传统的源域估计方法恢复适用于分类任务的抽象、稀疏表示，但无法捕获检测所需的密集、具体特征。为了解决这些问题，我们提出了PISA，一种新颖的无源OVOD-TTA方法，可以无缝集成到开放词汇视觉骨干网络中。我们方法的核心组件是损坏不变特征提取器（CIFE）、特征对齐模块（FAM）和多尺度对齐框架（BAA）。为了捕获适合检测的特征，我们开发了CIFE，利用CLIP视觉特征在损坏图像上的不变性，确保对各种损坏的鲁棒性。我们进一步开发了FAM和BAA用于预训练和自适应，将损坏不变特征转换为接近原始源域特征的伪个体源域特征。这样，密集而具体的伪个体源域特征被用于监督，而不是不可靠的伪标签信号。在损坏的VOC-C、COCO-C和LVIS-C基准上，使用三种基础模型的实验表明，PISA显著提高了原始模型的定位精度和类别识别准确率。值得注意的是，PISA在无需访问源域数据的情况下实现了最先进的性能，在COCO-C上的AP@50%上超过现有方法3.92%。

## Abstract
Open-vocabulary object detection test-time adaptation (OVOD-TTA) aims to address the performance degradation that pre-trained base models suffer when encountering image-domain shifts. Existing source-free OVOD-TTA methods rely either on refined test-time information for re-scoring or on pseudo-labels for self-training, leading to significant accuracy degradation when initial predictions are poor. Meanwhile, most conventional source-domain estimation methods recover abstract, sparse representations suitable for the classification task, but fail to capture the dense, concrete features required for detection. To address these issues, we propose PISA, a novel source-free OVOD-TTA method that can be seamlessly integrated into open-vocabulary visual backbones. The core components of our method are the Corruption-Invariant Feature Extractor (CIFE), the Feature Alignment Module (FAM), and a multi-scale alignment framework (BAA). To capture detection-suitable features, we develop CIFE to exploit the invariance of CLIP's visual features across corrupted images, ensuring robustness against various corruptions. We further develop FAM and BAA for the pre-training and adaptation to transform the corruption-invariant features into pseudo-individual source-domain features that are close to the original source-domain features. In this way, dense and concrete pseudo-individual source-domain features are used for supervision instead of unreliable pseudo-label signals. Experiments on the corrupted VOC-C, COCO-C, and LVIS-C benchmarks across three base models demonstrate that PISA substantially improves both the localization precision and the category recognition accuracy of the original models. Notably, PISA achieves state-of-the-art performance without requiring access to source-domain data, surpassing existing methods by 3.92% in AP@50% on COCO-C.

### 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：开放词汇目标检测（OVOD）通过大规模图像-文本预训练将文本与图像特征在共享嵌入空间中对齐，能够检测固定类别之外的目标。然而，OVOD 模型在面对真实场景中的各类图像损坏（如噪声、模糊、天气变化、数字失真等）时，性能严重下降。
- **核心问题**：如何在不访问源域数据的情况下（即 source-free），在测试阶段有效适配 OVOD 模型以适应目标域的域偏移？现有方法存在两大关键缺陷：
  - **低质量伪标签问题**：基于伪标签自训练或基于缓存信息重新评分的方法，在初始预测质量差时，误差会在迭代过程中逐步累积放大，导致模型性能显著退化。
  - **源域特征估计不匹配问题**：传统源域分布估计方法主要面向图像级分类任务，恢复出的是抽象、稀疏的全局表征，难以满足目标检测所需的密集、具体的像素级/区域级特征要求。
- **论文意义**：PISA 提出了一种全新的“伪个体源域特征”范式，无需源域数据、不依赖伪标签，通过特征级监督来引导模型在测试时的稳定优化，弥合了源-目标域间的分布差距，为 OVOD-TTA 提供了通用且有效的解决方案。

### 2. 论文提出的方法论

**核心思想**：利用 CLIP 视觉骨干对图像损坏具有天然不变性的特性，提取“抗损坏特征”，再通过精心设计的特征对齐与多尺度适配模块，将这些特征转换为接近原始源域特征的“伪个体源域特征”，以此作为测试时监督信号来优化 OVOD 模型的视觉骨干网络。

**关键技术组件**：

- **CIFE（抗损坏特征提取器，Corruption-Invariant Feature Extractor）** ：
  - 由 CLIP RN50 视觉骨干的 Stem 结构（第一个卷积层和批归一化层）构成。
  - 依据：CLIP 在训练过程中天然具备对损坏的鲁棒性；浅层特征既保留了像素级原始信息，又对噪声具有不变性（通过可视化分析 RiN50 和 ViT-B/16 在含噪输入下的特征响应验证）。
  - 输入图像不做归一化处理，以避免放大损坏的影响。
  - CIFE 输出的特征在不同损坏类型之间差异极小，能桥接域差距。
- **FAM（特征对齐模块，Feature Alignment Module）** ：
  - 由**主分支**和**目标分支**构成，将 CIFE 提取的特征与骨干网络的 Patch Embedding 输出对齐。
  - **主分支**：先经深度可分离卷积（捕获空间局部性并降参）→ LayerNorm + GELU；再通过 Squeeze-and-Excitation（SE）注意力重新校准通道响应，抑制域相关噪声通道、增强可迁移通道；残差捷径融合保证预训练阶段梯度稳定。
  - **目标分支**：对目标域特征使用 Mona（多尺度视觉适配器），并在其中应用**谱归一化**（Spectral Normalization）对每个卷积层进行重参数化处理，增强对输入扰动的鲁棒性。
- **BAA（多尺度骨干对齐适配器，Backbone Alignment Adapter）** ：
  - **BAA_t**：插入在骨干网络每个层的最后一个 Block 中，由 Mona 适配器和维度调整模块组成，用于预训练阶段将 CIFE 特征变换到伪个体源域特征空间。
  - **BAA_a**：插入到骨干的每个 Block 中，是测试阶段唯一保持可训练的部分，其余组件全部冻结，以保证模型更新的稳定性。

**训练与测试流程（文字描述）**：

- **预训练阶段**（使用干净图像 x_s 和增强图像 x_t 的配对数据）：
  - **第一阶段**：训练 FAM（不经过 BAA_t），损失函数 L¹_FAM 包含三项：目标特征与源特征之差的绝对值、增强后的源特征与源特征之差的绝对值，以及二者之间的差异（α 为超参数，设为 10）。
  - **第二阶段**：冻结已训练的 FAM，仅训练 BAA_t，损失函数 L²_BAA 仅度量目标特征和源特征的差异。
- **测试（适配）阶段**：
  - 输入测试样本 x_tta，分别经过两条路径获得伪个体源域特征 {f_p} 和测试特征 {f_tta}。
  - 通过余弦相似度损失（L_TTA）更新 BAA_a 模块。

  - 为防止灾难性遗忘，每隔 T 个测试样本将模型重置为初始状态。

### 6. 论文的主要结论与发现

- **有效性**：PISA 在三个数据集上均显著提升了基础模型的检测性能。在 VOC-C 上 base 损坏类型 mAP 平均提升 12.42%，COCO-C 上提升 7.65%，LVIS-C 上提升 3.09%；对所有损坏类型的平均 mAP 提升分别为 4.64%、2.78% 和 1.11%。

### 7. 优点

- **方法层面**：
  - 从“伪标签监督”转向“特征级监督”，从根源上规避了测试时低质量伪标签误差累积的问题，提供了 OVOD-TTA 的新范式。
